# 20260914_第23版_后端稳定性36组实验分析

## 0. 核心结论

本轮不是“全面成功”或“全面失败”，而是得到了可用于收敛设计的条件性结论：

1. **原动态后端D值得保留。** 在BikeNYC random0.4和TaxiBJ random0.4，D相对等权U的验证MAE、测试MAE和RMSE均为3/3种子改善。对“在这些条件下动态尺度融合有益”的证据比上一轮更强。
2. **固定半动态H不建议作为主力。** 三个条件的平均测试MAE都不如D；中等缺失率的验证MAE均为0/3胜D。高缺失下个别种子提升不能抵消另一种子的明显退化。
3. **可学习动态强度L是有价值的候选，而不是全条件赢家。** TaxiBJ random0.8中，L相对D在三个种子的验证MAE、测试MAE、RMSE上全部改善，同时样本标准差下降；中等缺失率则没有稳定超过D。
4. **需要修正先前“高缺失率等权更稳”的说法。** 增加seed3407后，U在TaxiBJ random0.8明显变差，三种子的平均误差与离散度反而高于D。之前两种子的结果不足以形成普遍结论。
5. **不能把L的收益解释为“缺失越多，模型越保守”。** L的平均alpha在BikeNYC0.4、TaxiBJ0.4、TaxiBJ0.8分别约0.585、0.806、0.844；TaxiBJ高缺失时没有整体降低，三个种子也并非都下降。
6. **本轮未验证前端不可替代。** 四组前端设计均相同且联合重训；没有移除前端路由、单聚合器或真正平均聚合控制，因此不能据此宣布两个MoE的独立作用都已证明。

建议：**D作为成熟对照，L作为下一步需要确认的改进候选；暂时停止H这一固定强约束路线，也不要继续增加专家数或复杂可靠性网络。**

## 2. 当前代码中的模型与数据流

本节重新检查当前实现，不仅依据历史文档。关键源码为[dual_moe.py](../src/stmoe_imputer/models/dual_moe.py)、[losses.py](../src/stmoe_imputer/losses.py)、[engine.py](../src/stmoe_imputer/engine.py)、[train.py](../scripts/train.py)。

### 2.1 输入与可见数据归一化

BikeNYC窗口为[B,2,12,24,12]，TaxiBJ为[B,2,12,32,32]；观测掩码为[B,1,T,H,W]，1为观测、0为缺失，两个流量通道共享掩码。

模型先通过where剔除缺失输入；仅使用当前窗口观测位置，逐样本逐通道计算均值和标准差，标准差下限为1。归一化后的观测值与掩码经1×1×1卷积和GELU进入32维特征。细粒度时空块产生fine特征及fine预测。目标真值只在损失和离线诊断中使用，不进入推理输入或路由。

### 2.2 前端：观测组织与目标读出

中、粗两个分支各有8个可学习聚合专家，目标粗节点数分别32、8，key_dim=8，assignment_temperature=0.5。每个专家通过细特征、可见上下文、坐标和掩码计算软成员映射A，不是固定几何区域。

本轮target_readout设计让各聚合专家先接收可见观测，而不是先硬删掉来源。内部源门控为等权；使用A与观测mask作归一化加权聚合，得到粗节点表示、质量/有效支持/异质性统计。支持统计是数值描述，不是已校准的预测置信度。

粗节点通过共享的节点注意力、时间卷积和前馈模块后，使用**该专家自己的A映射**还原到统一细坐标，再进行前端目标条件Top4-of8读出。不同组织的粗节点编号不会直接混合。这里“前端路由”发生在目标读出阶段，并非路由权重直接决定所有来源分配。

### 2.3 中粗尺度补全与后端

中、粗分支将读出表示与fine特征拼接，再通过条件融合和预测头形成各自预测。因此三条路径不是完全独立的模型，**中粗路径也在使用细粒度信息**。最终fine权重低不代表细特征没用，也不能据此删除细粒度主干。

后端读取三条隐藏特征、mask及中粗支持描述，计算3个尺度权重。D采用Top3-of3，即完整密集Softmax；不是只激活少数后端专家。

四组唯一核心区别：

| 组 | 融合权重w | 解释 |
|---|---|---|
| U | w=(1/3,1/3,1/3) | 等权，不学习后端选择 |
| D | w=p(x)，p为目标条件Softmax | 原始完全动态后端 |
| H | w=1/6+0.5p(x) | 固定半动态，单尺度权重限制在[1/6,2/3] |
| L | w=(1-alpha)/3+alpha p(x) | alpha为全局可训练sigmoid标量，初值0.5 |

L的alpha是**每个run的一项全局参数**，不是样本级、位置级或显式依赖缺失率的置信度。每个数据条件各自训练，所以不同条件学到不同alpha不等于单个模型会识别条件并自适应切换。

H/L与D保留相同路由头和共享参数初始化，但其融合强度从训练初期就不同，因此会影响整个联合优化轨迹。本轮无法把收益完全归因于“最终权重公式”而排除训练路径效应。

最终预测在归一化空间融合，再恢复原始范围。原始单位MAE/RMSE只在缺失通道元素上计算，按全split累积误差分子/分母，非batch均值直接平均。

### 2.4 损失与诊断

本轮损失为：

`L = L_main + 0.01 L_expert + 0.001 L_partition + 0.001 L_front_balance`

主任务和三个尺度辅助重建均为按观测标准差归一化的缺失位置SmoothL1；辅助项为三尺度平均。后端均衡权重为0，避免对职责不同的密集尺度路径强制等权。分区项可能为负，因此总loss不能直接当作原始MAE。

新增诊断全部detach，不提供待补全真值给路由：分局部观测密度误差、尺度专家胜率/误差相关、最大权重集中比例、alpha、裁剪前模块梯度范数。详细口径见第6节。

## 4. 按条件解释结果

### 4.1 BikeNYC random0.4：保持原动态后端更合适

D/U的三个指标均3/3改善；配对平均TEST MAE改善1.869%，RMSE改善0.615%。这是本轮很清楚的正面证据：在该条件与预算下，自适应尺度融合优于等权。

H虽然MAE优于U，但与D比较，VAL与TEST MAE三个seed全部变差，平均TEST MAE退化1.032%。把alpha固定0.5限制得过强，至少没有保住D的全部收益。

L基本保住MAE：平均3.014537，对比D的3.011863仅差约0.00267；但不能忽略RMSE：L为8.177517，D为8.138801，而且L/D的RMSE只有1/3改善，样本标准差0.09127也高于D的0.02221。因此L在该条件不是“性能完全相同而更稳”。

结论：D为该条件的首选现有参照；L可以作为跨条件统一候选继续确认，不能宣称已改进BikeNYC。

### 4.2 TaxiBJ random0.4：D的平均精度最好，L存在精度与波动权衡

D/U的VAL MAE、TEST MAE、RMSE全部3/3改善，配对TEST MAE平均改善1.881%，RMSE改善1.245%。前次“两seed动态收益偏弱”的认识被第三seed进一步补强，但这里没有静态SB，不能据此补写三seed动态优于静态的结论。

L对D在seed42、2026的MAE较好，seed3407则较差：12.860380对12.607621，退化2.005%。所以“2/3种子赢”仍不能忽略平均MAE退化0.432%的事实。

另一方面，L的TEST MAE样本标准差为0.08595，D为0.21640。这是本轮离散度较低的现象，但部分来自没有达到D在seed3407上的特别好结果；“波动更小”不自动等于更好的风险收益权衡。

H的平均RMSE为20.098429，略好于D的20.126692，但MAE较差；不能只选择RMSE讲成功，也不能只看MAE掩盖指标差异。

结论：继续保留D；L是更集中但略牺牲平均精度的候选，不是全面替代。

| 2026 | -0.899% | -0.963% | -1.379% |

验证和测试方向一致，且没有MAE改善而RMSE整体退化。配对均值分别为-1.292%、-1.156%、-1.357%。TEST MAE样本标准差由D的0.48276降至L的0.34896，约下降27.7%。

这是对“L相对原动态后端在这个高缺失条件更有效、更稳定”的描述性支持。只有3seed，尚不能扩展成普遍稳定性或统计显著性结论。

L仍不总胜U：seed42的MAE为20.614727，对比U的20.287930仍差1.611%，RMSE仍差2.826%。但seed2026/3407获益更大，因此平均优于U。

H表现不可靠：seed3407的19.793432是这一条件单次最低TEST MAE，但seed2026达到21.259100，对D退化5.159%。不能因为单次最好而把H作为主力；它的三seed均值和离散度都没有解决问题。

## 5. 必须修正的前次结论

上一轮只有seed42/2026时，TaxiBJ0.8的U平均MAE20.26740、D20.61091，U标准差约0.029、D约0.558，容易形成“等权稳定、动态不稳”的判断。

加入seed3407后：

- U seed3407 MAE21.492940，显著高于它的前两个seed。
- D seed3407 MAE20.129484，反而是D本轮该条件最好的seed。
- 三seed均值改为U20.675914、D20.450436，排序反转。
- 三seedMAE样本标准差改为U0.707863、D0.482757，稳定性排序也反转。

因此应将旧判断改成：“两个seed曾显示等权优势，但扩展后不成立；优化随机性同时影响等权与动态，不能把它专门归咎于动态路由。”

本轮U/D对应旧Q10/Q11的12个匹配run，在VAL MAE、TEST MAE、RMSE上与历史记录逐值完全相同，尽管这些是重新训练。说明排序改变来自新增seed和新候选，而不是旧指标口径变化。相同seed的重复运行不能作为新的独立种子证据。

## 6. 机制诊断：哪些假设得到支持，哪些没有

### 6.1 学到的alpha不是“越缺越保守”

表中alpha取验证最优权重对应的测试记录：

| 条件 | seed42 | seed2026 | seed3407 | 均值 |
|---|---:|---:|---:|---:|
| BikeNYC0.4 L | 0.56887 | 0.58492 | 0.60170 | 0.58516 |
| TaxiBJ0.4 L | 0.75298 | 0.79618 | 0.86876 | 0.80597 |
| TaxiBJ0.8 L | 0.76498 | 0.82007 | 0.94721 | 0.84409 |

所有run均从0.5向更动态的方向学习。TaxiBJ相同seed从0.4到0.8，alpha均增加；但两套模型独立训练，不能把这解释为一个模型内部识别缺失率的响应。

L在TaxiBJ0.8的优势更适合描述为“可学习的融合强度参数化，在本轮联合训练中改善了结果”，而不是“学到了可靠性”“自动回退到平均”或“证据少就保守”。

训练过程中alpha同时变化，因而存在两种尚未区分的可能：最终权重约束起作用；从较均匀状态起步的优化轨迹起作用。本轮没有冻结同一专家权重的后验干预，因此不能进一步作因果断言。

### 6.2 消除极端权重并不自动改善性能

三个seed平均的“缺失位置最大实际尺度权重>0.9”的比例：

| 条件 | D | H | L |
|---|---:|---:|---:|
| BikeNYC0.4 | 26.00% | 0 | 0 |
| TaxiBJ0.4 | 26.32% | 0 | 约0 |
| TaxiBJ0.8 | 36.80% | 0 | 5.43% |

H恒为0是数学约束，不是学出来的效果。尽管完全消除了>0.9的权重，H仍在多个条件变差，因此“权重越均匀越好”被本轮结果否定。

D BikeNYC seed2026的集中比例仅1.77%，seed42/3407却分别约36.29%/39.94%，但三者均优于U。仅靠集中比例不能诊断塌缩。

L TaxiBJ0.8的seed3407仍有约16.29%的高集中位置，却优于D；性能与“零集中”没有一一对应关系。

### 6.3 局部观测密度分组：L主要改善了高缺失条件的大多数位置

密度由同一时刻3×3空间mask比例计算，包含缺失中心，边缘不把网格外算作缺失。low=[0,1/3)，medium=[1/3,2/3)，high=[2/3,1]。统计仅覆盖缺失通道元素，不是样本数。

| 条件 | 组 | low MAE | medium MAE | high MAE |
|---|---|---:|---:|---:|
| BikeNYC0.4 | U | 1.7912 | 3.1871 | 3.3163 |
| | D | 1.7643 | 3.1356 | 3.2324 |
| | H | 1.7923 | 3.1805 | 3.2323 |
| | L | 1.7777 | 3.1444 | 3.2164 |
| TaxiBJ0.4 | U | 13.5464 | 13.6129 | 11.8406 |
| | D | 13.3925 | 13.3367 | 11.6353 |
| | H | 13.2955 | 13.4147 | 11.7125 |
| | L | 13.3340 | 13.4031 | 11.6917 |
| TaxiBJ0.8 | U | 20.8706 | 19.8362 | 17.8402 |
| | D | 20.6352 | 19.6542 | 17.6802 |
| | H | 20.8233 | 19.8190 | 17.8208 |
| | L | 20.3847 | 19.4669 | 17.7586 |

TaxiBJ0.8的三个bin分别为11,391,384、2,587,848、15,840个缺失通道元素，占比约81.4%、18.5%、0.11%。L相对D在low和medium三个seed均改善；high平均略差且样本占比很小，不应抹掉也不应夸大。

这支持“L在高缺失条件的大部分位置有效”，但尚不能证明L专门识别低可靠性位置：alpha是全局的，且不同密度组包含不同地理位置和目标值分布。BikeNYC low组绝对MAE反而较小，就说明绝对误差受目标量级/位置构成影响，不能直接用bin MAE跨组给“困难程度”排序。更合适的证据是同bin、同seed、同掩码的组间差异。

### 6.4 专家并非简单的三个独立预测器

三个seed的平均尺度独立MAE与融合MAE：

| 条件/组 | fine | mid | coarse | 最佳单专家oracle MAE | 最终MAE |
|---|---:|---:|---:|---:|---:|
| BikeNYC0.4 D | 10.2930 | 5.4644 | 4.6691 | 2.1776 | 3.0119 |
| BikeNYC0.4 L | 8.4945 | 5.3244 | 4.9086 | 2.4397 | 3.0145 |
| TaxiBJ0.4 D | 37.0416 | 24.0163 | 24.0150 | 10.5366 | 12.8499 |
| TaxiBJ0.4 L | 36.7732 | 25.0153 | 23.8514 | 10.9470 | 12.9035 |
| TaxiBJ0.8 U | 54.3667 | 71.6490 | 68.4871 | 30.4067 | 20.6759 |
| TaxiBJ0.8 D | 56.5950 | 51.9384 | 62.0045 | 20.7488 | 20.4504 |
| TaxiBJ0.8 L | 56.0845 | 49.6926 | 58.0661 | 19.7835 | 20.2120 |

独立头误差远大于融合误差，是重要的结构诊断。尤其U TaxiBJ0.8的融合MAE20.6759低于逐元素最佳单专家oracle的30.4067，说明“先选一个最好专家”并不能充分描述当前融合功能，联合输出中存在可抵消的误差。

oracle利用真值逐缺失通道元素选择最小绝对误差，只是事后参考；它既不可部署，也不是凸融合误差的下界。不能把最终MAE与oracle差距全部称为“路由损失空间”，更不能据此断言增加选择能力就会提升相同数值。

中粗绝对误差相关系数均值在TaxiBJ0.8为U0.6023、D0.2518、H0.5009、L0.2256。动态/可学习融合下误差模式更不同，但这些是**不同组联合训练后的专家**，不是固定专家仅换路由的结果。绝对误差相关也不是有符号残差协方差；它不足以单独证明误差抵消的方向。

可提炼的研究问题是“组织表示与多尺度重建如何共同适应”，而非简单“后端挑最准确的尺度”。当前诊断只覆盖三条尺度预测头，未独立衡量前端八个聚合专家的补全预测，因此不能把后端互补性当成前端八专家多样性的证明。

### 6.5 fine权重低，不代表细粒度模块无效

D在BikeNYC三个seed的fine平均权重约5.2%–5.6%；TaxiBJ0.4约0.75%–3.59%。但是mid/coarse分支都拼接了fine特征，前端组织也由fine驱动。因此最多能说“直接fine预测头在最终加权中占比低”，不能说“细粒度信息没用”或“删除fine会不影响效果”。

不同seed还会改变中粗主导关系：BikeNYC D seed42/3407主要使用coarse，seed2026主要使用mid，但都能改善U。不能跨独立训练seed将路由分配当作唯一且稳定的物理解释。

### 6.6 梯度：没有整体断梯度证据，但不能据此排除训练竞争

最后10epoch的batch裁剪前L2范数，先逐run平均再跨seed平均：

| BikeNYC0.4 | D | 0.00625 | 0.01056 | 0.00805 | 0.01309 |
| | L | 0.00494 | 0.01033 | 0.00823 | 0.00594 |
| TaxiBJ0.4 | D | 0.00059 | 0.01130 | 0.00846 | 0.00506 |

| TaxiBJ0.8 | D | 0.00120 | 0.06279 | 0.05178 | 0.03261 |
| | L | 0.00139 | 0.06337 | 0.04660 | 0.02254 |

fine特征主干范数在D/L TaxiBJ0.4约0.01996/0.02002，明显不是全无梯度；其作用不能用fine预测头的较小范数代替。

上述范数包含主任务、辅助及正则项，模块参数量也不同；不是独立主任务梯度贡献，不能直接比较绝对值判断模块重要性。没有记录跨损失梯度夹角，因此无法确认或排除梯度冲突。L后端梯度较小也部分受alpha缩放影响，不能据此宣布优化更稳定的原因已经找到。

## 8. 对idea的支持程度与下一步决策

### 8.1 可以写进阶段总结的结论

- 在两个数据集40%随机缺失条件下，目标条件尺度融合相对等权融合产生跨三个种子、验证和测试方向一致的收益。
- 固定50%等权基底不能普遍改善动态融合，降低权重极端程度本身不是充分条件。
- 一个全局可学习融合强度在TaxiBJ80%随机缺失下，相对原动态融合实现3/3种子的VAL MAE、TEST MAE、RMSE改善；值得作为简洁候选保留。
- 两seed可能误判均值和稳定性排序；本轮新增seed对结论产生实质影响。
- 融合与尺度专家会共同适应，独立头误差和oracle诊断表明当前功能不只是选择单个最佳尺度。

### 8.2 仍然不能宣称的内容

- 不能说L全面优于D，不能说每个seed都优于U。
- 不能说L学到了缺失可靠性或在高缺失时主动变得更保守。
- 不能说三个尺度每个都不可替代，或前端八个组织专家各自必要。
- 不能把本轮称作完整双MoE的2×2消融，也不能证明前端优于普通平均池化。
- 不能声称跨CHAP、fixed、全部缺失率、全部mask实现稳健改善。
- 不能仅凭三seed的均值/标准差声称统计显著、保证创新认可或发表。

### 8.3 建议停止与继续的方向

**停止：** 不继续以H作为主力，不为了确保均衡而增加后端均衡损失，不扩大专家数，不再只跑seed42决定路线。

**保留：** D作为精度参照，L作为高缺失稳定性候选。若需要一个下一步修改入口，可以选择L，但要明确这是基于条件性结果的候选选择，而非“已经全条件最优”。

**优先下一步：**

1. 先冻结D/L实现、整理本轮证据，不再修改同一批结果对应的科学源码。保存可复原的代码与配置快照。
2. 若研究主张是“L改善高缺失融合”，优先预先指定新的确认条件，例如TaxiBJ random0.6和BikeNYC random0.8，保留U/D/L、同预算、多个seed。新mask实现或独立确认划分能帮助检验是否只适用于当前mask，不能运行后再挑有利子集。
3. 若研究主张仍是“双MoE都必要”，下一轮更关键的是匹配预算的前端开/关×后端开/关完整2×2。后端候选应预先确定；前端等权读出仍保留可学习聚合器，不等同于普通平均聚合。需另外明确真正平均聚合、单可学习聚合器的容量/节点预算差异。
4. 若要解释L为什么有效，再做固定相同专家参数的后验融合干预及有符号残差分析，而不是直接加入新的可靠性网络。当前没有保存权重，因此不能从现有日志完成这种同参数干预；需下一轮另行决定是否保存每组一个最佳checkpoint或在内存最佳模型测试阶段安排预声明诊断。
5. 本轮已经多次查看TEST，后续不要把相同TEST用于反复调alpha、阈值、辅助损失后仍声称无偏终评。主要决策依据VAL，保留独立确认设置或清楚披露探索性选择过程。

我的优先判断是：**已有足够理由保留“目标条件尺度使用”这条主线；L让高缺失条件出现了更有质量的正面证据，但当前最缺的仍是前端组织与后端使用两个决策的独立作用证据，而不是再加一层路由。**
