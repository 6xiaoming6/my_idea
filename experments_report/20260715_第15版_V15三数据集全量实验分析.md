# 20260715_第15版_V15三数据集全量实验分析

## 1. 实验目的与结论摘要

本报告分析 `v15-single` 分支的 CBRP-MoE（Compact Base-Anchored Residual Pyramid Mixture-of-Experts，紧凑型基线锚定残差金字塔混合专家模型）完整实验结果。分析对象为 TaxiBJ、BikeNYC 和 CHAP_Beijing，在 fixed/random 两种缺失模式和 0.2、0.4、0.6、0.8 四种缺失率下的全部 24 个 Full Model 实验。

本次实验的目的，是检验 V15 对 V14 中“低 gate 与高幅残差相互补偿”问题的结构性修复是否能够转化为更稳定、更准确的测试结果。V15 不再生成一条完整值粗到细候选路径，而是在 main 多尺度 MoE 基础预测后增加受显式幅度约束的特征残差金字塔。

核心结论如下。

1. **24/24 组正式实验均已完整跑完。**全部组合都完成规定 epoch、定期验证、最佳 `best.pt` 覆盖保存、最佳权重重新加载和最终测试；最新正式结果中未发现 NaN、Inf、缺失测试记录或缺失 checkpoint。
2. **V15 的结构约束按设计生效，但整体精度没有超过 V14。**相同 24 点中，V15 仅在 6 个点取得更低 MAE，在 18 个点退化；因此当前 V15 不适合直接替代 V14 作为论文主模型。
3. **TaxiBJ 的收益高度依赖缺失设置。**V15 在 fixed@0.2、fixed@0.8、random@0.6、random@0.8 优于 V14，但 random@0.2 和 random@0.4 分别退化 28.56% 和 36.55%，导致 TaxiBJ random 四点平均 MAE 退化 12.03%。
4. **BikeNYC 全部 8 点 MAE 都不如 V14。**fixed 和 random 四点平均 MAE 分别退化 3.41% 和 5.11%。V15 相对本次训练内部 `x_base` 的修正幅度很小，fixed 下平均还造成轻微负收益。
5. **CHAP 相对稳定，但仍未形成整体优势。**只有 fixed@0.4 和 fixed@0.8 优于 V14；fixed/random 四点平均 MAE 分别退化 2.36% 和 5.26%。
6. **当前动态 residual budget 在 TaxiBJ 和 BikeNYC 上出现接近上限的饱和。**两者测试阶段平均 `beta` 约为 0.49，而配置上限为 0.5；这说明预算控制器没有形成足够的难度区分。CHAP 的 beta 为 0.057～0.176，表现出更合理的自适应范围。
7. **`L_v15_safe` 只是软惩罚，不构成逐样本安全保证。**BikeNYC fixed 的平均样本退化率约为 67.97%，TaxiBJ fixed 为 27.96%；虽然部分退化幅度很小，但与“非退化修正”的设计目标仍有明显距离。
8. **MAPE 不适合作为 TaxiBJ/BikeNYC 的论文主指标。**这两个数据集包含大量 0 或近 0 目标，当前 `eps=1e-6` 的实现会把 MAPE 放大到数万量级。本报告和论文对比应以原始范围 MAE、RMSE 为主。

综合判断：V15 成功消除了 V14 的无界残差尺度漏洞，工程实现也完整可靠，但当前 `beta_max=0.5`、动态预算学习和联合训练策略没有把结构优势稳定转化为精度优势。现阶段应继续把 **V14 作为主力版本**，把 V15 作为有价值但尚未调稳的候选方向。

统一数据布局为 `[B,C,T,H,W]`，mask 为 `[B,1,T,H,W]`：


所有训练损失和 MAE/RMSE 主指标都只在 `1-m_f` 对应的隐藏位置计算。每个数据集完整覆盖：

```text

missing rate    = 0.2 / 0.4 / 0.6 / 0.8
seed            = 42
```

fixed mask 在同一 split 内复用同一个缺失布局，random mask 则为每个样本提供独立离线掩码。各缺失率的 mask 并非严格嵌套，因此缺失率升高不必然造成 MAE 单调增大；不同 mask 隐藏区域本身的流量尺度和预测难度也会影响结果。

## 3. 最新 V15 模型结构

### 3.1 总体流程

V15 顶层类为 `V15CompactResidualMoE`。它只调用一次稳定的 `MultiScaleMoEBackbone`，复用主干产生的多尺度专家特征，然后预测一条受约束的修正残差：

```text
Fine / Mid / Coarse observed inputs
                ↓
MultiScaleMoEBackbone
  ├── x_base
  ├── z_f / z_m / z_c
  ├── h_main
  └── scale_gate
                ↓
CompactResidualPyramid
  z_c -> coarse adapter -> upsample
  z_m + coarse          -> mid fusion -> upsample
  z_f + h_main + mid    -> fine fusion
                ↓
delta_raw

mask difficulty + reliability + detached scale_gate
                ↓
ResidualBudgetController -> beta

x_final = x_base + beta * scale_ref * tanh(delta_raw)
```

V15 没有叠加 V14 的完整值 C2F 候选、三层 alpha、Geometry Descriptor 或 ObservedConsistencyEvaluator。它复用与 V14 相同的 main Backbone，但 V15 本身是一个独立包装器，并不是在 V14 输出后继续堆叠网络。

### 3.2 无目标泄漏的多尺度数据构造

Fine 输入由真实值与 mask 相乘得到。Mid 和 Coarse 通过 masked average pooling 逐级构造：

```text
Fine -> Mid    spatial kernel = 2
Fine -> Coarse spatial ratio  = 4
```

池化分子只累计已观测位置，分母为池化窗口内观测数量，同时生成：

- 下采样观测值 `x_m_obs/x_c_obs`；
- 二值有效 mask `m_m/m_c`；
- 观测比例可靠性 `r_m/r_c`。

隐藏位置 ground truth 不会进入 Forward 的多尺度输入构造。测试日志与已有单元测试也验证了 V15 Forward 不读取隐藏目标。

### 3.3 Stable Multi-Scale MoE Backbone

主干隐藏维度为 64，包含 4 个共享 ST Expert，每个尺度执行样本级 Top-2 路由：

1. `ScaleTokenEncoder` 将 value、mask、scale embedding、time embedding 和 spatial embedding 相加编码；
2. `compute_observation_stats` 从 mask 计算缺失率、观测率、时间缺失评分、空间块缺失评分和聚合可靠性；
3. `QualityRouter` 拼接全局特征、5 维观测统计和尺度向量，输出 4 个专家的 softmax 权重；
4. `TopKRoutedExpertPool` 选择 Top-2 专家并归一化权重，三个尺度共享同一套专家参数；
5. `ProgressiveRouteFusion` 执行 routed branch 的 coarse→mid→fine 或 mid→fine 融合；
6. `GatedCrossScaleSharedExpert` 依据尺度特征、观测统计和可靠性生成 fine/mid/coarse 权重，形成 shared branch；
7. `SharedRoutedResidualFusion` 以 shared 特征为主路径，叠加带 sigmoid 标量的 routed residual；
8. Prediction Head 输出基础预测 `x_base`。

TaxiBJ 沿用 `fine_mid`，coarse 尺度不参与最终 active scale；BikeNYC 和 CHAP 使用 `fine_mid_coarse`。V15 没有为了新增残差路径修改这些已经确定的数据集尺度设置。

### 3.4 Compact Residual Pyramid

残差金字塔不重新预测一套完整值，只聚合主干已经产生的特征：

```text
p_c = CoarseAdapter(z_c)
p_m = MidFusion(concat(z_m, up(p_c)))
p_f = FineFusion(concat(z_f, h_main, up(p_m)))
delta_raw = ResidualHead(p_f)
```

每个 Adapter 由 `1×1×1 Conv3D + GroupNorm + GELU + ResidualSTBlock` 组成。Residual Head 为：

```text
Conv3D(64,32,3,padding=1)
-> GroupNorm
-> GELU
-> Dropout3D(0.1)
-> Conv3D(32,C,1)
```

最后一层权重和偏置零初始化，因此模型初始化时严格满足 `delta_raw=0` 和 `x_final=x_base`。这避免了随机初始化的残差分支在训练开始时破坏 main 输出。

### 3.5 Residual Budget Controller

控制器输入固定为 8 维，仅依赖可观测信息：

```text
fine difficulty: missing_rate, temporal_missing_score, spatial_missing_score  3维
mid/coarse reliability mean                                                2维
main scale_gate                                                            3维
合计                                                                        8维
```

`scale_gate` 默认 detach，残差预算损失不会反向操纵 main 的尺度门控。控制器结构为：

```text
Linear(8,32) -> LayerNorm -> GELU -> Dropout(0.1) -> Linear(32,1)
beta = 0.5 * sigmoid(beta_bias + residual_logit)
```

末层零初始化，`beta_bias=-3`。初始 beta 约为 `0.5×sigmoid(-3)≈0.0237`，之后由训练学习每个样本的残差预算。

### 3.6 显式有界残差

基础预测的通道尺度定义为：

```text
scale_ref = RMS(stopgrad(x_base), over T/H/W)
scale_ref = max(scale_ref, 1e-3)
```

最终修正为：

```text
direction       = tanh(delta_raw)
effective_delta = beta * scale_ref * direction
x_final         = x_base + effective_delta
```

因为 `0≤beta≤0.5` 且 `|tanh(delta_raw)|≤1`，逐元素满足：

```text
|effective_delta| ≤ 0.5 * scale_ref
```

这从结构上消除了 V14 中“小 alpha × 无限大 residual”仍能形成任意大修正的尺度漏洞。但该上界只保证修正幅度有限，不保证修正方向正确，也不保证 final 必然优于 base；后者仍取决于优化和 `L_v15_safe`。

### 3.7 损失函数

所有主要误差均只在隐藏位置计算，基础类型为 Smooth L1。V15 的总损失包含 main 原有项和三个新增项：

```text
L = L_main
  + λ_cross      * L_cross
  + λ_importance * L_importance_balance
  + λ_load       * L_load_balance
  + λ_shared     * L_shared_aux
  + λ_route      * L_route_aux
  + λ_comp       * L_complementary
  + 0.50         * L_v15_base
  + 0.10         * L_v15_delta
  + 0.10         * L_v15_safe
```

其中：

- `L_main`：最终输出 `x_final` 对隐藏目标的 Smooth L1；
- `L_cross`：最终预测下采样后与 mid/coarse 已观测值的一致性；
- balance 项：约束专家重要性和实际 Top-K 负载；
- shared/route auxiliary：保持两条主干分支各自具备补全能力；
- complementary：降低 shared 与 routed 表征的重复性；
- `L_v15_base`：保持 `x_base` 的独立补全能力；
- `L_v15_delta`：监督 `effective_delta` 拟合 `target-x_base.detach()`；
- `L_v15_safe`：按样本计算 `ReLU(MAE_final-MAE_base)`，惩罚 final 相对 base 的退化。

TaxiBJ/CHAP 的 `λ_cross=0.03、λ_shared=0.05、λ_route=0.10、λ_comp=0.003`；BikeNYC 分别为 `0.05、0.03、0.05、0.001`。三个数据集的 `λ_importance=λ_load=0.001`。

### 3.8 指标定义

MAE、RMSE 和 MAPE 都只在缺失位置计算：

```text
MAE  = sum(|pred-target| * missing) / sum(missing)
RMSE = sqrt(sum((pred-target)^2 * missing) / sum(missing))
MAPE = sum(|pred-target| / max(|target|,1e-6) * missing) / sum(missing)
```

TaxiBJ 和 BikeNYC 的 0/近 0 目标使 MAPE 达到约 35,000～86,000，数值主要反映分母放大，不具有稳定解释性。CHAP 的 MAPE 约为 0.025～0.029，但为了三个数据集一致比较，正文仍以 MAE/RMSE 为主。

## 6. V15 残差路径诊断

下表的“内部 base MAE”和“平均增益”来自 V15 test diagnostics。平均增益定义为每个样本隐藏位置 `MAE_base-MAE_final` 的 batch 平均；由于它与全局 test MAE 的聚合顺序略有不同，两者不会严格逐位相减相等。

| 数据集 | Mask | 内部 base MAE | Final MAE | Final-base 平均增益 | 样本退化率 | 平均 beta |
|---|---|---:|---:|---:|---:|---:|
| TaxiBJ | fixed | 7.9911 | 8.0776 | **-0.0866** | 27.96% | 0.4991 |
| TaxiBJ | random | 12.4992 | 11.6072 | **+0.8921** | 11.04% | 0.4934 |
| BikeNYC | fixed | 1.9338 | 1.9496 | **-0.0158** | 67.97% | 0.4956 |
| BikeNYC | random | 2.0950 | 2.0880 | +0.0071 | 44.48% | 0.4935 |
| CHAP_Beijing | fixed | 0.6691 | 0.6094 | **+0.0597** | 1.92% | 0.1117 |
| CHAP_Beijing | random | 0.6954 | 0.6481 | **+0.0472** | 3.76% | 0.0984 |

### 6.1 动态预算的实际行为

TaxiBJ 和 BikeNYC 的 beta 基本都收敛到 0.49～0.50，接近 `beta_max=0.5`。这意味着：

- 有界公式确实限制了最大修正，但控制器多数时候直接使用了接近最大预算；
- 不同缺失模式、缺失率和样本难度没有被充分区分；
- “动态预算”在这两个数据集上更像一个接近常量的最大幅度开关；
- 当方向预测错误时，较大的预算会放大残差路径的负面影响。

CHAP 的 beta 明显更低：fixed 四点约为 0.068、0.076、0.129、0.174，random 四点约为 0.057、0.057、0.104、0.176。它随缺失率提高而增大，符合“信息越少，允许更大修正”的直觉，也对应了更低的样本退化率。

### 6.2 Safety loss 的局限

`L_v15_safe` 惩罚的是按样本平均 MAE 的正 regret，并且权重只有 0.1。它存在三个边界：

1. 它是期望意义的软惩罚，不是逐样本或逐位置硬约束；
2. 小幅退化样本很多时，退化率可以很高但平均 regret 仍较小；
3. 主干、残差金字塔和预算控制器联合训练，`x_base` 本身也在变化，目标锚点不是固定模型。

BikeNYC fixed 的平均退化率达到 67.97%，但平均 MAE 只比内部 base 差约 0.0158，说明主要是大量小幅退化，而非少数灾难性失败。TaxiBJ fixed@0.2 的单点退化更明显：内部 final-base 增益为 -0.7466，样本退化率为 54.62%。

### 6.3 V15 相对 V14 退化的可能原因

以下属于基于日志的推断，而不是已经被消融证明的因果结论：

- `beta_max=0.5` 对 TaxiBJ/BikeNYC 可能过大，且控制器饱和使动态预算失去调节作用；
- `L_v15_delta` 直接拟合 `target-x_base.detach()`，可能鼓励残差分支在训练集继续追逐 base 的瞬时误差，而未必提高验证泛化；
- main 与 V15 同时训练，`L_main + 0.5L_base` 形成两个相关目标，可能改变了 V14/main 已经稳定的最优点；
- 当前 Residual Pyramid 新增约 48 万参数，对 BikeNYC 仅 511 个训练样本而言更容易增加方差；
- V15 解决的是 V14 的尺度可辨识性问题，但删除了 V14 的 observed consistency 条件，因此“幅度有界”并不等价于“方向可信”。

## 8. Fixed、Random 与缺失率影响

### 8.1 Fixed 与 Random

三个数据集的 random 四点平均 MAE 都高于 fixed：

| 数据集 | Fixed 平均 MAE | Random 平均 MAE | Random 相对 Fixed |
|---|---:|---:|---:|
| TaxiBJ | 8.0776 | 11.6072 | +43.70% |
| BikeNYC | 1.9496 | 2.0880 | +7.10% |
| CHAP_Beijing | 0.6094 | 0.6481 | +6.36% |

TaxiBJ 的差距最大，说明 random mask 的隐藏位置或样本级变化显著增加了泛化难度。BikeNYC 和 CHAP 的差距较温和，但 random 仍整体更难。

### 8.2 缺失率非单调

结果没有随缺失率严格单调变差：

- TaxiBJ fixed 最好的是 0.8，random 最好的是 0.6；
- BikeNYC fixed/random 都在 0.6 最好；
- CHAP fixed 在 0.4 最好，random 在 0.6 最好；
- 多数组合的 0.8 并非最差，TaxiBJ random@0.4 反而显著最差。

这不应被解释为“缺失越多越容易”。更可能的原因是不同缺失率使用了不同离线 mask，隐藏位置对应的目标数值分布、空间区域和时间片难度不同；MAE 又在各自隐藏集合上计算，因此不同缺失率并不是对完全相同目标集合的逐步加难实验。论文中应明确这一点，并避免只根据缺失率大小推断模型鲁棒性。

## 9. 与 V14 的综合比较

V15 相比 V14 的设计收益和实验代价可以分开评价。

### 9.1 已经实现的结构收益

- 移除了 V14 无界 `alpha_final * delta_ctf` 的尺度补偿漏洞；
- 最终残差有明确逐元素上界；
- 初始化严格等价 main，不会在第一个 Forward 随机破坏基础预测；
- 条件输入从 V14 的多组难度、几何和 consistency 特征简化为 8 维可观测统计；
- 新增诊断能够直接测量 beta、残差相对幅度和 final/base 非退化情况；
- 24 点工程闭环完整，无数值异常。

### 9.2 尚未实现的性能收益

- 仅 6/24 点优于 V14；
- BikeNYC 0/8 点胜出；
- CHAP random 0/4 点胜出；
- TaxiBJ random 平均退化 12.03%，且 random@0.2/0.4 退化非常明显；
- 参数量比 V14 增加约 9.8%，总训练成本也有所增加；
- TaxiBJ/BikeNYC 的动态预算接近常数上限，未体现预期的自适应控制。

因此，“V15 结构比 V14 更容易解释”是成立的；“V15 比 V14 效果更好”则不受当前实验支持。论文主结果不应选择性忽略 18 个退化点。

## 11. 最终结论与下一步建议

### 11.1 当前版本选择

当前不建议把 V15 替换为论文主模型。理由是：

- V15 相对 V14 只有 6/24 点改善；
- V14 在 BikeNYC 和 CHAP 上更稳定；
- V15 的显式有界残差解决了可解释性问题，但动态预算在两个数据集上饱和；
- 当前精度收益主要集中在 TaxiBJ 的部分缺失设置，泛化范围不足。

因此后续主力方向建议仍以 **V14 为稳定性能基线**。V15 可以保留为“有界残差修正”研究分支，用针对性消融确认问题后再决定是否继续发展。

### 11.2 V15 优先消融顺序

现有配置已经提供 `fixed_budget、no_pyramid、no_base_loss、no_delta_loss、no_safety_loss、unbounded_residual`。不建议立即重跑全部 24×6 点，而应先选择最有诊断价值的组合：

1. BikeNYC fixed@0.6：BikeNYC 最佳点，但仍输给 V14，适合检验容量和预算饱和；
2. TaxiBJ random@0.4：V15 最大退化点，适合定位过拟合和错误残差；
3. TaxiBJ random@0.8：V15 明显胜出点，用于确认有效机制；
4. CHAP fixed@0.4：V15 小幅胜出且 beta 较低，用于对照合理预算行为。

优先比较：

```text
当前 dynamic beta_max=0.5
fixed budget（建议 0.02 / 0.05 / 0.10）
更低 beta_max（建议 0.10 / 0.20）
no_pyramid
no_delta_loss
no_safety_loss
```

如果降低 beta 上限能改善 BikeNYC/TaxiBJ fixed，同时保留 TaxiBJ random 的收益，可以确认主要问题来自预算饱和；如果 `no_pyramid` 更好，则说明新增残差容量本身没有有效利用多尺度特征。

### 11.3 训练策略建议

- 尝试先训练或加载稳定 main，再冻结 main 训练残差控制器，避免 base 与 residual 目标同时漂移；
- 或设置 residual warmup：前若干 epoch 固定较小 beta，只训练方向，再逐步开放动态预算；
- 将 checkpoint 监控从单一 final val MAE 扩展为同时记录 base/final gap 和 violation rate，但论文最终选择仍应预先固定规则；
- BikeNYC random 的最佳 epoch 多在 76～108，可启用合理 early stopping，减少小数据集后期过拟合；
- CHAP 最佳点都在最后一轮，若继续单独优化可小幅延长，但优先级低于修复 V15/V14 性能差距。

### 11.4 论文实验建议

1. 论文主表继续以 MAE、RMSE 为主，TaxiBJ/BikeNYC 不报告当前 MAPE，或明确标注其受零值影响不可解释；
2. 在确定最终模型后至少运行 3 个随机种子，报告 mean±std；当前全部结果只有 seed=42，不能据此判断小于约 1% 的改进是否稳定；
3. 保留 24 点完整结果，不应只报告 V15 胜出的 6 点；
4. 提交当前 dirty worktree，固定可复现 commit；
5. 完成 baseline 对比时确保 mask、split、原始范围指标和 checkpoint 选择规则一致。

最终评价：**V15 是一次工程上成功、机制上更清晰、但性能上尚未成功取代 V14 的改进尝试。**它明确指出下一阶段真正需要解决的不是继续增加模块，而是让 residual budget 避免饱和、让修正方向在验证集上可靠，并控制小数据集上的额外容量。
