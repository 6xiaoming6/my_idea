### 1.1 总体数据流（修正版）

### 1.2 关键澄清：双分支的输入

与常见 MoE 架构不同，本模型的两个分支处理**相同的原始嵌入但使用不同的变换路径**：

| 分支 | 输入 | 变换 | 输出 |
|------|------|------|------|
| **Shared** | 原始嵌入 `h_f, h_m, h_c` | GatedCrossScaleSharedExpert（尺度门控融合）→ 2×ResBlock | `h_shared` |
| **Routed** | 原始嵌入 `h_f, h_m, h_c` | QualityRouter → ExpertPool → ProgressiveRouteFusion | `h_route` → Conv+ResBlock → `h_route_proj` |

默认配置 `shared_input_mode="pre"` 意味着 Shared 分支接收**未经专家处理的原始嵌入**，而非专家输出。这使两个分支形成真正的互补：Shared 学习跨尺度全局结构，Routed 学习条件化专家表示。

### 1.3 ScaleTokenEncoder — 多尺度时空嵌入

```python
class ScaleTokenEncoder:
    def forward(x, mask):
        return (
            value_embed(x)           # Conv3d(C→64, k3) → GroupNorm → GELU
            + mask_embed(mask)       # Conv3d(1→64, k3)     ← 显式编码观测状态
            + self.scale_embed       # Parameter[1,64,1,1,1]  ← 可学习尺度标识
            + self.time_embed        # Parameter[1,64,T,1,1]  ← 可学习时间位置
            + self.space_embed       # Parameter[1,64,1,H,W]  ← 可学习空间位置
        )
```

3 个尺度各有独立参数（Fine: 32×32, Mid: 16×16, Coarse: 8×8），`max_t=24` 覆盖所有时间窗口。

### 1.4 QualityRouter — 质量感知路由

```python
class QualityRouter:
    def forward(h, q, scale_embed_vec):
        pooled = h.mean(dim=(2,3,4))                    # [B, 64]
        logits = MLP([pooled | q | scale_embed_vec])    # [B, 64+5+64] → [B, num_experts]
        return softmax(logits)
```

**观测统计量 q 的 5 个维度**（来自 `compute_observation_stats`）：

| 索引 | 名称 | 计算方式 |
|------|------|---------|
| 0 | `missing_rate` | 1.0 - mask.mean() |
| 1 | `observed_ratio` | mask.mean() |
| 2 | `temporal_missing_score` | 时间步观测率 < 0.1 的比例 |
| 3 | `spatial_missing_score` | 4×4 滑窗内缺失率最大值（衡量空间聚集性） |
| 4 | `aggregation_reliability` | = observed_ratio（粗尺度可靠性代理） |

### 1.5 TopKRoutedExpertPool — Top-K 稀疏专家池

每个专家 `STExpert`: `Conv3d(64→64, k3) → GroupNorm(8) → GELU → ResidualSTBlock`

```python
class TopKRoutedExpertPool:
    def forward(h, gate, routing_mode="topk"):
        expert_outputs = stack([expert_k(h) for k in range(4)])  # [B, 4, 64, T, H, W]
        top_values, top_indices = topk(gate, k=2)                  # 选 top-2 专家
        top_weights = top_values / sum(top_values)                  # 归一化
        z = Σ(w_k · expert_k(h))                                   # 加权组合
        return z, top_indices, top_weights, selected_mask
```

`share_experts=True`：3 尺度**共享同一组 4 个专家**，跨尺度参数复用。

### 1.6 ProgressiveRouteFusion — 渐进路由融合

```
z_c [8×8]  ──LearnableUpsample3D──► z_c_to_m [16×16]
z_m [16×16] ──GatedFusion2(z_m, z_c_to_m)──► z_mc [16×16]
                 gate_16 = softmax(Conv(z_m | z_c_to_m))   ← 学习逐位置 mid/coarse 权重

z_mc [16×16] ──LearnableUpsample3D──► z_mc_to_f [32×32]
z_f [32×32]  ──GatedFusion2(z_f, z_mc_to_f)──► h_route [32×32]
                 gate_32 = softmax(Conv(z_f | z_mc_to_f))  ← 学习逐位置 fine/merged 权重
```

上采样用三线性插值 + Conv3d+GroupNorm+GELU+ResidualSTBlock 精化（`LearnableUpsample3D`）。

### 1.7 GatedCrossScaleSharedExpert — 跨尺度共享专家

```python
class GatedCrossScaleSharedExpert:
    def forward(h_f, h_m, h_c, q_f, q_m, q_c, r_m, r_c, active_mask):
        # Step 1: 上采样到 fine 分辨率
        h_m_up = trilinear_upsample(h_m, target=(T,32,32))
        h_c_up = trilinear_upsample(h_c, target=(T,32,32))

        # Step 2: 可靠性感知尺度门控
        scale_weight = ReliabilityAwareScaleGate(
            h_f_pooled, h_m_pooled, h_c_pooled,  # 各 64d
            q_f, q_m, q_c,                        # 各 5d
            r_m_mean, r_c_mean,                   # 各 1d
        )  # MLP(209→128→3) → softmax → [B,3]

        # Step 3: 加权融合
        z_shared = Conv1x1+2×ResBlock(
            w_f·h_f ⊕ w_m·h_m_up ⊕ w_c·h_c_up
        )  # [B, 192, T, H, W] → [B, 64, T, H, W]
```

**ReliabilityAwareScaleGate 输入维度分解**：

```
p_f, p_m, p_c:     64 × 3 = 192  (各尺度全局平均池化特征)
q_f, q_m, q_c:      5 × 3 =  15  (各尺度观测统计量)
r_m_mean, r_c_mean:         2    (粗尺度可靠性评分)
                                    ────
                            Total: 209 → MLP(209→128→3) → softmax → [w_f, w_m, w_c]
```

### 1.8 SharedRoutedResidualFusion — 双分支残差融合

```python
class SharedRoutedResidualFusion:
    def forward(z_shared, h_route, q_f, scale_gate):
        # Shared 处理
        h_shared = 2×ResidualSTBlock(z_shared)           # 共享特征精化

        # Route 处理
        h_route_proj = Conv3d(64→64, k1) → ResidualSTBlock → Dropout3d(0.1)

        # 残差融合
        γ = sigmoid(self.route_gamma)     # 初始 sigmoid(-3) ≈ 0.047
        h_main = h_shared + γ · h_route_proj

        return h_main, h_shared, h_route_proj, branch_gate
```

### 1.9 损失函数

```python
# 所有 masked_loss 仅在 hidden positions (1 - m_f) 上计算
l_main          = SmoothL1(x_hat_main,  x_f_gt, hidden)    # λ = 1.0
l_cross         = SmoothL1(x_hat_pooled, x_obs, observed)  # λ = 0.10  (mid+coarse)
l_shared_aux    = SmoothL1(x_hat_shared, x_f_gt, hidden)   # λ = 0.05
l_route_aux     = SmoothL1(x_hat_route,  x_f_gt, hidden)   # λ = 0.10
l_importance    = Σ(gate_mean - 1/E)²                       # λ = 0.01
l_load          = Σ(selected_mean - mean_load)²             # λ = 0.01
l_complementary = (cos(h_shared, h_route_proj))²            # λ = 0.003

L = l_main + 0.10·l_cross + 0.01·(l_imp + l_load) + 0.05·l_shared_aux + 0.10·l_route_aux + 0.003·l_complementary
```

### 4.4 CHAP fixed rate=0.4 — Val < Train 与大幅 Test 改善

```
Epoch   1: TrainLoss=22.99  TrainMAE=19.42  SclGateF=0.12  SclGateM=0.45  SclGateC=0.43
Epoch  40: TrainLoss=5.75   TrainMAE=5.20   ValMAE=4.31   SclGateF=0.51
Epoch  80: TrainLoss=1.47   TrainMAE=1.55   ValMAE=1.32   SclGateF=0.69
Epoch 120: TrainLoss=0.89   TrainMAE=1.04   ValMAE=0.77   SclGateF=0.68
Epoch 150: TrainLoss=0.76   TrainMAE=0.90   ValMAE=0.72 ← BEST (Val/Train = 0.80×)
[Test]    MAE=0.587  RMSE=0.844  (Val→Test: ↓19.0%  ← 三数据集中最大改善)
```

**CHAP 三个独特现象**：

1. **Val MAE < Train MAE (gap 0.80×)**：训练时 route_dropout=0.1 + 多重辅助损失使 Train MAE 偏高；验证时完整推理。
2. **Test MAE << Val MAE (↓19%)**：PM2.5 后期年份（test 时间段）数据质量更好、污染模式更规律。
3. **Scale gate 保留 ~27% Mid 权重**（末期 Fine=65%, Mid=27%, Coarse=8%）：PM2.5 区域级模式适合作 16×16 分析，模型自适应保留粗尺度贡献。

### 4.5 学习率调度与收敛

CosineAnnealingLR(1e-3 → 1e-6)，160 epochs：

```
LR 阶段:
  1e-3 → 5e-4  (Epoch 1–80):   快速下降期，MAE ↓85%
  5e-4 → 1e-4  (Epoch 80–115):  波动调整期，Val MAE 震荡
  1e-4 → 1e-6  (Epoch 115–160): 精细收敛期，Val MAE 稳定逼近 Train
```

收敛至最佳 5% 范围内的 epoch：TaxiBJ~115–140, BikeNYC~60–76, CHAP~110–130。

## 5. 关键发现

1. **Test 系统性优于 Val（除 BikeNYC）**：模型泛化好，未出现过拟合。CHAP 的 19% 改善尤为显著。
2. **BikeNYC 是唯一 Test > Val 的数据集**（↑1–6%），288 节点小数据下测试分布略有偏移。
3. **多尺度门控自适应**：Scale gate 在不同数据集/缺失率下呈现差异化行为——TaxiBJ fixed Fine 独占，CHAP 保留 27% Mid 权重，验证了 ReliabilityAwareScaleGate 的有效性。
4. **双分支互补**：Shared 分支提供稳定基线（branch_gate_shared≈1.0），Routed 分支以残差（γ≈0.04–0.11）补充细节，`L_complementary` 强制特征正交。
5. **高缺失率的 MAE 效应**：Fixed mask 下 rate=0.6–0.8 的 Test MAE 不逊于 rate=0.2，高掩码率迫使模型学习更强的全局先验。
6. **MAPE 异常**：TaxiBJ/BikeNYC 的 Test MAPE 高达 30000–80000%，因流量数据含大量近零值。建议仅用 MAE/RMSE。
