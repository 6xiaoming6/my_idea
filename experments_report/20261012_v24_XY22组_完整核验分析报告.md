### 1.1 共同骨架、数据与训练协议

所有组使用四轮、八种异构专家 `T/S/TD/SD/TA/ST/TL/SL` 的跨轮共享专家池；每个样本每轮只执行原生动态 Top-2，组内 softmax 融合，每窗口共八次专家调用。尺度顺序固定为 `C→M→F→F`，TaxiBJ 空间网格为 8×8、16×16、32×32、32×32，时间长度始终 12。输入 `[B,2,12,32,32]`，hidden 64。**固定尺度调度与动态专家选择严格区分**；专家调用数相同不代表实际 FLOPs、显存或耗时相同。

训练 100 epoch、batch32、GPU0 单卡串行，每 5 epoch 验证，无早停。AdamW，初始学习率 1e-3，余弦至 3e-4，weight decay 1e-4，梯度裁剪 1，AMP、严格确定性，关闭 TF32 和 benchmark。模型/loader seed7；公共初始化逐值核验，新增模块使用隔离随机流。best.pth 仅依据同分布验证 MAE 选择，last.pth 保存优化器、scheduler、scaler、随机数与完整已提交训练历史。无额外轮后 FFN、第二 mask 视图、一致性、自由尺度、搭档重选或接受门。

实际 train/val/test 窗口数为 2452/342/707，对应 batch 数 77/11/23。使用原数据时间切分，不拼接为虚构连续时间线。`random0.4` 在本项目中包含四基础缺失族，而非仅随机点：random_point、node_outage、temporal_gap、spatial_region。训练逐 epoch 重采样；验证和测试固定。基础 mask seed 为 20260917，验证/测试偏移分别 20000/30000。各组共享同率测试窗口和 mask 协议。

Y05–Y08 是在 0.6 从头训练、同率验证并同率测试；其余为 0.4。两种缺失率改变了训练和测试分布，**不是 0.4 模型迁移到 0.6 的测试**。后续的两套 mask 复测只改变测试 mask seed，不增加训练种子。

### 1.2 实际模块实现与对照边界

**主链与受控差分。** 纯 CMFF 已存在上一轮 hidden 到下一轮的直接状态传递；“无额外信息传递”并非各轮互不相干。差分取当前轮输入 H 与上一轮输入 Hprev 之差，在每样本每通道 THW 上计算 RMS，并匹配 H 的 RMS；缩放系数 detach，分母下限 1e-6。共享条件门读取当前/前一状态的全局与缺失位置摘要，输出 `0.1*tanh`，末层零初始化。它在尺度池化前修正专家输入；Router 仍读取原 H。第一轮无历史。X02 仅将每轮融合输出 U 改为 H＋U，无差分、无可学习保留门。

**预测历史池。** 池初始为空，每轮共享 decoder 的预测用真实观测硬钳制后 detach 入池：`P_i = M*Xobs + (1-M)*prediction_i`，只读此前轮次，不跨 batch，不把预测计作真实观测。X03 读取最近一个；X04 对历史等权；X05/X06 逐位置 softmax 读取。自适应评分器输入 `P_i/s、最近 P/s、绝对差、年龄、原 mask 覆盖`，8→16→1 Conv/GELU/Conv；年龄为 `(历史数−索引)/3`，尺度 s 为每样本每原始通道观测 RMS 且下限 1。共享注入器读取 `[历史结果/s,mask]`，4→32→64，末层零初始化，注入 `0.1*RMS(H)*tanh(inject)*(1-mean_channel(mask))`。原 hidden 主链正常反传，历史预测 detach 只切断池存储支路的反传。自适应池新增 2433 参数，等权/最近历史新增 2272。

**ST 内部三平面。** X07/X08 保留原 ST 三维网格卷积分支，在 128 通道中间特征上添加 16 通道 TH/TW/HW 旁路。投影按真实观测覆盖归一化，零支持投影置零；每平面有独立 depthwise 3×3、GELU、pointwise Conv2D，再广播回网格。支持图是投影覆盖的 3×3 邻域平均；X07 在有效视角间等权，X08 用覆盖归一化；融合映射末层零初始化，乘 0.1，保留原网格细节。仅在 ST 被选中时运行，新增 5536 参数。覆盖表示支持程度，不等于校准置信度；三平面分支也不是一个新的第九专家。

**全专家共享输入三平面。** Y09/Y10 在 native scale 的 state_projection＋state_norm 后，对 64 通道特征运行同类三平面分支，每轮全 batch 只计算一次，输出加到所有被选专家的共同输入；实际仍只运行 Top-2，Router 不额外读取三平面。Y09 有效视角等权，Y10 覆盖加权，两者参数和初始化一致，均新增 3424 参数。与 X07/X08 相比，插入位置、通道数、容量、执行频率同时变化，因此仅能探索性比较“共享输入版与 ST 内部版”，不能将全部收益归因于可见范围。Y11 在 Y10 上增加原自适应历史池。

**双专家交互。** 已执行的两个输出按专家编号排序为 A、B，做无仿射通道 LayerNorm 后，X09 读 `[Abar,Bbar]`，X10 读 `[Abar*Bbar,Abar−Bbar]`；共享 MLP 128→32→64，两者各新增 6240 参数、相同初始化。输出末层零初始化，以 `0.1*RMS(U)*tanh(MLP)` 加到原 Top-2 加权和 U，不重选搭档、不改变两个融合权重、不执行第三专家。Y12 在 X05 的历史池上加入原 X10 的交互。乘积和差值属于捆绑改动；**本批没有“历史池＋同容量拼接 MLP”组**，Y12/X09 不是单独检验乘法的等条件比较。

**中间监督。** 除 Y01–Y04 外，损失为最终缺失标签 L1＋0.01 候选负载均衡；Y01–Y04 额外增加 `(0.1/3)*sum(前三轮缺失标签 L1)`，使用同一 decoder，无新增预测头，也无逐轮单调惩罚。真值仅进入损失和事后诊断，不输入历史评分器或门控。不同监督组的总 loss 定义不同，不能直接以总 loss 数值判优。

### 3.1 最值得保留的三个候选，目标不同

**Y12 是当前 0.4 批次的泛化优先候选。** ID MAE/RMSE 为 13.8871/24.7869，三类主要 OOD MAE 为 15.1617、18.8367、14.3517；在本批 0.4 的全部候选中，三个主要 OOD 和两套 mask 复测的 MAE、RMSE 均最低。相对既有 K04，ID MAE 退步 2.77%，三类 OOD MAE 分别改善 31.48%、27.49%、35.75%。这比较符合“允许小幅 ID 代价，换取更好的未见缺失表现”的研究目标，但本批没有预注册 ID 非劣阈值，不能宣称统计非劣。相对 ID 最强的 Y10，Y12 的 ID MAE 仍差约 7.99%，必须明确比较对象。

**Y10 是当前 0.4 批次的 ID 优先候选。** ID MAE/RMSE 12.8600/22.9164 均为本批 0.4 最低；相对 K04，ID MAE 改善 4.83%，三类 OOD 也分别改善 6.46%、17.26%、17.40%，六套 MAE/RMSE 全部更好。但它的组合缺失和三元缺失仍落后于 X09、X05、Y12，不能称为整体泛化最强。

**X05 是较轻量、跨两种缺失率有支撑的历史池方案；X09 是不能省略的强拼接对照。** X05 比 K04 仅多 0.74% 总参数、训练验证时间约多 2.63%，但 ID MAE 退步 4.45%，其 OOD 收益突出。X09 的 ID 更接近 K04（退步 0.88%），三类 OOD 均较好；相对纯 CMFF，六套 MAE/RMSE 全部改善。Y12 相对 X09 的主要 OOD MAE 改善约 5.95%–6.92%，ID 退步 1.88%，说明额外组合有泛化收益，但并非无代价。

### 3.2 历史池：从单模块到组合的证据

X03 只读最近预测时，相对 K04 的 ID 和三类 OOD 都退步，说明“再注入一次最近预测”本身不足。X04 的等权累积历史大幅改善组合缺失；X05 的自适应读取相对 X04 在未见几何上改善约 16.24%，但 ID 退步约 1.78%，两元和三元也略差。因此不能声称自适应读取全面优于均值，尤其不能直接将最终收益归因为准确的历史可靠性估计。

X06（无差分历史池）相对纯 X01 也有 ID 与未见缺失收益，说明历史池有独立积极信号。X05 比 X06 的六套 MAE/RMSE 都更好，但部分差距很小，例如第一套几何 MAE 仅约 0.23%。必须通过独立训练种子判断这类小差是否稳定。

0.6 的四格对照更有区分度。Y08（差分＋历史池）相对 Y06（仅差分）在 ID 改善 2.41%，三类 OOD 改善 4.25%、6.16%、9.23%，且六套 MAE/RMSE 全部改善；这是历史池在既有差分之上提供增量的直接证据。相比纯 Y05，Y08 的 ID 退步 7.58%，三类 OOD 则改善 34.34%、28.14%、43.12%。Y07 在两元组合的 MAE/RMSE 仍优于 Y08，部分三元 RMSE 也更好，因此组合并非对两个单模块都逐项支配。0.4 与 0.6 的积极结果来自同一数据集同一训练 seed，只能称为跨缺失率的一致方向，不能称为跨数据集或多种子稳定泛化。

### 3.3 Y12：交互收益依赖历史池，但乘法机制尚未单独成立

单独交互时，X10（乘积差值）劣于等容量 X09（拼接）：六套 MAE/RMSE 全部更差。因此“乘法天然优于加权和或拼接”不被这批支持。加入历史池后，Y12 相对 X05 的 ID MAE 改善 1.61%，三类 OOD 改善 6.84%、7.38%、8.68%，六套 MAE/RMSE 全部改善；相对 X10 也全面改善。**实际支持的是“在历史池背景下，这个交互分支有额外收益”**。

分族结果也揭示边界：Y12 相对 X09 的 time_plus_space MAE 从 18.979 降至 17.434，node_plus_time 从 15.815 降至 13.950，multi_block 从 21.082 降至 18.834；但 node_plus_space 从 14.072 略升至 14.096。因此“协议总体最好”不等于所有细分缺失族最好。Y12 的四个 ID 基础族 MAE 均略高于 X09。测试 mask 复测中的 OOD 优势方向一致，仍不能替代训练随机性复验。

目前缺少“历史池＋拼接 MLP”的直接组，不能排除历史池背景下任何等容量非线性分支都有效；也没有分别拆开乘积项与差值项。Y12 比 K04 多 2.62% 总参数，但训练验证时间约增加 12.75%，allocated 显存增加 32.67%，ID 单次测得推理耗时约增加 25.21%；比 X05 显存约增加 22.92%。小参数增量不代表低运行成本。建议将 Y12 定为待复验的第三方法候选，而非已经证明的新核心贡献。

### 3.4 三平面：共享输入版有价值，覆盖加权与历史组合均有条件性

ST 内部的 X08 覆盖加权版相对 X07 的 ID 和主要 OOD 都变差；全专家输入版的 Y10 相对 Y09 则是 ID 改善 5.79%、几何改善 7.60%，但两元组合退步 19.65%、三元组合退步 10.43%。这说明观测覆盖权重并未普遍提升鲁棒性，它改变了缺失类型之间的取舍。两组均以真实观测支持构造投影，Y09 也不是无条件对三个有无支持都相同的投影求平均。

Y11 是必须披露的强负结果：在 X05 上叠加共享覆盖三平面，ID 改善 4.63%，主要 OOD 却退步 45.48%、42.79%、39.13%；相对 Y10，连 ID 也退步 4.67%，三类 OOD 退步 14.38%、35.10%、18.50%。因此不能按单模块收益直接相加来选组合，也不能推荐当前 Y11。历史和三平面是否造成信息重复、状态分布改变或优化冲突只是待检验假设，现有结果无法区分原因。

### 3.5 “逐轮修复”尚未成立：不能让漂亮的中间曲线代替泛化

Y12 的 ID 四轮 MAE 为 **206.96→175.75→207.12→13.89**，第三轮反弹明显；三类 OOD 也有类似模式。X05 为 189.68→197.08→188.45→14.11。它们证明的是多轮 hidden 变换结合历史读取后能产生更好的最终预测，**不是每一轮已经形成更准确的补全结果**。前几轮没有直接监督且共享 decoder，早期预测可能未校准；这种解释合理，但仍是解释而非本批机制证明。高达 96% 左右的末轮改善比例也可能部分来自上一轮预测很差，不能单独充当修复机制证据。

Y01–Y04 的中间监督确实使 ID 四轮 MAE 单调降低，例如 Y04 为 56.00→48.39→30.26→14.35；但四个加监督组相对各自直接对照的三类 OOD MAE 全部退步，Y03 尤其明显。中间预测看起来更像逐轮修复，并没有带来更好的最终泛化。此负结果阻止我们把简单中间 L1 监督直接采纳为论文方法。即使平均 MAE 单调，也不代表每个样本、位置或未来数据都单调；各轮破坏比例仍非零。

X02 简单残差的 ID 很强，却出现严重组合泛化退步：相对 X01，两元 MAE 从 17.4069 升至 32.7642，三元从 16.4229 升至 32.9884。更直接的残差形式与更平滑的逐轮 ID 误差都不足以保证泛化。

### 3.6 对既定论文主线的准确定位

本批保持 CMFF＋受控差分作为开发基座，结果支持继续在其上研究历史信息利用；但本批全是 CMFF，没有新增 FFFF 对照，不能再次独立证明多尺度收益。0.4 下 K04 相对纯 X01 的 ID 更好、OOD 更差；0.6 下仅差分 Y06 相对纯 Y05 的 ID 更差、OOD 更好，说明差分效应依赖训练/缺失分布，不能仅凭本批给它冠以普遍泛化优势。前两项贡献的稳定性仍应以既有双数据集三训练种子的 K 系列完整证据为依据，本报告不替代也不重新筛除 seed27。

所有方案都在同一个训练 seed7 和 TaxiBJ 上探索，Y 系列又受已观察 X 结果启发，具有探索性选择偏差。best checkpoint 虽然严格由验证集选，当前候选优先级仍参考了这些 OOD 测试结果，因此后续论文确认需要独立种子/数据集或新冻结评估，不宜再把本轮已用于选方向的结果包装为完全独立验证。未提供置信区间、显著性检验或“稳定提升”的断言。MAE/RMSE 为主指标，零与近零流量使 MAPE 易失真，本报告不以 MAPE 排名。

### 3.7 后续实验优先级（仅建议，本次没有启动新实验）

1. **先补齐 Y12 的关键等容量对照。** 固定 CMFF＋差分＋自适应历史池，唯一变化为无交互、拼接 MLP、乘积差值 MLP；使用相同参数宽度、初始化与预算。现有 X05/Y12 可作为探索参考，补“历史池＋拼接”才有资格讨论乘积差值是否带来独立机制优势。若无明显优势，应接受普通拼接更简洁的结论。
2. **冻结候选后复验。** 优先 K04、X05、X09、Y12 及新增拼接历史组，在 TaxiBJ seed17/27 和 BikeNYC 相同协议验证；若预算有限先做直接对照最关键的几组。Y10 单列为 ID 优先备选。必须完整披露 seed27，不因方向不利而排除。
3. **检验“历史”而非额外容量。** 控制同容量注入器，对比真实历轮历史、只留最近、等权全部、打乱轮次、去掉早期项。干预分清仅测试时遮蔽与独立重新训练，两者回答的问题不同；测试时破坏不应冒充公平训练消融。观测历史权重与各历史预测误差/支持覆盖的关系，但诊断真值不能喂给模型。
4. **先明确逐轮修复的可检验目标。** 同时报告逐轮 MAE、修好和破坏率、缺失类型分解；若追求逐轮可解释预测，可探索共享最终解码空间下的受限修正，但必须与普通辅助监督做对照，并约束已观测位置与不可靠历史的影响。当前中间 L1 方案不继续默认叠加，不承诺误差必然下降。
5. **暂缓叠加更多模块。** Y11 当前组合不推荐继续扩大；全专家三平面保留 Y10 单模块路线，先研究覆盖融合导致的组合缺失退步。Y12 尚无 0.6 结果，如做高缺失率确认，应以 Y08 和同率拼接历史组为对照，而非直接跨率比较分数。
