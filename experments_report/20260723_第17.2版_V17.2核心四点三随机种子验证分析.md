# 20260723_第17.2版_V17.2核心四点三随机种子验证分析

## 1. 实验目的与设置

本阶段用于验证 V17.2 Adapter-Free HSA-MoE 能否在 V17.1 Stage 3
筛选出的四个核心点上，稳定复现 E1 No Adapter 的收益。V17.2 的唯一目标
结构变化是移除 Fine/Mid/Coarse 三个 Scale-Specific Adapter，其余 V17
分层尺度—专家路由、共享专家池、多尺度融合、分支融合、损失和训练协议保持
不变。

### 1.1 核心实验点

| Point | 数据集 | 缺失模式 | 缺失率 | 定位 |
|---|---|---|---:|---|
| P1 | TaxiBJ | random | 0.4 | V17 原相对成功点 |
| P2 | BikeNYC | fixed | 0.8 | V17 原相对成功点 |
| P3 | TaxiBJ | fixed | 0.4 | V17.1 E1 重点修复点 |
| P4 | CHAP | fixed | 0.4 | V17.1 E1 重点修复点 |

每个点使用 `42 / 2026 / 3407` 三个模型随机种子，共计划 12 组，实际完成
12 组。三 seed 使用同一组离线 Train/Val/Test Mask；seed 变化主要作用于
模型初始化、DataLoader shuffle 和训练随机过程，而不是重新生成缺失位置。

### 1.2 训练协议

| 数据集 | Batch size | 最大 Epoch | Val 间隔 | Early stopping |
|---|---:|---:|---:|---|
| TaxiBJ fixed | 32 | 160 | 5 | 关闭 |
| TaxiBJ random | 32 | 160 | 5 | 开启，patience=10 |
| BikeNYC | 16 | 140 | 2 | 开启，patience=12 |
| CHAP | 32 | 150 | 5 | 关闭 |

通用设置：

- 单张 RTX 3090；
- AdamW，主学习率 `1e-3`，weight decay `1e-4`；
- CosineAnnealingLR，`eta_min=1e-6`；
- AMP，梯度裁剪范数 1；
- 每次验证以原始数据范围缺失位置 Val MAE 判优；
- 仅覆盖保存一个 `checkpoints/best.pt`；
- 训练结束后加载最佳 checkpoint，并且只执行一次 Test。

## 2. 最新模型结构

### 2.1 输入、Mask 与多尺度数据流

输入采用 `[B,C,T,H,W]`：

- TaxiBJ：`[B,2,12,32,32]`；
- BikeNYC：`[B,2,12,24,12]`；
- CHAP：`[B,1,7,32,32]`。

数据集读取原始 `x_f_gt` 和离线 CSV Mask。`m_f=1` 表示已观测位置，
`m_f=0` 表示待补全位置。模型前向只接收 `x_f_obs/m_f` 及从已观测数据
构造的 Mid/Coarse 输入，不使用隐藏位置真值。最终完整张量为：

```text
x_comp = m_f * x_f_gt + (1 - m_f) * x_hat_final
```

Fine 通过 Mask-aware pooling 构造 Mid 和 Coarse。TaxiBJ 使用
`fine_mid`，因此 Coarse 最终融合权重严格为 0；BikeNYC 和 CHAP 使用
`fine_mid_coarse`。

### 2.2 Adapter-Free 三尺度编码

Fine、Mid、Coarse 分别通过 `ScaleTokenEncoder` 编码到 64 维隐空间。
V17 Full 原本在三个编码器后分别具有 `64→16→64` 零初始化残差 Adapter。
V17.2 使用强制包装类将三者替换为无参数 Identity：

```text
h_f = Identity(Encoder_f(x_f, m_f))
h_m = Identity(Encoder_m(x_m, m_m))
h_c = Identity(Encoder_c(x_c, m_c))
```

即使配置误写 `adapter_enabled=true`，构造层也会强制关闭。12 个正式 run
的 `adapter_parameter_count` 均为 0，相对 Full 减少 6,384 个参数。

### 2.3 分层尺度—专家路由

模型从每个尺度特征、观测统计和可靠性信息构造局部/全局路由表示。统一
Hierarchical Router 同时输出：

- 三尺度权重；
- 每尺度四专家概率；
- 样本级 Shared/Routed Route Gate。

每尺度从共享的四专家池中执行 Top-2 路由。Scale 权重经过线性
Fine-Preserved Floor（`fine_floor=0.25`），确保 Fine 信息不会完全被
Mid/Coarse 覆盖。

### 2.4 Routed、Shared 与最终融合

Routed 分支将三个尺度的 Top-2 专家输出并行投影回 Fine 分辨率，再按统一
Scale 权重融合。Shared 分支使用 `GatedCrossScaleSharedExpert` 聚合三个
尺度；当前 `unified_scale_weight=true`，因此 Shared 与 Routed 共享尺度
权重。

两个分支通过样本级残差 Route Gate 融合，随后由
`Conv3d → GELU → Conv3d` 预测头生成 `x_hat_main`。本阶段 Aux Branch
关闭，因此：

```text
x_hat_final = x_hat_main
```

### 2.5 损失、指标与训练流程

实际主损失为：

```text
L =
    L_main
  + 0.03  * L_cross
  + 0.001 * L_importance_balance
  + 0.001 * L_load_balance
  + 0.05  * L_shared_aux
  + 0.10  * L_route_aux
  + 0.003 * L_complementary
```

`L_main`、跨尺度监督和分支辅助损失使用 Smooth L1；所有主补全损失只在
缺失位置计算。Scale entropy、fusion entropy、branch entropy 在当前
配置中的权重为 0。

MAE、RMSE、MAPE 都在原始数据范围的缺失位置计算。由于数据包含大量 0 或
接近 0 的目标，MAPE 最高达到 62,590.51，数值不具有稳定解释性，本报告仅
将 MAE/RMSE 作为主要指标。

## 4. 结果分析

### 4.1 CHAP 是最稳定的正向证据

P4 在 MAE 和 RMSE 上都是 3/3 seeds 改善，平均改善分别为 4.24% 和
4.09%。三个 seed 的 V17.2 Test MAE 范围为 0.604797～0.656655，没有
依赖单个 seed 才能成立。该结果完整复现了 V17.1 E1 的主要趋势，是目前
支持删除 Scale Adapter 最可靠的证据。

### 4.2 BikeNYC 小幅但稳定，实际收益有限

P2 的 MAE 平均改善 1.33%、2/3 获胜，RMSE 则 3/3 获胜。V17.2 MAE
标准差仅 0.005181，说明自身训练结果很稳定。但绝对改变量较小，不能单独
作为版本升级的主要依据。更合理的解释是删除 Adapter 没有伤害 BikeNYC，
并带来轻微工程和精度收益。

### 4.3 TaxiBJ random 存在明显 seed 敏感性

P1 seed42 改善 15.48%，seed2026 基本持平，seed3407 退化 13.11%。
三 seed 平均仍改善 1.04%，但 MAE 标准差 0.855904，且 RMSE 仅 1/3
获胜。这表明平均数掩盖了两种不同优化结果，尚不能称为稳定改善。

### 4.4 TaxiBJ fixed 没有复现“3/3 稳定修复”

P3 seed42 改善 20.63%，但 seeds 2026/3407 分别退化 2.43% 和 1.07%。
其平均改善 5.71% 看起来较强，但胜率只有 1/3；与 V17.1 E1 的
`-9.49%、3/3` 相比，核心稳定性结论发生了变化。当前结果只能支持：

> 删除 Adapter 在 P3 上可能打开更优优化路径，但尚未证明该路径能够稳定
> 被不同随机种子找到。

### 4.5 路由诊断

下表为启发式 collapse detector 在三个 seed 上触发的次数。Expert 列按
Fine/Mid/Coarse 表示。

| Point | 模型 | Scale collapse | Route Gate collapse | Expert collapse F/M/C |
|---|---|---:|---:|---:|
| P1 | Full | 0/3 | 2/3 | 0/0/0 |
| P1 | V17.2 | 2/3 | 3/3 | 1/2/1 |
| P2 | Full | 0/3 | 2/3 | 0/0/0 |
| P2 | V17.2 | 0/3 | 2/3 | 0/0/0 |
| P3 | Full | 1/3 | 3/3 | 2/1/2 |

这些阈值是诊断工具，不是模型正确性的硬判据，但它说明删除 Adapter 没有
消除路由塌缩：

- P1 的 Scale/Expert/Route Gate 塌缩比 Full 更频繁；
- P3 的 Scale collapse 减少，但 Mid Expert 和 Route Gate 仍高度集中；
- P2 保持最健康、最稳定的多专家使用；
- P4 的专家使用总体改善，但 Route Gate 在一个 seed 上出现塌缩。

P1/P3 的 seed 波动与路由吸引域差异相符，后续应把确定性复现和路由稳定性
一起检查。

## 7. 结论与下一步

### 7.1 当前结论

V17.2 的三 seed clean 实验给出“总体正向但未完全稳定”的结果：

1. 整体 MAE/RMSE 分别改善 3.08%/3.17%，均为 8/12 获胜；
2. P4 CHAP 达到 3/3 稳定改善，是删除 Adapter 最可靠的正向证据；
3. P2 BikeNYC 保持稳定并小幅改善；
4. P1 TaxiBJ random 对 seed 敏感，存在一次 13.11% 退化；
5. P3 TaxiBJ fixed 平均改善，但只有 1/3 获胜，没有复现旧 E1 的
   `3/3` 稳定修复；
6. 删除 Adapter 没有解决 Route Gate 和 Expert collapse。

因此目前不宜写成“V17.2 已稳定优于 V17”，更准确的论文表述应是：

> Adapter-Free 结构在总体误差和 CHAP 上表现出明确收益，同时降低 6,384
> 个参数；但 TaxiBJ 的收益仍依赖优化轨迹，需要在确定性、clean 配对基线
> 下进一步验证。

### 7.2 建议执行顺序

1. 暂缓把 24 点 Stage 2 直接作为最终论文全量实验；
2. 增加可配置的 deterministic 训练模式，包括 CUDA/CuDNN 确定性设置；
3. 使用同一 clean commit、同一 Mask、同一 deterministic 配置，重新成对
   训练 Full V17 与 V17.2；
4. 优先复核 P3 的 seeds 2026/3407，以及 P1 的 seed3407；
5. baseline manifest 应拒绝 `git_dirty=true` 的历史 Full run；
6. 若 clean 配对后 P3 达到平均改善超过 1% 且至少 2/3 seeds 获胜，再进入
   24 点全量实验；
7. 全量阶段继续报告 MAE/RMSE mean±std，不使用 MAPE 作为主结论。

一句话结论：

> **V17.2 值得继续验证，CHAP/BikeNYC 结果支持该方向，但 TaxiBJ 尤其 P3
> 尚未通过预设稳定性门槛；在补齐 deterministic clean 配对前，不建议直接
> 宣布其为最终主力版本。**
