# 20260709_第8版_v8难度感知模型实验结果分析

## 1. 实验目的与设置

本报告汇总第八版 `v8-single` 模型在三个数据集上的完整实验结果。第八版的核心目标是在不改变整体多尺度 MoE 主干训练流程的基础上，引入“缺失难度感知”的显式描述符，让路由器能够同时参考原有质量统计、尺度嵌入、特征表示以及样本级缺失难度，从而改善不同缺失模式和缺失率下的专家选择。

本次解析的实验覆盖：

- 数据集：TaxiBJ、BikeNYC、CHAP_Beijing。
- 缺失模式：fixed、random。
- 缺失率：0.2、0.4、0.6、0.8。
- 随机种子：42。
- 模型版本：`v8-single`，实验族为 `full/model`。
- 输出根目录：`outputs/v8-single`。

训练策略来自 `configs/policies/full_model_paper.json`，并由 `configs/v8-single/*.json` 覆盖模型结构配置。整体训练流程为：多轮训练，按 `val_epoch` 定期验证；验证集 MAE 更优时覆盖保存 `checkpoints/best.pt`；训练结束或 early stopping 后加载最佳 checkpoint，在测试集上执行一次最终测试。

| 数据集 | batch size | 最大 epoch | val_epoch | early stopping | 学习率 | 调度器 |
|---|---:|---:|---:|---|---:|---|
| TaxiBJ | 32 | 160 | 5 | val_mae, patience=8 | 0.001 | cosine |
| BikeNYC | 16 | 140 | 2 | val_mae, patience=12 | 0.001 | cosine |
| CHAP_Beijing | 32 | 150 | 5 | val_mae, patience=8 | 0.001 | cosine |

本次所有组合均存在 `metrics.jsonl`、`test.log` 和 `checkpoints/best.pt`。部分实验 epoch 数少于最大 epoch，是 early stopping 正常提前停止，不是训练失败。

## 2. 最新模型结构

### 2.1 整体流程

第八版模型入口仍然是 `DualBranchSTImputer`。输入 batch 包含细尺度观测 `x_f_obs/m_f`、中尺度观测 `x_m_obs/m_m`、粗尺度观测 `x_c_obs/m_c`，以及细尺度真值 `x_f_gt`。模型主干根据 `model.main.architecture = "v8_difficulty_mr_moe"` 选择 `V8DifficultyMRMoEBackbone`，该类目前是对 `MultiScaleMoEBackbone` 的命名版本封装，实际结构逻辑在主干中完成。

模型输出包括：

- `x_hat_main`：主干在细尺度上的补全结果；
- `x_hat_final`：最终用于计算指标和测试的输出，本轮实验中 auxiliary branch 未启用，因此等于 `x_hat_main`；
- `x_comp`：观测位置使用原值、缺失位置使用预测值的补全结果；
- `gates`、`selected_masks`、`diagnostics`：专家路由、尺度融合和难度诊断信息。

### 2.2 多尺度表示与共享/路由双分支

模型先用三个 `ScaleTokenEncoder` 分别编码 fine/mid/coarse 三个尺度。TaxiBJ 当前配置使用 `fine_mid`，BikeNYC 和 CHAP_Beijing 使用 `fine_mid_coarse`。

主干保留之前版本的两条核心路径：

1. 共享跨尺度分支：通过 `GatedCrossScaleSharedExpert` 聚合不同尺度信息，并结合尺度可靠性门控。
2. 路由专家分支：通过 `TopKRoutedExpertPool` 对每个样本选择 top-k 专家。本轮配置为 `num_experts=4`、`top_k=2`，专家池在不同尺度之间共享。

最后通过 `SharedRoutedResidualFusion` 融合共享分支和路由分支。当前配置中共享分支和路由分支均启用，分支辅助损失和互补损失也启用。

### 2.3 第八版新增：难度描述符

第八版新增 `DifficultyDescriptor`，先从每个样本、每个尺度上计算 9 个显式难度统计量：

| 序号 | 统计量 | 含义 |
|---:|---|---|
| 1 | missing_rate | 缺失比例 |
| 2 | observed_ratio | 观测比例 |
| 3 | temporal_gap_score | 连续时间缺失强度 |
| 4 | spatial_block_score | 空间块状缺失强度 |
| 5 | neighbor_density | 缺失点周围观测邻居密度 |
| 6 | local_value_variance | 观测值局部/整体方差 |
| 7 | temporal_variance | 时间变化强度 |
| 8 | scale_reliability | 当前尺度可靠性 |
| 9 | cross_scale_consistency | 跨尺度一致性 |

这些原始统计量经过一个小型 MLP 投影为 `difficulty_dim=16` 的难度向量。为了避免训练开始时完全压制原有路由，第八版采用“描述符正常初始化、难度路由残差零初始化”的方式：难度描述符本身可以学习有效表征，但路由器的难度残差初始为 0，使初始路由行为与原始 QualityRouter 保持一致，然后在训练中逐渐学习难度条件。

### 2.4 第八版新增：难度感知路由器

原始路由器 `QualityRouter` 使用：

- 当前尺度特征全局池化；
- 观测质量统计 `q`；
- 尺度 embedding。

第八版新增 `DifficultyAwareRouter`，在原始 logits 的基础上加入由难度向量产生的残差 logits：

```text
base_logits = QualityRouter(h, q, scale_embed)
difficulty_logits = MLP(difficulty)
logits = base_logits + difficulty_logits
gate = softmax(logits)
```

正式配置中 `difficulty_router_mode = "hybrid"`，即保留原质量路由，同时增加难度残差。相关消融配置也已经保留在 `configs/v8-single/ablations/` 中，包括关闭难度、仅难度路由、关闭空间块统计、关闭跨尺度一致性等。

### 2.5 损失函数与指标

训练主损失仍在缺失位置计算，使用 `smooth_l1`。完整损失由以下部分组成：

- `l_main`：主输出在缺失位置的重建损失；
- `l_cross`：跨尺度一致性辅助损失；
- `l_importance_balance` / `l_load_balance`：MoE 专家重要性与负载均衡；
- `l_shared_aux` / `l_route_aux`：共享分支和路由分支辅助预测损失；
- `l_complementary`：共享特征与路由特征的互补约束；
- `l_final`：当前权重为 0，因此不额外加入最终输出损失。

评估指标为缺失位置上的 MAE、RMSE、MAPE 等。本报告以 MAE 和 RMSE 为主要指标。TaxiBJ 和 BikeNYC 的 MAPE 在日志中非常大，主要因为数据中存在 0 或接近 0 的真实值，分母过小会导致 MAPE 爆炸，因此不建议在论文主表中使用 MAPE 作为核心比较指标。

## 4. 简单结果分析

### 4.1 数据集整体难度

从绝对指标看，三个数据集的数值尺度不同，不能直接跨数据集比较 MAE 大小。就各自趋势而言：

- TaxiBJ 的 random 高缺失率明显更难，0.6 和 0.8 下测试 MAE 分别升至 11.4304 和 12.8207，RMSE 也升到 18.8727 和 21.3709。
- BikeNYC 的 fixed 表现呈现非单调趋势，0.6 反而是最优点；random 模式整体比 fixed 更差，且 RMSE 始终偏高。
- CHAP_Beijing 整体最稳定，fixed 和 random 的平均 MAE 接近，random 平均 MAE 甚至略低于 fixed，但 0.8 仍然是最难设置之一。

### 4.2 fixed 与 random 的差异

TaxiBJ 和 BikeNYC 上，fixed 的平均表现优于 random。尤其 TaxiBJ，fixed 平均 MAE 为 9.0067，而 random 平均 MAE 为 10.7070，说明随机空间缺失对该模型更具挑战性；这可能是因为 random 缺失破坏了更多局部邻域结构，使难度描述符中的邻居密度、时间变化和跨尺度一致性更难稳定利用。

CHAP_Beijing 上 fixed/random 差异较小。random 平均 MAE=0.6709，fixed 平均 MAE=0.6884，差距不大。从日志看，CHAP 的验证曲线大多持续下降到较晚 epoch，说明模型在该数据集上训练稳定，且对缺失模式不太敏感。

### 4.3 缺失率敏感性

TaxiBJ random 符合直觉：缺失率越高，测试 MAE 越大。fixed 则出现 0.8 优于 0.4 的非单调现象，这更像是固定空间 mask 的具体位置影响了难度，而不只是缺失率本身。固定 mask 下，如果缺失位置相对更容易被周边时空信息恢复，高缺失率也可能不一定产生更差 MAE。

BikeNYC fixed 也明显非单调：0.6 最好，0.2 最差。这说明 BikeNYC 的固定 mask 采样位置可能对结果影响较大。后续若用于论文，应考虑多 seed mask 或多次 fixed mask 重复实验，避免单个固定 mask 偶然性影响结论。

CHAP_Beijing 在 fixed 0.6 达到最好结果，random 则随缺失率升高略有变差，但整体变化幅度小于 TaxiBJ。

### 4.4 验证集与测试集一致性

大部分组合中，best val MAE 与最终 test MAE 排名方向基本一致。例如 TaxiBJ random 0.8 的 best val MAE 和 test MAE 都是该数据集 random 中最高；CHAP fixed 0.6 在验证和测试上均较优。个别非单调组合更可能来自 mask 位置和数据分布差异，而不是训练流程异常。

### 4.5 指标质量

所有 full 组合的 MAE/RMSE 均为有效数值，没有发现 NaN/Inf。MAPE 在 TaxiBJ 和 BikeNYC 上异常巨大，不适合用于主要结论。建议论文主表报告 MAE 和 RMSE；MAPE 如果保留，需要明确说明零值影响，或者改用带阈值过滤的 MAPE / sMAPE / NMAE。

## 5. 各数据集训练过程趋势

### 5.1 TaxiBJ

TaxiBJ 训练整体呈持续下降趋势，fixed 四个缺失率全部跑满 160 epoch，best epoch 集中在 150--160，说明 fixed 模式下模型仍在后期继续获得收益，未出现明显早期过拟合。

fixed 训练趋势：

- rate 0.2：train loss 从 81.4412 降到 7.9601，val MAE 从 23.5193 降到 9.0169，best epoch=155，test MAE=8.8876。
- rate 0.4：train loss 从 92.3035 降到 9.8933，best epoch=155，test MAE=9.7025。
- rate 0.6：train loss 从 92.2871 降到 10.5635，best epoch=160，test MAE=8.8356。
- rate 0.8：train loss 从 86.1164 降到 9.9348，best epoch=150，test MAE=8.6012。

fixed 下虽然训练损失随缺失率变化不完全单调，但验证 MAE 后期仍持续改善，说明当前训练轮数对 TaxiBJ fixed 是必要的。

random 训练趋势：

- rate 0.2：跑满 160 epoch，best epoch=155，test MAE=8.5245，是 TaxiBJ 最优结果。
- rate 0.4：跑满 160 epoch，best epoch=125，test MAE=10.0523。
- rate 0.6：early stopping 于 105 epoch，best epoch=65，test MAE=11.4304。
- rate 0.8：early stopping 于 130 epoch，best epoch=90，test MAE=12.8207。

random 高缺失率下 best epoch 明显提前，且后期验证集不再改善，说明模型在高随机缺失下更容易进入平台期或轻微过拟合。第八版难度路由虽然能完成训练并获得有效结果，但 TaxiBJ random 0.6/0.8 仍是当前最需要重点优化的场景。

### 5.2 BikeNYC

BikeNYC 的训练曲线整体下降明显，但 early stopping 更频繁。除 fixed 0.2 和 fixed 0.6 跑满 140 epoch 外，其余多数设置提前停止。结合 best epoch 分布看，BikeNYC 在 68--130 epoch 间已经达到最佳验证 MAE。

fixed 训练趋势：

- rate 0.2：train loss 从 9.7220 降到 1.9316，best epoch=122，test MAE=2.5272。
- rate 0.4：early stopping 于 132 epoch，best epoch=108，test MAE=1.7318。
- rate 0.6：跑满 140 epoch，best epoch=130，test MAE=1.4957，是 BikeNYC 最优结果。
- rate 0.8：early stopping 于 106 epoch，best epoch=82，test MAE=1.8362。

fixed 0.2 的误差反而最大，说明该固定 mask 的缺失位置可能覆盖了更难恢复的关键区域；这类现象在论文中需要谨慎解释。

random 训练趋势：

- rate 0.2：early stopping 于 128 epoch，best epoch=104，test MAE=2.0310。
- rate 0.4：early stopping 于 92 epoch，best epoch=68，test MAE=1.9909。
- rate 0.6：early stopping 于 98 epoch，best epoch=74，test MAE=2.0671。
- rate 0.8：early stopping 于 104 epoch，best epoch=80，test MAE=2.1188。

random 下 test MAE 变化幅度小，但 RMSE 始终在 5.8449--6.3929 之间，说明少数大误差样本对平方误差影响较大。BikeNYC 的后续分析建议增加误差空间分布图，判断是否存在局部热点区域补全困难。

### 5.3 CHAP_Beijing

CHAP_Beijing 是三组中训练最稳定的数据集。除 fixed 0.4 early stopping 于 120 epoch 外，其余组合全部跑满 150 epoch。best epoch 多集中在 125--150，验证 MAE 后期仍在改善。

fixed 训练趋势：

- rate 0.2：train loss 从 23.1918 降到 0.9025，best epoch=125，test MAE=0.6997。
- rate 0.4：early stopping 于 120 epoch，best epoch=80，test MAE=0.7134。
- rate 0.6：train loss 从 23.5434 降到 0.9199，best epoch=140，test MAE=0.6230，是 CHAP 最优结果。
- rate 0.8：train loss 从 23.2808 降到 0.9869，best epoch=150，test MAE=0.7176。

random 训练趋势：

- rate 0.2：best epoch=140，test MAE=0.6413。
- rate 0.4：best epoch=140，test MAE=0.6408。
- rate 0.6：best epoch=130，test MAE=0.6740。
- rate 0.8：best epoch=150，test MAE=0.7276。

CHAP 的 random 0.2/0.4 表现非常接近，说明低到中等随机缺失下模型已经能较好利用时空上下文。random 0.8 出现明显变差，但幅度仍小于 TaxiBJ random 高缺失率。

## 7. 结论与下一步

第八版 `v8-single` 已经完成三个数据集、两种缺失模式、四个缺失率的完整实验闭环，训练策略、验证策略、最佳 checkpoint 保存和最终测试流程均正常工作。从结果看，难度感知路由版本在 CHAP_Beijing 上表现稳定，在 TaxiBJ fixed 上后期持续改善，在 BikeNYC 和 TaxiBJ random 高缺失率下仍存在明显优化空间。

面向论文实验，建议下一步：

1. 主表优先报告 MAE 和 RMSE，不建议把 TaxiBJ/BikeNYC 的 MAPE 作为核心指标。
2. 对 fixed mask 的非单调结果增加多 seed mask 实验，尤其是 TaxiBJ fixed 和 BikeNYC fixed。
3. 对 TaxiBJ random 0.6/0.8 做重点误差分析，查看空间热点区域或时间段是否导致高 RMSE。
4. 后续补充 v8 消融实验：无难度路由、仅难度路由、无空间块统计、无跨尺度一致性，用于证明第八版新增模块的贡献。
5. 如果论文时间允许，建议对核心设置做 3 个随机种子并报告 mean/std，使结论更稳健。
