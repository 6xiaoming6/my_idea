## 1. 实验具体做法与复现信息

### 1.1 每组实验做了什么

| 实验 | 对照 | 实际做法 | 验证问题 |
| --- | --- | --- | --- |
| R1 | N3（seed7） | 共享四轮八专家 Top-2，单尺度；模型和 loader seed 改为17，mask seed不变 | 单尺度 CoE 的训练种子稳定性 |

| R5 | N5、N6 | seed7；前8epoch每窗口等概率选 CCFF/FCCF，之后 CCFF；评估始终 CCFF；无可学习尺度头 | 早期路径扰动是否足以改善泛化 |

| R9 | N3、N7、R8 | seed7；仅读取最近一份更早历史，保留门控 | 短历史是否优于全历史检索 |

C 表示空间16×16，F表示32×32，时间长度均为12。这里的“四轮”是一次模型前向中的专家执行轮次，和训练 epoch 不同。

参考组：N2为四层独立八专家 Top-2；N3为四轮共享八专家 Top-2；N5为 N3＋固定 CCFF；N6为 N3＋严格两粗两细的学习尺度选择；N7为 N3＋内容注意力历史检索。五组均为已有 seed7 检查点，本轮只补评估，没有重新训练。

### 1.2 共同模型与训练设置

输入为 `[B,2,12,32,32]`，隐藏维度64，专家池为 T/S/TD/SD/TA/ST/TL/SL。每轮每个窗口只执行选中的两个专家；R6每层独立专家池，其余 R 组共享专家参数。Router 读取动态状态，专家也处理动态状态；默认按照原生个体 logits 选 Top-2，组内 softmax 得到融合权重。R10仅替换硬选择规则。

初始化和状态投影接收可见输入、mask及已有支撑/位置特征。每轮采用 `direct` 状态更新：融合专家输出直接成为下一轮隐藏状态；`completion_feedback=false`，不将逐轮解码结果回写为新的补全输入。最终解码得到补全预测。R8/R9会先修正专家输入，构成额外历史路径；因此不能把它们描述为完全没有跨轮跳接的基准。

关闭 partner routing、acceptance、repair acceptance、previous expert context、global route weights、router input noise、专家软预热、pair dense warmup、局部 C3 路由及额外辅助分支。`use_shared=false` 指额外共享分支关闭，和 `expert_sharing=shared` 的跨轮专家参数共享不是同一开关。

训练：GPU0单卡串行；batch_size=32；100 epoch；每5epoch验证；不早停。AdamW，lr=1e-3，余弦下降至3e-4，100epoch到达下限；weight_decay=1e-4（按现有参数分组），grad_clip_norm=1.0，AMP开启。任务损失为 L1，加0.01倍 candidate 均衡损失；中间监督和 z-loss 系数均为0，不新增尺度、历史或组合辅助损失。

只按同分布验证 MAE 选择 `best.pth`，测试统一读取这个检查点；`last.pth` 保存第100epoch及优化器、调度器、AMP scaler、随机状态、训练状态。未见缺失测试不参与 best 选择。报告不把 best 与 last 的指标混在一起。

训练数据沿用 `data/TaxiBJ/v24_clean_abc_20260917/` 的时间切分。训练4种基础缺失：random_point、node_outage、temporal_gap、spatial_region，按均衡分配使用；每个窗口属于一种基础类型，每epoch重新构造训练 mask。它不是此前九种混合缺失训练。验证固定为相同4类。三元/两元组合则在同一个窗口内组合缺失结构。

模型 seed 与 loader seed：R1–R3为17，其余为7；mask seed保持20260917，因此换训练种子的对照不同时换数据缺失条件。R5另有独立路径扰动随机流。

### 1.3 各模块的实际实现

**R1、R2、R3：种子复现。** 对应 N3/N5/N6，仅修改模型种子、loader种子及实验元数据。N3/R1全程在 F 执行；N5/R2固定 CCFF；N6/R3每轮尺度头读取当前路由特征和预算，屏蔽会违反“两粗两细”的选项。

**共同尺度执行。** 粗尺度将隐藏表示、观测支撑和位置特征池化；观测值采用 mask 加权池化，观测覆盖率保留为分数。空池化单元使用已有初始估计作占位，并不把预测当成新观测。只在选中尺度上执行两个专家，粗输出再上采样至细网格后向后传递。`data.multiscale=false` 和旧 `main.use_multiscale=false` 不代表这些组未使用尺度模块；实际开关在 `model.coe.spatial_scale`。

**R4：固定路径＋代理梯度。** 使用与 N6 相同的尺度概率和剩余预算特征，但硬选择强制 CCFF。训练系数为 `hard + p - stop_gradient(p)`，前向仍为硬路径，反向允许尺度头及其上游接收代理梯度。只运行已选尺度，因此这个梯度并不是执行两个尺度后计算出的真实损失差。

**R5：早期尺度路径扰动。** 第1–8epoch每窗口以1/2概率选 CCFF或FCCF；第9–100epoch固定 CCFF；所有验证/测试均 CCFF。不学习尺度分数；预留的尺度头被冻结。独立 CPU 随机流 seed=20260930，随机状态存入检查点，不消耗 mask 或 loader 的随机序列。两种路径都严格两粗两细，仍每轮两个专家，不是激活全部专家的软预热。

**R6：独立专家＋尺度。** N2的四层独立专家池，执行路径固定 CCFF；其他共享训练条件不变。它用于检验尺度收益是否依赖专家共享，不能与共享 CoE 宣称严格等参数。

**R7：自由尺度。** 每轮独立尺度头读取当前路由特征、已用粗尺度轮数比例及剩余轮数比例；无粗细配额和候选屏蔽。输出层零初始化，加1e-3先验使初始硬路径为 CCFF。允许全部16条尺度路径，使用相同选中分支直通梯度，不加尺度均衡或计算惩罚。

尺度面积代理预算为 `2 × [(4−n_C)+n_C/4] = 8−1.5n_C`，两粗两细为5，全细为8。它只表示专家处理空间网格的相对面积，不等同于精确 FLOPs、实际耗时或显存；不同专家和尺度处理本身都有不同开销。

**R8、R9：历史读取。** 进入第r轮时，当前状态为 H(r−1)，历史可读 H0…H(r−2)。R8对这些历史均匀平均；R9只读 H(r−2)。专家输入修正为 `H_current + g × (H_memory − H_current)`，g是零初始化的逐通道有符号 tanh 门控。Router仍读取原当前状态；历史不detach，梯度可跨轮传递；每次 forward 后清空历史，不跨batch共享。query/key模块保留但冻结。第一轮无历史修正。

**R10：跨方向组合约束。** 时间类 T/TD/TA/TL，空间类 S/SD/SL，ST可与其他任意专家搭配；共4×3＋7=19对。选合法组合中个体 logits 之和最高的一对；并列时优先保留合法原生 Top-2，否则按固定组合顺序。仍用原 logits 的组内 softmax；candidate均衡仍按原生候选机制计算，没有组合评分头、试运行或排名损失。

## 2. 实验具体结果

### 2.1 完整性与异常检查

R1–R10全部完成100epoch，每组20次验证，均为第一次 attempt 完成。十组各6套测试共60格结果齐全；五个旧模型各6套补充测试共30格齐全。best/last检查点均存在，实际加载核验 best epoch 与日志一致、last epoch=100、浮点模型参数有限、保存的训练恢复状态完整。旧参考检查点按自身配置加载，不把当前配置覆盖到旧模型上。

主任务 loss、MAE、RMSE及最终检查点未发现 NaN/Inf。存在AMP动态缩放跳步：各 R 组共10–12次/7700训练batch，约0.13%–0.16%；R9第2epoch日志有第3轮 Router 梯度范数 inf，训练随后继续并完成，没有主指标发散。不能把这些记录隐去并声称训练中完全没有数值溢出。

本轮 preflight 记录66项检查通过，包括旧 B/N 前向、旧mask兼容、检查点加载和batch32显存检查；这属于启动验收记录，不替代实验效果证据。MAPE受零/近零流量影响较大，本报告不据此排名。

## 3. 结果分析、结论与下一步建议

### 3.1 最值得继续的是R5：早期尺度路径变化＋固定推理

本轮最清楚的正面结果来自R5。相对固定CCFF的N5，其两元组合MAE从25.371降至15.613，降低38.46%；未见形态从28.262降至20.303，降低28.16%；三元组合从23.893降至14.928，降低37.52%。换mask种子后的两元和形态误差分别降低37.46%、29.66%，所以不是仅在原来一张测试mask上出现的收益。

代价是ID MAE从13.581升至14.325，恶化5.48%。应将它表述为明显的泛化收益与小幅ID代价，而不是“所有条件都超过固定多尺度”。相对之前的N6，R5六套总体MAE均更低：ID降低1.74%，两元2.18%，形态6.08%，三元3.24%，两套复测降低1.76%、7.17%。但这两个方法目前关键对比仍只有seed7，不能据此认定统计显著优于N6。

R5没有可学习尺度选择器，推理始终固定CCFF，训练/推理也没有增加专家数。因此实验已经支持：**获得这类OOD收益不以测试时动态选择尺度为必要条件。** 它没有证明所有自适应尺度路由都无用，也没有证明随机路径扰动就是唯一原因。

从细分类型看，改善集中在包含时间缺失的组合：时间＋空间MAE从N5的33.265降至17.672，节点＋时间从27.559降至13.653；节点＋空间则从15.300小幅变差至15.506。移动区域和多块也改善。也就是说，它并非均匀改善每一种缺失结构，应围绕组合缺失的特定失败模式继续解释。

可能解释是早期不同尺度顺序让共享专家见到不同中间表示，减少对单一处理顺序的依赖，随后固定路径完成专门优化。这是待验证的训练正则化假设；本轮没有表示相似度、敏感性或梯度干预证据，不能把解释当实测机制。

### 3.2 R4和R5区分了N6收益的两个可能来源

R4保留尺度头和代理梯度、禁止硬路径变化；R5去掉可学习尺度头、保留早期路径变化。结果R4六套总体MAE均差于N5：ID恶化5.02%，两元1.24%，形态3.30%，三元7.77%；它没有复现N6的大幅OOD收益。R5则在五套OOD总体指标上均为本轮最优。

这组对照更支持优先研究早期路径变化，而不是继续扩大尺度评分网络。不过它不是完美拆分：R5的CCFF/FCCF随机序列并不逐样本复制N6实际经历的早期路径；R4/R5的可训练参数和梯度通道也不同。因此严谨结论是“额外代理梯度单独没有复现收益，预设早期扰动已经能产生收益”，不是“N6收益已被唯一归因”。

R4/R5几乎相同的ID验证MAE还提醒我们：只监控ID验证曲线无法判断组合缺失泛化。当前最佳检查点仍应按预注册的ID规则选择，不应看到OOD结果后反选epoch。

### 3.3 固定多尺度有效，但学习尺度的种子稳定性不够

固定尺度相对同种子单尺度的ID改善在两个种子均存在：seed7 N5对N3降低20.67%；seed17 R2对R1降低13.53%。形态OOD分别降低16.59%、30.30%。这使“粗细尺度处理值得继续”比“动态尺度选择已经成功”更有依据。

两元组合则不完全一致：seed7 N5相对N3变差3.88%，seed17 R2相对R1改善12.91%。不能把固定多尺度说成所有OOD都稳定提高。

N6换seed后的R3出现明显变化：最终从CCFF锁定为CFFC，ID MAE14.579→23.113，两元15.960→26.258，形态21.616→30.684。对seed17固定尺度R2，R3的ID恶化54.45%，但两元、形态、三元仍分别改善12.49%、5.66%、13.30%。因此，原先泛化提升方向并非完全消失，但收益幅度和ID代价很不稳定。

CFFC末轮在粗网格执行并上采样，没有额外细尺度专家继续修复空间细节，这是R3变差的一种合理结构解释。要确认，需要同种子固定CFFC训练对照；现在不能仅凭相关性认定是末轮粗尺度造成退步。

基础N3本身也有强OOD种子差异：ID17.120→17.306只差约1.1%，但两元24.423→34.453，形态33.884→46.664。两套新mask复测仍保留这种排序，表明必须优先补训练种子，而不是用更多mask种子代替。

### 3.4 R6表明，多尺度收益不是共享CoE专属

R6相对独立单尺度N2，六套总体MAE都更好：ID降低10.82%，两元7.61%，形态14.42%，三元7.02%。其ID MAE13.296是本轮及五个参考模型中的最低值。多尺度本身适用于独立MoE，因此不能把尺度收益全部算成CoE独有贡献。

共享固定N5与独立固定R6也没有统一胜负：R6 ID低2.10%、形态低10.01%，但两元和三元分别差2.74%、8.53%。共享模型以更少参数保持竞争力是事实；“共享一定更强”并未成立。

当前缺少最关键一格：**独立MoE＋与R5完全相同的早期尺度扰动**。没有这格，就不能判断R5的巨大OOD增益是否依赖共享多轮，还是任何多层模型都能得到相同收益。

### 3.5 R7没有学出按样本分化的自由尺度路径

R7允许16种路径，实际第13epoch之后全为FFFF，所有测试集也100% FFFF。它主要变成了经历早期尺度变化的全细尺度模型，没有表现出原设想的“根据缺失需求逐轮选择不同尺度”。

相对固定N5，R7六套总体MAE均更差；ID差14.11%，形态差8.40%，同时使用更多网格计算。它相对单尺度N3仍改善ID和形态，但两元和三元更差，因此也不能简单说它完全无效。

选中分支直通梯度没有实际未选尺度的反事实损失，加之无成本惩罚，可能促使早期路径锁定或偏向细网格。但这只是实现相关的优化假设，不是代码错误或因果定论。当前证据不支持将自由尺度Top-1作为主线核心；也不应为了漂亮分布而强制粗细平均。

### 3.6 跨轮记忆仍有空间，最近历史比均匀历史更值得保留

R8相对N3的ID改善15.71%，但两元MAE恶化42.35%、三元恶化40.50%；时间＋空间高达54.855。它说明ID更好的历史汇总可以同时损害组合泛化。

R9相对N3的ID、两元、形态MAE分别改善14.13%、7.81%、3.79%；三元小幅变差0.73%。对完整内容检索N7，R9六套总体MAE均更低，说明目前没有证据表明复杂历史注意力是必要的。不过形态RMSE从N7的55.707变为R9的57.295，不能声称所有误差指标均胜出。

R8/R9门控绝对值大且有符号均值多为负。由于 `H_current + g(H_memory−H_current)` 在g<0时沿远离历史的方向外推，模型可能在利用跨轮差分，而不只是回忆历史内容。可将“最近状态差分/惯性更新”作为次优先级假设，先比较有符号门控与非负门控，不宜立刻增加更大注意力网络。

R5的OOD优势远大于R9，因此暂时把记忆方向作为辅助探索，避免立即堆叠R5＋R9后失去归因能力。

### 3.7 R10不支持继续重投入专家组合搜索

R10约束大量改变了原生选择，但相对N3只在ID和形态MAE上改善8.32%、4.28%；两元和三元反而恶化12.86%、21.51%。跨方向结构互补不等于实际补全任务中的功能互补。当前结果不支持把简单方向约束作为通用更优选择器，更不能据此证明“最佳组合优于原生Top-2”。

R5在第2/4轮几乎固定专家对却有很好的OOD总体成绩，也表明路由集中本身不是模型无效的充分证据。应把实际效果与算力作为判断依据，而不是单独追求较高路由熵。固定专家链是否能完全替代它，还需要独立对照。

### 3.8 目前支持什么，不支持什么

| 判断 | 当前证据 |
| --- | --- |
| 固定粗细尺度值得继续 | 支持：两个训练种子的ID/形态改善，独立MoE上也成立 |
| 早期尺度路径扰动能改善组合泛化 | 强单训练种子信号：R5五套OOD总体MAE/RMSE最低，需补训练种子 |
| 推理必须动态选尺度才能获得这些收益 | 当前不支持：固定推理的R5已取得收益 |
| 学习尺度路径稳定可靠 | 当前不支持：N6换种子变路径且ID大幅退步，R7全细 |
| R5是CoE独有收益 | 尚未证明：缺独立专家＋同样扰动 |
| 全历史内容检索优于最近历史 | 当前不支持，R9总体MAE更好但并非所有RMSE更好 |
| 跨方向强制配对普遍优于Top-2 | 当前不支持 |
| 本轮已确立新颖性/论文最终方法 | 尚不能：需要稳定性、适用边界及相关工作核查 |

边界：主要是一个数据集、一个缺失率；R4–R10仍只有一个训练seed。mask复测固定同一组时间窗口且同一模型，不是独立训练重复。训练程序耗时和面积代理不是严格FLOPs匹配；共享/独立也不是等参数。现有两元、三元、形态测试已被多轮探索使用，后续若据此选择设计，应将其视为研发验证证据，并预留未参与设计的新时间切分、数据集或缺失条件作为最终确认测试。

### 3.9 下一步建议：先检验一条可证伪的主线

建议暂定研究问题为：**多轮共享时空专家的尺度路径训练，能否在固定推理成本下改善未见组合缺失泛化？** 这是工作假设，不预先宣称“自适应路径已经学会缺失机理”。它把优先方向④多尺度和③泛化连接起来，并留下①跨轮处理作为可验证贡献。

1. **优先补R5训练种子。** 先R5 seed17，对照已有N5/R2；再用新seed27成对运行固定CCFF与早期扰动。保留全部同一评估协议，报告逐种子结果和差值。目标是确认当前大幅收益不是单次优化偶然。
2. **补独立专家＋早期扰动。** 与R6严格配对，形成共享/独立×固定/扰动的2×2设计。比较两种架构内的扰动收益，而不只比较四个绝对分数。若独立模型也同幅改善，应把贡献定位为通用尺度路径训练；若共享收益更强，再研究共享如何参与。
3. **分离路径顺序与扰动时机。** 稳定性确认后，比较固定FCCF、早期8epoch扰动、全程扰动、同扰动总量的后期扰动，其他条件一致。它们分别检验第二条路径本身、训练早期特殊性和“先变化后固定”的作用。固定CFFC是解释R3的次优先级对照，不能代替主线验证。
4. **围绕失败类型补机制证据。** 优先看时间＋空间、节点＋时间为何获益，而节点＋空间未获益；在相同窗口上比较逐轮误差、表示变化和对mask变化的敏感性。可增加固定专家链对照，判断R5收益是否仍需要动态专家选择。记录这些分析时不要重新用测试结果选择best。
5. **记忆只做小规模独立验证。** R9原有有符号门控 vs 非负门控，检验历史差分是否关键；有稳定独立增益后再与R5组合。R7自由尺度和R10组合约束暂不扩大搜索。

当前最值得投入的不是继续增加路由头，而是先确认R5这条具体、低额外成本、可以严格对照的正面结果是否可复现。若复现失败，及时收缩结论；若复现成立，再用2×2结构实验判断它能否支撑共享多轮CoE的论文主张。
