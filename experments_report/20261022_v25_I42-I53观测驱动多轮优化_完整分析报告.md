### 定版实现细节与复现映射

输入为 `[B,2,12,32,32]` 的 F、`[B,2,12,16,16]` 的 M、`[B,2,12,8,8]` 的 C；输出为同 F 尺寸的补全值。M/C 在完整 F 上分别求和构造后独立生成缺失掩码。训练/验证/测试为 2452/342/707 个既有窗口，不重新拼接连续时间线。三尺度共用编码器并融合 H0，保留原学习分配投影和可见 F 回填。

除 I42/I53 固定 MMFF 外，其余组前三轮自由选尺度、第四轮固定 F。八种专家 T/S/TD/SD/TA/ST/TL/SL 跨轮共享，每轮只执行原生 Top-2，所有评估每窗口实测调用数均为 8。I48/I51 串行执行已选两个专家，增加临时解码和观测残差计算，调用数相等不表示计算量相等。

I43 当前预测逐轮刷新后，专家路由读取选中尺度融合输入。I44 将绝对观测注入替换为 F→M→C 去重区域的剩余观测差异；F 单点、M 扣可见 F、C 扣可见 M 及其他可见 F，消息为区域剩余预算与当前预测和之差除未知格点数。I45 用归一化残差绝对均值、RMS、覆盖率、自由度比例增强路由，尺度偏置头 12→16→3、专家偏置头 4→16→8，共享且末层零初始化。

I46 将预测差分分为区域总量与细节，按观测残差下降比例抑制总量消息，经 2C→32→64 映射和 0.1 倍隐藏 RMS 上限注入，替换原差分。I47 读取历史后减当前预测，去区域均值和最近细节变化的平行分量；零消息严格零注入。历史池保留原写入时机和 detach。I49 的 M/C 更新仅覆盖各物理通道区域归属交集的隐藏均值分量，区域外/细节保留；交集为空时仍执行专家但不改状态。

I50 是预先冻结的 I45＋I46 新差分＋I47 新历史；I51 再加串行双专家与区域状态更新。组合不是根据本批测试后临时调整。I52 为原 I37 seed17，I53 实际为 I42 seed17。I45/I46 等没有 seed17 配对复验，不能把 I53 当作这些新机制的复验。

AdamW：lr=1e-3，weight_decay=1e-4，grad_clip_norm=1；100 epoch 余弦至 3e-4；batch32，GPU1，AMP，严格重放设置，2 个 CPU 数值计算线程，num_workers=0。参考 I37 使用同一训练预算和数据协议。参数量相同不意味着可训练参数相同：固定路径冻结尺度头，详见成本表。

训练 mask 基种子 20260917，每 epoch 重采样；四族为 random_point/node_outage/temporal_gap/spatial_region，率均为0.4。ID验证固定 mask，只按 MAE 选 best。开发协议在验证窗口使用新 mask 基种子2026101701–2026101706；先冻结 I53 选择，再开放原测试协议。新 mask 确认协议沿用这些新基种子，在测试窗口评估，仅是 mask 确认。split 偏移由冻结加载器自动处理。

损失：投影前/后 F 缺失 L1 各0.5；投影前可见 F 重建0.1；投影前回填可见 F 后聚合得到的可见 M/C 一致性 L1 为0.1，按面积归一化、两尺度平均；候选均衡0.01。完整 M/C 标签不作为一致性监督。

### 核验后的具体结论与机制解释

**本轮没有找到在seed7上满足ID代价≤3%、OOD等权相对MAE改善≥3%、最差类别退步≤5%的新候选。** I45/I46/I48有ID收益，但不能以ID结果替代综合结论。I37 seed7仍是本批综合参考；seed17的明显退步则表明原I37还不能称为稳定的最终模型。

1. **I46是ID最好的新模型，但不是综合胜者。** ID测试7.6201比I37降低5.35%，三类OOD相对比值平均却退步84.68%。相对直接对照I44，I46同时改善ID（5.12%）和OOD（13.92%），所以新差分在这套残差输入骨干上有局部价值；仍无法证明把它加入原I37就会改善泛化。I46不是“原I37只换差分”，还继承I43/I44的输入和路由变化。
2. **I45路由证据也有局部收益。** 相对I44，ID改善4.55%，OOD比值平均改善11.49%；相对原I37，OOD仍退步87.45%。它在多套协议均选FMFF，残差驱动路由没有表现为按样本、按未解决问题自适应切换尺度，不能仅凭设计动机声称完成了这项机制。
3. **最大泛化代价来自含时间缺失的组合及移动区域。** I46的node+space为7.6365，优于I37的8.2945；time+space却从9.7576升至24.0492，moving_region从11.0036升至27.2222。I48的time+space达到51.7995、moving_region42.0696。部分空间组合能保留收益，说明不是所有OOD条件一律失效；需重点验证时间连续性线索不足时的预测补位反馈和专家交互。
4. **I43/I44不是可直接保留的数据流改良。** I43相比I37的ID退步15.18%、OOD退步68.81%。I44恢复了ID，但相对I43的OOD再退步27.76%。残差输入有助于拟合训练分布，不等于对未见观测布局稳定。合理假设是：当前预测参与消息构造后，预测偏差会改变后续输入；训练中学到的修正规律在含时间缺失组合中失配。该假设尚需只开“刷新补位”或只改“路由输入位置”的独立对照验证。
5. **投影仍在修正，退步在投影前已经存在。** 未见形态中I37原始MAE13.4917、投影后10.8212；I46为27.7676→22.9085；I48为57.6983→32.6226。投影对三者均有实测收益，且可见M/C总量残差接近零，说明不能把本批泛化失败归咎于投影不满足总量约束。总量校正只能约束部分区域，无法凭总量恢复正确局部形状和时间关系。
6. **无粗尺度约束的区域尤其脆弱，但受约束区域也变差。** 第一套未见形态中I46的无约束区域MAE39.5919，I37为18.9726；受约束区域18.3707，I37为8.6040。I48无约束区域更达到69.0409。不能只展示可见观测残差变小，而忽略缺失真值的区域分解误差。
