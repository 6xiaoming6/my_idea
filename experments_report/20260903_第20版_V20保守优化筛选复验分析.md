# 20260903_第20版_V20保守优化筛选复验分析

## 1. 实验目的与设置

本轮实验用于检验“保守接纳”优化后的 V20 是否超过 V14。对照使用已完成的 `v20_vs_v14_screening` V14 结果，新实验只重新训练 V20，数据集、缺失设置、随机种子和评价流程与对照保持一致。

- 随机种子：42。
- 筛选点：TaxiBJ 4 点、BikeNYC 2 点、CHAP 2 点，共 8 点。
- TaxiBJ：160 epoch，batch size 32，每 5 epoch 验证。
- BikeNYC：140 epoch，batch size 16，每 2 epoch 验证。
- CHAP：150 epoch，batch size 32，每 5 epoch 验证。
- checkpoint 策略：只保存验证 MAE 最低的 `best.pt`，训练完成后加载该 checkpoint 运行一次测试集。
- 完整性：8/8 组实验完成，8/8 存在最佳 checkpoint 和测试记录，未发现 NaN/Inf。

## 2. 最新 V20 模型结构与数据流

### 2.1 V14 主体

V20 以 `V14SafeC2FMoE` 为主体。输入是细、中、粗三个尺度的观测值、二值 mask 和池化可靠性。三尺度编码后，质量路由器产生专家先验概率，Top-K 专家分支与跨尺度共享分支融合，再经由粗到细的残差精炼器和安全控制门生成最终填补值。

V14 的最终残差校正使用动态 `alpha_mid` / `alpha_fine` / `alpha_final`，并结合缺失难度、观测区一致性、尺度可靠性及几何描述符。训练损失包含主输出损失、V14 base/mid/coarse 辅助监督、regret 约束和 gate 正则。

### 2.2 V20 Geometry Probe

V20 在 V14 之上增加自验证专家路由：

1. 只从已观测位置中选择 Probe，使 Probe 的空间局部、大范围空间、时间邻域和可靠性描述符尽量匹配真实缺失区。
2. 将 Probe 位置从当前样本中临时隐藏，所有专家参加现场预测，共享 Probe decoder 估计每个专家的误差。
3. 误差经归一化和 softmax 转为能力分布。保守优化版仅允许 Fine Probe 成为路由证据，Mid/Coarse 只保留损失和诊断。
4. 能力分布确定性低于 0.02 时拒绝证据，0.02–0.08 之间线性提高强度，最大 eta 为 0.25。
5. 融合使用“均匀能力分布为零证据”的中性乘法校正，理论上无信息 Probe 不改变 V14 先验。

训练态中 `apply_evidence_during_training=false`，Probe 损失权重为 0.05，Probe 特征和路由证据均 detach，Probe 参数还与 V14 主干分组裁剪。设计意图是仅训练 Probe decoder，不改变 V14 主任务更新。

### 2.3 验证校准与测试

每次验证都比较 `eta={0, 0.05, 0.10, 0.15, 0.25}` 的验证 MAE，为当前 epoch 选择最佳 eta。`eta=0` 是完全不接纳 Probe 路由修正的回退项。验证 MAE 最优的 epoch 与 eta 被写入 checkpoint 和 `effective_config.json`，最后测试仅加载这一个最佳状态。

### 3.3 与原始 V20 对比

保守优化相对原始 V20 在 6/8 个点上降低 MAE，其中 CHAP random@0.4 改善 37.85%；但 TaxiBJ fixed@0.4 反而退化 12.00%，最终 8 点算术平均 MAE 由 6.723619 变为 6.770371，整体又退化 0.70%。因此保守策略减少了部分极端伤害，但没有解决根本问题。

## 4. 核心分析

### 4.1 结论：V20 没有超过 V14

V20 在 MAE 和 RMSE 上均为 0/8 胜点，整体 MAE 退化 24.37%，RMSE 退化 30.76%。当前优化版不能作为优于 V14 的新主版本，也不应继续直接扩展到 24 点或多随机种子正式实验。

### 4.2 eta 校准实际上没有起作用

最佳 checkpoint 的 Fine 尺度平均实际 eta 仅约 `6.5e-5–1.85e-3`，不同 eta 候选间的验证 MAE 差通常只有 `1e-7–1e-6`。全部训练过程中，单次 eta 选择带来的最大验证 MAE 改善也仅为 `6.24e-6`，这与最终 0.12–4.15 的 MAE 差距不在同一数量级。

最直接的证据是 CHAP fixed@0.4：验证选择 `eta=0`，即测试时完全不用 Probe 路由校正，但 MAE 仍由 V14 的 0.578687 恶化为 1.877026。所以退化不是“测试时 eta 选错”，而是 V20 训练后的 V14 主体已不同于原 V14。

### 4.3 训练路径仍未做到严格等价

从日志看，V14 和 V20 在第 1 epoch 已出现不同的训练 MAE，长时间优化后差异被进一步放大。从最新代码可见：

- V20 在 V14 主前向之前先运行三尺度 Probe 前向。
- 训练时虽然 eta 被置零，Fine routing evidence 字典仍传入主干，路由门仍执行一次 `softmax(log(prior))`，而不是直接返回原 prior。
- Probe loss 虽然 detach 了主干特征并使用独立梯度裁剪，但 Probe 计算仍插入在主前向与反向传播之间。

结合上述事实，当前最可疑的原因是：微小的数值路径、Top-K 路由边界及 CUDA 非完全确定性使 V20 没有复制 V14 的优化轨迹。这是有日志和代码支持的高优先级解释，但仍需用“同初始权重、同 batch、单步参数差”测试最终证实。

## 5. 各数据集训练趋势

### 5.1 TaxiBJ

- V20 四个点的训练 MAE 都持续下降，从约 67–79 降至 6.34–10.23；训练总损失分别由 105.83/128.06/118.15/122.83 降至 10.78/14.10/15.19/19.21，没有数值发散。
- 但 V20 最佳 epoch 均早于 V14：fixed@0.2 为 85 vs 120，fixed@0.4 为 130 vs 155，random@0.4 为 35 vs 70，random@0.8 为 110 vs 130。
- random@0.4 在 epoch 35 达到最佳验证 MAE 11.9439，训练结束时回升到 13.5944，有明显过拟合。fixed@0.2 和 random@0.8 也分别从最佳 8.6413/14.2660 回升到 9.6004/15.8099。
- fixed@0.4 退化最突出，测试 MAE/RMSE 分别较 V14 变差 51.16%/79.10%，显示该点的主体优化轨迹失效，不是微小接纳强度所能解释。

### 5.2 BikeNYC

- V20 fixed@0.6 训练 MAE 从 5.0562 降至 1.1529，random@0.4 从 6.5112 降至 1.3150；训练总损失分别由 7.38/9.57 降至 1.60/2.01，训练收敛较平稳。
- fixed@0.6 在 epoch 112 达到验证 MAE 1.3996，最后为 1.4044，仅有轻微回升；V14 则到 epoch 140 仍在改善。
- random@0.4 在 epoch 72 达到 2.0107，结束时为 2.0474，存在轻度过拟合。
- BikeNYC 是退化最小的数据集，但 MAE 仍在两点均退化，平均为 7.23%，不能视为与 V14 持平。

### 5.3 CHAP

- CHAP 暴露了最严重的训练问题。V20 fixed/random 的训练总损失由 31.12/31.11 降至 5.29/5.49，但 V14 fixed/random 分别在 epoch 150/145 达到最优，而 V20 在 epoch 20/40 就达到局部最佳。
- fixed@0.4 的验证 MAE 从最佳 1.8319 恶化至训练结束的 2.7144；random@0.4 从 1.2628 恶化至 4.1878，后期过拟合/优化偏移很强。
- V20 最终训练 MAE 为 1.3678/1.4416，明显高于 V14 的 0.8258/0.8261，说明不仅是泛化问题，训练集拟合程度本身也更差。
- fixed 最佳 eta 为 0，random 为 0.05 但实际平均 eta 仅 0.00185。所以 CHAP 的 127%–224% MAE 退化几乎全部来自主体训练差异。

MAPE 未作为本报告的主指标：这些时空流量/环境数据包含零值或近零值，MAPE 对分母极其敏感，不适合替代 MAE/RMSE 做版本选择。

## 7. 结论与下一步

1. 本轮 V20 保守优化未达到“优于 V14”的目标，且数值证据不支持继续扩大实验。
2. 下一步不应继续调 eta、Probe 比例或置信阈值；这些因子对当前输出的影响只有 `1e-6` 级别。
3. 应先实现并验证“严格 V14 训练等价”：训练态先完成无 routing evidence 的 V14 主前向，再计算 Probe loss；当 eta=0 时直接不构造/不传入 routing evidence。
4. 增加单步等价测试：相同初始参数、相同 batch 和随机状态下，比较 V14 与 V20 的主输出、Top-K 选择、主干梯度和一步 optimizer 后参数，必须达到逐项严格一致。
5. 只有在 eta=0 的完整训练能复现 V14 后，才有意义评估 Probe 是否在该锚点上产生真实增益。
