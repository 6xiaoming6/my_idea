# 20260918_v24_COE七组路由诊断结果分析

## 1. 实验目的、覆盖与重要更正

七组均完成 20 epoch、10 次验证和最终测试；best checkpoint 均存在，最佳 epoch 均为 20。已检查训练/验证/测试数值，无 NaN/Inf。全部为 TaxiBJ、seed 7、batch 16、学习率 0.001、cosine 20 epoch、AMP、关闭早停。训练/验证/测试分别 2452/342/707 窗口，测试缺失标签数均为 6,949,810。

三份 split 采用同分布九类 mask：random_point、node_outage、temporal_gap、spatial_region、spatiotemporal_block、stripe、moving_region、multi_block、composite，缺失率 0.4。每窗口一种族，族内可含复合模式；train 按 epoch 重采样，val/test 独立 seed 固定。所有组 data 配置一致。

**重要：R4 实际不是 R0＋噪声。** 保存的 plan.json、运行 config.json 和测试诊断一致表明：R4 为两层、T/S 两专家、lambda_coe_balance=0，同时开启前两层 0.1 相对尺度高斯噪声。R0 为四层六专家、balance=0.01。因此 R4 的误差和路由改善都不能归因于噪声单个变量。

根因已从生成器确认：build_experiment_plan.py 先用 experiments/full.json 覆盖基配置，再应用各组补丁。full.json 指定两层 T/S 且 balance=0；其他 route20 补丁显式恢复结构和损失，route20_noise.json 只写了噪声字段，未恢复这些设置。此前声称是严格单变量对照的说明不准确，已有测试只检查噪声字段，未检查与 R0 的结构/损失等价性。本报告保留原始结果，不更改训练配置或启动补跑。

## 2. 从代码核对的模型和训练流程

输入为 [B,2,12,32,32] 网格序列。原始观测、二值 mask、仅由观测 mask 计算的时空支持统计及位置编码进入编码器，隐藏维度 64。无多尺度分支，辅助残差分支关闭。每层根据当前隐藏状态、补全值、缺失支持和更新变化等窗口级统计独立路由；各层有独立 router，链路共享同一专家池。共享点级专家与路由专家产生残差更新，解码后保留原观测，进入下一层。

六专家为 T/S/TD/SD/TA/ST（时间、空间、膨胀时间、膨胀空间、时间注意力、时空专家）。训练硬路由使用直通 Gumbel 采样，但为了路由反传实际计算候选专家；推理确定性 argmax 并只分派选中专家。因此训练全选一个专家不会把四层六专家的训练计算自动缩成单专家。

主损失为人工缺失且真值有限位置的 L1。可学习四层组和两层三专家组增加 0.01 权重的逐层 batch 均衡项（层内 E·Σ负载比例·平均概率，然后层间取均值，负载 detach）；无中间监督、无 z-loss。固定组与实际噪声组 balance=0。每两 epoch 验证，以验证 MAE 选最佳 checkpoint 后测试。报告误差采用全缺失点累计 MAE/RMSE，不把按 batch 平均的 loss 当成同一统计量。MAPE 极大，受零/近零真值影响，不作主判据。

R1 的实际调度为 epoch 1–3 软路由，4–5 混合过渡，第 6 epoch 已达到完全硬路由；之后持续硬路由至 20。预热同时含均匀混合和采样温度调度，因此是整个探索调度方案的效果，不能归因于其中单个组件。

## 5. 缺失族与训练趋势

R1 的后层对不同 mask 族存在明显差异：random_point 第3层 100% ST；node_outage、spatial_region 第3层均约 84.8% SD；temporal_gap 第3层约 96.2% ST。第4层 node_outage/spatial_region/stripe 均为 100% ST，而 temporal_gap 约 98.7% TA，random_point 约 78.5% TA。这支持“存在与缺失条件相关的选择”，但仅凭路由频率不能证明每个专家在该模式上更优，需要同输入替换专家的反事实评估。族内固定选择也不应与跨所有条件都选同一专家混为一谈。

## 6. 结论和下一步

1. 优先方向是软预热/过渡探索：当前唯一同时改善第一层、后层分化并明显领先固定链的四层方案；仍须处理第2层集中。
2. 九类同分布缺失并不足以阻止硬路由塌缩；本轮各组数据完全相同而路由结果不同，说明优化和路由设置是重要因素，不能归咎于模式种类单一。也不能仅凭这一轮证明 mask 设计已无任何问题。
3. 高斯噪声结论待定：先修正 R4 最终生成配置，使其与 R0 仅相差噪声字段，并加入模型结构/损失的配对断言。另可为实际两层 T/S、balance=0 方案补一个无噪声对照，利用已有结果检验噪声效果。
4. 后续可验证 R1＋噪声，但应在噪声单变量补齐后进行。第2层集中未必都是有害，应评估第2层固定 TA 与可学习路由的精度差，再决定是否强制探索。
5. 固定链应继续作为参照；两层三专家当前版本不值得直接加长训练，先解决其 S→S 饱和。单 seed 的百分比是描述性结果，没有统计显著性结论。
