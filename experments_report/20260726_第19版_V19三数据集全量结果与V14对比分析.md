# 20260726_第19版_V19三数据集全量结果与V14对比分析

## 1. 实验目的与结果口径

本报告汇总 V19-single 在 TaxiBJ、BikeNYC、CHAP_Beijing 三个数据集上的全部正式实验，并重点回答：

1. V19 的 24 组正式实验是否完整、有效；
2. V19 在不同数据集、缺失模式和缺失率下的表现；
3. V19 相对直接基础版本 V14 是否真正取得提升；
4. 新增通道残差增益模块本身是否发挥作用；
5. V19 是否已经足够稳定，可以替代 V14 作为下一步主力版本。

用户问题最后写成了“和 V19 相比有没有提升”，同一版本无法进行自比较。因此本报告以 V19 的直接基础版本 V14 为主要对照，同时补充与上一阶段 V18 的比较，避免遗漏可能的原意。

### 1.1 实验覆盖

```text
3 个数据集
× 2 种缺失模式（fixed、random）
× 4 个缺失率（0.2、0.4、0.6、0.8）
= 24 组正式实验
```

所有实验均使用：

- 随机种子：42；
- GPU：NVIDIA GeForce RTX 3090；
- 单卡顺序训练；
- 原始数据范围上的 MAE、RMSE 和 MAPE；
- 缺失位置作为指标计算区域；
- 验证集 MAE 作为最佳 checkpoint 选择依据。

### 1.2 数据和训练设置

| 数据集 | 输入尺寸 | Train/Val/Test | Batch size | Epoch | Val interval | 主尺度 |
|---|---|---:|---:|---:|---:|---|
| TaxiBJ | `[B,2,12,32,32]` | 2491/356/712 | 32 | 160 | 5 | fine + mid |
| BikeNYC | `[B,2,12,24,12]` | 511/73/147 | 16 | 140 | 2 | fine + mid + coarse |
| CHAP_Beijing | `[B,1,7,32,32]` | 2626/322/322 | 32 | 150 | 5 | fine + mid + coarse |

共同训练策略：

- AdamW；
- `lr_main=0.001`；
- `lr_v14=0.001`；
- `lr_v19_gain=0.0005`；
- `weight_decay=0.0001`；
- CosineAnnealingLR，`eta_min=1e-6`；
- AMP 混合精度；
- 梯度裁剪 `grad_clip_norm=1.0`；
- 不启用 early stopping；
- 定期验证，验证 MAE 更好时原子覆盖唯一的 `best.pt`；
- 全部训练结束后重新加载 `best.pt`，仅运行一次测试集。

## 2. 最新 V19 模型结构

### 2.1 数据与掩码流

模型输入包括 fine、mid、coarse 三个尺度：

```text
x_f, m_f
x_m, m_m
x_c, m_c
r_m, r_c
```

其中：

- 数据张量采用 `[B,C,T,H,W]`；
- 掩码采用 `[B,1,T,H,W]`；
- `1` 表示观测位置，`0` 表示缺失位置；
- 缺失输入在进入模型前由掩码处理；
- mid 和 coarse 由 mask-aware pooling 生成，空间缩放比分别为 2 和 4；
- V19 的前向控制特征只来自观测值、掩码和模型预测，不读取缺失位置真实值。

### 2.2 主干 MultiScaleMoEBackbone

V19 完整保留 V14 的主干网络。每个尺度首先经过 `ScaleTokenEncoder`，将数值和掩码编码到 64 维特征空间。

三个尺度分别经过：

1. 观测质量统计；
2. `QualityRouter`；
3. 4 个共享专家中的 Top-2 路由；
4. fine/mid/coarse 路由特征融合；
5. 跨尺度共享专家；
6. shared branch 与 routed branch 残差融合；
7. 三维卷积预测头。

主干同时保留：

- shared branch 辅助预测；
- routed branch 辅助预测；
- 专家重要性与负载均衡；
- 跨尺度一致性监督；
- shared/routed 特征互补约束。

主干输出记为：

```text
x_base
```

### 2.3 V14 安全粗到细残差路径

V19 内部直接实例化完整的 `V14SafeC2FMoE`，没有改变 V14 类的内部实现。

V14 包含：

- `DifficultyConditionEncoder`：根据 fine/mid/coarse 观测状态编码缺失难度；
- 尺度可靠性描述；
- scale gate；
- 数据几何描述；
- `SafetyController`：产生 mid、fine 和 final 三个安全门控；
- `SafeCoarseToFineRefiner`：依次产生 coarse、mid、fine 修正；
- `ObservedConsistencyEvaluator`：比较 base 和粗到细修正在观测位置上的一致性；
- correction adapter 和最终安全旁路。

V14 最终输出：

```text
x_v14 = x_base + alpha_final × delta_ctf
```

其中 `alpha_final` 是样本级标量，形状为：

```text
[B,1,1,1,1]
```

### 2.4 V19 通道残差增益控制器

V19 定义 V14 已经生效的残差：

```text
r_v14 = x_v14 - x_base
```

随后对每个样本、每个通道，从观测区域计算 7 个无标签泄漏特征：

```text
observed_scale
base_observed_error_relative
v14_observed_error_relative
v14_observed_gain_relative
effective_residual_mean_relative
effective_residual_q95_relative
observed_zero_ratio
```

这些特征输入共享 MLP：

```text
Linear(7,32)
→ LayerNorm(32)
→ GELU
→ Dropout(0.1)
→ Linear(32,16)
→ GELU
→ Linear(16,1)
```

最终增益为：

```text
gamma = 1 + 0.5 × tanh(raw_gamma)
```

因此：

```text
gamma ∈ [0.5,1.5]
gamma shape = [B,C,1,1,1]
```

最后一层零初始化，训练开始时 `gamma=1`，所以 V19 初始输出严格等于 V14：

```text
x_v19 = x_base + gamma × r_v14
```

正式配置仅新增 865 个参数：

| 数据集 | V14 参数量 | V19 参数量 | 新增 |
|---|---:|---:|---:|
| TaxiBJ | 4,947,169 | 4,948,034 | 865 |
| BikeNYC | 4,885,345 | 4,886,210 | 865 |
| CHAP_Beijing | 4,940,442 | 4,941,307 | 865 |

### 2.5 损失函数

主损失在缺失位置计算 Smooth L1，并保留主干和 V14 的全部训练项：

```text
L_main
+ λ_cross L_cross
+ λ_importance L_importance
+ λ_load L_load
+ λ_shared_aux L_shared_aux
+ λ_route_aux L_route_aux
+ λ_complementary L_complementary
+ 0.25 L_v14_base
+ 0.05 L_v14_mid
+ 0.03 L_v14_coarse
+ 0.10 L_v14_regret
+ 0.0001 L_v14_gate
```

V19 新增两个约束：

```text
L_v19_anchor_regret =
    mean(ReLU(MAE_sample(x_v19) - MAE_sample(stopgrad(x_v14))))

L_v19_gain = mean((gamma - 1)^2)
```

总损失增加：

```text
+ 0.05 L_v19_anchor_regret
+ 0.001 L_v19_gain
```

### 2.6 指标与 checkpoint

当前 V19 使用 float64 累加整个数据集全部缺失元素的误差和，再计算：

```text
MAE  = sum(|prediction-target|) / N_missing
RMSE = sqrt(sum((prediction-target)^2) / N_missing)
MAPE = sum(|prediction-target| / clamp(|target|,1e-6)) / N_missing
```

日志同时记录：

- V19 最终 MAE/RMSE；
- 同一 checkpoint 内的 V14 anchor MAE/RMSE；
- 主干 `x_base` MAE/RMSE；
- `gamma` 的均值、标准差、最小值和最大值。

### 4.2 V19 新增增益模块相对同权重 V14 anchor 的作用

V19 日志同时保存了同一个 checkpoint、同一组 V14 主体参数在 `gamma` 校准前的 `x_hat_v14`。这一比较不会受到独立训练随机轨迹和不同 checkpoint 的干扰，更能反映新增模块本身的作用。

| 数据集 | 模式 | V19/Anchor MAE变化均值 | MAE改善点 | V19/Anchor RMSE变化均值 | RMSE改善点 | V19/Base MAE变化均值 | gamma均值 |
|---|---|---:|---:|---:|---:|---:|---:|
| TaxiBJ | fixed | -0.480% | 2/4 | -0.470% | 2/4 | -3.229% | 1.4998 |
| TaxiBJ | random | -0.892% | 4/4 | -0.862% | 4/4 | -5.865% | 1.4999 |
| BikeNYC | fixed | -0.994% | 4/4 | -1.671% | 4/4 | -4.418% | 1.4732 |
| BikeNYC | random | -1.686% | 4/4 | -2.987% | 4/4 | -7.035% | 1.4889 |
| CHAP_Beijing | fixed | -1.287% | 4/4 | -0.958% | 4/4 | -8.445% | 1.4878 |
| CHAP_Beijing | random | -1.919% | 4/4 | -1.460% | 4/4 | -10.949% | 1.4910 |

整体上：

- V19 相对同权重 V14 anchor 的 MAE在 22/24 点改善；
- 平均改善约 1.209%；
- RMSE同样在 22/24 点改善，平均改善约 1.401%；
- V19 相对内部 `x_base` 在 24/24 点改善，平均 MAE改善约 6.657%。

这说明通道增益模块本身并非无效。它通常能够改善当前训练轨迹中的 V14 输出。

但另一个更重要的现象是：

- TaxiBJ 的 `gamma` 均值约 1.49985，几乎完全贴住 1.5 上界；
- CHAP 的 `gamma` 均值约 1.48941；
- BikeNYC 的 `gamma` 均值约 1.48102；
- TaxiBJ 各组的 `gamma_min` 也约为 1.49975～1.49990。

所以控制器大多数时候并没有学习到丰富的通道差异，而是倾向于把 V14 的有效残差统一放大到允许的最大值。V19 当前更像一个“有界残差放大器”，而不是充分发挥了预期作用的细粒度通道校准器。

## 6. 缺失模式与缺失率分析

### 6.1 Fixed

fixed 模式不一定随名义缺失率单调变差。原因是不同缺失率使用的固定空间掩码未必是严格嵌套集合，不同 mask 可能覆盖完全不同的高流量区域或关键空间位置。

具体表现：

- TaxiBJ fixed@0.6 优于 fixed@0.4；
- BikeNYC fixed@0.6 明显优于 fixed@0.2；
- CHAP fixed@0.2～0.6 几乎持平；
- fixed@0.8 通常开始出现更明显困难。

因此 fixed 结果应被解释为“特定空间缺失结构下的难度”，不能仅依据缺失率大小判断。

### 6.2 Random

BikeNYC 和 CHAP 的 random 结果大体符合缺失率增加、误差增大的预期。

TaxiBJ random 出现明显非单调：

- random@0.2：9.196551；
- random@0.4：11.183662；
- random@0.6：9.415518；
- random@0.8：9.901718。

random@0.4 反而比 random@0.8 更差，说明单种子下不同 mask 实例和训练轨迹的影响仍然很强。这也是后续必须补多随机种子的主要证据。

## 9. 最终结论

### 9.1 V19 是否比 V14 有提升

如果只看 MAE，答案是：

> V19 有一定提升，但提升幅度总体有限，而且存在明显单点不稳定。

证据：

- 名义 MAE胜点为 15/24；
- TaxiBJ 八点平均 MAE改善 2.724%；
- BikeNYC 八点平均 MAE改善 0.647%；
- CHAP 八点平均 MAE基本持平，退化 0.065%；
- V19 相对同权重 V14 anchor 在 22/24 点改善。

如果同时考虑 MAE、RMSE和稳定性，答案是：

> V19 尚不能被判断为对 V14 的全面、稳定提升。

主要问题：

- RMSE仅有 6/24 点改善；
- 三个数据集的八点平均 RMSE均高于 V14；
- CHAP 平均 RMSE退化 7.749%；
- TaxiBJ fixed@0.4 的 MAE退化 10.738%、RMSE退化 18.498%；
- `gamma` 大量饱和到 1.5，通道自适应没有充分体现；
- 多个明显提升点与明显退化点同时存在，单种子稳定性不足。

### 9.2 是否满足 V19 原设计目标

| 目标 | 结果 | 判断 |
|---|---|---|
| 至少 14/24 点 MAE不差于 V14 | 名义 15/24；考虑 0.1% 容差后 13 胜、3 平、8 负 | 部分满足 |
| 三数据集平均 MAE不明显退化 | Taxi、Bike改善，CHAP基本持平 | 满足 |
| BikeNYC 不差于 V14 | 平均 MAE改善 0.647% | 满足 |
| TaxiBJ fixed@0.2/0.4 不出现大幅退化 | fixed@0.4 退化 10.738% | 不满足 |
| 至少一个数据集平均 MAE改善超过 1% | TaxiBJ 改善 2.724% | 满足 |
| 新增参数低于 20K | 新增 865 | 满足 |
| 训练时间增加不超过 2% | Taxi/CHAP满足，Bike增加 2.80% | 基本满足 |
| 不出现超过 3% 的单点退化 | Taxi fixed@0.4、CHAP fixed@0.2 超过 3% | 不满足 |

### 9.3 版本选择建议

当前建议是：

> V14 继续作为稳定主版本和下一步结构改进的基础；V19 保留为具有有效信号但尚未稳定的实验分支。

理由：

1. V19 的新增模块在同权重 anchor 比较中确实有效；
2. V19 的 MAE总体优于 V14，尤其 TaxiBJ、BikeNYC；
3. 但收益主要来自 residual 强放大，gamma 几乎饱和；
4. RMSE和单点稳定性明显不足；
5. 当前证据还不足以证明 V19 是比 V14 更可靠的论文主模型。

### 9.4 下一步最有价值的实验

建议优先进行以下工作，而不是直接继续扩大模型：

1. 用当前已提交代码统一重跑 V14/V19 的指标口径；
2. 对 TaxiBJ fixed@0.2、fixed@0.4、random@0.4、random@0.8，以及 CHAP fixed@0.2、random@0.4 运行至少 3 个种子；
3. 单独记录 TaxiBJ/BikeNYC 两个通道的 gamma 均值和分布，确认是否真的存在通道差异；
4. 不建议直接扩大 `gain_range`，因为当前 RMSE已经恶化；
5. 优先测试更保守的增益范围，例如 `[0.75,1.25]`，或提高 `lambda_v19_gain`；
6. 在验证选择中增加 RMSE非退化约束，避免 MAE小幅改善但尾部误差扩大；
7. 如果保守校准仍不能改善 RMSE，应停止沿最终 residual 强度继续堆叠，返回 V14 寻找更早层的瓶颈。

总体判断：

> V19 证明“增强 V14 有效残差”具有价值，但当前的上界饱和和 RMSE退化说明其校准机制仍过于单向。它是一个值得继续验证的小改进方向，但还不是可以无条件取代 V14 的稳定最终版本。
