# 20260716_第15.1版_V15.1三数据集全量实验分析

## 1. 实验目的与结论摘要

本报告分析 `v15.1-single` 分支的 V15.1 尺度引导轻量残差接纳 MoE（Scale-Guided Lightweight Residual Acceptance MoE）全部正式实验结果。统计范围严格限定为：

```text
outputs/v15.1-single/{dataset}/full/model/{fixed|random}/rate{0.2|0.4|0.6|0.8}/...
```

TaxiBJ、BikeNYC、CHAP_Beijing 各覆盖 fixed/random 两种缺失模式和 0.2、0.4、0.6、0.8 四个缺失率，共 24 组。此前的 1、5、100 Epoch `debug` 诊断结果不进入正式结果表。

核心结论如下。

1. **24/24 组正式实验全部完整结束。**每组均跑满配置规定的 Epoch，完成定期验证、验证 MAE 最优 checkpoint 覆盖保存、重新加载 `best.pt` 和最终测试；没有缺失组合、缺失 checkpoint、缺失测试记录、NaN、Inf、OOM 或运行异常。
2. **V15.1 的轻量化目标实现。**三个数据集总参数约 4.67M～4.73M，只比 Main 增加约 5.15 万参数（约 1.1%），相对 V15 减少约 69.4 万参数（约 12.8%）；V15.1 新增参数约为 V15 新增参数的 6.9%。
3. **安全残差机制确实发挥作用。**六个“数据集×缺失模式”分组中，最终输出平均 MAE 全部优于同次训练的 `x_base`。BikeNYC 的无门控 Candidate 平均退化率为 fixed 83.18%、random 76.20%，接纳后分别降至 34.74% 和 32.03%；CHAP 则由 34.66%/29.97% 降至 9.52%/10.30%。
4. **但跨版本精度提升不稳定。**相对 V15，V15.1 在 24 点中 10 胜、14 负，逐点相对变化平均为退化 1.12%；相对 V14 仅 4 胜、20 负，平均相对退化 5.69%。
5. **V14 仍是当前最稳健的主力版本。**在 Main、V14、V15、V15.1 四版本逐点比较中，V14 取得 17/24 个最佳结果，V15 取得 5 个，V15.1 仅在 TaxiBJ fixed@0.2 和 BikeNYC fixed@0.8 两点取得最佳。
6. **V15.1 最明确的收益位于 BikeNYC fixed 和 TaxiBJ random@0.4。**BikeNYC fixed 四点全部优于 V15，平均改善 1.62%；TaxiBJ random@0.4 从 V15 的 14.9976 降至 12.4025，改善 17.30%。
7. **CHAP 是 V15.1 的主要退化区域。**相对 V15，CHAP fixed 四点全部退化，平均相对退化 5.94%；CHAP random 仅 0.2 点轻微改善 0.16%，其余三点均退化。
8. **Gate 更像连续残差缩放器，而非充分的样本级接纳分类器。**TaxiBJ 的测试 Gate 均值约 0.91～0.93、标准差低于 0.001，几乎全局接纳；CHAP 均值约 0.68～0.69、标准差约 0.0045，也较接近全局缩放。BikeNYC 的变化相对更大，但最终对 Base 的平均改善只有约 0.1%。
9. **缺失率与误差多处不单调。**TaxiBJ 和 BikeNYC 的 0.6/0.8 并不总比 0.2/0.4 更差。这与各缺失率离线 mask 不严格嵌套、被隐藏区域的数据尺度与难度不同有关，论文中不应把当前单次 mask 结果直接解释成严格的缺失率敏感性曲线。
10. **MAPE 不适合 TaxiBJ/BikeNYC。**两者存在大量零或近零目标，当前 `eps=1e-6` 的 MAPE 被放大到数万量级。论文主结果应使用原始范围 MAE、RMSE，MAPE 至多作为带明确警告的辅助指标。

综合判断：V15.1 成功把 V15 的重残差金字塔压缩为轻量、安全、可训练的修正模块，机制分析价值明确；但它没有形成跨数据集的一致精度优势。**当前仍建议以 V14 作为后续主力结构，V15.1 作为安全残差机制和轻量化消融方向，而不是直接替代 V14。**


## 3. 最新 V15.1 模型结构

### 3.1 总体数据流

V15.1 注册架构名为 `v15_1_scale_guided_residual_moe`，顶层模型为 `DualBranchSTImputer`。本次配置中旧 Aux Branch 关闭，因此最终预测完全由 V15.1 Main Branch 产生：

```text
Fine observed values + mask
        ↓ masked average pooling
Mid / Coarse observed values + masks + reliability
        ↓
MultiScaleMoEBackbone
  ├── x_base
  ├── z_f / z_m / z_c
  ├── h_main
  └── scale_gate
        ↓
ScaleGuidedResidualAdapter (64 -> 24 dim)
        ↓
delta_raw -> tanh -> bounded delta_candidate
        ↓
ResidualAcceptanceGate
        ↓
x_final = x_base + accept_gate * delta_candidate
```

模型还生成：

```text
x_comp = m_f * observed_truth + (1-m_f) * x_final
```

用于得到观测位置保持原值、隐藏位置使用补全值的完整输出。

### 3.2 无目标泄漏的多尺度输入

Mid 和 Coarse 只从观测值逐级构造：

```text
Fine -> Mid    spatial factor = 2
Fine -> Coarse spatial factor = 4
pooling mode                  = masked average
```

池化分子只累计 `x * mask`，分母为窗口内观测数量，同时产生：

- `x_m_obs/x_c_obs`：中、粗尺度观测值；
- `m_m/m_c`：窗口内是否存在观测的二值 mask；
- `r_m/r_c`：窗口内观测比例，范围 `[0,1]`。

隐藏 ground truth 不进入 Forward 的多尺度构造、路由条件或接纳条件。已有目标泄漏单元测试也验证了改变隐藏目标不会改变前向预测。

### 3.3 Stable Multi-Scale MoE Backbone

Main Backbone 隐藏维度为 64，使用 4 个共享时空专家和样本级 Top-2 路由：

1. `ScaleTokenEncoder` 对每个尺度叠加 value Conv3D、mask embedding、可学习尺度 embedding、时间 embedding 和空间 embedding；
2. `compute_observation_stats` 从 mask 计算 5 维观测质量统计；
3. `QualityRouter` 拼接全局池化特征、质量统计和尺度向量，产生 4 专家 softmax 权重；
4. `TopKRoutedExpertPool` 选取 Top-2 专家并归一化，Fine/Mid/Coarse 共享同一套专家参数；
5. `ProgressiveRouteFusion` 形成 coarse→mid→fine 的 routed branch；
6. `GatedCrossScaleSharedExpert` 根据尺度特征、观测质量与可靠性形成 shared branch；
7. `SharedRoutedResidualFusion` 以 shared 特征为主路径，叠加带缩放的 routed residual；
8. Prediction Head 输出基础补全 `x_base`。

TaxiBJ 的 Main `scale_mode=fine_mid`，所以 coarse 在主干有效尺度和 V15.1 残差分支中都严格关闭。BikeNYC 与 CHAP 使用 `fine_mid_coarse`。

### 3.4 24维尺度引导轻量残差适配器

V15.1 不再使用 V15 的三套 64 维 ResidualSTBlock。它先将主干特征投影到 24 维：

```text
z_f, z_m, z_c, h_main
      ↓ independent 1×1×1 Conv3D + GroupNorm + GELU
24-d projected features
```

主干 `scale_gate` 默认 detach 后乘到 Fine/Mid/Coarse 残差特征。非激活尺度不会执行对应投影或融合，避免卷积偏置、归一化偏置产生“伪尺度信号”。融合过程为：

```text
p_c = w_c * ProjC(z_c)
p_m = MidFuse(concat(w_m * ProjM(z_m), up(p_c)))
p_f = FineFuse(concat(w_f * ProjF(z_f), ProjMain(h_main), up(p_m)))
delta_raw = ResidualHead(p_f)
```

只有 FineFuse 包含一个 24 维 `ResidualSTBlock`。Residual Head 为：

```text
Conv3D(24,16,3,padding=1)
-> GroupNorm -> GELU -> Dropout3D(0.1)
-> Conv3D(16,C,1)
```

最后一层零初始化，因此初始状态严格满足 `delta_raw=0`、`x_final=x_base`。

### 3.5 固定上限的候选残差

基础预测通道尺度定义为：

```text
scale_ref = RMS(stopgrad(x_base), over T/H/W)
scale_ref = max(scale_ref, 1e-3)
```

候选残差为：

```text
direction       = tanh(delta_raw)
delta_candidate = 0.05 * scale_ref * direction
x_candidate     = stopgrad(x_base) + delta_candidate
```

逐元素始终满足：

```text
|delta_candidate| <= 0.05 * scale_ref
```

正式测试中候选残差相对 RMS 平均只有约 1.0%～2.3%，接纳后的有效 RMS 约 0.6%～2.1%，明显低于 5% 理论上限。

### 3.6 残差接纳门控

Gate 条件固定为 9 维：

```text
Fine mask difficulty  3维
Mid/Coarse reliability 2维
active scale weight     3维
candidate relative RMS  1维
```

网络结构为：

```text
Linear(9,24)
-> LayerNorm -> GELU -> Dropout(0.1)
-> Linear(24,1,bias=False)
+ fixed bias(-1.5)
-> sigmoid
```

末层权重零初始化，`-1.5` 是固定 buffer，不作为可训练全局偏置。最终输出：

```text
effective_delta = accept_gate * delta_candidate
x_final         = x_base + effective_delta
```

残差输入、尺度 Gate 和候选相对 RMS 默认 detach，使接纳监督不能通过旁路重塑 Main 或候选残差方向；隐藏 ground truth 只用于损失标签，不进入推理条件。

### 3.7 损失函数

基础误差类型为隐藏位置 Smooth L1。Main 原有损失包括：

```text
L_main
L_cross
L_importance_balance / L_load_balance
L_shared_aux / L_route_aux
L_complementary
```

其中 TaxiBJ/CHAP 的 `lambda_cross=0.03`、`lambda_shared_aux=0.05`、`lambda_route_aux=0.10`、`lambda_complementary=0.003`；BikeNYC 分别为 0.05、0.03、0.05、0.001。

V15.1 新增：

```text
L_v15_1_base      = SmoothL1(x_base, target)
L_v15_1_candidate = SmoothL1(x_candidate, target)
L_v15_1_accept    = BCEWithLogits(accept_logit, target_accept)
L_v15_1_safe      = mean(ReLU(sample_final_MAE - sample_base_MAE))
```

接纳标签按每个样本的相对候选收益定义：

```text
relative_gain >  0.002 -> target_accept = 0.95
relative_gain < -0.002 -> target_accept = 0.05
otherwise              -> target_accept = 0.50
```

新增权重为：

```text
lambda_base      = 0.50
lambda_candidate = 0.10
lambda_accept    = 0.05
lambda_safe      = 0.10
```

`BCEWithLogits` 与设计中的 BCE 等价，但对 AMP 更安全。`L_safe` 是平均软惩罚，不是逐样本硬保证。

### 3.8 指标定义

MAE、RMSE、MAPE 都在原始数据范围、隐藏位置上计算：

```text
missing = 1 - m_f
MAE  = sum(|pred-target| * missing) / sum(missing)
RMSE = sqrt(sum((pred-target)^2 * missing) / sum(missing))
MAPE = mean(|pred-target| / max(|target|,1e-6), over missing)
```

由于 TaxiBJ/BikeNYC 目标中包含大量零值，MAPE 会被极小分母放大，因此后续分析以 MAE、RMSE 为主。

### 4.5 缺失率敏感性

- CHAP random 才表现出较稳定的 `0.2 < 0.4 < 0.6 < 0.8` 误差增长；
- CHAP fixed 在 0.6 最好，0.8 明显变差。

这更像是不同缺失率 mask 隐藏了不同难度、不同数值尺度的网格，而不是“缺失越多模型越容易”。若论文要讨论严格缺失率敏感性，建议使用嵌套 mask 或多组 mask seed 后报告均值/标准差。

## 6. V15.1 机制诊断

### 6.1 Base、Candidate 与 Final

以下为四缺失率测试指标的平均值：

| 数据集 | Mask | Base MAE | Candidate MAE | Final MAE | Final 对 Base 增益 | Candidate退化率 → Final退化率 |
|---|---|---:|---:|---:|---:|---:|
| TaxiBJ | fixed | 8.2585 | 8.1681 | **8.1671** | +0.0914 | 13.76% → 12.02% |
| TaxiBJ | random | 11.3172 | **11.1336** | 11.1371 | +0.1802 | 12.06% → 11.35% |
| BikeNYC | fixed | 1.9194 | 1.9325 | **1.9176** | +0.0017 | 83.18% → 34.74% |
| BikeNYC | random | 2.0925 | 2.1060 | **2.0903** | +0.0022 | 76.20% → 32.03% |
| CHAP_Beijing | fixed | 0.6605 | 0.6528 | **0.6454** | +0.0151 | 34.66% → 9.52% |
| CHAP_Beijing | random | 0.6921 | 0.6820 | **0.6716** | +0.0205 | 29.97% → 10.30% |

直接事实是：六个分组的 Final 都优于 Base，说明 V15.1 不是完全无效的附加模块。

但不同数据集的工作方式不同：

- TaxiBJ 的 Candidate 本身已经有效，Gate 大多接近 1，只做轻微缩放；
- BikeNYC 的完整 Candidate 整体有害，Gate 把残差压到约三分之一，使最终结果仅略优于 Base；
- CHAP 的 Candidate 平均有益，但部分样本方向错误，约 0.68～0.69 的连续缩放同时提高平均精度并显著降低退化率。

### 6.2 Gate 行为

| 数据集 | Mask | Gate mean | Gate std | Acceptance Accuracy |
|---|---|---:|---:|---:|
| TaxiBJ | fixed | 0.9135 | 0.00015 | 88.07% |
| TaxiBJ | random | 0.9347 | 0.00063 | 89.29% |
| BikeNYC | fixed | 0.2941 | 0.02506 | 82.94% |
| BikeNYC | random | 0.3711 | 0.04480 | 77.78% |
| CHAP_Beijing | fixed | 0.6927 | 0.00452 | 65.90% |
| CHAP_Beijing | random | 0.6783 | 0.00439 | 70.75% |

TaxiBJ 和 CHAP 的 Gate 标准差远小于均值，说明其主要学到的是“当前数据集/缺失模式应使用多大残差”，样本级差异较弱。BikeNYC 的 Gate 变化更明显，但最终相对 Base 的平均增益只有约 0.1%，更多体现为风险抑制而不是额外精度。

Acceptance Accuracy 受正负标签比例影响，不能单独证明 Gate 具备强分类能力。例如四点诊断中的 CHAP fixed@0.4 Accuracy 为 38.88%，但 Final 仍明显优于 Candidate；这说明连续幅度校准比 0.5 阈值下的二分类更能解释当前 Gate 的实际作用。

### 6.3 尺度权重

| 数据集 | Mask | Fine | Mid | Coarse |
|---|---|---:|---:|---:|
| TaxiBJ | fixed | 90.72% | 9.28% | **0%** |
| TaxiBJ | random | 90.62% | 9.38% | **0%** |
| BikeNYC | fixed | 69.57% | 14.88% | 15.55% |
| BikeNYC | random | 62.39% | 16.57% | 21.04% |
| CHAP_Beijing | fixed | 50.79% | 39.57% | 9.64% |
| CHAP_Beijing | random | 45.41% | 41.37% | 13.22% |

TaxiBJ coarse 始终严格为 0，符合 `fine_mid` 设计。BikeNYC random 比 fixed 更依赖 coarse；CHAP 的三尺度分布最均衡，没有出现 100 Epoch 诊断早期曾出现的单尺度极端塌缩。

### 6.4 机制结论

V15.1 已经把 V15 的“高容量动态残差预算”转化为“低容量固定上限候选 + 连续接纳缩放”。这种变化带来三个确定收益：

1. 参数和显存明显降低；
2. 残差幅度有固定 5% 上界；
3. BikeNYC/CHAP 的样本退化率被显著压低。

但它没有解决两个问题：

1. Gate 的样本区分仍弱，尤其 TaxiBJ/CHAP 更像数据集级常数；
2. 安全性改善不等于跨版本精度改善，V14 仍在 17/24 点领先。

## 7. 各数据集训练过程趋势

### 7.1 TaxiBJ

#### Fixed

四点平均训练 Loss 从 **134.50** 降至 **13.82**，训练 MAE 从 **76.26** 降至 **7.86**；首轮验证 MAE 平均为 **24.30**，最佳验证 MAE 平均为 **8.66**，改善约 64.28%。

最佳 Epoch 分别为：

```text
rate0.2 -> 160
rate0.4 -> 160
rate0.6 -> 150
rate0.8 -> 160
```

三点在最后一轮才取得最佳，说明 TaxiBJ fixed 在当前 160 Epoch 下没有明显过拟合，甚至仍有少量延长训练的空间。不过最后验证 MAE 与最佳值平均只差 0.05%，继续增加 Epoch 的预期收益有限。

测试 MAE 对缺失率并不单调：0.2 最好，0.4 最差，0.6 又优于 0.4。这更可能来自 fixed mask 隐藏区域的空间难度差异。

#### Random

四点平均训练 Loss 从 **135.95** 降至 **15.97**，训练 MAE 从 **77.07** 降至 **8.88**；首轮验证 MAE 平均为 **27.93**，最佳值为 **11.61**，改善约 58.02%。

最佳 Epoch 为：

```text
rate0.2 -> 135
rate0.4 -> 145
rate0.6 -> 140
rate0.8 -> 155
```

最佳点集中在后 15% 训练阶段，最后验证值平均比最佳高约 0.97%。最后验证 MAE 与训练 MAE 平均相差约 2.85，random 下存在比 fixed 更明显的训练/验证间隙，但 best checkpoint 正确避免了使用退化后的最后参数。

random@0.4 是 V15.1 相对 V15 最大的改进点；random@0.6/0.8 绝对结果更低，但没有保住 V15 的领先幅度。

### 7.2 BikeNYC

#### Fixed

平均训练 Loss 从 **11.82** 降至 **2.35**，训练 MAE 从 **6.91** 降至 **1.48**；验证 MAE 从首轮平均 **5.22** 降至最佳 **1.83**，改善约 64.85%。

最佳 Epoch 为 132、132、126、134，均位于训练后段。最后验证值仅比最佳高约 0.15%，整体已经稳定收敛。V15.1 在 fixed 四点全部优于 V15，其中 fixed@0.8 还是四版本同点最佳；但与 V14 比较仍只有 fixed@0.8 获胜。

#### Random

平均训练 Loss 从 **11.66** 降至 **2.29**，训练 MAE从 **6.87** 降至 **1.37**；验证 MAE从 **5.89** 降至最佳 **2.01**，改善约 65.92%。

最佳 Epoch 为 110、128、106、102，普遍早于 fixed。最后验证 MAE 平均比最佳高约 1.05%，训练/验证 MAE 间隙约 0.66，说明 random 模式更早进入轻微过拟合或波动阶段。V15.1 相对 V15 在 0.4/0.6/0.8 三点小幅改善，但 random@0.2 退化 2.94%。

BikeNYC 的 Candidate 大多有害，而 Gate 将其压低后只获得很小的最终净增益。这说明当前残差分支对小数据集的主要贡献是“防止破坏”，而不是提供强的新信息。

### 7.3 CHAP_Beijing

#### Fixed

平均训练 Loss 从 **34.93** 降至 **1.30**，训练 MAE 从 **19.73** 降至 **0.99**；验证 MAE 从 **8.50** 降至最佳 **0.802**，改善约 88.43%。

最佳 Epoch 为 150、150、145、145，两点在最后一轮仍刷新最佳。最后验证值与最佳值平均只差 0.12%，没有明显后期退化。测试 MAE 全部低于对应验证 MAE，说明 test split 整体数值尺度或预测难度低于 validation split，不能简单把这一差异解释为模型在 test 上“泛化更好”。

#### Random

平均训练 Loss 从 **35.17** 降至 **1.43**，训练 MAE 从 **19.87** 降至 **1.07**；验证 MAE 从 **10.00** 降至最佳 **0.836**，改善约 90.42%。

CHAP 的安全 Gate 能明显降低内部样本退化率，但跨版本仍落后 V14/V15，说明问题不只是“残差是否安全”，还包括 Main 与候选残差的联合优化是否保持了原版本的最佳表示。

## 9. 结论与下一步建议

### 9.1 论文主模型建议

当前不建议用 V15.1 替换 V14。理由不是 V15.1 无效，而是它的收益集中在少数设置：

- V15.1 相对 Main 13胜11负，基本持平；
- 相对 V15 10胜14负，没有稳定超越；
- 相对 V14 仅4胜20负；
- 四版本逐点最佳中 V14 占17点，V15.1只占2点。

因此论文主模型仍建议选择 **V14**，V15.1 可作为“轻量安全残差接纳”机制实验或后续结构参考。

### 9.2 推荐保留的 V15.1 价值

1. 24维单残差块显著降低 V15 参数量；
2. 固定 `rho=0.05` 提供清晰、容易写入论文的幅度约束；
3. Gate 在 BikeNYC/CHAP 能显著降低样本退化率；
4. TaxiBJ coarse 严格关闭，尺度适配行为符合数据集配置；
5. TaxiBJ random@0.4 的 17.30% 改善表明该机制确实能修复 V15 的部分失败点。

### 9.3 下一步实验优先级

1. **先补多 seed，而不是继续堆叠新版本。**至少对 V14、V15 和 V15.1 的代表点运行 3 个 seed，报告均值±标准差；优先 TaxiBJ random@0.4/0.8、BikeNYC fixed@0.6/0.8、CHAP fixed@0.4。
2. **完成最小正式消融。**优先比较 Full、Fixed Acceptance、No Acceptance Loss、Fine-Only Residual；如果 Fixed Acceptance 持续优于 Full，应按设计文档删除学习型 Gate。
3. **把 Gate 重新定义为连续缩放器来分析。**当前日志不支持强“样本级分类”叙述，更适合表述为 difficulty-conditioned residual attenuation，并报告 Gate 与样本收益/缺失难度的相关性。
4. **统一缺失率协议。**使用嵌套 mask 或多个 mask seed，减少“0.6 比 0.2 更容易”的隐藏区域偏差。
5. **论文表格只把 MAE/RMSE 作为主指标。**TaxiBJ/BikeNYC 的 MAPE 应删除或单独解释零值处理策略。
6. **提交当前代码。**当前日志记录 `git_dirty=True`，应在继续实验前提交 V15.1 实现，确保后续报告能由 commit 精确复现。

最终结论：**V15.1 是一次成功的轻量化与安全机制验证，但不是当前最优主模型。V14 仍是后续主力修改的更可靠基础；若继续探索 V15.1，应集中解决 Gate 的样本区分能力和 CHAP 跨版本退化，而不是继续增加残差分支容量。**
