# 20260711_第11版_v11置信度校准MoE实验结果分析

## 1. 实验目的与设置

本轮实验评估 v11-single Confidence-Calibrated MoE（置信度校准专家融合）在 TaxiBJ、BikeNYC 和 CHAP_Beijing 三个数据集上的完整插补性能，并检查专家置信度是否真正改变 Router 权重、改善高缺失率下的稳定性。

### 1.1 覆盖范围

- 数据集：TaxiBJ、BikeNYC、CHAP_Beijing。
- 缺失模式：fixed、random。
- 缺失率：0.2、0.4、0.6、0.8。
- 正式任务：$3\times2\times4=24$ 组。
- 随机种子：42，每组当前只有 1 个种子。
- 设备：NVIDIA GeForce RTX 3090，使用 AMP。

覆盖审计结果：24/24 组均有 `metrics.jsonl`、最终 test 记录和唯一 `checkpoints/best.pt`；未发现 NaN/Inf，没有失败或缺失测试的正式任务。smoke/debug 运行未计入主表。

### 1.2 数据与训练策略

| 数据集 | 形状 | 训练/验证/测试 | Batch | 最大 epoch | `val_epoch` | Early stopping |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| TaxiBJ | $[N,2,12,32,32]$ | 2491/356/712 | 32 | 160 | 5 | patience=8 次验证 |
| BikeNYC | $[N,2,12,24,12]$ | 511/73/147 | 16 | 140 | 2 | patience=12 次验证 |
| CHAP_Beijing | $[N,1,7,32,32]$ | 2626/322/322 | 32 | 150 | 5 | patience=8 次验证 |

三个数据集均使用 AdamW，主学习率 $10^{-3}$，weight decay $10^{-4}$，梯度裁剪 1.0，cosine 学习率调度至 $10^{-6}$。最佳模型只由验证集 MAE 决定，新的最佳结果会覆盖原 `best.pt`；训练结束后重新加载该检查点，只运行一次测试集。

fixed 为所有样本共享的空间掩码，random 为每个样本不同的空间掩码；掩码在时间维上重复，所以这批实验主要评估空间位置缺失。

## 2. 最新 v11 模型结构

### 2.1 输入与多分辨率数据流

1. 输入形式为 $X\in\mathbb{R}^{B\times C\times T\times H\times W}$ 和 mask $M\in\mathbb{R}^{B\times1\times T\times H\times W}$，观测输入为 $X_{obs}=X\odot M$。
2. mid 和 coarse 尺度只由观测值做 masked average pooling 生成，同时计算聚合可靠性，不使用缺失位置真值构造粗尺度输入。
3. fine/mid/coarse 各自通过 `ScaleTokenEncoder`，将值卷积特征、mask embedding、时间、空间和尺度编码相加为 64 维特征。

### 2.2 Router 与置信度校准专家池

每个尺度的 `QualityRouter` 结合全局池化特征、5 维缺失统计和尺度编码，输出 4 个专家的 Router logits 和 softmax weight。v11 使用 4 个原始同构 `STExpert`，三个尺度共享专家参数。

每个专家配置一个 sample-level `ExpertConfidenceHead`：

$$
c_i=\sigma\left(\operatorname{MLP}\left[
\operatorname{GAP}(z_i),\operatorname{GAP}(h),\operatorname{mean}(M)
\right]\right).
$$

其中 $z_i$ 是专家输出，$h$ 是专家处理前的尺度特征。MLP 为 `129→64→1`（中间使用 GELU 和 dropout=0.1），最后一层零初始化，所以训练开始时所有专家的 confidence 均为 0.5。

校准权重为：

$$
\ell_i^{cal}=\ell_i^{router}+\beta\log(c_i+\epsilon),\qquad
w_i^{cal}=\operatorname{softmax}(\ell_i^{cal}).
$$

$\beta$ 使用有界 sigmoid 参数化，范围为 $[0,0.5]$，初值为 0.05。因为初始 $c_i$ 全部相等，初始校准权重与 Router 权重相同，但非零 $\beta$ 允许 confidence head 从第一步获得梯度。

v11 正式配置使用 soft routing，即所有 4 个专家都参与加权，不在主实验中做 Top-K 截断。

### 2.3 多尺度与双分支融合

- 路由分支先融合 coarse→mid，再融合 mid/coarse→fine，使用校准后专家特征。
- 共享分支使用可靠性感知 scale gate 加权 fine/mid/coarse 特征。本版 `use_calibrated_scale_fusion=false`，confidence 未直接进入尺度门控。
- `shared_input_mode=pre` 意味着共享分支使用专家处理前的 embedding。最终融合为 $H_{main}=H_{shared}+\sigma(\gamma)H_{route}$，因此 confidence 只直接作用于路由分支。
- 预测头使用 Conv3D–GELU–Conv3D 生成插补值，已观测位置在最终组合输出中保持原值。

### 2.4 损失、指标和训练流程

v11 没有新增 confidence 监督损失，仍使用：

$$
L=L_{main}+\lambda_{cross}L_{cross}
+\lambda_{imp}L_{importance}+\lambda_{load}L_{load}
+\lambda_{shared}L_{shared}+\lambda_{route}L_{route}
+\lambda_{comp}L_{complementary}.
$$

$L_{main}$ 是缺失位置 Smooth L1，$L_{cross}$ 约束粗尺度一致性，另有 Router 重要性/负载均衡、共享/路由分支辅助重建和分支互补损失。由于 soft routing 下 `selected_mask` 对所有专家都为 1，本轮 24 组日志的 `l_load_balance` 全部为 0，实际只剩权重 0.001 的 importance balance 约束 Router 集中。

MAE、RMSE 和 MAPE 都只在缺失位置上计算。MAE/RMSE 直接使用 NPZ 原始数值范围。

## 4. 置信度校准机制分析

### 4.1 Confidence 确实学习，但权重校准幅度较小

24 组任务的平均诊断如下：

| 诊断量 | 第1 epoch | 最终 test | 解读 |
| --- | ---: | ---: | --- |
| `confidence_beta` | 0.0504 | 0.0583 | 相对初值只小幅上升 |
| `confidence_mean` | 0.4995 | 0.4297 | confidence head 已偏离零初始化的 0.5 |
| `confidence_weight_shift_l1` | 0.00051 | 0.01543 | 校准权重已改变，但平均改变较小 |
| Router entropy | 1.3251 | 0.9896 | Router 随训练显著集中 |
| Calibrated entropy | 1.3246 | 0.9825 | confidence 平均只进一步轻微锐化分布 |
| 路由分支残差系数 | 0.0426 | 0.0803 | 路由分支仍是较小残差 |

最终 `confidence_weight_shift_l1` 的单任务范围为 0.00126–0.05693。这说明 confidence 并非完全没有参与，但在大多数任务中对 Router 权重的实际修正有限。

更重要的是，confidence 只修改路由分支，而路由分支在最终融合中又被约 5%–11% 的残差系数缩小。因此“校准权重的小改变”还会在最终输出端再次被衰减。这是根据代码路径和日志做出的推断，可以解释为什么 v11 并未表现出稳定的跨数据集收益。

### 4.2 Confidence 出现极端值，但它不是统计意义上的“已校准概率”

部分 test 任务的单专家 confidence 出现近 0 或近 1：

- CHAP fixed@0.8：expert 0 为 0.0001，expert 2 为 0.9803。
- TaxiBJ fixed@0.4：expert 3 为 0.0032，expert 2 为 0.9348。
- TaxiBJ fixed@0.6：expert 2 为 0.0021。
- TaxiBJ random@0.2：expert 2 为 0.0037。
- CHAP random@0.8：expert 1 为 0.0040。

由于 v11 没有专家真实误差标签或 calibration loss，这些值本质上是通过最终重建损失间接学得的 gating signal。因此 0.98 不能解释为“该专家有 98% 可靠性”，当前名称中的 calibrated 指融合权重校准机制，而不是经过 ECE/Brier score 验证的概率校准。

### 4.3 还不能证明 confidence 本身有效

当前 `outputs/v11-single` 只有 full/model 正式实验，没有完成下列已配置消融：

- `no_confidence`：保持 soft routing，关闭 confidence 修正。
- `gate_only_fallback`：恢复原始 homogeneous Top-K 主干。
- `topk_calibrated`：先校准再 Top-K。
- `confidence_no_mask`、`confidence_no_input_feature`。

因此，现在只能得出“confidence 分支可以学习并改变权重”，不能得出“confidence 带来了精度提升”。特别是 soft routing 本身也是相对旧主干的结构变量，必须用同代消融分离它与 confidence 的作用。

## 5. 各数据集训练趋势

### 5.1 TaxiBJ

8 个任务的平均训练总损失从 89.762 降到 10.229，降幅约 88.60%。首次验证 MAE 平均为 30.266，最佳平均为 11.795，末次平均为 12.102。最佳 epoch 平均为 127.5，约处在实际训练进程的 83.5%。

- fixed 四个任务都训练到 160 epoch，最佳点位于 150–160，后期仍在继续改善。fixed Test MAE 从 rate0.2 的 11.5527 逐步降至 rate0.8 的 8.1625，与 v10 类似，并非“缺失率越高误差越大”。
- random@0.2 在 epoch55 最好，epoch95 早停；random@0.4/0.6/0.8 都在 epoch115 最好，epoch155 早停。四个 random 任务全部触发早停，表明 v11 在 TaxiBJ random 掩码上的验证平台比 fixed 更早。
- random@0.2 的最佳 Val MAE 是 15.1058，末次已回升至 15.8702；random@0.4 从最佳 14.0618 回升至 14.937，有较明显的后期泛化退化。
- Test 与最佳 Val MAE 平均差仅 -0.011，两个划分的总体难度接近。

TaxiBJ fixed 比 v10 更好，但 random 更差，说明 v11 对固定空间缺失模式的建模更有利，对样本级不断变化的空间掩码缺乏同等稳定性。这是结果表现的观察，原因仍需 `no_confidence` 和 Top-K 消融区分。

### 5.2 BikeNYC

平均训练总损失从 7.398 降至 1.543，降幅约 79.15%。首次验证 MAE 平均为 5.779，最佳为 1.910，末次为 1.918；最佳 epoch 平均 116.3，平均处在训练进程的 86.3%。

- fixed 四个任务全部跑满 140 epoch，最佳点在 124–132，后期只有轻微震荡。
- random@0.2、0.4、0.8 分别于 132、110、132 epoch 早停，random@0.6 跑满 140 epoch。虽然有三组早停，最佳与末次 Val MAE 差异总体很小，更像平台后波动，而不是严重过拟合。
- fixed@0.6 是最好 fixed 任务，Test MAE/RMSE=1.4874/4.2834；random 四个缺失率的 Test MAE 只在 2.0316–2.0909 之间，对缺失率不敏感。
- Test MAE 平均比最佳 Val MAE 高 0.072，验证与测试排序基本一致。

BikeNYC 是 v11 最稳定的数据集：相对 v9 的 8 个任务全部改善，与 v10 差异仅约 0.9%。但 v11 未超过 v10，因此仍不能宣称 confidence 带来额外收益。

### 5.3 CHAP_Beijing

平均训练总损失从 22.728 降至 1.243，降幅约 94.53%。首次验证 MAE 平均为 9.958，最佳平均为 1.002，末次为 1.075。平均最佳 epoch 为 124.4，但 fixed@0.4/0.8 的早停使该平均值下降。

- fixed@0.2 和 fixed@0.6 稳定收敛到 145 epoch，Test MAE 分别为 0.6503 和 0.6442。
- **fixed@0.4 是本轮最明显异常项**：epoch25 的 Val MAE 已降至 2.0320，epoch50 只改善到 1.9805，之后反向恶化，epoch90 上升到 2.5229 并早停。末次训练损失为 2.693，显著高于正常 fixed@0.2/0.6 的 0.956/0.984，说明该任务进入了明显较差的优化解。
- fixed@0.8 在前 25 epoch 内一度恶化到 Val MAE=6.685，之后恢复，epoch55 得到最佳 1.0389，epoch95 早停，Test MAE=0.8580。该项也存在明显的早期优化不稳定。
- random 四组任务都跑满 150 epoch，且最佳点都是 epoch150，Test MAE 随缺失率从 0.6418 缓慢上升到 0.7277，趋势合理且稳定。

CHAP fixed@0.4 的 test `confidence_weight_shift_l1` 只有 0.00310，$\beta=0.0517$，都非异常大值。因此日志并不支持“confidence 过强修正权重直接导致坏收敛”的说法。更可能的是 soft routing、随机初始化与该 fixed mask 共同导致了较差优化路径，但这仍是待通过多种子和消融验证的推断。

## 6. 缺失率、指标与数据解释

### 6.1 非单调缺失率现象

TaxiBJ fixed/random 的 MAE 都随缺失率增大而下降，BikeNYC fixed 在 0.6 最好。这与“缺失率越高越困难”的直觉不一致。

fixed 各缺失率对应的空间位置集不同，评估目标难度也不同。例如 BikeNYC fixed@0.2 的缺失目标零值比例为 57.5%，而 fixed@0.6 为 70.3%，后者天然包含更多容易的零值。random 在各缺失率的目标分布更接近，TaxiBJ random 的反常下降趋势不能只由目标分布解释，应通过多种子与嵌套 mask 重复确认。

### 6.2 MAPE 限制

| 数据集 | Test 值域 | 零值比例 | MAPE 解读 |
| --- | ---: | ---: | --- |
| TaxiBJ | [0,1250] | 5.36% | 不可靠，零值使结果达数万量级 |
| BikeNYC | [0,670] | 66.05% | 不可靠，零值比例过高 |
| CHAP_Beijing | [3,155.8] | 0% | 基本可用，0.027约表示 2.7% |

论文主表应使用 MAE 和 RMSE。TaxiBJ/BikeNYC 如需百分比指标，建议使用 WAPE 或对零值更稳健的 sMAPE，不应报告当前 MAPE。

### 8.1 结论

1. v11 已完整跑通 24/24 组正式实验，没有 NaN/Inf、缺失检查点或缺失 test 记录，工程完整性合格。
2. Confidence head 确实从 0.5 初始值学习到了专家差异，也改变了 Router 权重，但平均权重改变只有 0.0154，并且作用路径被较小的路由分支残差系数进一步衰减。
3. v11 没有在三数据集上形成统一优势：整体比 v10 差，TaxiBJ random 和 CHAP fixed 的退化明显；BikeNYC 稳定，但未超过 v10。
4. CHAP fixed@0.4 是必须重跑的坏收敛点，当前不应将其直接作为稳定模型性能。
5. 尚无消融证据表明 confidence 可以提高精度。现阶段最准确的说法是：“置信度校准机制可训练且会修正融合权重，但其净性能收益尚未得到验证。”

### 8.2 建议的实验顺序

1. **先重跑异常点**：CHAP fixed@0.4 和 fixed@0.8 用 seed 42 复现一次，再加 seed 7/2026，判断是否为随机初始化问题。
2. **跑最小必要消融**：在 TaxiBJ fixed@0.8、TaxiBJ random@0.2、BikeNYC fixed@0.6、CHAP fixed@0.4 和 CHAP random@0.8 上比较 full v11、`no_confidence`、`gate_only_fallback` 和 `topk_calibrated`。
3. **检验 confidence 是否可解释**：记录每个专家的单独重建误差，计算 confidence 与 expert error 的 Spearman 相关；否则不应在论文中将 confidence 表述为真实可靠性。
4. **修正 soft routing 的均衡策略**：当前 `l_load_balance` 恒为 0，应明确在 soft routing 下关闭该项，或改为基于 effective weight 的连续负载正则，并单独记录 Router 集中问题。
5. **增强校准作用时保持单变量**：如果要增大 $\beta$ 或让 confidence 进入 scale fusion，应作为新版本/独立消融，不覆盖 v11 结果。
6. **论文前统计复现**：最终候选模型至少运行 3 个种子，报告 MAE/RMSE 的均值±标准差，并固定可追溯 commit hash。
