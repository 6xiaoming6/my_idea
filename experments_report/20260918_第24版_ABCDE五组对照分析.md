# 20260918_第24版_ABCDE五组对照分析

## 1. 实验目的与设置

本轮检验四个问题：路由输入处理是否改善塌缩（B−A）；稳定训练措施是否改善塌缩及误差（C−B）；丰富训练缺失模式是否有帮助（D−A）；传递上一轮专家身份是否有帮助（E−D）。

| 组别 | 设置 | 解释范围 |
|---|---|---|
| A | 清洁 TaxiBJ + 原始硬路由 + balance=0.01 | 本轮参照 |
| B | A + 分组路由输入、训练统计缩放、仅观测点时空差分 | 整组输入处理变化，不能归因于其中一个子项 |
| C | B + FP32 路由、小初始化、路由低学习率、软到硬预热、z-loss=0.001 | 整组稳定策略，不能归因于 z-loss 单项 |
| D | A + 九类训练 mask 均匀覆盖、每轮重采样 | 同时改变形态、重采样和训练任务分布 |
| E | D + 上一轮实际选择专家的信息 | 检验显式路由历史 |

五组均为单尺度、四轮、六专家、seed=7、batch=16、70 epoch、每两轮验证、70 轮余弦日程。清洁数据训练/验证/测试为 2452/342/707 个窗口，每轮 154 batches。数据清理剔除时间断点窗口及跨集合共享帧窗口，保留原窗口对应掩码。所有组使用同一个验证/测试 random_point 40% CSV；A/B/C 使用固定随机点训练 mask，D/E 使用九种训练几何模式，缺失总量都为每窗口 4915/12288。D/E 同 epoch、同窗口的 mask 相同。

实际训练起始为 2026-09-17 22:23:45，最后 E 约在 2026-09-18 07:24:36 完成；五组训练流程用时合计 9.01 小时，单组约 1.78–1.83 小时。

### 完整性核验

五组均通过启动器 `check_complete`：70 个连续 epoch、35 条验证、1 条最终测试、最佳 checkpoint 存在；CPU 读取 checkpoint 内 epoch 与验证最优 epoch 相符。保存配置与计划一致，protocol 中全部文件内容哈希与当前文件一致，没有失败或遗漏组合。日志数值字段没有 NaN/Inf。

AMP 全程跳步 A/B/C/D/E 分别为 9/10/10/14/13 次，对应实际更新 10771/10770/10770/10766/10767 次；名义更新槽均为 10780，差异不足 0.05% 的更新槽。最后十轮均无 AMP 跳步。这些少量差异已记录，不把“相同 epoch”写成“实际 optimizer update 完全一致”。

## 2. 最新模型结构

以下依据当前源码，并通过 protocol 哈希确认与训练时一致。

输入为 `[B,2,12,32,32]` 流量及观测 mask。隐藏位置以零填充给模型，真实标签仅用于缺失位置监督；原始观测 mask 全链固定。模型由原始观测 mask 计算时间/空间可用性、缺口长度、前后观测距离等 10 类支持特征，并加入 T/H/W 坐标投影。编码器得到 64 维隐藏状态，解码初始预测，观测点始终恢复真实可见值。

每轮路由聚合当前隐藏状态、补全值、支持特征、预测变化以及缺失比例；四个路由器参数独立。专家池跨轮共享：T 是局部时间卷积，S 是局部空间卷积，TD/SD 是 dilation=2 的方向卷积，TA 是每个空间节点内全窗口时间注意力，ST 是局部三维时空卷积。每轮将选中专家更新与共享逐点专家更新加到隐藏状态，再解码、保留可见值、记录预测变化供下一轮使用。

硬路由训练使用 straight-through Gumbel，计算所有专家候选再用选中权重融合；硬路由评估使用确定性 argmax，并只执行选中的专家。因此当前训练实现的路径稀疏不等于训练计算量按 Top-1 减少。

B/C 用按组投影替换原路由输入处理；训练集均值/标准差只用于路由中的数值特征，观测差分不读取隐藏真值。参数数分别为 A/D 211507、B/C 194787、E 212659；B/C 还含 4 个均值/标准差 buffer 元素，它们不是可训练参数。

C 路由学习率 1e-4，主干 1e-3；前五轮采用带均匀底座的软融合，第 6–10 轮逐渐转硬，第 10 轮开始完全硬选择。验证/测试从第一轮就采用硬 argmax。E 在第 2–4 轮路由 MLP 的隐藏激活处，加入上一轮实际选中专家 one-hot 的可学习嵌入；共 1152 个新增参数、零初始化。训练时使用实际 Gumbel 选择；one-hot detach，而正常动态状态梯度仍保留。不禁止重复选同一专家。

目标为缺失位置原流量单位的 L1，五组都加逐轮 batch balance 的均值，权重 0.01；C 额外加 logits 的 `logsumexp²` 均值，权重 0.001。中间轮预测损失关闭。MAE/RMSE 在完整 split 的有限缺失目标上累积分子与分母计算；训练 `loss` 是 batch 日志均值并含辅助项，不应与数据集级 MAE 混用。每两轮按验证 MAE 保存最佳模型，最后加载它测试一次。

## 4. 可以得出的结论与机制线索

### 4.1 A/B：清洁数据和路由输入分组都未消除单路径退化

A 从第 4 轮开始每次验证只走一条路径；B 从第 2 轮开始始终只有一条验证路径。最终测试分别为 `TA→ST→S→TA` 和 `TA→ST→TA→ST`。误差继续下降说明这些固定专家组合能学习补全任务，但没有展示按样本选择不同专家链的优势。

B−A 的小幅误差变化不支持“只改路由输入就能解决问题”。但 B 同时改变输入结构、特征和参数数，不能据此认定观测差分等每一个子项都无用。

### 4.2 C：缓解概率饱和与专家长期无梯度，但还未变成精度增益

C 第 70 轮训练记录 60 条路径，最大路径仅占 15.25%；六个专家该轮都在一部分 batch 获得有效梯度。A/B 同期训练均为一条路径，多个专家整轮无梯度。

C 的测试只有两条路径，实际仅选 TA/ST，第三轮始终选 ST。训练中的 60 条路径包含 Gumbel 随机探索；不能把训练路径数直接写成推理时已经学习了 60 种有用模式。训练/测试还涉及不同样本，严格区分采样与输入条件化需要在同一批样本上分别统计随机与确定性路由。

C 第 70 轮 balance 约为 2.757（加权后 0.02757），A/B 接近 6（加权后 0.06）。C 抽样记录的路由 balance 梯度范数约 0.0525，z-loss 梯度约 0.0394；A/B 当轮记录为 0。这支持“C 整组措施保持了路由可训练性”，但诊断梯度是每 50 batch 抽样、未经 GradScaler 放大的单项 autograd 梯度，且 A/B 路由处于 AMP，记录的零不能等同于精确数学梯度严格为零。概率饱和及数值精度可能共同影响它。

C 第 4 轮训练 MAE 为 **20.3377**，硬路由验证 MAE 为 **272.6373**；第 6 轮分别约 **14.6037/205.7693**，第 8 轮验证才回落到 **11.6901**。结合代码的软融合训练、硬选择验证，强烈提示软/硬执行方式的适配问题；精确归因仍应在同一 checkpoint、同一验证样本上对比软/硬执行，不能单凭不同 split 的指标认定唯一原因。

C 在与 B 相同的随机点 mask 下已经恢复部分确定性路径多样性，说明路由优化设置本身也影响塌缩，缺失模式单一不是唯一解释。C 比 B 测试 MAE 更差约 3.94%，目前应视为“路由状态改善、任务误差尚未改善”的机制对照。

### 4.3 D：支持“丰富 mask 能缓解单路径退化”，但不支持“这样就会更准确”

D 测试有三条确定性路径，最大占比 **47.67%**；这一结果出现在与 A 相同的 random_point 测试 mask 上，因此不仅是统计了更复杂的训练 mask 所产生的路径数。D 训练第 70 轮有 10 条路径，各专家都曾获得梯度，但 T/TD/SD 的覆盖仍很低。

与此同时 D 的随机点测试 MAE 比 A 上升 **61.88%**。D 把直接 random_point 训练窗口比例由 A 的 100% 降至约 1/9，其余是相关缺失、连续断点、区域缺失等更难的任务；它同时引入逐轮重采样。相同缺失总量和 epoch 不代表相同任务难度或随机点任务暴露次数。因此不能从本轮结果断言复杂缺失训练对所有模式都不好，也不能把性能下降唯一归因于路由。

九类训练任务平均覆盖是一项实验设计选择，并非已验证的最优比例。测试分布集中在随机点任务，而训练目标在九类任务间分配容量，这构成明确的分布改变。D/E 最后训练 MAE 为 38.16/40.56，验证 MAE 约 12.50/12.89；训练 mask 更难，不能把这个 train-val 落差直接判断为泄漏或普通过拟合。

值得进一步检查容量与感受野：当前共享专家是逐点的；TA 只沿同一空间节点的时间轴聚合。D/E 前两轮在测试中都固定 TA，对于整节点缺失或大块缺失，这种早期处理顺序可能限制获取空间证据的能力。但该解释尚无固定路径/专家替换对照支持，属于待验证机制。

### 4.4 E：新增历史通道确实学了参数，本轮没有带来收益

E 的测试 MAE 比 D 更差 **4.35%**，RMSE 更差 **2.88%**。路径数从 3 增至 4、最大路径占比从 47.67% 降至 46.53%，却没有带来更好的误差。故当前 E 实现没有支持“显式传上一轮专家身份能改善补全”的结论；单种子也不足以宣称这类机制普遍无效。

checkpoint 中三个新增嵌入均已非零，确认它们参与了学习。关键限制是：E 测试的第 1、2 轮均 100% 选 TA，因此第 2、3 轮接收的上一轮身份同样恒为 TA；在这些测试样本之间，新增历史没有区分度，只有最后一轮能接收到变化的上一轮身份。原动态状态本来也携带前面专家处理结果，额外离散身份并不必然增加足够有用的信息。

E 还在第 8、12、14、16、20 轮验证出现单一路径，后面才恢复多路径。它未阻止早期退化；“路径更丰富”不能单独证明历史传递成功。

### 4.5 路径多样性尚未证明专家按缺失模式分工

下列均为验证选出的最佳模型在相同随机点测试集的确定性硬路由，707 个窗口：

- **A**：`TA → ST → S → TA` 100.00%。
- **B**：`TA → ST → TA → ST` 100.00%。
- **C**：`ST → TA → ST → ST` 61.24%；`TA → ST → ST → TA` 38.76%。
- **D**：`TA → TA → TA → TA` 47.67%；`TA → TA → S → TA` 44.41%；`TA → TA → TA → SD` 7.92%。
- **E**：`TA → TA → TA → TA` 46.53%；`TA → TA → SD → TA` 34.23%；`TA → TA → TA → T` 12.45%；`TA → TA → ST → TA` 6.79%。

D/E 的主要变化集中在第 3 轮；第 1、2 轮持续依赖 TA。A/B 多次选用 TA/ST 也说明专家存在明显偏好，但可能同时来自结构适配、容量差异和训练中的选择反馈，尚不能证明弱专家天生无用。

## 7. 结论与下一步

**最稳妥的结论：输入缺失分布和路由优化都影响塌缩；缓解塌缩还没有转化为当前随机点任务的误差收益；E 的历史通道本轮没有收益。** A 是当前随机点评测的误差参照，C 是保持路由可训练性的机制参照，D 是丰富缺失任务能改变路径行为的机制参照。三者用途不同，不宜只按一个分数选定后续所有设计。

建议按以下顺序补证据，先利用现有 checkpoint，暂不重复大规模训练：

1. **共用九类固定 mask 做评估。** 用已有 evaluate_mask_panel.py 在同一窗口、同一固定 mask 上比较 A/C/D/E，报告每类 MAE/RMSE和硬路由；主验证选择规则不变，不利用新测试面板挑训练 checkpoint。这样能区分 D/E 是多任务迁移代价，还是所有模式都退步，并检查路径是否随 mask 改变。
2. **补等深固定路径对照。** A/B 已经展示固定链可取得较低误差，但尚未证明动态选择的价值。用训练/验证记录确定候选固定链，从头训练同样四轮、相同数据和预算的固定模型，与动态模型比较；不要从测试成绩筛选固定路径。共享链级模块使“堆深后变好”仍是未排除解释。
3. **拆开“形态”与“重采样”。** 保留 A；增加逐轮重采样随机点对照，再逐步加入结构 mask。如果最终目标仍以随机点缺失为主，可试验以随机点为主的混合比例，而非一开始九类等权。比例是待验证超参数，不声称某个新比例一定有效。
4. **拆分 C 的稳定策略。** 优先用同一 checkpoint 的软/硬执行诊断确认差距，再测试更接近硬推理的探索/预热方式；分别验证 FP32、学习率、z-loss 等，保留有效部分。当前 C−B 不能判定是哪一项带来好处或损失。
5. **暂缓把 E 作为默认改进。** 等前两轮有可验证的条件化选择后，再检验上一轮身份的边际价值。可先在固定 checkpoint 下做历史输入置零干预，量化当前 E 到底多依赖这条通道；干预结果属于机制诊断，不等同于重新训练消融。
6. 后续选定少量候选再补多个随机种子，用均值/标准差检验稳健性。当前所有结果仅 seed 7，尤其 A/B 的 0.17% 差距不能用来作确定性优劣结论。
