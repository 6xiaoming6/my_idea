# 20260714_第14版_V14三数据集全量实验分析

## 1. 实验目的与结论摘要

本报告分析 `v14-single` 分支的 DAS-C2F-MoE（Difficulty-Adaptive Safeguarded Coarse-to-Fine Multi-Resolution Mixture-of-Experts）完整实验结果。分析对象为 TaxiBJ、BikeNYC 和 CHAP_Beijing，在 fixed/random 两种缺失模式和 0.2、0.4、0.6、0.8 四种缺失率下的全部 24 个 Full Model 实验。

核心结论如下。

1. **实验覆盖完整且日志质量合格。**24/24 个正式组合均完成训练、定期验证、最佳模型保存、最佳权重加载和最终测试；未发现 NaN、Inf、失败任务、缺失测试记录或缺失 `best.pt`。
2. **V14 是 main、V9、V14 三者中跨数据集综合稳定性最好的版本。**24 个单点中，V14 获得 15 个 MAE 最优，V9 获得 6 个，main 获得 3 个。
3. **V14 对 BikeNYC 和 CHAP 的改进成立。**相对 main，BikeNYC 八点平均 MAE 改善 3.46%，CHAP 改善 7.81%；相对 V9，分别改善 19.70% 和 4.77%。
4. **TaxiBJ 只取得有限改善，仍不如 V9。**V14 相对 main 的 TaxiBJ 八点平均 MAE 改善 2.82%，但相对 V9 退化 11.99%。
5. **安全残差路径有效，但门控可解释性存在问题。**24 个实验中 V14 final 均优于同次训练的 `x_base`；但原始 `x_ctf` 候选远差于 `x_base`，同时出现“极小 `alpha_final` + 极大 `delta_ctf`”的尺度补偿。当前收益更像来自高幅值 CorrectionAdapter，而不是完全校准、可直接解释的安全 gate。
6. **TaxiBJ random 存在明显中后期过拟合，CHAP 则仍在末期改善。**最佳 checkpoint 机制成功避免使用最后一轮退化参数，但训练预算仍可优化。

第14版可以作为下一阶段统一主力方向，但不应直接把当前 alpha 解释为严格的安全概率。下一版应优先解决 correction/gate 的尺度不可辨识问题，并完成消融和多随机种子实验。

## 2. 实验设置

### 2.1 数据集与输入

| 数据集 | Train / Val / Test | 输入 shape | Batch size | 参数量 |
|---|---:|---:|---:|---:|
| TaxiBJ | 2491 / 356 / 712 | `[N,2,12,32,32]` | 32 | 4,947,169 |
| BikeNYC | 511 / 73 / 147 | `[N,2,12,24,12]` | 16 | 4,885,345 |
| CHAP_Beijing | 2626 / 322 / 322 | `[N,1,7,32,32]` | 32 | 4,940,442 |

模型使用 `[B,C,T,H,W]` 数据布局。Mask 为 `[B,1,T,H,W]`，1 表示观测位置、0 表示隐藏位置。训练损失和 MAE/RMSE 均只在隐藏位置计算。

每个数据集完整覆盖：

```text
mask_pattern = fixed / random
missing_rate = 0.2 / 0.4 / 0.6 / 0.8
seed = 42
```

不同缺失率下被隐藏的位置集合不同，所以更高缺失率不必然机械地产生更大 MAE；fixed mask 的区域难度差异尤其明显。

### 2.2 训练策略

| 数据集 | Epoch | Val interval | 验证次数 | Scheduler | AMP | Early stop |
|---|---:|---:|---:|---|---|---|

| BikeNYC | 140 | 2 | 70 | Cosine | 开启 | 关闭 |
| CHAP_Beijing | 150 | 5 | 30 | Cosine | 开启 | 关闭 |

共同设置：

```text
optimizer = AdamW
lr_main = 1e-3
lr_v14 = 1e-3
weight_decay = 1e-4
grad_clip_norm = 1.0
eta_min = 1e-6
```

训练流程为：

```text
训练 val_epoch 个 epoch
  -> 完整验证
  -> 以 val_mae 判断是否更优
  -> 更优时覆盖 checkpoints/best.pt
  -> 训练至配置上限
  -> 重新加载 best.pt
  -> 只运行一次完整 test
```

最终测试指标来自验证集 MAE 最优 checkpoint，而不是最后一轮。

## 3. 第14版最新模型结构

### 3.1 总体结构

V14 不复制新的 Encoder 或 MoE 专家池，而是只调用一次 main Backbone：

```text
Fine/Mid/Coarse observed inputs
        ↓
main MultiScaleMoEBackbone
        ├── x_base
        ├── z_f / z_m / z_c
        ├── h_main
        └── scale_gate
                ↓
Difficulty + Reliability + Geometry
                ↓
alpha_mid / alpha_fine
                ↓
SafeCoarseToFineRefiner -> x_ctf
                ↓
ObservedConsistency(x_base, x_ctf, x_obs, mask)
                ↓
alpha_final
                ↓
x_final = x_base + alpha_final * delta_ctf
```

Architecture Registry 通过 `v14_safe_c2f_moe` 启用该包装器；未指定架构时仍默认 main，因此没有改变 main 的默认结构。

### 3.2 数据与多尺度构造

细尺度观测输入为 `x_f_obs=x_f_gt*m_f`。Mid/Coarse 只从观测值执行 masked average pooling：Fine→Mid 的空间核为 2，Fine→Coarse 为 4。池化同时产生观测值、二值有效 mask 和观测比例可靠性 `r_m/r_c`，不会读取隐藏位置 ground truth。

### 3.3 main 稳定 Backbone

main Backbone 的维度为 64，包含 4 个共享专家，路由 Top-K 为 2。每个尺度依次执行：

1. `ScaleTokenEncoder` 融合 value、mask、scale、time 和 spatial embedding；
2. `QualityRouter` 根据尺度特征和观测统计产生专家权重；
3. `TopKRoutedExpertPool` 产生 `z_f/z_m/z_c`；
4. `ProgressiveRouteFusion` 执行 routed branch 的 coarse→mid→fine 融合；
5. `GatedCrossScaleSharedExpert` 根据尺度质量和可靠性融合 shared branch；
6. `SharedRoutedResidualFusion` 融合稳定 shared 主路径与 routed 残差；
7. Prediction Head 输出 `x_base`。

TaxiBJ 保留 `fine_mid`，BikeNYC/CHAP 使用 `fine_mid_coarse`，没有为了 V14 强行改写原数据集尺度策略。

### 3.4 DifficultyConditionEncoder

V14 在 fine/mid/coarse 三尺度分别计算 9 个仅依赖观测的统计量：

```text
missing_rate, observed_ratio,
temporal_gap_score, spatial_block_score,
neighbor_density, local_value_variance,
temporal_variance, scale_reliability,
cross_scale_consistency
```

三尺度共 27 维。方差特征先经 `log1p`，再通过 `Linear(27,32) -> LayerNorm -> GELU -> Dropout -> Linear(32,32)` 得到 32 维条件向量。

### 3.5 安全前置条件与几何

生成 C2F 候选前，控制器拼接：

```text
difficulty embedding: 32
mid/coarse reliability: 2
main scale_gate: 3
geometry descriptor: 5
总计: 42 维
```

Geometry 包含 `H/32、W/32、H/W、min(Hc,Wc)/8、Hc*Wc/(H*W)`，用于感知 BikeNYC 的非方形小 coarse 网格，而不硬编码 dataset ID。

### 3.6 SafeCoarseToFineRefiner

Refiner 复用 `z_f/z_m/z_c/h_main`：

```text
x_coarse = CoarseHead(z_c)
x_mid = up(x_coarse) + alpha_mid * MidResidual(z_m, embed(up(x_coarse)))
x_ctf = up(x_mid) + alpha_fine * FineResidual(z_f, h_main, embed(up(x_mid)))
```

Fine residual 额外接收 `h_main`，用于保护 main 已融合的细粒度信息。候选修正为：

```text
concat(x_ctf-x_base, x_base, x_ctf)
 -> Conv3D(3C,16,3x3) -> GELU
 -> Conv3D(16,C,1x1) -> delta_ctf
```

最后一层零初始化，初始 `delta_ctf=0`。

### 3.7 ObservedConsistency 与 SafetyController

得到 `x_ctf` 后，仅在真实观测位置计算 base MAE、ctf MAE、二者差值、`|ctf-base|` 均值和 q95。预测在构造这些统计时被 detach，避免模型操纵安全信号。

控制器最后一层零初始化，基础设置为：

```text
alpha_mid_max = 0.8,  bias = -3
alpha_fine_max = 0.8, bias = -3
alpha_final_max = 0.5, bias = -5
```

初始 `alpha_mid≈alpha_fine≈0.038`、`alpha_final≈0.0033`；配合零初始化 CorrectionAdapter，V14 初始化严格满足 `x_final=x_base`。

### 3.8 Loss 与指标

V14 保留 main 的主损失、跨尺度一致性、MoE balance、shared/route auxiliary 和 complementary loss，并增加：

```text
L_base   = SmoothL1(x_base, y_hidden)
L_mid    = SmoothL1(x_mid, y_mid_hidden)
L_coarse = SmoothL1(x_coarse, y_coarse_hidden)
L_regret = mean(ReLU(|x_final-y| - |stopgrad(x_base)-y|))
L_gate   = mean(alpha_final)
```

权重为 0.25、0.05、0.03、0.10、0.0001。`L_regret` 是软约束，不保证每个隐藏元素严格不退化。

MAE/RMSE/MAPE 只在隐藏位置计算。TaxiBJ/BikeNYC 含大量 0 或近 0 目标，当前 MAPE 被 `1e-6` 分母放大到数万量级，不适合作为论文主指标；本报告以原始范围 MAE/RMSE 为主。

## 6. 各数据集训练趋势

### 6.1 TaxiBJ

八个实验平均训练 loss 下降 89.57%，训练 MAE 从平均 76.13 降至 7.93，没有数值不稳定。

Fixed 最优 epoch 为 125–160，说明需要接近完整 160 epoch。fixed@0.4 在 epoch125 后验证 MAE 退化 2.31%，其余 fixed 末期退化不超过 0.14%。

Random 最优 epoch 明显提前到 55–105。最后验证相对最佳验证退化：rate0.2 为 18.00%、rate0.4 为 12.56%、rate0.6 为 4.18%、rate0.8 为 3.88%。这是最明确的过拟合组。最佳 checkpoint 机制避免了使用第160轮参数，但 future multi-seed 可针对 TaxiBJ random 启用 patience 节省时间。

Best-val 与 test MAE 的 Pearson 相关约 0.963，平均绝对差 0.393，整体排序一致。Fixed 呈 U 形，random@0.6 也优于 0.2/0.4；这更像 mask 隐藏区域难度差异，而不是日志错误。

V14 相对 main 有小幅整体收益，但只在 fixed@0.6、fixed@0.8 两点优于 V9。TaxiBJ 是下一版首要优化对象，当前过于谨慎的安全路径没有保留 V9 的主要上限。

### 6.2 BikeNYC

平均训练 loss 下降 80.66%，训练 MAE 从 6.70 降至 1.36。Fixed 最优 epoch 为 108–138，random 为 76–106。最后验证相对最佳验证的退化为 fixed 0.06%–0.22%、random 0.69%–3.06%，过拟合较轻。

Best-val 与 test 相关约 0.988，平均绝对差仅 0.062，checkpoint 选择很稳定。Fixed@0.6 最好，random 四点接近。较高 RMSE 表明仍存在少量长尾大误差位置。

V14 相对 V9 的 fixed/random 平均改善 11.60%/26.13%，相对 main 八点平均改善 3.46%，只有 fixed@0.8 比 main 高 0.86%。因此 V14 基本解决了 V9 在 BikeNYC 上的整组退化，main bypass、fine protection 和几何/可靠性条件的整体策略是有效的。

### 6.3 CHAP_Beijing

平均训练 loss 下降 96.49%，训练 MAE从 19.50 降至 0.858。5/8 个实验最佳 epoch 正好为150，另3个为145；末期验证退化不超过0.70%。CHAP 没有明显过拟合，训练末期仍在缓慢改善。

Best-val 与 test 相关约 0.989。所有 test MAE 均比 best-val 低约 0.14–0.16，平均偏移 -0.151，表现为稳定的 split-level 难度差异，而不是单点异常。

V14 相对 main 平均改善 7.81%，相对 V9 改善 4.77%；七点优于 V9，仅 fixed@0.6 比 V9 高 1.85%。这是 V14 最成功的数据集。

## 7. 安全门控诊断

### 7.1 Final 对同次 Base 的收益

这里 `x_base` 是 V14 同次联合训练的 main 路径，不等于独立 main 实验。

| 数据集 | Fixed 改善 | Random 改善 | 全部改善 |
|---|---:|---:|---:|
| TaxiBJ | 3.03% | 16.82% | **9.92%** |
| BikeNYC | 4.21% | 6.76% | **5.49%** |
| CHAP | 8.16% | 10.96% | **9.56%** |

24/24 点 final MAE 都低于同次 `x_base`，说明新增修正确有平均正收益。

### 7.2 Raw C2F 候选异常

直接 `x_ctf` 的 MAE 远高于 base，平均 `ctf_mae/base_mae` 为：

```text
TaxiBJ fixed/random:  7.85x / 5.71x
Bike fixed/random:    5.74x / 4.01x
CHAP fixed/random:   23.64x / 18.85x
```

因此当前 C2F Refiner 没有形成可独立使用的高质量候选。最终收益主要来自 CorrectionAdapter 对 `[x_ctf-x_base,x_base,x_ctf]` 的重新映射。

### 7.3 极小 alpha 与极大 correction

Test 平均 `alpha_final`：

| 数据集 | Fixed | Random |
|---|---:|---:|
| TaxiBJ | 0.00255 | 0.01815 |
| BikeNYC | 0.00865 | 0.01945 |
| CHAP | 0.00115 | 0.00139 |

但 `delta_ctf` RMS 平均达到 TaxiBJ 约 569–579、Bike 约 57–81、CHAP 约 236–257。模型可通过 alpha 变小、delta 同比例变大保持实际修正幅度，削弱 `L_gate=mean(alpha)` 的意义。alpha 不能直接解释为分支贡献率或校准置信度。

后续必须同时记录：

```text
alpha_final
delta_ctf_norm
effective_residual_norm = norm(alpha_final * delta_ctf)
final-base improvement
```

### 7.4 Non-regression violation

隐藏位置 final error 大于 base error 的比例平均为 TaxiBJ 41.6%、BikeNYC 41.4%、CHAP 40.8%。这与平均 MAE 改善不矛盾：约40%的位置小幅退化，其余位置取得更大改善。当前 regret 是软保护，不是严格逐点保证。

部分 gate 行为符合预期：TaxiBJ/Bike random alpha 高于 fixed，raw C2F 观测一致性较差时 alpha 多数很小。但 CHAP random@0.8 没有显著更高 alpha，TaxiBJ alpha 还经常随缺失率升高而下降；结合尺度补偿，不能只用 alpha 曲线支撑论文叙事。

## 9. 论文结论与下一步

### 9.1 当前可以支持的结论

1. V14 相对 main 提升了三个数据集的平均 MAE；
2. V14 显著缓解了 V9 在 BikeNYC 上的跨网格不稳定；
3. V14 在 CHAP fixed/random 上均取得稳定收益；
4. main bypass + residual correction 避免了 raw C2F 较差时的整组灾难性退化；
5. 验证集最佳 checkpoint 机制有效保护了 TaxiBJ random 的最终测试。

### 9.2 尚不能宣称的内容

当前不能声称 alpha 是校准置信度、V14 逐点不退化、每个新增模块都有效或结果具有统计显著性。原因是 gate/correction 尺度补偿、约40% point-wise violation、未完成消融且只有单种子。

如果目标是三个数据集统一模型，V14 比 main/V9 更适合作为下一步主力方向；如果只关注 TaxiBJ，V9 当前仍更强。

### 9.3 优先建议

1. **解决尺度不可辨识：**对 `delta_ctf` 做 RMS normalization/有界映射，或正则化 `norm(alpha*delta)` 而不是 alpha；增加 `effective_residual_norm` 日志。
2. **提升 raw C2F：**检查 Mid/Coarse 有效监督率，尝试让 C2F 预测相对 `x_base` 的多尺度残差，而非从 coarse 重建完整绝对值。
3. **运行核心消融：**至少验证 no_dynamic_gate、no_difficulty、no_observed_consistency、no_regret_guard、no_multiscale_supervision、no_fine_protection、no_main_bypass 和 main_fallback。
4. **多种子复跑：**优先复核 TaxiBJ fixed@0.2、TaxiBJ random@0.8、Bike fixed@0.8、CHAP fixed@0.4，再扩展到24点。
5. **训练策略：**TaxiBJ random 可用 patience 节省训练；CHAP 可单独检查170–180 epoch上限，但论文主对照仍保持150；Bike140已足够。
