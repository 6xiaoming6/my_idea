# 20260719_第16版_V16三数据集全量实验分析

## 1. 实验目的与结论摘要

本报告分析 `v16-single` 分支的 V16 教师锚定连续残差校准 MoE（Teacher-Anchored Continuous Residual Calibration MoE，TA-CRC-MoE）全部正式实验结果。统计范围严格限定为：

```text
outputs/v16-single/{dataset}/full/model/{fixed|random}/rate{0.2|0.4|0.6|0.8}/...
```

TaxiBJ、BikeNYC、CHAP_Beijing 各覆盖 fixed/random 两种缺失模式和 0.2、0.4、0.6、0.8 四个缺失率，共 24 组。`unknown/debug/smoke_v16` 不进入正式统计。

核心结论如下。

1. **24/24 组正式实验全部完整结束。**每组均跑满配置 Epoch，完成定期验证、验证 MAE 最优 checkpoint 覆盖、重新加载 `best.pt` 和最终测试。24 个 `config.json`、`metrics.jsonl`、`best.pt`、`test.log` 全部存在，3440 个 Epoch 记录和所有数值字段均未发现 NaN/Inf。
2. **V16 是目前四个后期版本中逐点最佳次数最多的版本。**在 V14、V15、V15.1、V16 的 24 点对比中，V16 取得 11 个最佳，V14 取得 9 个，V15 取得 3 个，V15.1 取得 1 个。V16 相对 V15.1 为 18 胜 6 负，逐点相对 MAE 平均改善 5.01%；相对 V15 为 19 胜 5 负，平均改善 4.18%。
3. **CHAP 是 V16 最成功、机制最完整的数据集。**八组全部优于 V14、V15 和 V15.1；相对 V14，fixed/random 分组平均分别改善 5.50%/4.89%；相对 V15.1 两组都平均改善约 12.84%。最终输出八点全部优于同次训练的 Student Base，Alpha Spearman 为 0.687～0.899，中间 Oracle Alpha 比例为 90.3%～98.0%，Calibration Regret 仅 0.0005～0.0047。
4. **TaxiBJ fixed 同样明显成功。**四点中 V16 在 0.2、0.4、0.6 三点为四版本最佳，分组平均相对 V14 改善 5.81%、相对 V15.1 改善 7.12%。其中 fixed@0.2 从 V14 的 8.7773 和 V15.1 的 7.5310 降至 7.4791。
5. **TaxiBJ random 仍是主要失败区域。**random@0.2 和 random@0.4 分别比 V14 退化 22.20% 和 21.25%；Student Base 相对教师分别弱 24.46% 和 19.43%。random@0.4 的 Candidate 比 Base 差 1.2414，最终仍比 Base 差 0.1996，样本非退化违反率达到 77.99%。这说明 Teacher Anchor 没有稳定保护该区域，连续校准也没有充分抑制有害候选。
6. **BikeNYC 没有获得稳定净收益。**相对 V14 八点全部退化 0.13%～9.50%；fixed/random 平均比 V14 退化 3.42%/3.79%。Alpha 样本标准差只有 0.0025～0.017，平均 Spearman 仅 fixed 0.126、random -0.007；Candidate 八点中仅一点评价均值略优于 Base，最终分组平均仍略差于 Base。
7. **连续校准的有效性具有强数据集依赖。**CHAP 上观察位置 Candidate Gain 与 Oracle Alpha 的相关性达到 fixed 0.772、random 0.843，说明新增条件确实学到了可解释的样本级缩放；BikeNYC 上 Alpha 接近实验级常数；TaxiBJ fixed 的 Alpha 也较集中，而 TaxiBJ random 虽有较大样本变化，但 random@0.4 仍明显不够保守。
8. **设计文档的三 seed 准入标准尚未满足，也不能用当前结果宣称统计显著。**本批 24 点只有 `seed=42`，没有 `2026/3407`。在设计文档指定的六个诊断点上，V16 seed42 仅 3/6 优于 V15.1、2/6 优于 V14；TaxiBJ random@0.4/@0.8 均未保留 V15.1 的优势。因此 V16 可以作为下一阶段主力候选，但还不能直接取代 V14 成为所有场景的统一论文模型。
9. **训练成本上升但显存仍可控。**24 组累计 Epoch 时间约 22.59 小时，较 V15.1 报告中的 17.84 小时增加约 26.6%。峰值显存为 TaxiBJ 11.86 GB、BikeNYC 1.83 GB、CHAP 7.18 GB，单卡 RTX 3090 可以完成。
10. **MAPE 仍不适合 TaxiBJ/BikeNYC。**两者存在零或近零目标，`eps=1e-6` 使 MAPE 达到数万量级；论文主结果应使用原始范围 MAE、RMSE。CHAP 的 MAPE 约为 0.023～0.028，可作为辅助指标。

综合判断：**V16 是目前最有潜力的后续主力方向，因为它在 24 点中取得最多最佳结果，并彻底修复了 V15.1 在 CHAP 上的退化；但当前版本不是全局稳健赢家。后续应保留 V16 的 Teacher Anchor + Continuous Calibration 主框架，优先修复 TaxiBJ random 低缺失率的 Base 漂移和 BikeNYC 的 Alpha 塌缩。**

### 2.1 数据集、输入与学生参数量

| 数据集 | Train / Val / Test | 输入 shape | Batch size | Scale mode | V16 学生参数量 |

| CHAP_Beijing | 2626 / 322 / 322 | `[N,1,7,32,32]` | 32 | fine + mid + coarse | 4,729,121 |

统一张量布局为 `[B,C,T,H,W]`，mask 为 `[B,1,T,H,W]`：

```text
m_f = 1：已观测位置
m_f = 0：需要补全的位置
x_f_obs = x_f_gt * m_f
```

Mid/Coarse 只从 `x_f_obs` 和 mask 进行 masked average pooling，不读取隐藏 target；同时输出窗口观测比例 `r_m/r_c`。MAE、RMSE、主损失和 V16 诊断均在 `1-m_f` 对应的隐藏位置计算。

每个实验使用：

```text
student seed = 42
teacher seed = 42
mask pattern = fixed / random
missing rate = 0.2 / 0.4 / 0.6 / 0.8
```

当前各 rate 的离线 mask 不是严格嵌套 mask，因此不同缺失率之间的难度不能只按 rate 大小解释。

## 3. 最新 V16 模型结构

### 3.1 总体数据流

V16 注册架构为 `v16_teacher_anchored_residual_moe`，顶层仍由 `DualBranchSTImputer` 调用。旧 Aux Branch 在正式配置中关闭：

```text
Observed Fine/Mid/Coarse + mask + reliability
            ↓
Student MultiScaleMoEBackbone
  ├─ x_base
  ├─ z_f / z_m / z_c / h_main
  ├─ x_hat_shared / x_hat_route
  └─ scale_gate
            ↓
ScaleGuidedResidualAdapter (64 -> 24 dim)
            ↓
delta_candidate = 0.05 * scale_ref * tanh(delta_raw)
            ↓
12-D observable condition
            ↓
ContinuousResidualCalibrator (12 -> 32 -> 1)
            ↓
alpha = sigmoid(logit)
            ↓
x_final = x_base + alpha * delta_candidate
```

最终完整输出为：

```text
x_comp = m_f * observed_truth + (1-m_f) * x_final
```

### 3.2 V14 Teacher Anchor

训练启动时，`AUTO_RESOLVE` 严格按以下字段寻找对应 V14 `best.pt`：

```text
dataset + mask pattern + missing rate + teacher seed
```

随后把 V14 内部 `main_backbone` 的同名同 shape state tensor 拷贝到 V16 `student_backbone`，24 组均为 324/324。V14 完整模型作为冻结 Teacher：

```text
teacher.eval()
requires_grad = False
teacher forward under no_grad
```

Teacher 不注册为 V16 子模块，不进入学生 state dict；学生 checkpoint 只保存 Teacher branch、commit、checkpoint path、SHA256、best epoch 和 seed 等元数据。测试日志中的 `teacher_hidden_mae` 与对应 V14 正式结果一致，因此它可直接作为同 mask、同 rate 的 V14 参照。

需要注意：Student 只初始化为 V14 的内部 Main Backbone，不复制 V14 的安全粗到细 Refiner；Teacher 监督目标则是 V14 完整最终预测。这就是 `x_base` 与 `x_teacher` 初始职责不同的原因。

### 3.3 Stable Multi-Scale MoE Student Backbone

Student Backbone 沿用稳定 Main 结构，隐藏维度 64，4 个共享时空专家，样本级 Top-2 路由：

1. `ScaleTokenEncoder` 融合 value、mask、尺度、时间和空间 embedding；
2. `compute_observation_stats` 从 mask 产生观测质量统计；
3. `QualityRouter` 根据全局特征、质量和尺度条件产生专家权重；
4. `TopKRoutedExpertPool` 选择 Top-2 专家，三尺度共享专家参数；
5. coarse→mid→fine 的 routed branch 与跨尺度 shared branch 并行；
6. `SharedRoutedResidualFusion` 以 shared 为主路径，加入 routed residual；
7. Prediction Head 输出 `x_base`。

V16 没有增加专家、Encoder、Router 或第二套 Main Backbone。

### 3.4 轻量残差候选

V16 复用 V15.1 的尺度引导轻量 Adapter：

```text
z_f/z_m/z_c/h_main
  -> 独立 1x1x1 Conv3D 投影到 24 维
  -> coarse/mid 轻量融合
  -> 一个 24维 Fine ResidualSTBlock
  -> Residual Head
  -> delta_raw
```

Backbone 特征和 scale gate 默认 detach 后进入残差支路，使 Candidate Loss 主要训练 Residual Proposer，不通过旁路改写 Main。非激活尺度严格屏蔽；TaxiBJ 只使用 fine+mid。

候选残差定义为：

```text
scale_ref       = RMS(stopgrad(x_base), over T/H/W), min=1e-3
direction       = tanh(delta_raw)
delta_candidate = 0.05 * scale_ref * direction
x_candidate     = stopgrad(x_base) + delta_candidate
```

逐元素满足 `|delta_candidate| <= 0.05 * scale_ref`。Residual Head 最后一层零初始化，初始严格满足 `x_final=x_base`。

### 3.5 12维连续校准条件

Calibrator 的输入全部是推理可见信息：

```text
1-3   missing rate / temporal missing / spatial missing
4-5   mid / coarse reliability
6-8   active fine / mid / coarse scale weight
9     candidate relative RMS
10    shared-route disagreement RMS
11    observed base MAE
12    observed candidate relative gain
```

其中 observed error/gain 只在真实已观测位置比较 `x_f_obs`，不读取隐藏 target。网络为：

```text
Linear(12,32) -> LayerNorm -> GELU -> Linear(32,1,bias=False)
+ fixed_bias(-2) -> sigmoid
```

Calibrator 无 Dropout，最后一层零初始化，联合阶段初始 `alpha≈sigmoid(-2)=0.119`。最终 Alpha 始终位于 `[0,1]`。

### 3.6 Oracle Alpha 与损失

训练 Loss 在隐藏位置对每个样本搜索：

```text
alpha_grid = [0, 0.125, 0.25, 0.375, 0.5, 0.625, 0.75, 0.875, 1]
```

选择使 Smooth-L1 最小的 `alpha_star`。它只用于 Loss，不进入 Forward 条件，因此不存在目标泄漏。

联合阶段总损失为原 Main 损失加：

```text
L_anchor = L_base_gt + 0.5 * L_base_teacher

L_total = L_main_original
        + 0.30 * L_anchor
        + 0.05 * L_candidate
        + 0.10 * SmoothL1(alpha_pred, alpha_star)
        + 0.10 * ReLU(final_sample_MAE - base_sample_MAE)
```

原 Main Loss 还包括跨尺度一致性、MoE importance/load balance、shared/route auxiliary 和 complementary loss。V16 Full 不使用 V15.1 的二值 BCE 接纳标签。

## 7. Teacher Anchor 与连续校准机制分析

### 7.1 分组机制指标

| 数据集 | Mask | Candidate-Base Gain | Final-Base Gain | Alpha mean±sample std | Alpha* mean | Middle Alpha* | Spearman | Regret |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| TaxiBJ | fixed | +0.106606 | +0.125497 | 0.747±0.024 | 0.791 | 30.54% | 0.119 | 0.0453 |
| TaxiBJ | random | -0.400400 | +0.050581 | 0.470±0.315 | 0.427 | 18.82% | 0.522 | 0.1482 |
| BikeNYC | fixed | -0.004018 | -0.000731 | 0.656±0.011 | 0.539 | 28.23% | 0.126 | 0.0043 |
| BikeNYC | random | -0.006040 | -0.001020 | 0.578±0.010 | 0.499 | 23.65% | -0.007 | 0.0114 |
| CHAP | fixed | +0.007907 | +0.045754 | 0.582±0.153 | 0.570 | 93.39% | 0.742 | 0.0012 |
| CHAP | random | +0.019823 | +0.067269 | 0.587±0.189 | 0.570 | 96.16% | 0.856 | 0.0025 |

24 点中，Candidate 均值只在 10 点优于 Base；经过连续校准后，Final 在 19 点优于 Base。这说明校准器总体上确实把“不稳定候选”转化成了更多净收益点，但不同数据集的质量差异很大。

### 7.2 CHAP：连续校准达到设计目标

CHAP 的 Alpha 具有三个同时成立的特征：

1. 样本标准差为 0.122～0.221，不是全局常数；
2. Alpha 与 Oracle Alpha 的 Spearman 为 0.687～0.899；
3. Oracle 中间比例超过 90%，说明二值接纳确实不足，连续比例是必要的。

观察位置 Candidate Gain 与 Alpha Star 的分组平均相关性为 fixed 0.772、random 0.843，是最主要的有效条件。即使 Candidate 聚合均值在 fixed@0.2、fixed@0.8、random@0.6 略差于 Base，Calibrator 仍能通过样本级缩放使 Final 在全部八点优于 Base。

CHAP 的 Calibration Regret 接近零、样本违反率低于 6%，说明当前 12 维条件在这个数据域内既能判断方向，也能估计采用比例。

### 7.3 BikeNYC：Alpha 塌缩，Residual 基本无效

BikeNYC Alpha 样本标准差只有 0.0025～0.017，远小于 Alpha Star 的 0.322～0.396；Alpha MAE 为 0.352～0.511。random 分组平均 Spearman 接近 0，fixed 也只有 0.126。

八点中 Candidate 只有 fixed@0.4 比 Base 好 0.00013，其余都更差；Final 虽然减少了候选伤害，但分组均值仍略差于 Base。可能原因包括：

- BikeNYC 训练集只有 511 个样本，12 维条件与 Oracle 监督仍不足以稳定拟合样本级比例；
- fixed mask 下难度/可靠性条件在同一实验中近似常量；
- Residual Proposer 没有学到足够可靠的方向，Calibrator 只能做近似固定缩放；
- 120 Epoch 中多个最佳点出现在 16～50 Epoch，后期存在轻微过拟合。

这里应优先修 Candidate 方向或采用更强的“拒绝默认值”，而不是继续扩大 Calibrator。

### 7.4 TaxiBJ：fixed 成功，random 两极分化

TaxiBJ fixed 的 Student Base 已经在四点全部优于 V14 Teacher，Final 又在三点继续改善 Base；整体性能很好。但 Alpha 样本标准差只有 0.014～0.045，Spearman 除 fixed@0.4 为 0.502 外，其余较弱。fixed 的主要优势更像是“强 Base + 有效 Candidate”，而不是高度精确的样本级校准。

TaxiBJ random 的 Alpha 样本标准差达到 0.237～0.362，random@0.4/0.6/0.8 Spearman 为 0.554/0.707/0.720，说明校准器确实在变化；但有变化不等于足够安全：

- random@0.2：Base 比 Teacher 差 24.46%，Final 仍比 Teacher 差 22.20%；
- random@0.4：Base 比 Teacher 差 19.43%，Candidate 比 Base 差 1.2414，Final 仍差 0.1996；
- random@0.4 Alpha mean=0.328，而 Alpha Star mean=0.171，仍明显过度接纳；
- random@0.4 Calibration Regret=0.3383、违反率=77.99%，是全部实验最差点。

因此 TaxiBJ random 的首要问题不是 Calibrator 没有样本变化，而是 Base Anchor 在 0.2/0.4 崩坏，同时 Candidate 在 0.4 的方向非常差。仅提高 Calibration Loss 权重可能不够，必须先保护 Base 并抑制有害 Candidate。

### 7.5 Base Anchor 标准

设计文档要求 Student Base 与 Teacher 的平均 MAE 差距不超过约 1.5%。按“Student 比 Teacher 更差的正向差距”检查，24 点中只有 9 点满足“不比 Teacher 弱超过 1.5%”；主要失败点是：

- BikeNYC 多数点：Base 弱 2.6%～9.2%；
- CHAP random 多数点：Base 弱 3.1%～9.3%，但 Final Residual 能全部追回；
- TaxiBJ random@0.2/@0.4：Base 弱 24.46%/19.43%，且 Final 无法追回。

Anchor Loss 在 CHAP 上虽然没有完全保持 Base，却由优秀的残差校准补偿；在 TaxiBJ random 低 rate 上则同时暴露 Base 和 Residual 两层问题。

## 12. 结论与下一步

### 12.1 论文与版本选择建议

V16 已经证明以下设计是有效的：

- V14 Teacher 作为训练期锚点能够帮助跨版本恢复；
- 连续 Alpha 比 V15.1 二值接纳更适合 CHAP；
- 不增加专家/Backbone 的轻量残差结构可以取得 11/24 个四版本最佳；
- CHAP 八点和 TaxiBJ fixed 构成清晰、可解释的主要收益区域。

因此，**建议把 V16 作为下一阶段主力修改分支，而不是回退到 V15/V15.1。**但论文主表若现在必须选单一稳定版本，仍应保留 V14 作为 BikeNYC 和 TaxiBJ random 低 rate 的强对照，不应宣称 V16 全面支配 V14。

### 12.2 优先修复顺序

1. **TaxiBJ random@0.2/@0.4 Base 漂移。**先检查 Anchor 强度、Student LR 和 warm-up 后解冻冲击；可尝试更低 Student LR、分阶段渐进解冻或对 Teacher 差距增加显式相对约束。
2. **TaxiBJ random@0.4 有害 Candidate。**当前 Oracle Alpha mean 仅 0.171，建议增加“默认拒绝”偏置或按 observed gain/candidate uncertainty 设置更严格的 residual budget。
3. **BikeNYC Alpha 塌缩。**不要先扩大网络；优先减少条件冗余、对条件做实验内标准化、缩短训练并提高样本级有效变化。必要时为小数据集使用更简单的一维/三维 calibrator。
4. **平滑 Epoch 12→13 切换。**CHAP 虽能恢复，但阶段冲击很大。可在 3～5 Epoch 内把 alpha、Anchor 和 Main 解冻权重线性 ramp，而不是单点切换。
5. **补齐设计规定的六点三 seed。**优先补 seed2026、3407，而不是立即重跑另一个完整 24×3 矩阵。
