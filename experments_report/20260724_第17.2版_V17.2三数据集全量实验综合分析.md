# 20260724_第17.2版_V17.2三数据集全量实验综合分析

## 摘要

V17.2 Adapter-Free HSA-MoE 已完成两部分正式实验：

1. TaxiBJ、BikeNYC、CHAP 三个数据集，fixed/random 两种缺失模式，
   `0.2/0.4/0.6/0.8` 四个缺失率的 seed42 全量实验，共 24 组；
2. 四个核心点 `P1/P2/P3/P4` 的 seeds `42/2026/3407` 稳定性实验，共
   12 组。

全量 seed42 结果相对显式 V17 Full 历史基线：

- 配对 MAE 平均改善 **2.52%**，14/24 获胜；
- 配对 RMSE 平均改善 **2.83%**，15/24 获胜；
- random 模式的收益明显强于 fixed；
- TaxiBJ 总体改善最大，CHAP 次之，BikeNYC 略有退化；
- 缺失率 0.4 的收益最强，缺失率 0.8 整体轻微退化。

核心四点三 seed 结果表明：

- P4 CHAP fixed@0.4 达到 3/3 稳定改善；
- P2 BikeNYC fixed@0.8 小幅稳定；
- P1 TaxiBJ random@0.4 和 P3 TaxiBJ fixed@0.4 仍有明显随机种子敏感性；
- P3 未复现 V17.1 E1 原先的 3/3 获胜，不能宣称已被稳定修复。

因此 V17.2 是一个总体优于 V17、结构更简洁的有效候选，但不是所有数据集、
模式和缺失率下都占优的“无条件替代版本”。

## 1. 实验目的与设置

### 1.1 实验目的

V17.1 三阶段探索性消融发现，去除 Fine/Mid/Coarse 三个
Scale-Specific Adapter 是当时最有希望的简化方向。V17.2 将该 E1
No Adapter 结构正式化，并通过全量实验回答：

1. 删除 Adapter 的收益能否扩展到三个数据集、两种模式和四个缺失率；
2. 收益是否只来自少数核心点；
3. 不同数据集、模式、缺失率下是否存在明显退化；
4. 训练、验证、最佳 checkpoint 和最终 Test 流程是否完整稳定；
5. 删除 Adapter 后的尺度、专家和 Route Gate 是否更稳定。

### 1.2 实验矩阵

| 维度 | 设置 |
|---|---|
| 数据集 | TaxiBJ、BikeNYC、CHAP |
| 缺失模式 | fixed、random |

| 全量随机种子 | 42 |

| 全量实验数 | 3×2×4=24 |

### 1.3 训练协议

| 数据集/模式 | Batch | Epoch | Val interval | Early stopping |
|---|---:|---:|---:|---|
| TaxiBJ fixed | 32 | 160 | 5 | 关闭 |
| TaxiBJ random | 32 | 160 | 5 | 开启，patience=10 |
| BikeNYC fixed/random | 16 | 140 | 2 | 开启，patience=12 |
| CHAP fixed/random | 32 | 150 | 5 | 关闭 |

通用设置：

- AdamW，主学习率 `1e-3`，weight decay `1e-4`；
- CosineAnnealingLR，`eta_min=1e-6`；
- AMP；
- gradient clip norm=1；
- 以缺失位置、原始数据范围的 Val MAE 选择最佳模型；
- 每个 run 只保存并覆盖一个 `checkpoints/best.pt`；
- 训练结束加载 `best.pt`，在 Test 上只评估一次。

## 2. 最新 V17.2 模型结构

### 2.1 输入、Mask 与输出

模型输入格式统一为 `[B,C,T,H,W]`：

| 数据集 | 输入形状 |
|---|---|
| TaxiBJ | `[B,2,12,32,32]` |
| BikeNYC | `[B,2,12,24,12]` |
| CHAP | `[B,1,7,32,32]` |

真实数据从 NPZ 读取 `x_f_gt`，从离线 CSV 读取 Train/Val/Test Mask：

```text
m_f = 1：已观测位置
m_f = 0：待补全位置
x_f_obs = x_f_gt * m_f
```

Mid 和 Coarse 通过 Mask-aware spatial pooling 从 Fine 构造，尺度比例为
`Fine:Mid:Coarse = 1:1/2:1/4`。模型前向只使用观测数据和 Mask，不使用
隐藏位置真值。最终补全结果为：

```text
x_comp = m_f * x_f_gt + (1 - m_f) * x_hat_final
```

### 2.2 三尺度编码与去 Adapter

Fine、Mid、Coarse 分别使用 `ScaleTokenEncoder` 编码到 64 维隐空间。V17
Full 在每个尺度编码器后使用一个 `64→16→64` 零初始化残差 Adapter。
V17.2 的包装类在配置层和构造层双重强制：

```text
adapter_enabled = false
```

因此三个 Adapter 被参数为 0 的 Identity 替代。即使配置误写为 true，
模型也不会创建可训练 Adapter。相对 V17 Full，V17.2 减少 6,384 个参数。

### 2.3 Hierarchical Scale-Expert Router

每个尺度根据编码特征、Mask 观测统计和可靠性信息构造路由输入。统一的
Hierarchical Router 同时预测：

- Fine/Mid/Coarse 三尺度权重；
- 每个尺度对四个共享专家的概率；
- 样本级 Shared/Routed Route Gate。

每尺度从共享的四专家池中执行 Top-2 路由。当前采用
`hierarchical_shared_head`，尺度与专家决策共享分层路由表示。

### 2.4 Fine-Preserved 多尺度融合

原始尺度权重经过线性 Fine Floor：

```text
fine_floor = 0.25
fine_floor_mode = linear
```

避免 Fine 信息被 Mid/Coarse 完全覆盖。三个尺度的 Routed Expert 输出被
并行投影到 Fine 分辨率，然后按统一尺度权重融合。TaxiBJ 使用
`fine_mid`，Coarse 是 inactive scale；BikeNYC 和 CHAP 使用
`fine_mid_coarse`。

### 2.5 Shared/Routed 双分支融合

模型包含：

- Routed 分支：Top-2 Expert + Fine-Preserved Parallel Fusion；
- Shared 分支：`GatedCrossScaleSharedExpert`；
- Shared/Routed Residual Fusion；
- 样本级 Route Gate；
- `Conv3d → GELU → Conv3d` 预测头。

当前 `unified_scale_weight=true`，Shared 和 Routed 分支使用相同尺度权重。
外层 Aux Branch 关闭，因此：

```text
x_hat_final = x_hat_main
```

但主模型内部的 Shared/Route Auxiliary Heads 仍启用，并参与辅助监督。

### 2.6 损失函数

所有主要补全损失只在缺失位置计算，损失类型为 Smooth L1：

```text
L =
    L_main
  + λ_cross          * L_cross
  + 0.001            * L_importance_balance
  + 0.001            * L_load_balance
  + λ_shared_aux     * L_shared_aux
  + λ_route_aux      * L_route_aux
  + λ_complementary  * L_complementary
```

数据集权重：

| 数据集 | λ_cross | λ_shared_aux | λ_route_aux | λ_complementary |
|---|---:|---:|---:|---:|
| TaxiBJ | 0.03 | 0.05 | 0.10 | 0.003 |
| BikeNYC | 0.05 | 0.03 | 0.05 | 0.001 |
| CHAP | 0.03 | 0.05 | 0.10 | 0.003 |

Scale/Fusion/Branch entropy 权重均为 0。MAE、RMSE、MAPE 均在缺失位置、
原始数据范围计算。

## 5. 结果分析

### 5.1 TaxiBJ：平均收益最大，但稳定性不是最好

TaxiBJ 的 8 点 MAE 平均改善 6.38%，RMSE 平均改善 7.24%，是全量实验中
收益最大的数据库。random@0.2/0.4/0.6 分别改善 12.91%、15.48%、4.14%，
说明去 Adapter 对中低随机缺失有明显帮助。

但需要谨慎：

- random@0.8 退化 0.79%，高缺失率优势消失；
- fixed@0.6/0.8 分别退化 1.80%/0.33%；
- fixed@0.4 和 random@0.4 的 seed42 大幅收益在三 seed 中并不稳定；
- TaxiBJ 的 Route Gate 在 8/8 点被诊断为高饱和/低变化。

更合理的结论是：去 Adapter 提升了 TaxiBJ 某些优化路径的上限，但没有
稳定控制路由收敛到该路径的概率。

### 5.2 BikeNYC：基本持平，删除 Adapter 的主要价值是简化

BikeNYC 的 MAE/RMSE 分别平均退化 0.73%/0.69%，总体接近持平。八点中：

- fixed@0.4、fixed@0.8 和 random@0.2 的 MAE 改善；
- fixed@0.2 退化 6.04%，是 BikeNYC 最明显异常；
- random@0.4/0.6/0.8 都是小幅退化；
- RMSE 在 random 模式几乎持平。

BikeNYC 没有表现出 Adapter-Free 的普遍精度优势，但参数减少且 P2 三 seed
稳定，因此删除 Adapter 没有造成系统性失败。论文中应将其描述为“基本保持
性能并简化模型”，不宜描述为显著提升。

### 5.3 CHAP：random 全面改善，fixed 两极分化

CHAP random 四个缺失率全部改善，MAE 平均改善 4.40%，RMSE 平均改善
4.18%，是全量实验中最一致的子组。

CHAP fixed 则明显分化：

- fixed@0.4 改善 7.34%，且三 seed 3/3 获胜；
- fixed@0.6 改善 1.12%；
- fixed@0.2 退化 3.94%；
- fixed@0.8 退化 6.91%，是全量最差点。

这说明去 Adapter 对 CHAP 的帮助更偏向样本级随机缺失和中等 fixed 缺失，
在极高 fixed 缺失下可能缺少必要的尺度校正能力。

### 5.4 缺失率趋势不是单调关系

三个数据集的绝对 MAE 都没有随缺失率严格单调变化。例如：

- TaxiBJ fixed 在 0.4 取得最低 MAE，而不是 0.2；
- TaxiBJ random 在 0.6 最好；
- BikeNYC fixed 在 0.6 最好；
- CHAP fixed/random 都在 0.4 最好。

这并不必然表示指标错误。fixed mask 的不同缺失率会覆盖不同空间区域，不同
区域本身的流量/污染值和可预测性不同；random mask 也会改变有效样本分布。
因此“缺失率越高、MAE 必然越高”并不适用于当前不同 Mask 文件的直接比较。

### 5.5 验证与测试一致性

大部分子组的 Best Val 排名与 Test MAE 排名一致：

- TaxiBJ fixed：0.4 最好；
- TaxiBJ random：0.6 最好；
- BikeNYC fixed：0.6 最好；
- CHAP fixed/random：0.4 最好。

主要例外是 BikeNYC random：Val MAE 认为 0.6/0.4 较好，但 Test MAE
以 0.2 最好。三者差距很小，更像是验证集与测试集的有限分布差异，而不是
训练异常。

### 5.6 MAPE 不适合作为主指标

24 点 Test MAPE 范围约为 0.0265～78,742.33。TaxiBJ 中存在大量 0 或
接近 0 的目标，代码用 `1e-6` 作为分母下限，因此少量绝对误差会产生极大
相对误差。论文对比应使用 MAE/RMSE，MAPE 只作为附录指标或不报告。

## 8. 结论与建议

### 8.1 可用于论文的结论

1. 删除 Scale Adapter 后，V17.2 在 seed42 全量 24 点上取得 MAE
   2.52%、RMSE 2.83% 的平均改善，同时减少 6,384 个参数；
2. 收益主要来自 TaxiBJ 和 CHAP random，而不是所有数据集普遍改善；
3. CHAP random 的 4/4 改善是全量实验中最一致的证据；
4. BikeNYC 基本持平，删除 Adapter 的主要价值是简化而非显著提分；
5. fixed@0.8 和部分低缺失 fixed 场景可能需要 Adapter 或其他尺度校正；
6. 核心三 seed 结果证明 TaxiBJ 的大幅 seed42 收益仍有随机性；
7. V17.2 可以作为后续简洁主干候选，但不能表述为全面稳定优于 V17。

建议论文使用如下克制表述：

> 去除尺度特定 Adapter 后，模型在减少参数的同时，在完整 seed42 网格上
> 取得更低的平均 MAE/RMSE，优势主要集中于随机缺失、TaxiBJ 和 CHAP。
> 多随机种子实验进一步表明，该简化在 CHAP 上稳定，而 TaxiBJ 的收益仍
> 具有优化路径依赖。

### 8.2 下一步优先级

1. 对以下四个新增代表点补三 seed：
   - 最差点：CHAP fixed@0.8、BikeNYC fixed@0.2；
   - 强改善点：TaxiBJ random@0.2、CHAP random@0.4；
2. 在同一 clean commit 下重新训练对应 V17 Full，替代缺少 Git 元数据或
   dirty 的历史基线；
3. 增加可配置 deterministic 模式，并让 Full/V17.2 使用完全相同设置；
4. 优先研究 TaxiBJ Route Gate 饱和，而不是重新加入复杂 Adapter；
5. 若后续仍考虑 Adapter，应采用受限/条件化的小幅校正，并与当前
   Adapter-Free 主干做单因素对照；
6. 论文主表报告 MAE/RMSE，不以 MAPE 得出结论；
7. 保留 V17.2 的独立输出和配置，不覆盖 V17/V17.1 历史结果。

### 8.3 最终判断

从全量覆盖、平均精度、参数效率和 CHAP random 的一致性看，V17.2 是一个
有价值的正式版本，整体优于 V17 的概率较高；但 BikeNYC、high-missing
fixed 场景和 TaxiBJ 跨 seed 稳定性仍限制了结论强度。

最终建议：

> **保留 V17.2 作为下一阶段的简洁主干候选，但在完成四个新增代表点的
> clean 多 seed 配对前，不将其定性为最终全面最优版本。**
