# 20260903_第20版_V14与V20筛选对比分析

## 1. 实验目的与设置

本次实验用于判断 V20-single 的“缺失几何匹配 Probe + 自验证专家路由”是否能在 V14-single 基础上带来稳定改进，并决定是否值得继续进行三随机种子和全量 24 点实验。

### 1.1 比较范围

采用同一数据、同一掩码、同一随机种子和相同训练预算进行 V14/V20 配对比较，共 8 个点位、16 次完整训练：

| 数据集 | 点位 |
|---|---|
| TaxiBJ | fixed@0.2、fixed@0.4、random@0.4、random@0.8 |
| BikeNYC | fixed@0.6、random@0.4 |
| CHAP | fixed@0.4、random@0.4 |

统一随机种子为 42，使用单张 NVIDIA GeForce RTX 3090。任务从 2026-09-02 15:00 左右开始，于 2026-09-03 06:32 完成，累计训练耗时约 15.49 小时。

### 1.2 训练协议

| 数据集 | Epoch | 验证间隔 | Batch size | Active scales |
|---|---:|---:|---:|---|
| TaxiBJ | 160 | 每5轮 | 32 | fine + mid |
| BikeNYC | 140 | 每2轮 | 16 | fine + mid + coarse |
| CHAP | 150 | 每5轮 | 32 | fine + mid + coarse |

共同设置：AdamW 风格参数组、基础学习率 0.001、weight decay 0.0001、cosine scheduler、AMP、梯度裁剪 1.0、关闭 early stopping。每次验证以 MAE 判断是否更新 `best.pt`；训练结束后重新加载唯一的最佳 checkpoint，再运行一次完整测试集。

V20 完整继承 V14 的训练预算和主损失，仅增加：

```text
L_total = L_V14 + 0.05 × L_probe
```

由于 Probe expert features 已 detach，`L_probe` 只训练共享 Probe Decoder。

## 2. 最新模型结构

### 2.1 V14 基础结构

输入为三个空间尺度：

```text
x_f, m_f: Fine 原始观测与掩码
x_m, m_m, r_m: Mid masked pooling 结果、有效掩码与可靠性
x_c, m_c, r_c: Coarse masked pooling 结果、有效掩码与可靠性
```

各尺度先经过 `ScaleTokenEncoder`，再进入四个共享 `STExpert`。`QualityRouter` 基于特征和观测统计生成专家先验概率，选择 Top-2 专家。多尺度 routed branch 经 Progressive Route Fusion 聚合；shared branch 提供不依赖稀疏路由的稳定表示；随后由 branch fusion、尺度可靠性门和输出头产生 `x_hat_main`。

V14 在此基础上继续执行：

```text
V14 DifficultyConditionEncoder
→ SafeCoarseToFineRefiner
→ Mid/Fine correction
→ CorrectionAdapter
→ SafetyController
→ x_hat_final
```

SafetyController 通过有界残差校正保护 V14 不轻易偏离主干结果。

### 2.2 V20 新增结构

V20 不改变 V14 专家和 C2F 模块，只改变正式路由使用的概率：

1. GMP 根据 3×3、7×7 空间邻域可用率、3-step 时间邻域可用率和 5×5 局部可靠性描述真实缺失几何。
2. 从 observed 区域选择与真实缺失几何最相似的约 8% 位置作为 Probe。
3. 从输入中删除 Probe，再重新编码并让全部四个专家完成现场考试。
4. 共享 Probe Decoder 将每个专家隐特征映射回原始数值空间。
5. 根据 Probe MAE 形成 competence，并与 V14 learned prior 融合：

```text
p_comp = softmax(-normalized_error / 0.5)
eta = 0.85 × clamp(1 - min(normalized_error), 0, 1)
p_final = softmax((1-eta)log(p_prior) + eta log(p_comp))
```

6. `p_final` 用于正式 Top-2 路由；V14 后续所有模块保持不变。

Probe Decoder 最后一层零初始化，所以初始化时所有专家考试分数一致，`eta=0`，V20 严格回退到 V14。正式 forward 不读取隐藏位置真实值；真实缺失 ground truth 只参与训练主损失和独立离线分析。

四专家均匀分布的最大熵为 `log(4)=1.3863`。V20 competence entropy 平均为1.3653，达到最大熵的98.5%，说明 Probe 给出的专家能力分布大多接近均匀，专家区分度很弱。

与此同时：

- prior/probe Top-1一致率平均只有28.8%，仅略高于四专家随机一致率25%。这不能直接证明 Probe ranking 错误，因为 prior 也不是 oracle，但至少说明 Probe 没有提供与已有路由稳定一致的强信号。
- probe/final Top-2重合率52.2%，接近两个随机 Top-2 集合的期望重合比例50%。
- 尽管能力分布接近均匀，`eta` 平均仍达到0.095，CHAP达到0.125；即弱且可能噪声化的考试信号持续进入正式路由。
- prior/final Top-2重合率达到97.2%，表明 V20 大多数时候并没有更换专家集合，主要改变了专家权重，少数情况下才改变 Top-2 边界。

### 6.1 最可能的失效机制

以下属于由日志支持的机制推断，而非已经由消融或 oracle ranking 直接证明的事实：

1. **Probe 能力信号辨识度不足。** competence 高熵说明四个专家考试误差十分接近，目前 Decoder 没有产生清晰、稳定的专家排序。
2. **现有 confidence 对小误差差异仍过于敏感。** 接近均匀的 competence 仍得到约7%～14%的 `eta`，特别是 CHAP 的融合强度最高，恰好也是退化最严重的数据集。
3. **当前几何融合会在 competence 近似均匀时软化 prior。** 公式中的 `(1-eta)log(p_prior)` 等价于对 prior 做温度软化；只要 eta 非零，即使 competence 完全均匀也不会严格保持原 prior。这与“考试没区分度就回退 V14”的设计意图存在实际偏差。
4. **长期小扰动改变了联合优化轨迹。** Top-2集合大体不变，但 routed weights 持续变化，随后通过主损失影响 routed/shared/C2F 的共同训练，最终形成明显不同的参数解。

CHAP 的分支诊断进一步支持第4点：

| CHAP 平均（fixed/random） | V14 | V20 |
|---|---:|---:|
| `v14_base_hidden_mae` | 约0.645 | 约7.839 |
| `mae_shared_aux` | 约0.681 | 约10.452 |
| `mae_route_aux` | 约0.809 | 约7.955 |
| 最终 Test MAE | 约0.585 | 约2.045 |

问题在进入最终输出前就已经出现，Safety C2F 虽然把约7.84的 base hidden MAE挽救到约2.05，但无法恢复 V14 的0.58水平。因此不能把 CHAP 失败归因于最终 checkpoint 加载或单独的输出校正模块。

## 9. 结论与下一步

### 9.1 最终结论

当前 V20-single **没有相对 V14 取得进步，不应直接进入全量24点或三随机种子正式实验，也不应替代 V14 作为后续主版本**。

关键证据：

- MAE：仅1/8胜，而且唯一胜点只有0.01%的近似持平优势。
- RMSE：0/8胜。
- TaxiBJ、BikeNYC、CHAP 三个数据集平均全部退化。
- CHAP 出现234%～265%的 MAE退化，属于结构性失败而非随机波动。
- V20 的最佳验证结果本身已落后，因此不是 test 或 checkpoint 流程问题。
- Probe competence 接近均匀、融合置信度却非零，当前自验证证据质量与融合强度不匹配。

### 9.2 建议的最小诊断顺序

不建议立刻更改多个模块。应先用已有 checkpoint 完成 Probe↔Oracle 离线排序分析，然后只跑能定位原因的少量实验：

1. **现有 V20 checkpoint 离线 Probe ranking analysis**：计算 Spearman、Top-1 agreement、Top-2 overlap，不需要重新训练。若相关性低，说明现场考试未能预测真实 missing 上的专家能力。
2. **A5 Geometry Probe + Prior-Only**：令 `eta=0`，保留 Probe Decoder loss。如果结果恢复到 V14附近，可确认主要问题来自 routing evidence，而不是 Probe 辅助损失或代码路径。
3. **低 eta / entropy-aware confidence 单变量实验**：只降低最大融合强度，或要求 competence entropy/第一第二名 margin 达到阈值后才启用证据。
4. **修正 near-uniform fallback**：考虑使用保持 prior 系数为1的乘性校准形式，使 uniform competence 数学上严格等价于 V14 prior，而不是软化 prior。
5. 只有诊断版本在原8点中达到至少5/8 MAE获胜、无单点超过3%退化、三个数据集均不明显退化后，再做三随机种子和24点全量实验。

V20 的“让专家现场考试”叙事仍有研究价值，但当前实现没有证明考试成绩可靠，也没有实现弱证据下的真正无扰动回退。下一轮重点不应继续堆叠结构，而应先修复“能力测量可信度”和“低置信证据如何安全融合”这两个核心问题。
