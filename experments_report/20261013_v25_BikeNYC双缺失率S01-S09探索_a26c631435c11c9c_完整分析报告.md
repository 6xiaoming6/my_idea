### 执行版本、诊断改动与本次核验

本报告分析的中心问题是差分何时损害泛化、现有对照能否解释损害；S01–S03另行回答结构问题，不作为差分机制的直接因果证据。

- 所有新增组均为从头训练的seed7；0.4旧B1/B2只作冻结参考。S04@0.4与旧B2采用相同种子、相同初始化，不是新的独立训练种子。
- 固定尺度路径决定本轮计算网格和该尺度原始观测注入；Top-k决定实际执行哪些专家。S01虽自由选择计算尺度，H0仍已融合F/M/C，不是按轮首次看到一个尺度。
- 第二轮差分读取H1−H0（C输出减融合初态）；第三轮读取H2−H1（M输出减C输出）；CMFF第四轮读取H3−H2（F输出减M输出）。因此CMFF最后两轮均在F计算，不意味着第四轮读取F/F差分。CFFF的第四轮才读取两个F输出的差分。
- 条件门是共享的通道门，读取当前/历史状态的全局与F缺失区域摘要；±0.1约束并非“修正方向可靠”的保证。比例匹配按样本/通道在T/H/W上计算RMS，比例detach，分母下限1e-6。只修正本轮专家输入，当轮路由读取未修正状态；差分仍可通过后续状态间接影响后续路由。
- S01硬尺度选择和S03首轮Top-1使用所选分支的straight-through梯度估计，不能将本次负结果外推到所有自由路由训练方法。
- 训练四族为random_point、node_outage、temporal_gap、spatial_region；目录中的random/rate0.4或0.6不代表纯随机点缺失。两率分别训练、分别在对应率测试，本批不是同一模型跨缺失率迁移实验。

## 3. 结果分析与建议

### 3.1 差分泛化损害是否复现，以及复现到什么范围

0.4的S04完整差分与旧B2逐位复现；相对B1，ID MAE仅退步0.17%、RMSE改善0.13%，五套OOD MAE全部退步3.53%–12.08%，RMSE全部退步3.18%–10.57%。因此，BikeNYC 0.4上“ID相近、OOD变差”的现象确实保留。

0.6却不成立：S04相对本率B1，ID MAE改善0.60%，五套OOD MAE改善0.82%–2.46%，RMSE六套均改善。这批数据不能支持“多尺度输入加差分普遍损害泛化”。能支持的是：在固定训练流程与seed7下，差分作用随训练/测试缺失率设置发生变化。本批每个率使用不同训练模型；这不是同一模型从0.4迁移到0.6的证据，也没有排除种子波动。

### 3.2 跨尺度差分解释：有针对性的证据，但尚未证实

同尺度对照应使用S09/S08，而不是仅使用S09/B1。0.4时，固定CFFF后加末轮F/F差分，使五套OOD MAE改善1.96%–11.65%；0.6时同一做法使五套OOD MAE退步1.80%–5.57%。0.4的ID MAE基本相同（改善0.03%），RMSE微幅退步；0.6的ID MAE也退步0.36%。因此，同尺度来源不能保证差分可靠。

另一方面，S06使用M输出减C输出的跨尺度差分，却在两个率的ID和五套OOD上均改善MAE/RMSE。S07使用F输出减M输出，在0.4也全部改善。跨尺度变化本身不是泛化损害的充分解释。

仍不能反过来证明尺度变化完全无关：CFFF/CMFF同时改变了第二轮计算网格、观测注入和训练后的状态分布；两条路径内的配对能够测量各自的差分效应，但路径之间没有只改变差分语义的严格对齐对照。

### 3.3 更值得追查的位置与多轮作用

0.4的S05仅在第二轮加入H1−H0，五套OOD MAE均退步2.57%–4.94%；S06仅第三轮和S07仅第四轮却均改善。完整差分S04比这些单位置组的OOD更差。结果把怀疑重点指向初始融合态到首轮C输出的早期传递，以及多次传递后的联合适应。

但“早期差分造成全部问题”还没有被证实。尚缺只启用第三、四轮的组合（关闭第二轮）以及其他两轮组合；各组从头训练后所有权重都发生适应，单位置效果不能相加，S04与S05的差距也不能直接量化累积误差。0.6的S05多数OOD改善、S04全部改善，又限制了普遍有害的说法。

S06的价值在于它作为反例帮助排除过强解释，而不是本批必须将其选成新主线。当前最稳妥的机制表述是：差分的作用取决于注入位置、状态来源及模型在不同缺失条件下学到的联合适应；具体因果通路仍待验证。

### 3.4 门与RMS诊断能解释什么

0.4 S04第三轮绝对门均值在ID/组合OOD上为0.0975/0.0972，接近0.1上限，没有在组合OOD时明显关闭。对应平均隐藏修正由0.0839升至0.1045，三元OOD为0.1067。S06同轮修正在ID/组合OOD为0.0436/0.0450。完整差分在组合条件下更大的修正及其变化，是后续干预可检验的线索。

然而，0.4几何OOD的S04第三轮修正为0.0824，略低于ID，却仍退步；0.6 S04的第三、四轮门也接近0.095，却能改善OOD。因此“幅度增大”或“门接近上限”都不能独立解释所有退步。隐藏空间的平均绝对幅度不能直接跨独立训练模型当作同单位的预测损害，方向、状态尺度和下游敏感性都可能变化。

同样，已存RMS比例均值没有显示整体数量级爆炸，但这是聚合诊断，不排除局部极端，也不说明方向正确。尚未测量差分与目标修正方向的对齐、直接关闭通路后的误差、或模型在相同隐藏状态下的反事实响应。不能把这些日志关联写成已经证实的机制。

逐轮decoder读出普遍不单调：例如0.4 B1的ID四轮MAE为30.79→10.32→25.72→2.85；S06为20.60→17.23→32.88→2.84。中间轮无监督且decoder主要适配最终状态，不能用第三轮读出较差断言第三轮信息无用，更不能声称逐轮必然修复。

### 3.5 结构探索S01–S03的独立结论

S01自由尺度：两个率的ID MAE分别退步24.03%、22.53%，所有OOD均退步（0.4为12.47%–18.08%，0.6为16.03%–19.21%）；RMSE也全部退步。路由集中于少数以M结束的路径，0.6没有F计算轮，且训练误差也更高。当前实现未显示优势，可能与所选路径、细粒度计算不足及硬路由优化有关；没有固定已学路径/强制末轮F等对照，不将某个可能原因确定为根因，也不否定所有自由尺度架构。

S02固定CMFF Top-4：0.4 ID MAE改善2.25%、RMSE改善3.47%；组合与三元OOD改善，但两套几何OOD MAE退步3.11%–3.35%。0.6 ID MAE改善3.27%、RMSE改善3.53%，五套OOD MAE改善1.67%–3.81%、RMSE改善1.20%–4.12%。它提供了更强的高缺失率参考，但不是全条件全面占优。

S03 CMFF Top-1→2→4→8：0.4 ID MAE退步1.11%、五套OOD退步6.47%–7.29%；0.6 ID退步2.26%、五套OOD退步3.03%–8.42%；RMSE也全部退步。前期较窄/后期较宽的安排在本预算内不成立，不能单独归因于第一轮Top-1，因为轮次分配、梯度估计与计算预算一起改变。

成本：B1每窗口执行8个专家，S02为16、S03为15；面积加权计算代理分别为4.625、9.25、12.5625。S03比S02更侧重细网格，调用次数略少也可能更慢。实测训练累计分钟在0.4为B1 8.19、S02 11.55、S03 13.72；0.6为8.41、11.47、13.80。它们不是等成本比较，且GPU非严格独占、运行有中断，累计训练耗时不等于排队/故障在内的墙钟耗时。S02的收益不能表述为免费的改进。

### 3.6 证据边界

- 只有一个训练种子，两个缺失率不是两个种子，五套OOD也不是五次独立训练。多候选筛选后观察到的优势需要独立种子确认。
- 结果属于BikeNYC、T=12、200轮余弦学习率和当前四族混合mask；不能代替TaxiBJ、纯随机mask或50轮固定1e-3的结论。
- 各率只使用ID验证MAE选择checkpoint，未用OOD挑选单个run的checkpoint；但本轮研究方向已参考OOD测试结果，后续正式确认应保留新的验证/测试条件，避免持续对同一OOD测试调参。
- S04复验一致有助于排除旧B2运行偶然差异，但无法证明所有中断恢复都完全无影响；保留中断、恢复与诊断包装器变更的来源记录。
- 仍包含BikeNYC底部三行填充零，且F/M/C独立观测提供了不同于仅F输入的观测信息预算；不能把本批绝对误差外推到其他预处理/输入协议。MAPE不作为主要判断依据。
- 全部best出现在195或200轮，结论是统一预算下的结果，而不是保证所有结构都达到最优收敛。

### 3.7 下一步应优先补什么证据

1. 先补最直接的位置组合控制：相同CMFF、Top-2和训练预算下，只关闭第二轮差分、保留第三和第四轮（启用集合为{3,4}），与B1、S04、S05–S07比较。它回答去除早期融合→C差分是否足以消除0.4的退步；如果仍退步，再用{2,3}与{2,4}区分组合效应。不能只在0.4运行后忽略0.6的反转。
2. 对已训练S04做明确标注的评估干预：分别关闭各轮差分及全部差分，保持checkpoint和mask不变。该操作测量已学模型的通路依赖，不等价于无差分从头训练，不用它替代训练消融，也不保证关闭后改善。
3. 若确实需要检验方向失配，再设计保持同一CMFF路径的对齐差分、幅度匹配但不含历史方向的信息控制，并记录修正方向与误差变化的关系。必须隔离新投影层带来的容量与优化变化，不能仅通过CFFF替换推断纯尺度语义。
4. 用seed17/27复验核心机制对照（B1、S04、最有辨别力的单轮/组合组），随后在TaxiBJ同协议回验。S02作为结构成本参考单独讨论；本批不据最佳分数直接更换论文主线。
