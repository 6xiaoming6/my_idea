# 20260920_v24-COE 全部实验综合分析

## 1. 报告范围与最终判断

这份报告汇总当前 v24-COE 代码线上已经完成的主要实验阶段：BikeNYC 的 55 组核心机制实验、TaxiBJ 的 ABCDE 机制实验、route20 路由诊断、修正后的噪声/软预热/第二层固定实验，以及最后的双 mask×固定链矩阵。它们不是一个严格同分布的大表，而是围绕数据构造、硬路由坍塌、软预热和自由选择逐步收窄问题的实验链。所有正式结果均为单 seed=7，不能给出统计显著性结论。

当前最稳妥的判断是：

1. **软预热是目前最可靠的主方案。** 在 TaxiBJ 九类混合缺失上，四层六专家软预热自由路由的测试 MAE 为 34.85，明显优于原始硬路由 41.45，也优于本轮测试的多条固定链。它应作为后续工作的主干配置。
2. **自由选择的优势依赖缺失分布。** 在九类混合缺失上，自由路由相对最强固定链 TA→ST→S→TA 的 MAE 下降约 5.64%；在单一随机点缺失上只下降约 0.46%，并且自由路由最终完全收敛到同一条 TA→ST→S→TA 路径。
3. **路由多样性本身不是成功标准。** D/E 让训练或测试路径更多，但精度明显下降；N1 高斯噪声也没有消除前两层坍塌。应优先看同一缺失条件下的 MAE/RMSE和条件选择是否带来收益，而不是追求均匀专家使用率。
4. **链式状态更新有一定证据，硬路由当前证据不足。** BikeNYC 55 组中，冻结专家输入状态后多数结构的 MAE 变差，支持后续专家读取更新状态；但只让 router 读取当前状态的增益很小。两轮 Soft 在时空块和混合缺失上大幅优于硬路由，说明连续融合和早期梯度覆盖比硬 argmax 更值得继续。
5. **当前还没有完全证明“自由选择本身”优于最优固定链。** 最后的固定链矩阵仍未覆盖包含 SD/TD 的强固定链，也没有把软预热、均衡损失、动态状态更新和路由选择完全拆开。下一步应做少量强固定链和同 checkpoint 路由替换，而不是继续盲目增加固定链数量。

## 2. 最终主方案结构

当前主方案是单尺度四层 Temporal-Spatial Chain-of-Experts：

- 输入为 TaxiBJ 的 `[B, 2, 12, 32, 32]`，BikeNYC 对应 `[B, 2, 12, 24, 12]`；隐藏维度为 64。
- 模型把观测值、二值观测 mask、由 mask 计算的时间/空间支持统计、缺口距离特征和位置编码送入编码器。
- 每一层都有独立 router，专家池跨层共享，专家为 `T/S/TD/SD/TA/ST`：方向时间、方向空间、膨胀时间、膨胀空间、时间注意力及时空专家。
- 共享点级专家和路由专家共同产生残差更新；每层解码、恢复原始观测值，再把更新状态交给下一层。
- 训练硬路由使用 straight-through Gumbel；评估使用确定性 argmax。硬路由训练为了让 router 获得梯度，实际计算所有候选专家，因此训练计算不会像推理一样只执行一个专家。
- 主损失是有效缺失目标上的 L1。当前主方案保留 `lambda_coe_balance=0.01`，不加入中间监督、z-loss或路由输入噪声。

主方案的软预热调度为：epoch 1–3 采用带均匀底座的软融合，epoch 4–5 逐步增加硬选择，epoch 6 起完全硬路由。初始均匀混合系数为 0.5，采样温度为 2。验证和测试始终使用确定性选择。它的作用不是强制专家均匀分工，而是避免某个专家在最初几个 epoch 抢先占优后让其他专家长期得不到梯度。

## 4. BikeNYC 核心 55 组：为什么转向软预热

BikeNYC 核心批次使用 5 种结构缺失，缺失率约 0.4，80 epoch、seed 7。Full 硬路由、固定时间/空间链、初始状态路由、冻结专家状态、Parallel、仅共享、仅路由及两轮 Soft 均在相同预算下比较。

关键测试 MAE：

| 变体 | 平均 MAE（5 种 mask） | 主要现象 |
|---|---:|---|
| Full 硬路由 | 5.495 | 多个协议后期确定性单路径 |
| 初始状态 router | 5.514 | 与 Full 很接近 |
| 冻结专家输入 | 5.931 | 多数结构变差，支持状态传递 |
| Parallel | 5.416 | 单轮软融合，不稳定地胜过/落后 Full |
| 两轮 Soft | **5.015** | 最强平均结果，时空块和混合缺失提升最大 |
| 仅共享专家 | 8.822 | 纯点级共享结构明显不足 |
| 仅路由专家 | 5.535 | 共享分支不是主要收益来源 |

两轮 Soft 相比 Full 的平均 MAE 下降约 8.74%。在时空块和混合缺失上分别下降约 18.22% 和 17.26%；而在节点连续缺失上略差。这个结果说明：

- 时空专家池本身有价值，纯共享点级分支不能替代方向性专家。
- 后续专家读取更新状态有较明确收益；冻结专家状态后的 MAE 在节点、空间区域、时空块和混合缺失上明显变差。
- 仅让 router 读取初始状态，与 Full 的差异通常不足 1%，当前没有足够证据证明每轮重新读取最新状态一定带来收益。
- 硬路由并没有整体胜过 Soft 或验证选定固定链，硬路由“自由选择更强”的初始假设没有被支持。

硬路由在多个协议上从早期就锁定为单一路径，且多个专家长期没有有效梯度。Soft 在同样的两轮和专家池下保持了连续梯度覆盖，说明收益更可能来自优化和融合机制，而不是增加计算层数本身。

这一阶段还发现 AMP 状态管理问题：旧训练实现曾在每个 epoch 重建 GradScaler，且部分组出现非有限梯度诊断。Float/Half dispatch 写回冲突已修复，但 AMP 稳定性仍应在最终论文实验前单独排除。BikeNYC 结果适合作为机制筛选，不适合作为已经完全稳定的最终证明。

## 5. TaxiBJ ABCDE：数据丰富度和专家历史的作用

ABCDE 使用清洁 TaxiBJ、四层六专家、70 epoch，A/B/C 使用单一随机点训练 mask，D/E 使用九类训练 mask，验证/测试当时仍是固定随机点 mask。

| 组 | 改变 | 测试 MAE |
|---|---|---:|
| A | 原始硬路由 | 7.148 |
| B | 分组路由输入和观测差分 | 7.160 |
| C | FP32、小初始化、路由学习率、软到硬、z-loss | 7.443 |
| D | 九类训练 mask、逐轮重采样 | 11.571 |
| E | D + 上一轮专家身份 | 12.074 |

主要结论：

- B 几乎没有改善，说明单纯重新组织 router 输入不足以解决坍塌。
- C 明显提高了训练中专家获得梯度的机会、增加了训练路径数，但测试 MAE 反而比 A 差约 4.12%。因此“路由更均匀”不等于“补全更准确”。C 还暴露出软训练、硬验证之间的适配问题。
- D 在测试时出现 3 条路径，证明丰富训练 mask 能改变路由行为，但随机点测试 MAE 比 A 高约 61.9%。因为训练任务被从单一随机点改成九类等权，训练目标和测试目标不再匹配，不能据此断言丰富 mask 本身有害。
- E 的历史专家身份嵌入学到了非零参数，但比 D 进一步变差约 4.35%。测试前两层都选 TA，身份通道在早期没有足够区分度；当前不建议把它作为默认机制。

ABCDE 最重要的贡献是排除了“数据模式单一是唯一原因”：即使在相同随机点测试协议下，路由优化和训练 mask 改变也会导致完全不同的坍塌程度。

## 6. route20 和修正后的 route20_next

route20 的共同协议是 TaxiBJ 九类混合 mask，20 epoch。原始硬路由 R0 的测试 MAE 为 41.450，Soft warmup R1 为 34.716，提升约 16.25%。分组输入为 37.658，传递历史专家身份为 38.985，固定 TA→ST→S→TA 为 37.184，两层三专家为 56.526。

原 `route20_noise` 运行错误：它实际使用了两层 T/S、无 balance，而不是四层六专家 R0 加噪声。因此它不能作为噪声结论使用。修正后的 N1 才是有效噪声实验：四层六专家、balance=0.01、前两层训练 router 输入加 0.1 相对高斯噪声。

修正后结果：

| 组 | 测试 MAE | 测试 RMSE | 路由现象 |
|---|---:|---:|---|
| N1 修正噪声 | 37.420 | 69.107 | 第1/2层测试均100% TA |
| N2 Soft warmup | **34.851** | 64.800 | 第1层分化，第2层约95.8% TA |
| N3 Soft + 第2层固定 TA | 34.978 | **64.716** | 其他层重新适应，路径减少 |

N1 在误差上优于硬路由，但并没有缓解前两层坍塌：epoch16–20 训练第一层始终 TA 100%，第二层约 99.7%–99.9%。因此输入噪声 0.1 不是当前优先方案。

N2 与 N3 极为接近，说明第二层集中选择 TA 暂时不能直接判定为有害。第二层可能承担了通用时间处理，真正的条件分工发生在第一、三、四层。后续不应把“每层均匀”作为目标。

## 7. 双 mask×固定链矩阵：对自由选择最直接的验证

最后一轮包含 8 个四层六专家方案，每个方案分别在九类混合 mask 与单一随机点 mask 上运行，共 16 组。固定链包括 TA→ST→S→TA、T→S→T→S、S→T→S→T、TA×4、S×4、T×4、ST×4；主方案为软预热自由路由。

### 7.1 九类混合 mask

| 方案 | 测试 MAE | 测试 RMSE |
|---|---:|---:|
| **自由路由＋软预热** | **35.140** | **65.473** |
| TA→ST→S→TA | 37.238 | 69.263 |
| ST×4 | 42.867 | 77.365 |
| TA×4 | 44.053 | 79.929 |
| T×4 | 49.022 | 86.730 |
| T→S→T→S | 45.967 | 80.969 |
| S→T→S→T | 46.664 | 82.389 |
| S×4 | 53.826 | 89.530 |

自由路由相对最强固定链 MAE 降低 5.64%、RMSE 降低 5.47%。混合测试中路由使用为：第一层 TA/S/ST=52.2/17.4/30.4%，第二层 TA/TD=96.5/3.5%，第三层 ST/SD=68.7/31.3%，第四层 ST/TA/TD=58.4/41.4/0.1%。共有 13 条路径，最大路径约21.2%。

第三、四层的选择随缺失族变化：节点/空间区域/条带更常选 SD/ST，随机点/时间段更偏 ST/TA。这是目前支持“缺失条件决定专家组合”的最直接证据。

### 7.2 单一随机点 mask

| 方案 | 测试 MAE | 测试 RMSE |
|---|---:|---:|
| **自由路由＋软预热** | **7.533** | **12.623** |
| TA→ST→S→TA | 7.567 | 12.758 |
| T→S→T→S | 10.824 | 21.421 |
| S→T→S→T | 11.220 | 21.846 |
| ST×4 | 10.857 | 21.744 |
| TA×4 | 11.709 | 21.562 |
| T×4 | 12.905 | 25.818 |
| S×4 | 25.538 | 51.768 |

自由路由只比固定 TA→ST→S→TA 降低 0.46% MAE，但推理时所有窗口都选择这条路径。换句话说，在单一随机点任务上，主方案学到了一个稳定的全局最优链，并没有表现出跨样本的路径多样性。

这不是失败：如果一个缺失协议确实适合统一链，集中选择可能是正确行为。但它也说明，不能只用路径数证明动态选择优于固定链。

## 8. 关于“自由选择更好”的最终证据等级

### 已有较强支持

- 九类混合缺失下，自由路由优于本轮 7 条预设固定链。
- 混合缺失下，路径按缺失族发生变化，且第三、四层真正使用 SD、ST、TA 等不同专家。
- 软预热在硬路由基准上大幅提升 TaxiBJ 精度，并在 BikeNYC 的时空块/混合缺失上优于硬路由。
- 后续专家读取更新状态在 BikeNYC 多数结构上比冻结专家输入更好，支持链式状态传递。

### 部分支持，仍需控制变量

- 自由路由相对固定链的优势，可能同时来自软预热、均衡损失、动态状态更新和训练时计算全部专家，尚未只改变“选择方式”。
- 混合缺失下主方案使用 SD，而固定链矩阵没有包含含 SD 的强固定链；固定链集合仍不完整。
- D 的丰富 mask 增加了路径多样性但降低了随机点精度，说明多任务训练的收益取决于测试分布。
- 单一随机 mask 下自由路由和最强固定链近乎相同，动态选择的必要性尚不普遍。

### 当前不支持

- 硬路由普遍优于 Soft。
- 强制专家均衡会提高补全精度。
- 路由噪声 0.1 能解决前两层坍塌。
- 历史专家身份传递当前能提高性能。
- 仅增加层数或专家数量就能带来收益。
- 路径越多、最大路径占比越低，模型就越好。

## 9. 数据与训练可靠性限制

1. **单 seed。** 所有正式结果都以 seed 7 为主，特别是 0.46%、0.39% 这类小差异不能当作稳定优劣。
2. **20 epoch 只是机制筛选。** route20、route20_next 和 dual mask 的最佳点都在 epoch20，模型还在下降；延长训练可能改变近邻方案排序。
3. **AMP 需要最终复核。** BikeNYC 核心阶段出现非有限梯度诊断，虽然最终指标可用，且 Float/Half 写回错误已修复，但 GradScaler 跨 epoch 状态管理和跳步影响仍应在最终主实验前确认。
4. **mask 协议不同。** 九类混合训练每 epoch 重采样；单一随机点协议使用固定 CSV。两者同时改变形态数量与训练刷新方式，跨协议差异不能只归因于模式复杂度。
5. **MAPE 不可用作主指标。** TaxiBJ 流量含零或近零目标，MAPE 被极小分母放大；应只报告 MAE/RMSE，必要时增加 WAPE 或分位数误差。
6. **固定链训练成本不同。** 当前硬路由训练计算全部候选专家，固定链只计算选中专家，所以相同 epoch 不是相同 FLOPs/时间预算。
7. **训练中路径统计和测试路径统计不同。** 训练有 Gumbel 随机采样，测试是确定性 argmax；不能用训练路径数直接代表最终输入自适应能力。
8. **原始 mask 命名。** 最后一轮的 `original_random` 是清洁 TaxiBJ 配套的 random_point CSV，并非旧目录中按节点跨时间广播的旧 random_mask。报告中将其称为“单一随机点协议”更准确。

## 10. 建议的下一步计划

### 阶段一：补足自由路由与固定链的公平证据

只保留当前软预热主方案和少量强固定链，避免再做弱链网格：

- 根据混合验证集而不是测试集，选出主方案高频路径。
- 至少补一条包含 `SD` 的固定链，以及一条包含 `TD` 的固定链；路径长度仍为四层六专家。
- 固定链也使用相同的软预热/训练预算，或者增加“预热后固定”的版本，避免把优化方式和路由自由度同时改变。
- 在两种 mask 上分别比较，保持每种协议内部严格配对。

目标是回答：自由路由是否超过“同样专家组合但固定路径”，而不是是否超过明显不合理的重复专家链。

### 阶段二：拆分软预热的真正贡献

在主方案上逐项控制：

1. 软预热＋balance=0.01。
2. 软预热＋balance=0。
3. 无软预热＋同样 balance。
4. 两轮固定等权融合。
5. 两轮可学习但不条件化的全局融合权重。

这样才能判断提升来自早期连续梯度、均衡项、条件路由，还是三者组合。

### 阶段三：验证缺失条件与路由选择的因果关系

在同一批固定窗口上，保存主方案 checkpoint 后：

- 对每个窗口分别替换九种 mask。
- 记录确定性路径、逐层 logits、MAE/RMSE。
- 对同一个窗口强制改用候选专家/路径，比较误差差值。
- 报告每种缺失族的路径熵、专家选择率和误差，而不是只报整体路径数。

这一步最能证明“路由选择不是随机多样，而是有任务意义的条件决策”。

### 阶段四：稳定性和泛化

在筛选出 2–3 个候选后，再进行：

- 至少 3 个 seed 的均值和标准差。
- 20 epoch 早期筛选后，对胜出方案延长到 50 或 80 epoch。
- TaxiBJ 上保持当前协议，再选一个数据集确认不是单数据集现象。
- 统一 AMP scaler 跨 epoch 复用，并增加 FP32 小规模复核。

## 12. 最终给 idea 的评价

这个 idea **值得继续做，但论文主张需要从“多层硬路由自由选择必然更好”收窄为**：

> 软预热支持的多轮时空专家链能够在复杂、多类型缺失条件下形成条件相关的专家组合，并在当前 TaxiBJ 混合缺失协议上优于多条预指定固定链；在简单单一缺失协议上，模型会退化为稳定的统一链，说明自由路由既能选择多路径，也能在不需要时集中选择。

这是目前数据最支持的版本。若下一阶段补齐含 SD/TD 的强固定链、软预热控制变量、同窗口专家替换和多 seed 后结论仍成立，就可以把贡献从“实现了一个能多次路由的模型”提升到“自由链式专家选择根据缺失条件调整，并带来可解释的重建收益”。
