# 20260713_最终版_Main至V13全版本实验综合分析

## 1. 报告目标与结论先行

本报告对稳定main以及独立基于main开发的V7～V13进行最终横向比较。比较范围为3个数据集、fixed/random两种缺失模式和0.2/0.4/0.6/0.8四档缺失率，共：

\[
8\text{个版本}\times3\text{个数据集}\times2\text{种模式}\times4\text{档缺失率}=192\text{组正式结果}。
\]

先给出最终判断：

1. **现在必须选一个统一、稳定、跨数据集的主模型：选择main。** main的24点平均排名为3.33，是全部版本最低；Top-3覆盖15/24，也是最高。它没有明显的数据集灾难点。
2. **现在选择最值得继续深入的结构方向：选择V9的Coarse-to-Fine Residual MoE。** V9获得11/24个MAE第一，在TaxiBJ和CHAP上都是平均最优，单点冠军和有效改进最多。
3. **不建议直接把完整V9当成新的统一主干。** V9在BikeNYC平均MAE比main差20.22%，说明“从coarse预测开始、逐级输出残差”对小型非方形网格并不稳健。
4. **建议下一版仍从main独立开发，把V9改造成main上的可回退小残差分支，并用V8的难度描述控制coarse/mid/fine残差强度。** 这是当前最有证据支持的后续主力方向。
5. 如果论文允许按数据集使用不同结构，当前经验最优选择是：TaxiBJ用V9、BikeNYC用V10、CHAP用V9。但这种按测试结果选模型会产生选择偏差，正式论文必须在验证集或新随机种子上重新确定，不能直接按本报告的测试集冠军进行部署。

## 2. 比较范围与公平性

### 2.1 结果选择规则

- main：使用 `outputs/{dataset}/full/model/` 中每个组合时间戳最新的2026-07-06～07-07正式运行；
- V7～V13：使用 `outputs/vX-single/{dataset}/full/model/` 下每个组合最新正式运行；
- 只比较 `full/model`，不混入smoke或消融；
- 每个运行从 `logs/metrics.jsonl` 读取最佳验证MAE、最终Test MAE/RMSE；
- 所有模型均在加载唯一 `best.pt` 后测试。

### 2.2 一致训练协议

| 数据集 | Batch | 最大Epoch | 验证间隔 | Early stopping |
| --- | ---: | ---: | ---: | --- |
| TaxiBJ | 32 | 160 | 5 | patience=8 |
| BikeNYC | 16 | 140 | 2 | patience=12 |
| CHAP_Beijing | 32 | 150 | 5 | patience=8 |

所有版本均使用seed=42、相同数据划分、相同mask文件、相同主学习率和最佳验证MAE选择规则。因此可以比较完整版本方案。

但有两个结构性实验变量需要明确：

- main、V7、V8在TaxiBJ保留 `fine_mid`；V9～V13将TaxiBJ改为 `fine_mid_coarse`；
- V9不仅改变模型结构，还用mid/coarse显式监督代替原跨尺度损失。

因此本报告比较的是“完整版本方案”，不能把V9的全部收益严格归因于单一模块。

### 3.1 main稳定主干

main对fine/mid/coarse进行多尺度编码，以QualityRouter执行样本级Top-K专家选择；共享分支聚合跨尺度稳定结构，路由分支逐级融合条件专家输出，再以小残差门控融合两条分支。其优势不是某个数据集绝对第一，而是跨数据集和缺失模式没有严重失效。

### 3.2 V9为何是最重要的创新版本

V9抛弃隐藏特征层面的共享/路由融合，直接在输出空间执行：

\[
\hat x_c=H_c(z_c),
\]

\[
\hat x_m=\operatorname{up}(\hat x_c)+\alpha_m\Delta_m,
\]

\[
\hat x_f=\operatorname{up}(\hat x_m)+\alpha_f\Delta_f.
\]

它让coarse负责全局结构，mid/fine只学习剩余误差，并分别接受真实多尺度监督。TaxiBJ训练后fine residual系数平均约0.79、mid约0.71；CHAP约0.57和0.53，说明这些数据需要较强的细化残差。BikeNYC的两个系数仅约0.28和0.26，模型更依赖粗尺度起点，这很可能是其Bike退化的重要线索。

## 10. 逐版本最终评价

### 10.1 main：最稳定的统一主模型

优势：平均排名第一、Top-3覆盖最高、跨数据集无明显失效、训练稳定。弱点是单点冠军较少，说明结构偏保守。它最适合作为下一版的代码和预测主路径。

### 10.2 V7：语义清晰，但实际提升有限

V7保留main逻辑并强化先验—专用残差语义，Bike fixed表现不错，但Taxi和CHAP整体退化，且9组早停。说明仅重组共享/专用分支不足以产生稳定收益，不建议作为主力方向。

### 10.3 V8：最稳健的新组件候选

V8只增加难度感知Router，参数增量极小。它在Bike与main接近，在CHAP random@0.2第一，24点有10点优于main，最差退化仅27.4%，比其他大改版本温和。虽然整体没有击败main，但“显式难度描述”非常适合用作后续门控条件。

### 10.4 V9：效果上限最高，但数据集依赖强

V9冠军最多，Taxi和CHAP平均最优，训练最快且持续收敛。其问题集中而清晰：Bike的coarse 6×3表示过于粗糙，且学习到的mid/fine残差系数过小，无法恢复细节。V9是最值得继续研究的方向，但必须增加main直连或尺度自适应保护。

### 10.5 V10：Bike最优，功能专家值得保留

V10八点Bike平均最低，参数量也接近所有版本中的最小值。功能专家对Bike局部、时间和缺失形态的分工可能比强coarse先验更合适。但其Taxi和CHAP整体不够强，不能单独作为统一主干。可考虑把V10的局部/时间/缺失形态专家引入V9的fine residual阶段，而不是替换整个专家池。

### 10.6 V11：置信度校准收益不足

V11在Bike略好于main，也拿到Taxi fixed@0.8冠军，但Taxi整体退化24.4%，CHAP存在极端失败点。当前sample-level confidence没有形成可靠收益，不建议优先继续。

### 10.7 V12：频率分工只对Bike部分点有效

V12拿到Bike fixed@0.8、random@0.6/0.8三个冠军，但Taxi和CHAP显著退化，且Top-1趋势/细节专家存在选择集中。频率思想可以作为局部模块消融，但不适合作为主干。

### 10.8 V13：低秩全局假设过强

V13没有获得任何全局MAE冠军，只在两个点优于main。它在Taxi fixed@0.6接近最佳，但random、Bike、CHAP普遍较差。低秩全局路径可能适用于固定空间缺失，却不足以处理不同数据域的局部异质性，不建议作为后续主力底座。

## 11. 最终主力方向建议

### 11.1 当前模型选择

| 使用目标 | 推荐版本 | 理由 |
| --- | --- | --- |
| 一个统一模型覆盖三个数据集 | **main** | 平均排名最低、Top-3最多、无整数据集失效 |
| TaxiBJ单数据集最优方向 | **V9** | 6/8点第一，平均MAE改善13.22% |
| BikeNYC单数据集当前最低平均 | **V10** | 平均MAE比main低2.05%，功能专家更适合局部网格 |
| CHAP单数据集最优方向 | **V9** | 5/8点第一，平均MAE改善3.19% |
| 下一版结构创新主线 | **main + 安全化V9 + V8条件门控** | 兼顾main稳定性与V9效果上限 |

### 11.2 推荐的下一版结构

下一版仍应从main原始代码独立开发，不直接叠加V9分支代码。建议结构为：

```text
main stable backbone --------------------------> x_main

fine/mid/coarse MoE
  -> coarse prediction
  -> difficulty-conditioned mid residual
  -> difficulty-conditioned fine residual ----> delta_ctf

x_final = x_main + sigmoid(g(q, difficulty, scale reliability)) * delta_ctf
```

关键点：

1. **保留main预测直连。** 新分支初始系数接近0，任何数据集都可以退回main，不再像V9那样必须从coarse预测开始。
2. **保留V9输出空间逐级残差与mid/coarse监督。** 这是Taxi/CHAP收益最有力的结构证据。
3. **使用V8难度描述控制alpha_m、alpha_f和最终残差门。** random/fixed、空间块缺失和跨尺度一致性应产生不同尺度权重。
4. **Bike使用细尺度保护。** 当网格宽度较小、coarse可靠性低或跨尺度一致性差时，提高fine直连、压低coarse贡献。
5. **可在fine residual阶段测试V10的Local/Temporal/Missing专家。** 不建议一次引入全部5种专家，应先做一个小规模消融。
6. **不要优先叠加V11/V12/V13。** 当前证据不足，而且会增加无法归因的复杂度。

### 11.3 必须做的验证

1. 先在代表性5点进行main、V9、安全化V9三者比较；
2. 至少使用3个随机种子，报告均值±标准差；
3. 版本选择和超参数选择只看验证集，测试集只在方案冻结后运行一次；
4. 对Bike记录coarse/mid/fine残差范数、alpha、尺度可靠性，确认是否为coarse信息损失；
5. 对Taxi/CHAP检查延长训练是否继续改善V9；
6. 修复Git commit记录和V13 AMP范数诊断Inf；
7. 论文主指标只使用MAE/RMSE，MAPE仅在CHAP作为补充。
