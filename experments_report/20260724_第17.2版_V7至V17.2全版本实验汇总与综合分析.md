# 20260724_第17.2版_V7至V17.2全版本实验汇总与综合分析

## 1. 报告范围

本报告统一汇总 V7 至 V17.2 的全部正式版本实验，并在文档底部给出跨版本
综合分析和下一步基础版本选择。

正式全量比较包括 13 个版本：

```text
V7、V8、V9、V10、V11、V12、V13、
V14、V15、V15.1、V16、V17、V17.2
```

每个版本均比较：

| 维度 | 设置 |
|---|---|
| 数据集 | TaxiBJ、BikeNYC、CHAP |
| 缺失模式 | fixed、random |
| 缺失率 | 0.2、0.4、0.6、0.8 |
| 正式全量随机种子 | 42 |
| 每版本实验数 | 3×2×4=24 |
| 正式全量实验总数 | 13×24=312 |
| 主指标 | 缺失位置、原始数据范围 Test MAE/RMSE |

V17.1 是围绕 V17 进行的三阶段探索性消融，不是一个具有独立 24 点全量
结果的正式模型版本，因此单独汇总，不参与 13 个正式版本的综合排名。
V17.2 额外完成四个核心点的三随机种子验证，也在后文单列。

所有 13 个正式版本均找到 24/24 个有限 Test MAE/RMSE，正式全量覆盖为
312/312，无缺失组合，无 NaN/Inf Test MAE/RMSE。

## 2. 指标和统计口径

详细表格中的单元格统一为：

```text
Test MAE / Test RMSE
```

MAE、RMSE 越低越好。每个数据集和模式的平均值为四种缺失率的算术平均。

由于 TaxiBJ、BikeNYC 和 CHAP 的原始数值尺度不同，不能直接把三个数据集的
绝对 MAE 相加作为总分。因此综合比较使用：

1. 每个数据集内部 8 点平均 MAE/RMSE；
2. 24 个同数据集、同模式、同缺失率实验点的内部排名；
3. 24 点 MAE 第一次数和 Top-3 次数；
4. 相对每个实验点最优 MAE 的平均超额比例。

MAPE 不用于版本选择。TaxiBJ 等数据包含大量 0 或近零目标，MAPE 会被极小
分母放大，不能稳定反映模型补全质量。

## 4. 当前 V17.2 模型和训练流程

当前 V17.2 源码使用 `v17_2_no_adapter_hierarchical_scale_moe`。

输入为 `[B,C,T,H,W]`：

| 数据集 | 输入形状 |
|---|---|
| TaxiBJ | `[B,2,12,32,32]` |
| BikeNYC | `[B,2,12,24,12]` |
| CHAP | `[B,1,7,32,32]` |

Fine、Mid、Coarse 分别通过 64 维 `ScaleTokenEncoder`。V17.2 在构造层
强制关闭三个 Scale-Specific Adapter，并将其替换为无参数 Identity。

Hierarchical Router 同时输出：

- Fine/Mid/Coarse 尺度权重；
- 每尺度四个共享专家的概率；
- 样本级 Shared/Routed Route Gate。

每尺度执行共享专家池 Top-2 路由，尺度融合使用 `fine_floor=0.25` 的
Fine-Preserved 约束。Routed 分支和 Shared 分支经残差 Route Gate 融合，
最后由 `Conv3d → GELU → Conv3d` 输出补全值。

训练采用 AdamW、CosineAnnealingLR、AMP 和梯度裁剪。按配置中的
`val_epoch` 定期验证，以原始范围缺失位置 Val MAE 选择最佳模型；每个
run 只覆盖保存一个 `best.pt`，训练完成后重新加载最佳参数，只运行一次
Test。

## 12. 分析结果

### 12.1 V7–V13：找到有效思想，但没有统一稳定主干

V7 强化先验和专用分支后没有形成跨数据集收益。V8 的难度条件路由相对
稳健，但提升幅度不足。V9 是这一阶段最重要的结构突破：TaxiBJ 8 点平均
MAE 为 8.2197，是所有版本最低；CHAP 也很强。但 V9 的 BikeNYC 平均
MAE 为 2.4109，明显落后于其他主力版本，说明强制 Coarse 起点对非方形
小网格损失过大。

V10 在 BikeNYC fixed 上取得最低四点平均 MAE 1.8835，但 TaxiBJ 和
CHAP 缺乏稳定性。V11 的置信度校准存在 CHAP fixed@0.4 明显失败点。
V12 只在 BikeNYC 少数点有效。V13 在 24 点平均排名、Top-3 覆盖和距逐点
最优差距上均最弱，不适合作为后续基础。

### 12.2 V14：跨数据集最均衡

V14 的主要优势不是冠军最多，而是没有明显数据集灾难点：

- 24 点 MAE 平均排名 3.375，所有版本第一；
- 24 点 RMSE 平均排名 3.500，所有版本第一；
- MAE Top-3 覆盖 18/24，所有版本最高；
- 距每个实验点最优 MAE 的平均差距为 6.98%，所有版本最低；
- BikeNYC 8 点平均 MAE 1.9359，所有版本最低；
- CHAP 8 点平均 MAE 0.6055，仅次于 V16；
- TaxiBJ 虽不及 V9 的极限结果，但没有 V9 在 BikeNYC 上的系统性失败。

V14 因此是最适合覆盖三个数据集、两种缺失模式和全部缺失率的统一版本。

### 12.3 V15/V15.1：没有形成对 V14 的有效替代

V15 在 TaxiBJ random@0.6/@0.8 和 fixed@0.8 获得单点第一，说明紧凑
残差金字塔在部分高缺失场景有效。但它的综合平均排名、Top-3 覆盖和
BikeNYC 表现均弱于 V14。

V15.1 的尺度引导残差接纳没有带来稳定提升，24 点没有单点第一，综合结果
介于 V15、V17 之间。两者可以提供局部模块线索，但都不适合取代 V14。

### 12.4 V16：精度上限最高，但场景偏科

V16 获得 10/24 个 MAE 第一和 9/24 个 RMSE 第一，是单点冠军最多的
版本：

- 包揽 CHAP fixed/random 8 个点的 MAE 第一；
- TaxiBJ fixed@0.4/@0.6 第一；
- CHAP 8 点平均 MAE 0.5745，所有版本最低。

但 V16 的优势集中在 CHAP 和 TaxiBJ fixed。它的 BikeNYC 平均 MAE
2.0123，弱于 V14 的 1.9359；TaxiBJ random 平均 MAE 11.3688，也弱于
V14 的 10.3612。V16 的 24 点平均排名为 4.000、Top-3 为 13/24，均
不如 V14。它更适合作为教师锚定/连续残差校准模块来源，而不是唯一统一
基础版本。

### 12.5 V17/V17.2：工程和结构清晰，但精度尚未超过 V14/V16

V17 引入统一分层尺度—专家—分支路由，研究结构清晰，但全量精度相对
V14/V16 回落。V17.1 的三阶段消融证明删除 Scale Adapter 是最可信的
修复方向，复杂组合 C3 则是单 seed 假优势。

V17.2 正式化 No Adapter 后：

- 相对 V17 的 MAE/RMSE 分别平均改善 2.52%/2.83%；
- 24 点综合排名位列第三；
- 参数量和可复现性具有优势；
- 但只取得 1/24 个 MAE 单点第一，Top-3 仅 3/24；
- 相对 V14、V16 的 MAE 分别平均退化约 4.18%、4.68%；
- TaxiBJ Route Gate 饱和、Taxi 多 seed 波动和 CHAP 退化仍未解决。

因此 V17.2 是有价值的轻量路由研究底座，但不是当前精度最强的统一底座。

### 12.6 三数据集分别选择

若只按单数据集选择：

| 数据集/目标 | 推荐版本 | 依据 |
|---|---|---|
| TaxiBJ 平均精度 | V9 | 8点平均 MAE 8.2197，最低 |
| TaxiBJ fixed 中高缺失 | V16 | fixed@0.4/@0.6 第一 |
| BikeNYC 综合 | V14 | 8点平均 MAE 1.9359，最低 |
| BikeNYC fixed | V10 | 四点平均 MAE 1.8835，最低 |
| CHAP | V16 | 8/8点第一，平均 MAE 0.5745 |
| 轻量分层路由研究 | V17.2 | 参数少、工程记录完整 |

这种按测试集事后选择不同版本的方式不能直接作为正式论文模型选择策略，
只能用于理解不同结构的适用范围。

### 12.7 最终基础版本选择

如果必须从 V7–V17.2 中只选择一个版本作为下一步改进的统一基础，最终
推荐：

> **选择 V14-single。**

理由是：

1. MAE 和 RMSE 的 24 点平均排名均为第一；
2. Top-3 覆盖最高；
3. 相对逐点最优的总体距离最小；
4. 在三个数据集之间最均衡，没有 V9、V16 式的明显场景偏科；
5. Safe Coarse-to-Fine 和可回退残差结构适合继续做受控的单因素改进。

下一阶段建议从 V14 独立建立新版本，并按单因素方式测试：

1. 优先引入 V16 的教师锚定或连续残差校准，但保留 V14 的安全回退；
2. 再单独测试 V17.2 的轻量分层路由，不直接移植全部 V17 结构；
3. 将 V9 的 Coarse-to-Fine 输出残差作为 TaxiBJ/CHAP 上限参考，但必须
   增加 BikeNYC 的尺度保护；
4. 新版本必须同时与 V14、V16、V17.2 比较；
5. 至少在 TaxiBJ fixed/random、BikeNYC random、CHAP fixed 四类代表点
   做三随机种子；
6. 正式实验保持 clean Git、固定 Mask、唯一 best checkpoint 和最终一次
   Test 的协议。

最终一句话结论：

> **V16 的单点上限最高，V9 的 TaxiBJ 上限最高，V17.2 的轻量研究价值
> 最高，但 V14 是 V7–V17.2 中跨三数据集综合表现最稳、最适合作为下一步
> 唯一基础版本的选择。**
