# 20260927_v24_组队路由首批阶段结果分析

> 快照：2026-09-27 20:14 CST。仅分析已完成的 E0–E4；E5 为 23/50 epoch，E10 尚未启动，均不纳入最终排名。

## 1. 实验目的与设置

本轮检验确定性 Top2 的选择代理梯度（E1 对 E0）、专家对交互（E2 对 E1）、Router 容量（E3 对 E1/E2）和位置级接受门（E4 对 E1）。后续 E5 是交互加接受门，E10 是每层独立专家池。

七组使用 TaxiBJ clean 训练/验证/测试切分，九类缺失模式、缺失率 0.4；训练 mask 每 epoch 重采样，验证/测试 mask 固定，模型 seed 7。每组 50 epoch、batch 16、AdamW 主学习率 1e-3、cosine 50、AMP；每 2 epoch 验证，按验证 MAE 保存 best.pt，再用该权重测试。路由 balance 系数 0.01，其余损失为缺失监督位置的 L1。所有组由单 GPU 队列顺序运行，没有并卡。

## 2. 最新模型结构与指标口径

从当前源码核对：输入为 `[B,2,12,32,32]` 观测流量和二值观测 mask；原始观测值在补全过程中回填。编码器用观测值、mask、支撑特征与位置特征构造隐藏状态。每轮共享点级专家与路由专家候选共同更新隐藏状态，再解码候选补全；三轮共用 T/S/TD/SD/TA/ST 六类专家池，E10 才改为每层独立池。Top2 按窗口选择两个专家并归一化融合权重；前 3+3 epoch 的温度日程只改变组内权重，不是六专家 dense soft 预热。现有实现每轮仍计算六个候选专家。

E0 使用原生 Top2；E1 用加性专家对评分及确定性 straight-through 选择代理；E2 另加专家对交互头；E3 将 E1 的 Router hidden 从 64 提到 68；E4 给 E1 加位置级接受头，使接受后的补全进入下一轮与最终输出。主任务只监督有限、被隐藏且允许评估的位置；日志中的 MAE/RMSE 与每缺失族误差按标签点数累计，而非平均 batch 指标。测试集只评估验证集选出的 checkpoint。

## 4. 缺失族、路由和接受门诊断

九族测试标签数接近，每族约 76.7–77.7 万。E3 相对 E0 在 random_point、temporal_gap、spatiotemporal_block、stripe、moving_region、multi_block、composite 七族 MAE 更低；spatial_region 基本持平；node_outage 从 27.06 升至 29.09，说明提升并非对所有缺失形态一致。E2 相对 E1 在九族中的八族变差，尤其 spatial_region +5.10、stripe +4.23；只有 random_point 约低 0.26。E4 相对 E1 的族别变化均较小，空间区域约低 0.84，时间缺口约高 0.22。

专家对选择并未均匀覆盖。测试集 E0 第一轮 T+SD 占 95.5%，整条专家对路径最多的一条占 51.9%；E1 第三轮 TA+ST 占 95.5%；E2 第三轮 S+TA 占 92.2%；E4 第三轮 TA+ST 占 93.9%。E3 的第一轮最大专家对频率为 T+S 52.3%，第二轮 TD+SD 48.9%，第三轮 S+TA 82.5%；整条路径最大频率 22.2%，低于 E0。E3 的路径较多样与误差较低同时出现，但这不是多样性造成收益的因果证据，且第三轮仍有较强集中。

E4 的测试集接受门平均权重为 0.99855，几乎总是直接接受候选。三轮候选有害修改均值分别为 4.597、3.933、4.974，接受后为 4.595、3.932、4.973；有益修改均值也几乎不变。这说明当前 E4 的 0.127 MAE 收益不能解释为明显“拒绝了有害候选”，更可能与新增参数或训练轨迹变化有关；需等 E5 和反馈消融进一步判断。

## 5. 训练趋势与数据质量

五组训练 MAE 从首轮约 107 下降到末轮约 27–32，验证 MAE 持续下降：E0 从 epoch 10 的 39.922 到 50 的 27.212，E1 从 38.627 到 27.805，E2 从 40.879 到 29.680，E3 从 39.028 到 26.377，E4 从 38.013 到 27.563。E2 并非单次测试波动，验证集从中期起也明显落后。最佳 epoch 均为 48 或 50，尚不能断言 50 epoch 已让所有方法充分收敛；当前也没有明显的验证误差反弹。E0–E4 均完成 50 epoch、具有测试记录和 best.pt，未见 NaN/Inf；E5/E10 不完整，尚无最终测试成绩。MAPE 不作为主要判断依据，因为接近零的目标值会放大百分比误差。

## 7. 阶段结论与下一步

目前最有用的发现是：**增加一点普通 Router 容量的 E3 胜过当前交互组队 E2，也胜过原生 E0**；显式专家对交互在单 seed、50 epoch 下表现为明显负增量。接受门 E4 虽略改善 E1，但几乎没有实际拒绝动作，尚不能支撑“接受反馈保护补全”的主张。应等待 E5/E10 最终结果，再决定是否保留交互头与接受门；若 E3 仍领先，优先对 E0/E3 做额外 seed，并检查 node_outage 的退化。单 seed 的本轮结果仅用于方案筛选，不能作统计显著或跨数据集泛化结论。
