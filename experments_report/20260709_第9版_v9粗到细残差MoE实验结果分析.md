# 20260709_第9版_v9粗到细残差MoE实验结果分析

## 1. 实验目的与设置

本报告汇总第九版 `v9-single` 模型在 TaxiBJ、BikeNYC、CHAP_Beijing 三个数据集上的完整实验结果。第九版的核心假设是：与其直接在细尺度上完成全部补全，不如先在粗尺度恢复全局低频趋势，再由中尺度和细尺度 MoE 逐级预测残差，从而形成更加明确的 coarse-to-fine 渐进补全过程。

本次解析的正式实验覆盖：

- 数据集：TaxiBJ、BikeNYC、CHAP_Beijing。
- 缺失模式：fixed、random。
- 缺失率：0.2、0.4、0.6、0.8。
- 模型版本：`v9-single`。
- 实验族：`full/model`。
- 随机种子：42。
- 输出目录：`outputs/v9-single`。

本次共有 3 × 2 × 4 = 24 个正式组合，全部有完整训练、验证、最佳 checkpoint 和最终 test 记录。额外存在 2 个 synthetic smoke 结果，本报告不纳入正式统计。

训练策略来自 `configs/policies/full_model_paper.json`，模型结构配置来自 `configs/v9-single/{taxibj,bikenyc,chap}.json`。训练流程仍保持项目统一规范：每轮训练后按 `val_epoch` 定期验证，验证集 MAE 更优时覆盖保存 `checkpoints/best.pt`，训练结束后加载该最佳参数，在测试集上执行一次最终测试。

| 数据集 | batch size | 最大 epoch | val_epoch | early stopping | 学习率 | 调度器 |
|---|---:|---:|---:|---|---:|---|
| TaxiBJ | 32 | 160 | 5 | val_mae, patience=8 | 0.001 | cosine |
| BikeNYC | 16 | 140 | 2 | val_mae, patience=12 | 0.001 | cosine |
| CHAP_Beijing | 32 | 150 | 5 | val_mae, patience=8 | 0.001 | cosine |

本轮 v9 的 24 个实验全部跑满配置 epoch，没有触发 early stopping。MAE/RMSE 均为有效数值，没有 NaN/Inf。

## 2. 最新模型结构

### 2.1 整体数据流

第九版模型入口仍然复用 `DualBranchSTImputer`，但当配置中 `model.main.architecture = "v9_coarse_to_fine_residual_moe"` 时，会实例化 `CoarseToFineResidualMoE`。输入 batch 仍然包含：

- `x_f_obs`, `m_f`：细尺度观测值与 mask；
- `x_m_obs`, `m_m`：由 observed fine 数据 masked pooling 得到的中尺度输入；
- `x_c_obs`, `m_c`：由 observed mid 数据继续 masked pooling 得到的粗尺度输入；
- `x_f_gt`：用于训练/验证/测试指标计算的细尺度真值。

forward 不读取完整真值来构造预测，真值只在 loss 和 metrics 中使用。

### 2.2 v9 主干：Coarse-to-Fine Residual MoE

v9 的主干是 `CoarseToFineResidualMoE`，显式按 coarse → mid → fine 的顺序生成补全结果：

```text
h_c = Encoder_c(x_c_obs, m_c)
z_c = MoE_c(h_c, gate_c)
x_hat_coarse = coarse_head(z_c)

h_m = Encoder_m(x_m_obs, m_m)
z_m = MoE_m(h_m, gate_m)
x_c_to_m = upsample(x_hat_coarse)
x_hat_mid = x_c_to_m + alpha_m * mid_residual_head([z_m, x_c_to_m])

h_f = Encoder_f(x_f_obs, m_f)
z_f = MoE_f(h_f, gate_f)
x_m_to_f = upsample(x_hat_mid)
x_hat_main = x_m_to_f + alpha_f * fine_residual_head([z_f, x_m_to_f])
```

与 main/v8 相比，v9 的思路更“干净”：它不再依赖共享专家 + 路由专家双分支融合，而是把多分辨率任务本身变成逐级残差预测。模型仍保留 MoE 的核心组件：

- 三个尺度各自有 `ScaleTokenEncoder`；
- 三个尺度各自有 `QualityRouter`；
- 每个尺度经过 `TopKRoutedExpertPool`；
- 当前配置为 `num_experts=4`、`top_k=2`；
- `gates`、`selected_masks`、top-k indices/weights 会写入日志，用于专家使用分析。

### 2.3 残差强度门控

v9 引入两个可学习残差强度：

```text
alpha_m = sigmoid(alpha_m_logit)
alpha_f = sigmoid(alpha_f_logit)
```

TaxiBJ 和 CHAP 的初始化为 `alpha_m_init=-3.0`、`alpha_f_init=-3.0`，初始值约为 0.047；BikeNYC 更保守，初始化为 -3.5，初始值约为 0.030。这个设计的作用是让模型初始更接近稳定的 coarse prior，训练过程中再逐步放大中/细尺度残差。

从日志看，残差门控在训练中确实被主动打开：

- TaxiBJ 最终 `alpha_m/alpha_f` 大多升到 0.5--0.83；
- CHAP_Beijing 最终 `alpha_m/alpha_f` 大多升到 0.29--0.72；
- BikeNYC 最终 `alpha_m/alpha_f` 多在 0.18--0.34，说明小数据集上模型更保守。

这说明 residual gate 没有“死掉”，模型确实在学习从粗到细逐步增强细节。

### 2.4 Loss 设计

v9 新增 `multi_resolution_supervision_loss`，配置为：

```text
L = L_fine + 0.2 * L_mid + 0.1 * L_coarse + balance terms
```

其中：

- `L_fine`：最终细尺度输出 `x_hat_main` 在 fine 缺失位置的 smooth L1；
- `L_mid`：`x_hat_mid` 对 pooled fine target 的中尺度监督；
- `L_coarse`：`x_hat_coarse` 对 pooled target 的粗尺度监督；
- `l_importance_balance` / `l_load_balance`：MoE 专家重要性和负载均衡。

需要特别注意：日志显示低缺失率下很多组合的 `l_coarse_supervision=0`。原因不是代码没运行，而是 coarse mask 经 pooling 后可能已经变成全 observed；而当前 loss 规则只在对应尺度 mask 的缺失位置监督，所以粗尺度没有缺失位置时，直接 coarse supervision 不产生损失。高缺失率下该项开始出现，例如 TaxiBJ random 0.8 最后一轮 `l_coarse_supervision≈11.02`，CHAP random 0.8 约 2.92。也就是说，v9 的 coarse head 在低缺失率下主要通过 mid/fine 下游误差反传学习，高缺失率下才会有更直接的 coarse loss。

### 2.5 验证、checkpoint 与测试流程

训练入口 `scripts/train.py` 中，验证规则为：

```text
should_validate = epoch % val_epoch == 0 or epoch == cfg["train"]["epochs"]
```

每次验证后，如果 `val_mae` 优于历史最佳，就覆盖保存：

```text
checkpoints/best.pt
```

训练完成后加载 `best.pt`，再对 test set 执行最终测试。所有训练、验证、测试指标分别写入：

- `logs/train.log`
- `logs/val.log`
- `logs/test.log`
- `logs/metrics.jsonl`

## 4. 简单结果分析

### 4.1 v9 的主要收益：TaxiBJ 明显增强

TaxiBJ 是 v9 最成功的数据集。无论 fixed 还是 random，v9 都比 v8 明显更好，尤其 random 高缺失率改善非常大。TaxiBJ random 0.6 和 0.8 的 MAE 分别下降 2.4159 和 2.5167，RMSE 分别下降 4.3865 和 4.5064。

这说明 coarse-to-fine 残差补全对于交通流这种有明显全局结构、区域模式和局部细节叠加的数据是有效的。粗尺度先估计整体交通分布，中/细尺度再修局部残差，比直接在细尺度融合多尺度特征更稳定。

从训练日志看，TaxiBJ 的 best epoch 几乎都在最后一轮：fixed 四个缺失率全部 best epoch=160，random 除 0.2 是 150 外，其余也都是 160。这说明 v9 在 TaxiBJ 上还没有明显过拟合，训练到最后仍在改善，甚至可能还有继续训练的空间。

### 4.2 CHAP_Beijing 稳定小幅提升

CHAP_Beijing 上，v9 对 fixed 和 random 都有提升。fixed 平均 MAE 从 v8 的 0.6884 降到 0.6236，random 平均 MAE 从 0.6709 降到 0.6481。

这与 v9 的设计预期一致：CHAP 是更平滑的环境场，粗尺度低频先验本身更有价值。coarse-to-fine 结构先恢复全局空间背景，再逐级修正残差，对这类平滑场比较友好。

CHAP 的 best epoch 也集中在后期：多数设置在 145--150 达到最佳，只有 random 0.4 在 135、fixed 0.8 在 140。整体训练平稳，没有早停，没有 NaN。

### 4.3 BikeNYC 是 v9 的明显短板

BikeNYC 上 v9 全面弱于 v8，尤其 random 模式退化严重。BikeNYC random 平均 MAE 比 v8 高 0.6371，平均 RMSE 高 2.8628。这个退化比 fixed 更明显，说明 v9 的逐级残差结构可能不适合 BikeNYC 当前数据特性。

可能原因有三点：

1. BikeNYC 数据量较小，v9 拆成 coarse/mid/fine 三阶段预测后，监督路径更长，参数利用更复杂，容易比 v8 的共享/路由融合结构更难训练。
2. BikeNYC 的空间分辨率是 24×12，粗尺度后空间尺寸更小，coarse prior 可能过度平滑；如果全局趋势本身表达不足，后续 residual 需要补偿更多细节，反而增加误差。
3. random 缺失下，v9 的 mid/fine residual 很依赖局部细节修正，但 BikeNYC 的 random 结果 RMSE 很高，说明少数区域或样本出现了较大的补全偏差。

从 residual gate 看，BikeNYC 的 `alpha_m/alpha_f` 最终大多只升到 0.18--0.34，而 TaxiBJ/CHAP 常常升到 0.5 以上。这说明模型在 BikeNYC 上没有充分信任残差分支，或者残差分支学习受限。

### 4.4 fixed/random 与缺失率变化

TaxiBJ 上结果比较符合直觉：fixed 和 random 都随缺失率升高而变差，random 0.8 是最难设置，test MAE=10.3040，RMSE=16.8645。与 v8 相比，高缺失 random 反而是 v9 改善最明显的部分，这正是 v9 值得保留的证据。

CHAP 上缺失率变化较温和。fixed 0.6 是最优点，test MAE=0.5710；random 0.8 最差，test MAE=0.6772，但整体变化不剧烈。说明 v9 在 CHAP 上对缺失率比较鲁棒。

BikeNYC 仍然呈现非单调现象。fixed 0.6 最好，fixed 0.2 最差；random 四个缺失率之间 MAE 差距不大，但整体 RMSE 都偏高。这更像是 BikeNYC 的空间 mask 位置和少数大误差样本在主导结果。

### 4.5 MAPE 指标不适合主表

TaxiBJ 和 BikeNYC 的 MAPE 仍然巨大，例如 BikeNYC random 多个设置超过 160000，TaxiBJ 多个设置超过 70000。这不是模型突然离谱，而是目标值存在 0 或接近 0 时，MAPE 分母过小导致指标爆炸。

建议论文主表只报告 MAE 和 RMSE。MAPE 如果保留，必须说明零值问题，或者改成 sMAPE、NMAE，或者设置阈值过滤。

## 5. 各数据集训练过程趋势

- rate 0.8：train loss 从 133.9342 降到 11.6468，best epoch=160，test MAE=8.2557。

residual gate 方面，TaxiBJ 的 `alpha_f` 最终达到 0.72--0.83，`alpha_m` 最终达到 0.52--0.83。越高缺失率下，尤其 fixed/random 0.8，`alpha_m` 和 `alpha_f` 越大，说明模型会主动增强中/细尺度残差修正来补偿粗尺度不足。

BikeNYC 也全部跑满 140 epoch，但结果并不理想。训练 loss 持续下降，验证 MAE 也明显下降，说明训练流程本身没有问题；问题在于最终泛化性能弱于 v8，尤其 RMSE 明显偏高。

- rate 0.8：train loss 从 9.9233 降到 1.6683，best epoch=140，test MAE=2.1096。

random 模式：

- rate 0.2：best epoch=120，test MAE=2.7347，RMSE=9.3547。
- rate 0.4：best epoch=126，test MAE=2.6554，RMSE=8.8722。
- rate 0.6：best epoch=116，test MAE=2.6282，RMSE=8.7518。
- rate 0.8：best epoch=116，test MAE=2.7379，RMSE=9.0908。

BikeNYC 的 random 四组 RMSE 都接近或超过 9，明显高于 v8。结合 residual gate 偏小来看，v9 对 BikeNYC 的细节恢复可能不够积极，或者 coarse prior 过度平滑后，fine residual 没有足够能力恢复局部尖峰。后续如果继续发展 v9，需要优先为 BikeNYC 设计轻量回退，例如共享专家融合回退、fine residual 更强的直接细尺度路径，或者降低 coarse-to-fine 约束强度。

### 5.3 CHAP_Beijing 训练趋势

CHAP_Beijing 训练稳定，所有组合都跑满 150 epoch。验证 MAE 从 15--17 左右快速下降到 0.7--0.84 区间，测试 MAE 在 0.5710--0.6772 之间。

fixed 模式：

- rate 0.4：train loss 从 45.0112 降到 1.5034，best epoch=150，test MAE=0.6207。
- rate 0.6：train loss 从 45.1410 降到 0.8136，best epoch=150，test MAE=0.5710，是 CHAP 最优组合。
- rate 0.8：train loss 从 48.4960 降到 1.0608，best epoch=140，test MAE=0.6443。

random 模式：

- rate 0.2：best epoch=150，test MAE=0.6669。
- rate 0.4：best epoch=135，test MAE=0.6112。
- rate 0.6：best epoch=145，test MAE=0.6370。
- rate 0.8：best epoch=145，test MAE=0.6772。

CHAP 上 `alpha_f` 最终多在 0.54--0.63，`alpha_m` 会随缺失率增大而显著变大。例如 fixed 0.2 的 `alpha_m≈0.3542`，fixed 0.8 的 `alpha_m≈0.7236`。这说明高缺失下模型更依赖中尺度残差修正，这与 coarse-to-fine 设计预期一致。

## 7. 结论与下一步

v9 的实验结论比较鲜明：这是一个“对 TaxiBJ 和 CHAP 有价值、但不适合当前 BikeNYC 设置”的版本。

可以保留的结论：

1. Coarse-to-fine residual MoE 对 TaxiBJ 提升非常明显，尤其 random 高缺失率。
2. 对 CHAP_Beijing 也有稳定小幅提升，符合平滑环境场更依赖低频先验的直觉。
3. residual alpha 在训练中能从很小值自动增大，说明残差门控机制有效。
4. v9 全流程稳定，没有 NaN，也没有训练失败。

需要谨慎的地方：

1. BikeNYC 全面退化，尤其 random 模式 RMSE 过高，不建议直接把 v9 作为最终统一模型。
2. coarse supervision 在很多低缺失设置下没有直接贡献，当前实现更像是“coarse prediction + mid/fine residual 反传”，粗尺度显式监督还不够充分。
3. v9 去掉了 v8/main 的共享专家融合路径，这可能是 BikeNYC 退化的重要原因之一。

建议下一步：

1. 做 v9 消融：`no_mid_residual`、`no_fine_residual`、`alpha_fixed_1`、`alpha_learnable`，重点看 TaxiBJ/CHAP 的收益来自哪一级残差。
2. 为 BikeNYC 增加回退结构：例如保留 fine direct head，或把 v9 coarse-to-fine 输出与 main/v8 输出做轻量门控融合。
3. 修改 coarse supervision：不要只在 coarse 缺失位置计算，可以考虑 reliability-weighted valid supervision，让 coarse head 在低缺失率下也有明确直接监督。
4. 如果论文中使用 v9，可以作为“粗到细残差结构对交通/环境大场景有效，但小数据集需要结构约束”的实验版本；若要作为最终模型，还需要修复 BikeNYC 退化。
