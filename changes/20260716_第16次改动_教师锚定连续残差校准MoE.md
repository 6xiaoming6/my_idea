## 3. 训练与推理边界

教师由训练引擎持有，永久 `eval + no_grad + requires_grad=False`，不属于学生模型子模块。学生 `best.pt` 只保存学生权重和教师来源元数据，不保存教师权重。V16 模型能够在没有教师对象和教师配置参与 Forward 的情况下独立加载与推理。

正式训练流程为：

```text
前 12 epoch：冻结学生主干和校准器，仅训练 residual proposer，alpha=1
第 13 epoch 起：学生主干、residual proposer、calibrator 联合训练
定期 validation：按 val MAE 覆盖唯一 best.pt
训练结束：重新加载 best.pt，运行一次 test
```

## 4. 配置

正式训练上限：

```text
TaxiBJ：160 epoch，val_epoch=5
BikeNYC：120 epoch，val_epoch=2
CHAP：150 epoch，val_epoch=5
```

分组学习率：

```text
student backbone = 2e-4
residual proposer = 1e-3
calibrator        = 5e-4
```

教师默认固定使用同数据集、同 mask、同 rate 的 V14 seed42 验证最优模型；学生 seed 和 teacher seed 独立记录，三 seed V16 实验不会错误寻找不存在的 V14 student-seed 检查点。
