Multi-Scale MoE、V14 模型文件、注册项、配置和历史实验均保留，V18 使用独立
架构注册、配置、脚本和输出目录。

## 2. 修改目标

V18 保留 V14 已验证稳定的 Main Backbone，并删除 V14 修正路径中的
`alpha_final × delta_ctf` 双重幅度变量。新增分支只预测以稳定 Main 输出为锚点的
有界残差方向：

```text
x_base = StableMainMoE(x_obs, mask)
d_f = tanh(DirectionPyramid(z_c, z_m, z_f, h_main, stopgrad(x_base)))
s_f = observed_channel_rms(x_obs, mask)
rho_f = BoundedBudgetController(condition)
x_final = x_base + rho_f * s_f * d_f
```

其中：

```text
|d_f| <= 1
0 <= rho_f <= rho_fine_max
|x_final - x_base| <= rho_fine_max * s_f
```

方向头最后一层零初始化，因此模型初始化时严格满足
`x_final == x_base`。模型 Forward 只读取观测输入、mask 和由它们生成的多尺度
输入，不读取隐藏位置真值。

## 3. 核心模型模块

### 3.1 Observed Scale Normalization

新增 `observed_scale.py`，按样本、通道在观测位置计算 RMS：

```text
s = sqrt(sum(x_obs² * mask) / max(sum(mask), 1))
```

输出形状为 `[B,C,1,1,1]`，使用 FP32 计算后恢复输入 dtype，并执行
`detach + clamp_min(scale_eps)`。完全无观测值时只从已遮蔽的观测输入计算有限
回退值，不使用 ground truth。

### 3.2 Base-Anchored Residual Direction Pyramid

新增 `base_anchored_residual_pyramid.py`：

```text
a_f = stopgrad(x_base)
a_m = resize(a_f, mid)
a_c = resize(a_f, coarse)

d_c = tanh(H_c(z_c, embed(a_c)))
d_m = tanh(H_m(z_m, embed(a_m), embed(rel_c * up(d_c))))
d_f = tanh(H_f(z_f, h_main, embed(a_f), embed(rel_m * up(d_m))))
```

Coarse/Mid 方向只作为更细尺度的结构条件，不逐级替代 `x_base`。三个方向头均为
轻量 3D 残差块，最后一层零初始化。提供 `fine_only_residual` 和
`use_reliability_filtered_propagation` 两个受控消融开关。

### 3.3 Observed Relative Utility

新增 `observed_relative_utility.py`。先构造固定小预算、完全 detach 的候选：

```text
x_probe = stopgrad(x_base) + rho_probe * s_f * stopgrad(d_f)
```

然后仅在观测位置输出五个相对统计量：

```text
base relative observed error
probe relative observed error
probe relative gain
probe relative delta mean
probe relative delta q95
```

这些统计可在推理阶段获得，经过数据尺度归一化且不会把隐藏真值泄漏给控制器。

### 3.4 Bounded Residual Budget Controller

新增 `bounded_residual_controller.py`。控制器输入由以下内容组成：

```text
Difficulty embedding: 32
Mid/Coarse reliability: 2
Main scale gate: 3
Geometry: 5
Observed relative utility: 5
```

控制器输出唯一的三个幅度变量 `rho_c/rho_m/rho_f`，每个输出均由对应
`rho_max * sigmoid(logit(rho_init/rho_max) + residual)` 计算。默认上限为
`0.15/0.15/0.20`，初始预算均为 `0.02`，不存在额外 final gate。

### 3.5 V18 顶层模型

新增 `v18_base_anchored_residual_moe.py`，只构建并调用一次
`MultiScaleMoEBackbone`。配置若关闭 Main bypass 或要求第二套 Backbone 会直接
报错。输出在原训练器 contract 上增加：

```text
x_hat_base
x_hat_probe
x_hat_mid
x_hat_coarse
features.direction_c/m/f
features.effective_residual
features.observed_scale_f
diagnostics.v18
v18_enabled
```

## 5. V18 专用训练损失

V18 在原 Main loss 基础上增加：

```text
L_total
= 0.25   * L_base
 + 0.05   * L_mid
 + 0.03   * L_coarse
 + 0.10   * L_sample_regret
 + 0.02   * L_observed_guard
 + 0.0001 * L_budget
```

- `L_base`：保持稳定 Main Base 的隐藏位置重建能力。
- `L_mid/L_coarse`：对锚定后的中、粗尺度预测提供隐藏位置监督。
- `L_sample_regret`：按样本比较 Final 与 detach Base 的隐藏位置 MAE。
- `L_observed_guard`：限制 Final 在已知观测位置相对 Base 的反常退化。
- `L_budget`：直接正则唯一实际幅度变量 `rho_f`。

V18 通过 `v18_enabled` 与 V14 损失明确隔离，不会重复计算 V14 的逐点 Regret、
CorrectionAdapter 或 alpha gate loss。

## 6. 优化器、指标与诊断日志

V18 保留 V14 Main 原有的 Main/Gate/Scalar/No-decay 分组规则，并为新增模块加入：

```text
Difficulty Condition：lr_main
Residual Direction Pyramid：lr_v18_refiner
Budget Controller：lr_v18_controller
```

正式默认学习率为 `1e-3 / 1e-3 / 5e-4`。单元测试逐参数核对 V14/V18
Main Backbone 以及 Difficulty Condition 的学习率和 weight decay 协议一致。

MAE、RMSE、MAPE 改为先累计整个 split 的缺失位置误差充分统计量，再除以全局
缺失元素总数。验证集最优模型因此由严格的全局 `val_mae` 选择，不受尾批大小
影响；其他按样本产生的诊断也按真实 batch size 加权。日志新增并在
train/val/test 全过程保存：

- Base/Final 隐藏位置 MAE、RMSE、绝对和相对增益；
- sample/point non-regression violation rate；
- `rho_c/m/f` 的 mean/std/min/max 和上下界饱和率；
- 三尺度 direction RMS、Fine direction q95；
- effective residual RMS/q95、相对 Base 和观测尺度比例；
- observed utility、difficulty、reliability、geometry；
- Main scale gate、专家熵和专家使用率。

重复的 Direction/Residual 汇总字段已去除，每个语义只保留一个规范日志键。


支持单点、三数据集真实数据 Smoke、六点筛选、四关键点三种子、完整 24 点实验、
完整任务跳过、参数统计和与同点同 seed V14 结果配对汇总。自动跳过要求正常结束
标记、唯一可读 `best.pt`、完整日志及严格配置签名；不表示支持从中断 epoch
恢复。签名覆盖 seed、训练/验证协议、完整模型与损失、mask SHA256、原始
train/val/test NPZ SHA256 和训练源码 SHA256。正式训练默认要求 Git 工作区
干净，避免未提交代码产生无法复现的论文结果。

当前提供 7 项独立配置消融：

```text
Absolute C2F
Unbounded Residual
No Observed Utility
No Reliability Filtering
Fine-only Residual
Fixed Budget
No Sample Regret
```

`Absolute C2F` 使用独立的绝对值 C2F 候选类，并在 V18 Controller 预算下围绕
Base 组合；它是机制级破坏性对照，不是 V14 全结构复刻，也不具备 Full 的严格
初始化回退与观测尺度硬界。`Unbounded Residual` 只把 DirectionHead 的
`tanh` 换成线性输出，用于验证方向硬界。二者均由专用配置构造，不改变 Full
V18。`Fine-only Residual` 同时将不存在的 Mid/Coarse 残差监督权重置零，避免
把 detached Base anchor 的常数项计入该消融训练损失。

新增 `run_v14_controls.py` 在完全相同的 mask、数据、seed、batch、训练预算、
验证频率、早停和全局指标口径下重跑 V14 对照。汇总器会拒绝旧 batch-average
指标或任一协议签名不一致的历史 V14 结果。
