# 第17次改动：分层尺度专家路由 MoE

## 1. 修改信息

- 修改日期：2026-07-19
- 开发分支：`v17-single`
- 基础分支：`v15-single`
- 修改前提交：`6b8e2f4a6a409d2a1698d175dad81f279bf3c1f3`
- 修改后提交：`待本次工作区提交后回填`
- 对应设计文档：`model_designs/v17-single_分层尺度专家路由MoE详细改进方案.md`
- 模型名称：HSA-MoE（Hierarchical Scale-Adaptive Mixture-of-Experts）

V17 按设计文档从 `v15-single` 的工程基础实现，但模型结构以 Main 的 `MultiScaleMoEBackbone` 为核心基线重新组织。V17 不调用 V15 残差金字塔，也不继承 V16 Teacher/Calibration 路径。

## 2. 版本目标与约束

V17 把全部创新限制在主要多尺度 MoE 内部：

```text
Scale-Specific Adapter
→ Hierarchical Scale-Expert Router
→ Fine-Preserved Parallel Fusion
→ Sample-wise Shared–Routed Residual Fusion
```

明确不使用：

```text
Teacher / Distillation / Teacher Anchor
额外 Candidate Prediction
Oracle Alpha
Acceptance / Calibration Gate
输出后的 Residual Pyramid 或 C2F Correction
```

## 3. 新增结构

### 3.1 Scale-Specific Lightweight Adapter

新增 `scale_specific_adapter.py`。Fine、Mid、Coarse 分别使用：

```text
Conv1x1(64→16) → GELU → Conv1x1(16→64) → Residual Add
```

最后一层零初始化，因此模型初始时三个 Adapter 都严格为 Identity。三个尺度参数不共享，公共 Expert Pool 仍保持跨尺度共享。

### 3.2 Hierarchical Scale-Expert Router

新增 `hierarchical_scale_expert_router.py`。Router 使用每尺度的：

```text
GAP(feature) + 5维 mask 统计 + reliability + 8维 scale embedding
```

先经共享 Local Projector 得到三个 32 维尺度 token，再形成 64 维全局上下文，并统一输出：

- 三尺度权重；
- Fine/Mid/Coarse 各自的专家概率；
- 样本级 Routed Branch Gate。

尺度 logits 加入可学习 reliability prior；inactive scale token 在进入 Global Context 前清零，其最终尺度权重严格为零。Expert Head 没有零初始化，避免 Top-K 初始固定索引；Route Head 最后一层零初始化并加固定 bias=-3，初始 routed 强度约为 0.047。

### 3.3 Fine-Preserved Parallel Fusion

新增 `fine_preserved_scale_fusion.py`。Scale Router 的权重先经过：

```text
w_safe = (1 - 0.25) * w
w_safe_f += 0.25
```

从而保证 Fine 权重不低于 25%。Mid/Coarse 分别直接上采样到 Fine，经 1×1×1 投影后与 Fine 并行加权，不再执行强制 Coarse→Mid→Fine 串行传播。

Shared 分支和 Routed 分支使用同一组安全尺度权重；最终融合为：

```text
h_main = h_shared + route_gate(sample) * h_route_proj
```

## 4. 兼容性修改

只对 `fusion.py` 增加两个默认值为 `None` 的可选接口：

```text
GatedCrossScaleSharedExpert.external_scale_weight
SharedRoutedResidualFusion.external_route_gate
```

旧 Main、V14、V15 不传入外部门控，继续执行原有 Scale Gate 和全局 `route_gamma`。已有 18 项 V14/V15 测试全部通过，未改变旧版本模型结构和默认行为。

V17 通过 Architecture Registry 注册为：

```text
v17_hierarchical_scale_moe
```

未指定 architecture 时仍默认构建 Main。

## 5. Loss 与诊断

V17 继续使用 Main 已验证的损失：

```text
L_main + L_cross
+ L_importance + L_load
+ L_shared_aux + L_route_aux
+ L_complementary
```

不增加 Teacher/Candidate/Calibration Loss。新增可选 Scale Entropy Floor，正式配置 `lambda_scale_entropy=0`，只记录不施加约束；仅在预实验确认尺度早期塌缩后才能从 JSON 开启。

训练、验证和测试日志新增：

- scale weight/raw weight 的 mean/std、entropy、top1 frequency；
- 每尺度 expert gate mean、entropy、top1 frequency、Top-K load；
- `scale_weight × expert_gate` 联合行为；
- route gate mean/std/min/max，以及与 missing rate/scale entropy 的相关性；
- Adapter delta RMS 和 relative RMS；
- reliability prior strength 和 active scale mask。

所有诊断只使用输入、mask 和中间特征，不读取隐藏 target。

## 6. 配置与训练策略

正式配置位于 `configs/v17-single/`：

| 数据集 | Epoch | Val Epoch | Scale Mode | Early Stopping |
|---|---:|---:|---|---|
| TaxiBJ fixed | 160 | 5 | fine+mid | 关闭 |
| TaxiBJ random | 160 上限 | 5 | fine+mid | patience=10 次验证 |
| BikeNYC fixed/random | 140 上限 | 2 | fine+mid+coarse | patience=12 次验证 |
| CHAP fixed/random | 150 | 5 | fine+mid+coarse | 关闭 |

Optimizer 使用 AdamW，`lr=1e-3`、`weight_decay=1e-4`、梯度裁剪 1.0、AMP 和 CosineAnnealingLR。配置中的 `train_policy_by_mask` 由 V17 单实验入口解析并写入实际运行配置，避免在代码中硬编码不同 mask 的 Early Stopping。

统一训练协议仍为：定期验证 → 只覆盖唯一验证 MAE 最优 `best.pt` → 训练结束重新加载最佳参数 → 完整测试一次。

## 8. 核心消融

四个消融均由 JSON 控制并已验证实际改变执行路径：

```text
no_scale_adapter   → Adapter 改为 Identity
decoupled_router   → 独立 QualityRouter + 独立 Scale Gate
progressive_fusion → 恢复 Main 的串行 ProgressiveRouteFusion
global_route_gamma → 恢复全局 sigmoid(route_gamma)
```

正式尺寸下参数量为：

| 数据集 | Main | V17 | 变化 |

## 11. 相对设计文档的合理调整

1. 文档建议修改共享/分支融合接口；实际仅增加可选参数，默认 `None`，保证旧版本回归兼容。
2. Fine-Preserved 权重单独封装并在 Shared/Routed 两条路径复用，避免两处分散实现导致权重不一致。
3. Decoupled Router 消融仍保留相同的样本级 Route Context，只替换尺度和专家选择，以便单独测量“统一 Scale-Expert 决策”的贡献。
4. Early Stopping 按数据集和 mask 写入 JSON 策略；正式运行的 `config.json` 保存展开后的真实策略。
5. 测试使用项目已有 `unittest`，不引入当前环境缺失的 pytest 依赖。
