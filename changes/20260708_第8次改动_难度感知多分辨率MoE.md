## 3. 第八版整体结构

```text
x_f_obs, x_m_obs, x_c_obs + masks + reliability
  ├── ScaleTokenEncoder(F/M/C) -> h_f, h_m, h_c
  └── DifficultyDescriptor(F/M/C) -> d_f, d_m, d_c

h_s + q_s + scale_embed_s
  -> QualityRouter base logits

d_s
  -> difficulty residual logits (zero initialized)

base logits + difficulty residual logits
  -> softmax gate_s
  -> TopKRoutedExpertPool
  -> ProgressiveRouteFusion
  -> 原 main 后续共享/路由融合
  -> pred_head
  -> x_hat
```

Tensor shape 保持：

```text
d_f, d_m, d_c: [B,16]
gate_f/m/c:     [B,E]
z_f:            [B,D,T,H,W]
z_m:            [B,D,T,H/2,W/2]
z_c:            [B,D,T,H/4,W/4]
x_hat:          [B,C,T,H,W]
```

## 4. DifficultyDescriptor

### 4.1 九维原始难度统计

`compute_raw_difficulty_stats` 为每个样本、每个分辨率计算：

| 序号 | 特征 | 实现含义 |
|---:|---|---|
| 1 | `missing_rate` | 样本整体缺失比例 |
| 2 | `observed_ratio` | 样本整体观测比例 |
| 3 | `temporal_gap_score` | 相邻时间片连续缺失程度 |
| 4 | `spatial_block_score` | 局部窗口中最严重的空间块缺失程度 |
| 5 | `neighbor_density` | 缺失位置周围 `3×3` 邻域的平均观测密度 |
| 6 | `local_value_variance` | 有效观测值的样本内方差 |
| 7 | `temporal_variance` | 相邻且同时被观测位置的时间差分平方均值 |
| 8 | `scale_reliability` | masked pooling reliability 的样本均值 |
| 9 | `cross_scale_consistency` | 当前尺度与相邻尺度对齐值的一致程度 |

边界保护：

- coarse scale 小于 `3×3` 时，邻域密度退化为样本观测比例；
-时间长度为 1 时，时间差分设为 0；
- 无缺失位置时避免除零；
- 所有统计最终执行 `nan_to_num`，避免 NaN/Inf 进入 Router；
- cross-scale reference 自动插值到目标尺度。

### 4.2 难度向量编码

```text
raw_stats [B,9]
  -> Linear(9,32)
  -> GELU
  -> Dropout
  -> Linear(32,16)
  -> difficulty embedding [B,16]
```

BikeNYC 的 difficulty dropout 设置为 `0.15`，TaxiBJ 和 CHAP 设置为 `0.1`，用于降低小数据集难度分支过拟合风险。

## 5. DifficultyAwareRouter

第八版没有删除 `QualityRouter`，而是继承其基础路径：

```text
base_logits = QualityRouter.net([pooled_h, q, scale_embed])
diff_logits = DifficultyNet(difficulty)
logits = base_logits + diff_logits
gate = softmax(logits)
```

DifficultyNet：

```text
Linear(16, max(D/2,16))
GELU
Dropout
Linear(hidden, E)
```

最后一个线性层执行零初始化，因此初始状态满足：

```text
diff_logits = 0
v8_initial_gate = QualityRouter_base_gate
```

这里仅将 Router 的 difficulty residual 输出层置零，而不同时将 DifficultyDescriptor 输出层置零。若两侧同时零初始化，难度分支在初期会形成近似无梯度路径。当前策略既保证初始 gate 与基础路径一致，又保证 difficulty 输出层从第一个反向步骤开始获得非零梯度。

## 6. Forward 接入

第八版在三尺度 encoder 之后、Router 之前增加：

```python
d_f = difficulty_descriptor(
    x_f, m_f,
    cross_scale_reference=mean(up(x_m), up(x_c))
)
d_m = difficulty_descriptor(
    x_m, m_m,
    reliability=r_m,
    cross_scale_reference=up(x_c)
)
d_c = difficulty_descriptor(
    x_c, m_c,
    reliability=r_c,
    cross_scale_reference=down(x_m)
)
```

然后将 `d_f/d_m/d_c` 分别传入对应 Router。其他 forward 路径保持 main 不变。

TaxiBJ 原配置使用 `fine_mid`，第八版没有强制改成 `fine_mid_coarse`；BikeNYC 和 CHAP 保留原来的 `fine_mid_coarse`。这是为了不让尺度数量变化和 difficulty router 同时成为实验变量。

## 8. Loss 与训练策略

按照设计要求，第一轮不新增 difficulty loss 或 monotonic loss。总 Loss 完全沿用 main：

```text
L = L_main
  + lambda_cross * L_cross
  + lambda_importance_balance * L_importance
  + lambda_load_balance * L_load
  + lambda_shared_aux * L_shared_aux
  + lambda_route_aux * L_route_aux
  + lambda_complementary * L_complementary
  + 其他原有可选项
```

因此，当前实验中的效果变化来自 Router 输入与 logits 的变化，而不是额外监督或 loss 权重变化。
