# 第 17.2 次改动：去尺度 Adapter 的稳健分层尺度 MoE

## 基本信息

- 开发分支：`v17.2-single`
- 修改前提交：`83aa9ba4d9b0e31a46bb3c6b52fb1ec345f16a9d`
- 修改后提交：待本次修改提交后补充
- 修改日期：2026-07-23
- 修改性质：将 V17.1 E1 No Adapter 的多随机种子结论正式化

## 修改依据

V17.1 三阶段实验表明：

- E1 在 12 个 point-seed 上相对 Full 平均改善 3.58%，获胜 8/12；
- TaxiBJ fixed@0.4 平均改善 9.49%，3/3 seeds 获胜；
- CHAP fixed@0.4 平均改善 4.24%，3/3 seeds 获胜；
- C3 扩展到三 seed 后平均退化 0.96%，不进入 V17.2。

因此 V17.2 只正式化一项结构变化：

```text
V17.2 = V17 Full - Fine/Mid/Coarse Scale Adapter
```

## 模型实现

新增 `V17_2NoAdapterHierarchicalScaleMoEBackbone`：

- 继承 V17 主干，保留全部 Hierarchical Scale-Expert Router、Top-2
  Shared Expert Pool、Fine-Preserved Parallel Fusion、线性 Fine Floor、
  Sample-wise Route Gate、Shared/Routed Residual Fusion 和原损失；
- 配置层与构造层双重强制 `adapter_enabled=false`；
- 即使配置误写为 true，也只创建参数为 0 的 Identity Adapter；
- 输出 `v17_2_enabled`、`v17_2_remove_adapter` 和来源消融元数据；
- Adapter 诊断字段继续保留，数值严格为 0。

新增独立 Registry 架构名：

```text
v17_2_no_adapter_hierarchical_scale_moe
```

原 `v17_hierarchical_scale_moe` 未被重定向，V17/V17.1 可继续复现。

```text
configs/v17.2-single/
├── taxibj.json
```

训练协议严格复用产生 E1 结论的 V17.1 协议：

- TaxiBJ：batch 32、160 epochs、每 5 epoch 验证；
- BikeNYC：batch 16、140 epochs、每 2 epoch 验证；
- CHAP：batch 32、150 epochs、每 5 epoch 验证；
- AdamW、主学习率 1e-3、weight decay 1e-4；
- CosineAnnealingLR、AMP、grad clip=1；
- Val MAE 覆盖保存唯一 `best.pt`，训练后加载 best 执行一次测试。

## 协议与工程保护

新增协议审计：

- 自动构造 V17.1 Full、V17.1 E1、V17.2 三份 resolved config；
- 除版本、架构、输出目录、实验元数据和 Adapter 状态外，其他差异均终止；
- 每个正式 run 保存 `protocol_audit.json`；
- 显式 baseline manifest 取代“最新目录”隐式基线选择。

主训练入口新增通用可复现文件：

- `resolved_config.json`
- `config_sha256.txt`
- `mask_metadata.json`（包含三个 mask CSV 的 SHA256）
- `parameter_report.json`

V17.2 启动时检查：

- Adapter 参数必须为 0；
- 正式训练默认要求 clean Git working tree。

Full 与 V17.2 的参数差 6,384 由独立单元测试固定验证，避免正式训练时为
参数计数额外构建一份 Full 模型。
