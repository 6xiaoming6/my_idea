# 数据与评价协议

## 参考数据

本分支不附带数据和权重。复现原 I37 应单独传输三个已清洗、已划分的 NPZ，字节校验值见 `data_reference.json`。参考样本数：训练 2452、验证 342、测试 707。每个样本为双通道、12 时间步、32×32 细尺度网格。

数据是窗口样本，不能把这些样本拼成连续时间序列后重新滑窗。窗口有各自的原始位置和划分；直接复用既有数据能避免重新划分造成对比失真。原始 `.grid` 到清洗窗口的完整上游数据工程不属于此发布分支，不能仅凭原始文件和样本数声称复现了参考划分。

## 文件结构

| 键 | 形状 | 含义 |
| --- | --- | --- |
| `x_f_gt` | N×2×12×32×32 | 完整细尺度物理流量 |
| `x_m_gt` | N×2×12×16×16 | 每个 2×2 细网格区域的总量 |
| `x_c_gt` | N×2×12×8×8 | 每个 4×4 细网格区域的总量 |

三尺度共享样本、通道与时间对应关系。`scripts/prepare_data.py` 接受已经划分的完整 F 窗口，按上述规则生成 M/C，检查有限值、非负和嵌套总量。它不会重新划分、归一化或覆盖已有数据。若使用不同的上游数据，结果不能直接视为原 I37 的精确复现。

训练加载器逐窗口生成掩码，只把 `x_*_obs` 和 `m_*` 传给模型。可见值为原物理值，缺失处填零；`x_f_gt` 用于监督和指标，I37 不返回完整 M/C 标签作为损失输入。mask 的生成不依据真值大小。

同一窗口三尺度采用同缺失族与缺失率，但使用独立随机流；不是把 F 的缺失掩码池化得到 M/C 掩码。训练每 epoch 重采样，验证和测试固定。`data/observed_multiscale.py` 保留原 split 种子偏移，不能把协议中的基础 seed 当作加载器最终使用的 seed。评估产物记录 `effective_mask_seed`。

## 六套协议

`configs/test_protocol.json` 给出冻结协议。ID 使用 random_point、node_outage、temporal_gap、spatial_region 四类单缺失；OOD 包括二元组合、未见移动区域/多块形态、三元组合，另对前两类换 mask 种子复测。所有协议使用相同测试窗口，只改变缺失条件。

评估 MAE/RMSE 使用 F 缺失位置及相同指标聚合方式。模型选择只使用 ID 验证 MAE。历史训练凭据中单次 test 字段与六协议评估产物的计算入口不同，正式对照应统一读取六协议 `evaluation.json`，不要混用二者。

对三类 OOD 等权汇总时，先分别平均二元组合的两次 mask 测试和未见形态的两次 mask 测试，再与三元组合一起求平均。附加测试 mask 不能当作新的训练种子或独立数据集。

## 新观测推理

`infer.py` 不需要任何完整标签。输入六个数组 `x_f_obs,m_f,x_m_obs,m_m,x_c_obs,m_c`；掩码为二值、与各尺度值同形状。三尺度必须对齐且空间嵌套。最终投影假设可见总量相容，部署到带噪声或互相矛盾的感知数据时，需要另行设计与验证观测误差模型。
