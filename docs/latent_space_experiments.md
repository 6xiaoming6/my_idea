# L01–L10：固定空间 latent 的多尺度专家实验

基于 best `3ab02340`，隔离分支 `latent-space`。本轮为十组从头训练，旧 I37 只作参考，不覆盖 best；不恢复可学习损失配比。

本轮将 latent 理解为固定空间网格，而不是无空间结构的 token。输入仍是 F/M/C 三份真实独立缺失观测；全部隐藏通道64、时间长度12。F/M/C 各自编码后映射到同一个网格，再融合 H0。每轮输入、输出的 H 始终是该网格；选中尺度后将 H 映射到原生网格，与该尺度可见观测、mask、support、位置融合后计算两个专家，再映射回 latent。第四轮输出经 latent→F 映射与 Decoder，再通过原可学习分配投影。

原 I37 隐藏状态本来就是64通道但空间始终是F。新的重点是跨轮空间载体及尺度映射，不把已有通道隐藏表示改名当作新方法。所有默认模块、训练损失与评估定义沿用 I37。尺度/专家路由时序、缺失输入由H0预测补位的规则保持不变，本批不顺带引入输入时序优化。

| 编号 | 对照 | 唯一改动或预定组合 | 目的 |
| --- | --- | --- | --- |
| L01 | I37 | 统一为M网格16×16；池化/插值双向映射，直接回写 | 新策略基本可行性 |
| L02 | L01 | latent改为C网格8×8 | 更强压缩的精度与成本代价 |
| L03 | L01 | 双向每尺度添加残差1×1映射，零初始化、跨轮共享 | 适配尺度语义 |
| L04 | L01 | 双向空间子格重排+可学习通道压缩/展开 | 保留可学习的子格位置区别 |
| L05 | L01 | 返回latent时使用输入状态加原生尺度增量的映射 | 缓解整份状态被粗尺度替换 |
| L06 | L01 | 关闭差分，门参数保留冻结 | latent统一后差分是否必要 |
| L07 | L01 | 关闭历史读写，参数保留冻结 | 历史是否仍有价值 |
| L08 | L06/L07 | 差分和历史都关闭 | 纯顺序latent状态与通信交互 |
| L09 | L01 | 固定CMFF | 排除自由尺度路由的影响 |
| L10 | L03/L05 | 可学习映射+残差回写 | 预先确定的两种映射改进组合 |

L03：`native→latent`和`latent→native`各有三份映射，共六个64→64无bias 1×1卷积；各自位于确定性池化/插值后，以`y+W(y)`输出，W初始为0。初始三尺度编码及每轮回写复用同方向映射，末端解码也复用latent→F映射。

L04：下采样先把2×2子格搬到通道，再用无bias 1×1压缩；上采样先通道展开再重排为空间。初始压缩为均值，展开为复制。该压缩并不无损，且增加参数量；它只提供区分子格的学习能力。M↔M为恒等映射。

L05/L10：`H_next = H_corrected + map_back(V - map_to_scale(H_corrected))`。这只是状态更新设计，不保证重建误差递减。映射无bias，零增量对应零回写。

历史保留原I37的可见F回填、因果顺序和detach规则。P1/P2/P3仍是F预测，读取时按latent大小池化，mask变为可见覆盖比例；历史读取器输出latent增量。中间Decoder读出只服务历史和诊断，不会把跨轮H改回F。L07/L08不写池，不执行读取。差分在同一latent网格计算并沿用RMS匹配与±0.1门控。最终可学习投影读取原始F/M/C观测，保持可见F与可见M/C的剩余区域总量约束。

## 固定协议

- TaxiBJ、seed7、双通道、12时间步、四类混合mask 0.4；数据F32×32/M16×16/C8×8，sum聚合，独立尺度mask。
- 100epoch、batch32、每5epoch验证、AdamW、lr 1e-3余弦降至3e-4、weight_decay1e-4、梯度裁剪1、AMP、GPU1串行。
- 共享八专家，每轮原生Top-2；除L09外前三轮自由、第四轮F；同一窗口仍只有8次专家执行。
- 固定投影前/后F缺失L1权重0.5/0.5；可见F重建0.1、投影前可见M/C一致性0.1、候选均衡0.01。
- 不加载任何已训练模型。原参数初始化逐项相同；新增映射用seed+114001独立随机数流；构造后保存每组初始化及SHA256。
- best只根据ID验证MAE。原六套测试协议保持不变，全部报告；先在二元/形态类别内部平均mask复测，再对三个OOD类别等权。
- 优先考虑ID MAE不超过I37的103%的候选，再比较OOD类别相对比值与最差类别；若无更好的折中明确保留I37。不把测试筛选当独立确认，不宣称单seed显著性。

## 预检与运行

CPU检查旧I37、F-grid兼容逐位一致、十组形状/梯度/8次专家执行、无泄漏、空/全观测、投影约束、公共参数与数据mask一致；完整CLI恢复与六套评估。GPU1实际batch32检查十组原生路由和末轮强制TA/ST、AMP反向及L01/L04/L10完整状态恢复。预检不是正式训练。

冻结源码、配置、数据哈希、协议、初始化、参考结果；`scripts/queue_latent.py --suite <目录>`依次运行L01→L10，完成跳过、断点完整恢复、失败停止。每run保存best/last、逐轮诊断及15秒GPU日志。专用tmux以队列为主进程，完成训练、评估和正式报告后自动结束。

报告器遵循 export-experiments-report 的方法配置→完整结果诊断→分析边界顺序，输出至主仓库`experments_report/`；不理想和失败组也保留。
