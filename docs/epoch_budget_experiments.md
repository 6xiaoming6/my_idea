# I37：训练轮数与最低学习率的十一组对照

保持best提交`3ab02340`的I37方法和性能实现，不修改模型或损失。原始`src/`、训练及评估入口逐文件保持一致。新实验放在独立`epoch-budget`分支，不覆盖best或旧实验。

## 对照表与队列顺序

| 轮数 | eta_min=3e-4 | eta_min=1e-5 |
| --- | --- | --- |
| 100 | 已有I37参考，不重训 | E100_L |
| 120 | E120_H | E120_L |
| 140 | E140_H | E140_L |
| 160 | E160_H | E160_L |
| 180 | E180_H | E180_L |
| 200 | E200_H | E200_L |

顺序：E100_L → E120_H → E120_L → E140_H → E140_L → E160_H → E160_L → E180_H → E180_L → E200_H → E200_L。共十一组、1700个训练epoch，每组完整六套测试。

## 固定内容

- TaxiBJ，训练seed7，双通道，12时间步，真实F/M/C为32/16/8，sum聚合后各尺度独立mask。
- 沿用四类混合mask0.4：random_point、node_outage、temporal_gap、spatial_region。数据划分与I37相同，训练每epoch重采样、验证和测试固定；不是纯random_point实验。
- 初始三尺度融合，隐藏状态仍是`[B,64,12,32,32]`。四轮共享八专家，每轮原生Top-2，前三轮自由尺度、末轮F；受控差分、历史池、原Decoder、学习分配投影均保留。
- 不引入空间Linear或latent压缩。投影前后F缺失L1固定0.5/0.5，可见F0.1、投影前可见M/C一致性0.1、候选均衡0.01。没有可学习beta。
- batch32、workers0、线程2、GPU1、AMP、AdamW，lr初值1e-3、weight_decay1e-4、梯度裁剪1；每5轮验证，无早停。性能诊断降频保持I37发布设置。

## 唯一配置差异与归因边界

每组只修改`train.epochs`、`train.scheduler.total_epochs`及`train.scheduler.eta_min`；总周期与该组预算相同，`reach_min_at_last_epoch=true`，所以训练最后一轮使用指定最低学习率。所有组从相同未训练初始化独立训练，不加载原I37的训练后权重，也不共享某次长训练的中途检查点作为其他预算的结果。

不同总轮数的余弦轨迹不同：比较的是完整训练预算与衰减计划，不是保持前100轮轨迹后追加训练。所有组初始参数逐位一致，前若干步的优化率可能不同；这一点必须在报告中披露。

原100轮、eta_min3e-4参考目录：`outputs/v25/experiments/i37_performance/d920258a_seed7_20261026/run`。沿用六套协议和ID验证选择best。不能用测试集或OOD决定单组最佳epoch，也不将mask复测当作新训练种子。

## 验收与冻结

CPU检查：十一配置仅存在上述差异、参数量及初始化一致、学习率首末值/单调性/恢复一致、完成跳过规则以及完整/阶段报告覆盖；并运行已有发布版和性能测试。GPU1以真实batch32、AMP、E200_L和最后一轮强制TA/ST进行前后向及完整检查点/RNG往返检查。仅超参数变化，不额外声称性能或精度收益。

`scripts/freeze_epoch_budget.py`冻结源码、配置、数据/协议摘要、参考结果、公共初始状态及验收收据。公共初始化文件用于审计；训练仍走原seed初始化路径，训练完成后核对其哈希。`scripts/queue_epoch_budget.py`调用未修改的公开train.py入口；run内variant沿用I37_seed7，具体实验由目录和配置唯一标识。

## 运行与报告

专用tmux主进程运行整个GPU1串行队列；完成组跳过，中断组从完整last恢复，失败保留日志并停止。每run保存best/last、训练诊断、每15秒一次的logs/gpu_status.jsonl。监控只读记录两张卡，不占用GPU0执行训练。

全部组结束后自动在experments_report/输出正式报告并关闭会话。报告按方法与复现配置、完整六套结果/曲线/成本、分析和边界组织；比较同轮数最低学习率及同eta_min的训练预算。OOD先合并类别内mask复测，再对二元组合、未见形态、三元组合等权；报告MAE、RMSE、最差类别和ID代价。沿用ID不超过I37的103%作为探索筛选参考，不强行推荐新模型。即使新组改善也不自动更换best。
