# I37 方法与实现边界

## 输入与预测

输入是空间对齐、区域嵌套的 F/M/C 观测与各自掩码。三尺度时间长度相同，空间边长分别为 F 的 1、1/2、1/4。参考实验的 M/C 在完整 F 上求和构造，再分别生成独立的缺失掩码；这是一种多尺度观测的实验模拟，不意味着部署时能获取完整 F。

模型内部将 M/C 总量除以区域面积作为编码值，保留原物理总量供投影使用。三个尺度复用编码器，空间对齐后通过 1×1 融合得到 H0。每轮隐藏状态仍映射回 F 网格；解码器输出细尺度预测。最终可见 F 回填，缺失部分接受一致性投影。

## 四轮共享专家

每轮选择一个计算尺度和两个专家。前三轮尺度为原生硬 Top-1，第四轮固定 F；专家始终为原生 Top-2。八个专家为 T/S/TD/SD/TA/ST/TL/SL，参数跨四轮共享，每窗口共八次专家执行。尺度候选、专家候选和最终执行是不同概念。

I37 实现沿用被冻结的数据流：路由基于当前隐藏状态计算；跨轮信息修正状态，再到选中尺度融合观测、执行专家，加权融合后回到细网格。专家路由并非读取最新的选中尺度融合结果。每轮缺失处的补位保留 H0 初始预测来源，并非逐轮刷新。这些是 I37 本身的行为，发布版没有把后续优化探索混入其中。

配置中的父类 `core_validation.path=CMFF` 是构造所需设置；实际尺度路径由 `scale_delta_exploration.path=free` 和 `last_round_fine=true` 控制。历史 I37 best 在对应评估中偏向 MMFF，不应把它描述成固定 MMFF 或固定 CMFF。

## 受控差分与历史池

受控差分利用相邻隐藏状态变化，经过 RMS 幅度匹配和 ±0.1 有界门控修正下一轮输入。这里的差分是隐藏状态变化，不是已知的预测误差下降方向。

历史池从空开始，保存本样本前面各轮的预测；按原实现回填可见 F，并截断保存结果的梯度。下一轮自适应读取已有历史并以受限幅度注入。第 k 轮只能读取前 k−1 轮，不能读取未来状态或真实缺失标签。

两者属于不同的跨轮信息来源，但组合收益需要对照实验支持。I37 不保证每轮误差下降，也不声称具有收敛证明。

## 可学习分配投影

H4 经解码器得到原始预测。投影只使用可见 F/M/C 与掩码：先保留可见 F，在可见 M 区域扣除已知细尺度值后分配剩余总量；再在可见 C 中扣除已由可见 M 约束的部分及其他可见 F，处理剩余区域。

分配头产生正权重，采用加权非负单纯形投影，在符合总量约束的缺失位置分配校正量。没有粗尺度约束的位置不会凭空获得总量条件。不相容的真实观测不能被假定总能同时满足；当前验证主要覆盖由同一完整 F 聚合产生的相容观测。非负约束适用于参与投影的区域，不能扩大为所有无约束位置均有非负保证。

## 训练目标

- 投影前 F 缺失位置 L1：β。
- 投影后 F 缺失位置 L1：1−β。
- 投影前可见 F 重建 L1：0.1。
- 可见 M/C 聚合一致性 L1：0.1，在投影前预测上回填可见 F、按面积归一化并平均两尺度。
- 候选均衡损失：0.01。

当前默认采用可学习凸组合：β = sigmoid(a)，a 初始化为0，因此初始前后权重均为0.5，训练时始终非负且和为1。a 是独立的全局标量参数，使用主学习率且不加权重衰减，梯度来自两项缺失位置损失，不 detach；随模型保存在检查点中。可见 F、M/C 一致性及候选均衡项的权重保持不变。不使用完整 M/C 标签计算一致性损失。选择 best 只使用 ID 验证 MAE。

原 I37 的已报告结果使用固定0.5/0.5；当前配置保留其骨干，将损失权重改为可学习，因此需要独立训练评价。旧固定权重检查点仍按其内置配置加载，不会自动增加这个标量或更改已有结果。

## 代码导览

| 入口 | 职责 |
| --- | --- |
| `scripts/train.py` | 设备隔离、数据/源码指纹、单 run 锁、训练及可选六套评估 |
| `scripts/train_core.py` | 保留冻结训练循环；完整 epoch 断点恢复 |
| `scripts/evaluate_core.py` | 保留六套协议的 split、mask 种子偏移与指标实现 |
| `models/imputer.py` | 原始参数命名及公开模型包装；可见 F 回填 |
| `models/observed_consistency_coe.py` | I37 组合、学习分配与非负总量投影 |
| `models/observed_history_coe.py` | 历史写入和自适应读取 |
| `models/scale_delta_exploration_coe.py` | 自由尺度和选中分支梯度 |
| `models/observed_multiscale_coe.py` | 真实三尺度观测编码与逐轮输入 |
| `models/core_validation_coe.py` 及其父类 | 受控差分、共享专家与原有初始化 |
| `losses.py`, `engine.py` | 冻结损失、训练和诊断 |
| `data/observed_multiscale.py`, `data/diverse_masks.py` | 物理聚合观测和独立多尺度掩码 |

源码路径以 `src/stmoe_imputer/` 为根。保留继承链是为了维持已验证实现和原检查点兼容性，不代表发布了父类中所有历史实验方案。
