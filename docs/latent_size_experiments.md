## 数据流

三尺度各自编码 → 映射到lh×lw → 拼接融合H0。

每轮：lh×lw隐藏状态 → 原跨轮差分与历史 → 映射到选中尺度的原生网格 → 融合该尺度可见观测 → 两个专家 → 映射回lh×lw。

最终：H4 → 映射到F的32×32 → 原Decoder → 原可学习分配投影。

固定64通道、12时间步。F/M/C真实输入的网格仍为32/16/8。四轮共享八专家、每轮原生Top-2、前三轮自由尺度/末轮F、受控差分、历史池和原Decoder与投影都保留。没有无网格token或交叉注意力；原路由时序和H0预测补位规则也不变。

历史仍存可见F回填的detach预测，读取时固定重采样到lh×lw；原始观测和mask不被预测覆盖。线性对照只替换主隐藏状态的双向映射，不连带替换mask、support或历史原始预测的重采样。

## 两种空间映射

固定映射：下采样为像素覆盖面积加权平均，整数缩放严格复用原平均池化的归约顺序；放大为原确定性双线性插值。非整数比例同样适用，恒等大小直接返回。

空间Linear：高度和宽度分别一个无bias的`nn.Linear`。以F32×32→latent16×16为例，宽度Linear(32,16)，高度Linear(32,16)，依次得到16×16；64个通道和12个时间步共用这些空间权重，不改变通道数。

每尺度、每方向各一对高度/宽度权重，跨四轮共享；进入latent的映射同时用于初始各尺度编码和每轮专家结果回写，离开latent的映射同时用于原生尺度计算和最终F解码。即便尺寸相同，启用的Linear也是可训练恒等初始化。

权重初始化为对应固定重采样矩阵，使初始功能尽量接近固定映射；随后不约束行和或正负。这里投影的是隐藏特征，不直接代表物理流量，总量约束仍由原最终一致性投影负责。采用高度/宽度分解，不是把整幅图flatten后接巨型全连接层。FP32累加后恢复原dtype，与原重采样精度政策一致；矩阵乘法与均值归约顺序不同，初始仅按数值容差比较，不宣称线性组与固定组逐位相同。
