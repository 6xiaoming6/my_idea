## 2. 实际模型结构

V15.1 完整复用 main 多尺度 MoE Backbone，只替换 V15 的大残差金字塔和动态 beta：

```text
main MultiScaleMoEBackbone
  -> x_base, z_f, z_m, z_c, h_main, scale_gate

active scale mask + detached main scale gate
  -> active_scale_weight

ScaleGuidedResidualAdapter
  64维 main 特征 -> 24维残差空间
  coarse/mid 使用轻量 1x1 投影与融合
  fine 只保留一个 24维 ResidualSTBlock
  -> delta_raw

delta_candidate = 0.05 * scale_ref * tanh(delta_raw)

ResidualAcceptanceGate(9维可观测条件)
  -> accept_gate

x_final = x_base + accept_gate * delta_candidate
```

默认设置：

```text
residual_dim          = 24
rho                   = 0.05
accept_hidden_dim     = 24
accept_fixed_bias     = -1.5（buffer，不可训练）
accept_gain_margin    = 0.002
detach_residual_inputs = true
detach_scale_gate      = true
```

## 3. Active Scale 强约束

V15.1 将 main 的 `scale_gate` 与 residual active mask 相乘后重新归一化：

```text
fine            -> [1,0,0]
fine_mid        -> [1,1,0]
fine_mid_coarse -> [1,1,1]
```

实现比文档伪代码更严格：inactive coarse/mid 不仅权重为零，对应 Projection 和 Fusion 也不执行，避免卷积 bias 或 GroupNorm 在全零输入上生成伪特征。

TaxiBJ 正式配置沿用 `fine_mid`。完整尺寸 Forward 已验证其 coarse residual weight 严格为 0。

## 4. 固定候选幅度与接纳 Gate

候选残差逐元素满足：

```text
|delta_candidate| <= rho * scale_ref = 0.05 * scale_ref
```

接纳 Gate 只决定候选采用比例：

```text
0 <= accept_gate <= 1
|delta_effective| <= |delta_candidate|
```

Gate 输入为：

```text
missing_rate
temporal_missing_score
spatial_missing_score
mid reliability mean
coarse reliability mean
active fine/mid/coarse weights
candidate_relative_rms
```

`candidate_relative_rms` 在进入 Gate condition 时 detach。这一调整保持“Candidate Loss 学方向、Acceptance Loss 学接纳”的职责分离，避免 Gate 的 BCE 通过幅度描述旁路改写 residual candidate。

## 5. Loss 修改

V15.1 保留 main 原有损失，并新增：

```text
0.50 * L_v15_1_base
+ 0.10 * L_v15_1_candidate
+ 0.05 * L_v15_1_accept
+ 0.10 * L_v15_1_safe
```

- `L_base`：保持 `x_base` 的独立补全能力；
- `L_candidate`：训练固定幅度候选残差方向；
- `L_accept`：使用候选相对收益的 0.95/0.50/0.05 软标签监督 Gate；
- `L_safe`：惩罚 final 的样本隐藏 MAE 高于 base。

真实 AMP smoke 发现 PyTorch 禁止在 autocast 中直接调用 probability BCE。实现改为数学等价的：

```text
binary_cross_entropy_with_logits(accept_logit, target_accept)
```

Gate 同时输出 `accept_logit` 和 `accept_gate=sigmoid(accept_logit)`。该调整提高半精度稳定性，不改变损失定义。

## 9. 验证结果

已通过 30 项 V14/V15/V15.1 回归测试，其中 V15.1 新增 12 项：
