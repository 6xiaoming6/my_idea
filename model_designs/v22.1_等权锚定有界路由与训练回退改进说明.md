# V22.1：等权锚定有界路由与训练回退

日期：2026-09-08。在当前 `v22` 分支新增的实验性小版本，不切换分支，不覆盖 V22。

## 1. 改进依据与边界

BikeNYC fixed/random@0.4、seed=42/2026/3407 的 30 组实验显示：

- 不同粗化几何的 uniform，相比相同固定几何的共享/独立处理器对照，两模式的验证 MAE、测试 MAE 和测试 RMSE 均为 3/3 个种子改善。
- fixed：uniform 测试 MAE 均值 1.8415，原 MoE 为 1.8645；原 MoE 三个种子的 MAE/RMSE 都更差。
- random：原 MoE MAE 均值 2.2624，uniform 为 2.2770；MoE 有 MAE 改善，但 RMSE 没有改善。
- 原 MoE checkpoint 直接改等权或置乱权重会明显退步。它支持路由和专家共同适配，不等价于 MoE 比从头训练 uniform 更好。

因此保留几何专家，不增加新的预测分支；针对路由偏离稳定等权解以及过度共同适配进行可拆分验证。
这是优化假设，不是对误差改善的保证，也不把新的门控参数化本身包装成已证明的论文创新。
当前实验只有一个数据集、一个缺失率，且已根据历史测试结果提出假设；后续需要独立数据集/点位检验，不能把这些点位当作完全未见过的最终验证证据。

## 2. 保留哪些内容

- 观测位置上的样本/通道归一化，以及缺失输入清理；不读取隐藏真值构造特征。
- 原 V22 stem、时空 encoder、stride=2/4 的两尺度。
- 每尺度固定/局部/更宽范围三种粗化，观测支持度、方差与重心统计。
- 每个专家使用自己的分配回投到细网格；共享粗尺度处理器。
- 原尺度融合、时空 decoder、输出 head、反归一化。
- 归一化缺失位置 SmoothL1、几何质量平衡和全局路由使用平衡项；权重不变。
- 单阶段联合训练，无教师、无 checkpoint 初始化、无第二轮模型前向、无额外验证真值监督。

## 3. 有界路由

原 V22 的最后一层路由器本来就是零初始化，首次 forward 已经等权。所以本改动的区别是**整个训练和推理期间的偏离约束**，不是简单声称首次等权初始化是新功能。

对尺度 s、位置 i、专家 e：

```text
p(s,i,:) = softmax(original_router(features, mask, support, variance))
rho(s,i) = rho_max * sigmoid(strength_head(same_router_inputs))
g(s,i,e) = (1 - rho(s,i))/3 + rho(s,i) * p(s,i,e)
mixed(s,i) = sum_e g(s,i,e) * expert_view(s,i,e)
```

每个尺度各有一个 1×1×1 Conv3d 强度头，输出每个位置的单个 rho；不额外输入 fixed/random 标签、测试指标或真值。
同一规则适用于所有数据集和模式，不通过硬编码“fixed 用 uniform、random 用 MoE”获取已知结果优势。

默认：

- `max_strength=0.5`：每个最终专家权重在 `[1/6, 2/3]` 范围内，权重和为 1。
- `initial_strength=0.1`：强度头权重为 0，偏置为 `log(0.1/(0.5-0.1))`。
- 偏好路由仍零初始化，初始输出精确等权；新增参数是在原模型全部完成初始化之后建立，因此共享主干参数保持相同 seed 初始化。
- 两尺度、dim=48 时仅增加 `2×(48+7+1)=112` 个可训练参数。

等价表示为 `均值特征 + rho × (偏好加权特征 - 均值特征)`。
rho 可以靠近 0，但 sigmoid 在有限参数下不等于 0；它是可学习的保守偏离程度，不是经过校准的置信概率。
初始化时偏好恰好均匀，强度头第一步梯度可能为 0，后续偏好偏离均匀后可学习；参数仍在计算图中，不产生 DDP unused-parameter 问题。

边界只约束混合权重，**不约束最终预测误差，也不保证优于训练好的独立 uniform 模型**。后续 decoder 仍可能放大差异。

## 4. 训练时等权回退

仅在 `bounded_fallback` 中启用：每个尺度、每个样本独立抽取 Bernoulli 掩码，以概率 0.25 将该尺度的 rho 设为 0。
一个样本内该尺度的全部时空位置共享此回退决定；不同尺度独立抽样。

```text
training: rho_effective = keep * rho
validation/test: rho_effective = rho
```

- 所有三个专家仍然计算，不是稀疏 MoE，不是节省计算的专家丢弃。
- 不做 `1/(1-p)` 放大，确保训练期间也满足权重上界；这不是无偏 dropout 估计。
- 除原本的 Dropout3d 外，只增加少量随机掩码计算，无额外完整模型前向。
- 部分训练样本仍需在等权路径下完成补全，以减轻模型完全依赖特定路由的共同适配。
- 验证和测试不抽样、不平均多次预测，使用确定性的学习路由。
- 回退是正则化假设，可能损害有用专门化，所以必须保留不回退的 bounded 消融。

## 5. 验证方案

配置：`configs/v22/refinement.json`。

| 候选 | 有界偏离 | 回退概率 | 用途 |
|---|---|---:|---|
| 原 uniform | 不使用动态路由 | 无 | 复用稳定等权对照 |
| 原 moe | 原始自由 softmax | 无 | 复用原路由对照 |
| bounded | rho_max=0.5，初值=0.1 | 0 | 检验有界参数化 |
| bounded_fallback | 同上 | 0.25 | 检验训练回退的增量作用 |

第一轮快速筛选：TaxiBJ、BikeNYC、CHAP 三个数据集的 fixed/random@0.4，仅 seed=42，每组 60 epoch，val_epoch=2（共 30 次验证）、每卡 batch=4、全局 batch=8。
lr=0.001、cosine、weight decay=0.0001、AMP=false、梯度裁剪=1，均沿用 quick 协议。
共 24 组比较（3 数据集 × 2 模式 × 1 种子 × 4 候选），全部模型使用相同 60 epoch 预算。实际待运行数量以启动时的 skip/pending 为准。
旧 100/120 epoch 结果完整保留，但预算和 cosine 调度已改变，不能复用为本轮 60 epoch 已完成结果；包括原 uniform/moe 也需要相同预算重跑。不截取旧训练的前 60 轮冒充新协议。已有完全匹配的 60 epoch 结果仍会自动跳过。
本次不修改模型实现或旧 verification 配置，之前的 120 epoch 三种子固定几何对照仍然有效。正在运行的进程已加载旧配置，修改 JSON 不会自动改变它的预算。

### 跨数据集验证的约束

- BikeNYC 已被用于提出和修改假设，只作为开发集上的重复验证，不能当作完全独立的确认性证据。
- TaxiBJ/CHAP 作为本次新增外部点位，沿用相同的路由上界、初始化强度和回退概率，不根据它们的测试结果分别调参。
- 每个候选都必须在同一数据集、同一模式、同一种子与原 uniform/moe 比较。相同 60 epoch 是数据集内部公平预算，不代表三个数据集具有相同训练时间或均已完全收敛。
- 汇总按数据集和模式分开给出均值、标准差、配对差值。不可把不同单位的原尺度 MAE 直接平均后宣称总体最佳；综合判断可查看相对改善和胜负点位，并明确权重。
- 这一轮仍只覆盖 0.4 缺失率，不是全缺失率验证，也不是跨数据集零样本迁移。各数据集独立训练；若结果支持改进，再冻结方案扩展 0.2/0.6/0.8。

主要检验：

1. bounded 相对原 moe：fixed 是否改善，同时 random 是否保留 MAE 收益。
2. bounded 相对 uniform：是否获得真正增益，而不是仅修复原 moe 的退步。
3. bounded_fallback 相对 bounded：回退是否提供一致增量；无改善则保留更简单版本。
4. 同时检查 RMSE、种子间波动、最佳轮次与 rho 诊断，不只报告最好的一次 MAE。

不预设成功结论；不能只选择候选最有利的种子、模式或测试指标报告。
当前仅单种子，用于第一轮快速筛选，无法估计种子间方差，不自动输出显著性结论。排名接近或验证曲线仍明显下降的候选，不应仅凭本轮结果淘汰；后续再补种子或延长匹配预算。若需要扩展，可在 JSON 中更换 `points`，但统一更改比较预算，确保基线与候选匹配。

## 6. 运行方法

在内层项目根目录执行。先查看计划：

```bash
python scripts/v22/run_refinement.py --gpus 0 1 --dry-run
```

完整比较（双卡 DDP 同训一组，组间顺序执行）：

```bash
python scripts/v22/run_refinement.py --gpus 0 1
```

可选的 bounded 子集：共 18 组比较（3 数据集 × 2 模式 × 1 种子 × 3 候选，包含原 uniform/moe）；第一轮约定的完整 24 组命令不要加此筛选参数。只跳过相同 60 epoch 协议下已完整完成的组：

```bash
python scripts/v22/run_refinement.py --gpus 0 1 --variants bounded
```

完成后执行完整命令会跳过 bounded，只补 bounded_fallback。训练中断后同样重跑命令，完整且匹配的结果会跳过，中断组从头训练并新建运行目录。

只读汇总及保存汇总：

```bash
python scripts/v22/run_refinement.py --gpus 0 1 --summary
python scripts/v22/run_refinement.py --gpus 0 1 --save-summary
```

输出均值、样本标准差和同种子配对差值。`--save-summary` 写入 JSON 和同名 `.log`，默认 `--summary` 不写文件。
若改变 GPU 数量、预算、数据或原模型源码导致协议不匹配，旧组不会被误认为当前实验完成。
默认没有自动选择验证集更好的候选后跳过其他候选，避免隐式修改已约定的比较流程。

## 7. 文件组织、日志与兼容性

- 新模型实验扩展：`scripts/v22/refinement_model.py`。
- 新入口：`scripts/v22/run_refinement.py`。
- 新配置：`configs/v22/refinement.json`。
- 新结果：`outputs/v22/refinement/<dataset>/ablation/v22_<variant>/<mask>/rate<rate>/...`。

没有新增顶层目录，没有修改历史 `src/stmoe_imputer`、V22 启动器或 verification 实现。原因是历史指纹覆盖整个 src；直接增加 src 文件会使已有 30 组被原完成判定视为不同源码。
沿用固定几何对照的实验扩展机制：新 worker 显式注册 V221 builder，然后复用原 DDP 训练循环。
模型配置的 `version` 为 v22.1，基础 architecture 接口仍为 v22_coarsening_moe；加载本版本 checkpoint 必须通过此入口注册新 builder，不能直接用原 V22 backbone 加载。
两个新增实现文件的 SHA256 纳入候选有效配置。worker 启动时再次检查，避免排队期间修改实现造成配置与实际代码不一致。

沿用训练 60 轮→每 2 轮验证→单个 best.pt 原子覆盖→重载 best→最终一次 test 的流程。
保存 train.log、val.log、test.log、metrics.jsonl、config.json 和唯一 best.pt。
额外记录每个尺度的：

- `mix_strength` / `effective_mix_strength`：学习强度和实际应用强度。
- `mix_strength_missing` / `mix_strength_observed`：缺失/观测位置的平均强度。
- `fallback_fraction`：该 batch 回退样本比例，验证/测试为 0。
- `gate_deviation`：最终权重偏离等权的平均绝对值。
- 原有专家使用量、路由熵、粗化几何统计仍保留。

这些诊断沿用引擎按样本加权聚合，缺失/观测子集强度是 batch 内均值的样本加权汇总，不是额外计算的全数据集像素精确加权指标。
两个候选不生成多阶段训练或教师文件，也不保存每轮模型。
