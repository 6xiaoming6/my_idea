# B01 双 MoE：相关工作调研与改进依据

日期：2026-09-10。当前基础：V23 的 B01，不切换分支，不替换历史模型或实验。本文是研究依据和待验证方案，不是新模型的效果报告。

用户明确要求先调研再改代码，因此本轮撤回了刚刚试写、尚未验证的 target-readout/local-dual-MoE 候选。核对 `outputs/v23/scale_completion/comparison/d51981943b16114a/protocol.json` 中全部源码哈希，已与已完成实验完全一致。没有删除旧模型、旧配置、旧日志或 checkpoint。

## 1. 研究目标与现有证据的边界

目标是证明两类不同决策具有互补作用：前端选择如何组织有限观测，后端选择如何利用尺度信息重建目标；完整模型需要稳定优于去掉任一决策的、充分训练的合理对照。

现有78组实验支持：

- B01（原模型、前端专家均匀融合、后端 learned 路由、0.01分支监督）是目前较稳妥的主力。
- 新共享细预测有界修正相对B01，在TaxiBJ random、BikeNYC random的三种子平均测试MAE分别退步约7.02%、3.23%，验证集方向一致。
- 规则聚合在新残差模型的TaxiBJ fixed有收益，但在两个交通数据集random上明显退步。这不是B01下的严格聚合消融，也存在参数量与粗节点数量差异。
- 旧路由实验尚未证明前端动态MoE普遍优于均匀融合。不能把“多个可学习聚合器有效”混同于“动态专家选择有效”。

以下论文只能提供技术依据或竞争边界，不能保证迁移到本项目后提升，更不能保证每个数据集每个种子都满足预设排序。

## 2. 核实的相关工作

### 2.1 组内多尺度补全工作

**Spatio-Temporal Pyramid-Based Multi-Scale Data Completion in Sparse Crowdsensing**：TMC 25(1), 2026，DOI 10.1109/TMC.2025.3599322。已读取作者公开PDF的任务动机和方法说明。论文处理多尺度感知数据，以金字塔结构、尺度内/间交互及跨尺度约束进行补全。[作者PDF](https://cis.temple.edu/~jiewu/research/publications/Publication_files/Spatio-Temporal_Pyramid-Based_Multi-Scale_Data_Completion_in_Sparse_Crowdsensing.pdf)

**Non-Aligned Multi-Scale Data Completion for Sparse Mobile CrowdSensing**：IWQoS 2025，DOI 10.1109/IWQoS65803.2025.11143411。已读取作者公开PDF的任务、摘要和消融部分；其非对齐问题来自不同尺度感知范围的组合关系，采用最小公倍数尺度对齐、双向处理及ST-Mamba/Cross-Mamba。[作者PDF](https://cis.temple.edu/~jiewu/research/publications/Publication_files/iwqos2025-final14.pdf)

对本项目的含义：可以学习“显式处理尺度对应关系、分别检验交互模块”的方法，但不能把由单一细尺度输入构建的隐藏粗特征称为额外的粗尺度传感器观测。也不能把论文中的物理求和/平均约束直接当成本模型隐藏特征的真值约束。

### 2.2 ImputeFormer：为什么要明确专家擅长的依赖类型

**ImputeFormer: Low Rankness-Induced Transformers for Generalizable Spatiotemporal Imputation**，KDD 2024。已读取方法4.3与消融5.3：通过投影注意力引入低秩结构，其消融区分空间交互和时间交互的作用，并讨论不同缺失形态下贡献差异。[论文全文](https://arxiv.org/html/2312.01728v3)

可借鉴：给表示模块明确、可检验的结构偏置，而非期待若干同构分支仅靠随机初始化自然分工。

限制：论文的时间投影机制不等于本项目的空间区域聚合，不能直接引用其结论证明这里的聚合必要。本项目窗口T=7/12，也没有证据直接引入日周期/长历史专家。

### 2.3 SAITS：组合学习的价值要靠合理替代对照证明

**SAITS: Self-Attention-based Imputation for Time Series**，ESWA 2023。已读取3.2.5与4.5.2/4.5.3：根据注意力信息和缺失掩码进行加权组合，对比只用某块输出、残差相加等替代方法；进一步堆叠第三块并非稳定获益。[论文全文](https://arxiv.org/html/2202.08516v3)

可借鉴：保留不同候选的有效信息，由缺失条件参与组合；消融不仅是“删除”，还包括合理的固定融合。不能只靠增加模块数量论证创新。

不能直接迁移的结论：它不是空间聚合双MoE，不能据此承诺本模型两个门控都必要。

### 2.4 AdaptIR：专家需要有不同的表示能力

**Parameter Efficient Adaptation for Image Restoration with Heterogeneous Mixture-of-Experts**。已读取方法3.2、消融4.5及附录H。其分支分别侧重局部空间、全局空间与通道表示，并学习自适应组合；文中通过组件与组合替代实验评估这种分工。[论文全文](https://arxiv.org/html/2312.08881)

可借鉴：把专家差异落实到信息处理方式，而不是给三个相同网络分别起名字。其“orthogonal”设计动机不能自动解释为本项目专家已经数学正交，也不能凭结构同构就认定本项目专家实证同质。

这篇是图像恢复/参数高效适配，不是时空补全；不建议照搬FFT到零填充缺失输入，缺失掩码本身会改变频谱。

### 2.5 MoCE-IR：异质专家与路由必须共同设计

**Complexity Experts are Task-Discriminative Learners for Any Image Restoration**，CVPR 2025。核实作者摘要和会议论文搜索可访问内容，完整CVF页面读取失败，未据此复述未核实公式。其专家采用不同复杂度/感受野，并用偏向低复杂度的机制引导分工。[作者预印本](https://arxiv.org/abs/2411.18466)

可借鉴：路由是否有用取决于专家是否提供有差别的能力和代价；均匀使用不是唯一目标。不能仅凭熵更大或专家负载更平衡宣称更有效。

不直接采用：现在没有证据需要在本项目加入计算预算惩罚；也不建议把增加参数量带来的收益伪装为双MoE贡献。

### 2.6 STMoE：必须正面对比的直接相关工作

**STMoE: a structured mixture-of-experts framework for robust spatiotemporal series imputation**，ESWA 2026，DOI 10.1016/j.eswa.2026.132137。读取出版社摘要、引言与方法片段，未取得完整方法正文。其明确区分静态空间、动态空间、短期时间、长期时间四类专家，并描述记忆注意力门控和误差感知监督。[出版社页面](https://www.sciencedirect.com/science/article/abs/pii/S095741742601050X)

对创新性的约束：不能再把“时空依赖分专家＋误差辅助路由”直接称为新贡献。应进一步取得全文/实现后确定基线复现和差异；目前不能声称完整复现了其训练方法。

### 2.7 MiM-DiT：两个MoE本身已经不是充分区分点

**MiM-DiT: MoE in MoE with Diffusion Transformers for All-in-One Image Restoration**，2026-03预印本。已核实作者摘要：Inter-MoE处理大类退化，Intra-MoE处理类内细分变化。[作者摘要](https://arxiv.org/abs/2603.02710)

它不是时空补全，但说明双层MoE本身已有研究。项目需要证明的是“观测组织决策”和“重建利用决策”的具体作用差异，而非声称首次使用两个MoE。

### 2.8 Perceiver IO：解耦读入和读出值得参考，但不是双MoE证据

**Perceiver IO: A General Architecture for Structured Inputs & Outputs**，ICLR 2022。已读取第3节方法：将输入编码到潜在表示，再以输出查询读取潜在表示。[论文全文](https://arxiv.org/html/2107.14795v3)

这给“组织观测”和“读取信息”解耦提供技术参考，但不证明本项目原归属映射回传必然有错，也不证明添加查询注意力能让前端MoE胜过平均聚合。此前试写的目标查询读出已撤回，未作为主力改动保留。

## 3. 源码检查：哪些是事实，哪些尚未证实

事实，来源 `src/stmoe_imputer/models/dual_moe.py`：

1. 三个 LatentRegionExpert 架构与输入类型相同，参数独立；这不等于它们的输出相同。
2. 聚合器只使用观测输入；每个专家的区域独立处理，通过自己的assignment对齐后才融合，这是需要保留的正确约束。
3. 前端source gates参与池化；用于最终专家融合的prior则在观测空间维上平均。同一时刻的不同目标共享这个prior。该平均可能弱化局部决策，但没有实验直接证实它是主要瓶颈。
4. `dual_moe_expert_weight=0.01` 监督的是fine/mid/coarse三个尺度预测，并不分别监督每个尺度内部的三个组织专家。
5. partition正则在每个专家内部计算条件熵减边缘熵，不是不同专家之间的互补性约束。

不能跳过的判断：给前端加局部门控、更多专家或更强多样性正则，都只是待验证假设，不是已确定的修复。

## 4. 本轮补充执行的验证集诊断

没有训练，没有再次读取测试集指标，也没有修改checkpoint。使用上述120轮实验的B01、seed42、六条件最佳参数，完整验证集、FP32推理。重算验证MAE与保存值相对差异小于1e-4。

诊断A：保留模型输出，事后用验证真值逐缺失元素选择fine/mid/coarse中误差最小者（scale oracle）。

诊断B：分别强制前端只读组织专家0、1、2；中/粗两个尺度选择相同专家编号；固定原模型后端completion gates，仅改变组织专家读出。然后事后用验证真值逐元素选择三次输出中最好者（front oracle）。这只检查三个对角组合，不是所有3×3组织组合的全局最优。

| 条件 | B01验证MAE | 三种强制组织读出的MAE | front oracle MAE | scale oracle MAE |
|---|---:|---|---:|---:|
| TaxiBJ fixed | 7.90843 | 14.00604 / 13.61281 / 14.54314 | 5.98274 | 5.01391 |
| TaxiBJ random | 18.42025 | 47.53584 / 43.06453 / 37.43868 | 17.60425 | 13.48702 |
| BikeNYC fixed | 1.80764 | 2.10875 / 2.13481 / 2.07177 | 1.18926 | 1.22081 |
| BikeNYC random | 2.88534 | 5.35348 / 4.71848 / 4.72276 | 1.93271 | 1.89694 |
| CHAP fixed | 0.58120 | 0.58704 / 0.58256 / 0.58387 | 0.52331 | 0.44333 |
| CHAP random | 0.59044 | 0.60153 / 0.60162 / 0.62526 | 0.48116 | 0.45353 |

解释边界很重要：

- oracle需要真值，不可部署，不能作为正式成绩。逐元素最优甚至能按通道选不同专家，比当前共享通道路由更自由；因此不是实际门控能达到的保证。
- 冻结参数下强制单专家属于分布干预，不等于充分训练后的单专家消融，不能据此宣称“删前端MoE必然变差”。
- 结果说明候选输出确实有局部误差差异，不能笼统认定完全同质。
- 强制单用专家普遍比B01差，尤其TaxiBJ random幅度很大。这与强协同/互相抵消或离开训练分布相容，尚不能区分具体原因。
- 因而“复制更多专家＋直接换成局部选择”没有足够依据；应先检查专家是否能形成可独立利用、且其胜任区域可以从观测输入预测的互补能力。

## 5. 建议的下一阶段改动顺序，不一次全部加入

### 第一步：组织专家互补性，优先于单纯换路由

保留B01的细/中/粗独立预测、归一化、尺度MoE和训练策略。不使用共享细预测硬限幅，不引入教师或多阶段训练。

借鉴AdaptIR/MoCE-IR的原则，研究同尺度下不同观测组织偏置：

- 空间连续性组织：优先利用几何邻近与局部观测结构；
- 短窗口时间一致性组织：根据可见时间轨迹组织关联节点；
- 内容关联组织：保留现有全局可学习区域。

这三项是本项目的待验证设计，不是任何一篇论文已经证明的最优组合。应尽量匹配粗节点数量和参数预算；不能简单用不同窗口大小冒充不同组织原则，也不能使用缺失真值构造轨迹相似度。时间有效重叠不足时必须有明确回退。

先保持前端均匀融合，验证异质组织是否改善表示；同时检查各组织的独立预测、局部误差排序及在训练数据上学得的选择规则能否泛化到验证集。若没有互补收益，停止，不继续叠门控。

### 第二步：前端MoE决定组织，后端MoE决定尺度

仅在第一步显示有用差异后，引入面向缺失条件的组织路由。可以借鉴SAITS的缺失条件组合、Perceiver IO的输入/输出决策解耦，但需要在本项目单独检验。

两级职责不能混成同一个尺度选择：

- 前端：在同一尺度上选择哪些观测应该被组织到一起/哪类组织对目标有帮助；
- 后端：根据细、中、粗候选及观测支撑选择尺度信息。

保留专家各自的区域映射对齐后再融合。是否取消空间平均、是否加入专家级弱监督，分别做单变量对照。若使用误差标签训练路由，只可由训练目标生成并detach；推理输入不得读取val/test真值。STMoE已有误差感知门控，不能把这个训练手段单独写成原创贡献。

### 第三步：用完整、公平对照证明必要性

| 前端 | 后端 | 要回答的问题 |
|---|---|---|
| 普通观测均值聚合 | 固定尺度融合 | 无MoE基础 |
| 组织MoE | 固定尺度融合 | 前端独立贡献 |
| 普通观测均值聚合 | 尺度MoE | 后端独立贡献 |
| 组织MoE | 尺度MoE | 双决策组合 |

另需普通求和、单个充分训练的可学习聚合器、多个同构专家均匀融合(B01)、异质专家均匀融合、旧双MoE等对照。常规均值必须除以真实观测数，不能用含零占位的均值故意削弱；求和需配合一致且合理的尺度处理。普通聚合对照保留后续完整补全网络，不能删掉整个粗路径来代替。

主对照统一训练预算、mask和划分，至少三种子；同时报告各数据集/模式MAE与RMSE，不只展示胜出的子集。增加参数量的模型需要参数匹配对照。两MoE各有条件贡献不等于额外协同作用；如要声称协同，另检查2×2交互项，不能仅凭双模型排名第一。

## 6. 当前结论

最有依据的主线不是“强行做出两个都不可删除”，而是：**让不同观测组织产生可利用的互补信息，再检验组织选择与尺度选择是否分别必要。**

现阶段不能承诺新颖性或效果已成立。B01保持主力；本轮完成相关工作核查、源码核查和验证集冻结诊断，暂不保留未经上述依据检验的新模型改动。
