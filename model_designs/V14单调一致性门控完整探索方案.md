# V14 单调一致性门控（MCG）完整探索方案

## 1. 出发点

本路线始终以原始 V14 为唯一基础，不组合 E02、E03、S01、S02 或 RLB，
也不采用教师模型、多阶段训练或测试集后验选参。

对已有 V14 seed=42 最优检查点进行 24 点只读验证集诊断后得到：

- 当前 `alpha_final` 与缺失区解析 MSE 最优系数的 Spearman 相关在 24/24
  点均为负，跨点平均为 `-0.539`；
- 观测区 CTF 相对 base 的收益与缺失区 oracle 系数在 22/24 点为正相关；
- 原始观测收益与缺失区 CTF 收益的跨点平均 Spearman 相关为 `+0.746`；
- TaxiBJ 和 BikeNYC 的 `fixed@0.8` 是明确反例，因此任何新门控都必须接受
  高缺失率固定模式的安全压力测试。

这些结果说明 V14 不是完全缺少可用的 target-free 信号，而是无约束门控
MLP 可能学出了错误的样本排序。继续放大残差、增加残差尺度正则或增加路由
均衡都没有直接解决该问题。

## 2. 唯一修改变量

记观测位置上的 base 和 CTF MAE 分别为 `E_base_obs`、`E_ctf_obs`，定义
无量纲观测收益：

```text
r_obs = clip(
    (E_base_obs - E_ctf_obs) / (E_base_obs + E_ctf_obs + eps),
    -1,
    1
)
```

MCG 的最终门控为：

```text
context = beta * tanh(MLP(precondition, zeros_like(consistency)))
gate_logit = final_bias + context + gamma * r_obs
alpha_final = alpha_final_max * sigmoid(gate_logit)
```

其中：

- `beta=0.5`，限制上下文网络最多只提供有界扰动；
- `gamma>=0` 为固定正系数，保证在上下文相同的条件下，观测收益越大，
  `alpha_final` 必然越大；
- MLP 仍沿用 V14 原有参数和维度，不增加参数；
- consistency 槽位传入零，仅用于保持原有网络形状和检查点兼容性，防止
  无约束 MLP 再次反向抵消显式单调项；
- `x_final=x_base+alpha_final*delta_ctf`、主干、专家、Top-K、refiner 和全部
  V14 损失保持不变。

legacy 模式仍为默认值，因此不开启实验配置时，原始 V14 前向行为不变。

## 3. 预筛候选

只改变 `gamma`：

| 候选 | gamma | context bound | 说明 |
|---|---:|---:|---|
| M01 | 0.5 | 0.5 | 最保守的单调校正 |
| M02 | 1.0 | 0.5 | 中等强度 |
| M03 | 2.0 | 0.5 | 较强但仍有界 |

预筛点固定为：

| 数据集 | 模式 | 缺失率 | 作用 |
|---|---|---:|---|
| TaxiBJ | fixed | 0.8 | 已知反例与安全压力点 |
| BikeNYC | random | 0.2 | 低缺失率敏感点 |
| CHAP | random | 0.4 | 第三数据集代表点 |

共 `3 个候选 × 3 个点 = 9` 次完整训练。每次均执行正常的多轮训练、
定期验证、只覆盖保存最佳验证 MAE 检查点，并用该检查点测试一次。

## 4. 严格推进条件

### 4.1 三点预筛

候选相对匹配的原始 V14 验证结果必须同时满足：

1. 至少 2/3 点验证 MAE 改善；
2. 三点宏平均验证 MAE 改善至少 0.5%；
3. 三点宏平均验证 RMSE 不退化超过 0.5%；
4. 任一点验证 MAE 退化不超过 1%；
5. 任一点验证 RMSE 退化不超过 2%；
6. 无 NaN/Inf，训练、验证、最佳参数覆盖和测试链路完整。

若多个候选通过，仅按验证 MAE、验证 RMSE、安全退化幅度依次选择一个，
不得使用测试排名选 `gamma`。若全部失败，MCG 路线立即关闭，不继续插值
更多 gain。

### 4.2 Core-6

预筛唯一入选候选扩展到 Core-6，必须满足：

1. 至少 4/6 点验证 MAE 改善；
2. 宏平均验证 MAE 改善至少 0.5%；
3. 任一点验证 MAE/RMSE 退化分别不超过 2%/3%；
4. `alpha_final`、`final_gate_context`、`relative_observed_advantage` 均有限；
5. 参数量和显存峰值不得出现实质增加。

### 4.3 三随机种子与全 24 点

Core-6 通过后，先执行 seeds `42/2026/3407` 的配对重复，再执行 seed=42
全 24 点。三种子阶段只改变模型随机种子，不重新生成固定离线 mask。正式
版本至少要求：

- 三种子 Core-6 宏平均 MAE、RMSE均优于 V14；
- 三个数据集没有一致性退化；
- 全 24 点至少 14 点达到 0.5% 以上的明确 MAE 改善；
- 全 24 点宏平均 MAE 改善至少 0.5%；
- 任一点 MAE/RMSE 退化分别不超过 3%/5%。
