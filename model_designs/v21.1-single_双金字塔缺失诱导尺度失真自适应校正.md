# V21.1-single：双金字塔缺失诱导尺度失真自适应校正

## 1. 修改动机

V21 Core-6完整实验确认了两个事实：

1. V14层级masked mean存在Fine→Mid→Coarse与Fine→Coarse不一致；
2. 无条件Measure Pyramid在TaxiBJ random@0.6有效，但在BikeNYC与CHAP上没有普遍收益。

因此，路径一致不等于任务最优。V21.1不再用Measure Pyramid整体替换V14，也不再把7维Evidence直接注入原MoE Token。它将问题改写为：

> 对每个样本、时间和尺度单元，当前Measure校正相对V14表示产生了多大失真差异，以及模型应该接纳多少校正？

## 2. 核心结构

数据端同时构造两个只依赖观测值的金字塔：

\[
Z_s^L=\operatorname{LegacyPyramid}(X\odot M),
\qquad
Z_s^M=\operatorname{MeasurePyramid}(X\odot M,M).
\]

其中，\(Z_s^L\)严格复现V14；\(Z_s^M\)由fine观测的sum/count直接生成，满足聚合路径一致性。

显式尺度失真描述包含：

\[
d_s^{abs}=\frac{\operatorname{mean}_c|Z_s^M-Z_s^L|}
{\operatorname{mean}_c|Z_s^M|+\operatorname{mean}_c|Z_s^L|+\epsilon},
\]

\[
d_s^{signed}=\frac{\operatorname{mean}_c(Z_s^M-Z_s^L)}
{\operatorname{mean}_c|Z_s^M|+\operatorname{mean}_c|Z_s^L|+\epsilon},
\]

以及Legacy与Measure可靠度的差异。三个显式失真通道与V21已验证无隐藏真值泄漏的7维观测Evidence共同输入局部接纳门。

接纳结果为：

\[
\alpha_s=\alpha_{max}\sigma(g_s(d_s,e_s)),
\]

\[
Z_s^{cal}=Z_s^L+\alpha_s(Z_s^M-Z_s^L).
\]

当前设置\(\alpha_{max}=0.5\)、初始\(\alpha=0.01\)。因此模型从接近V14的位置开始，只能有界接纳Measure校正，不能无约束地破坏V14尺度状态。

对当前两级金字塔，Fine→Mid在V14中已经是直接fine masked mean，与Measure Mid严格相同；非交换性只在再次聚合的Coarse层出现。因此实现只为Coarse使用一个轻量1×1×1局部接纳门，Mid严格保持V14，不引入无效参数。原V14主干、专家数、Top-K、粗到细Refiner、损失和训练策略保持不变。Evidence只服务于尺度校正，不直接修改MoE Router。

## 3. 严格消融

| 编号 | 结构 | 作用 |
|---|---|---|
| P0 | V14 Legacy Pyramid | 严格性能锚点 |
| P1 | 无条件Measure Pyramid | 判断固定路径替换 |
| P2 | Measure + 直接Evidence Token | 已验证的旧双状态方案 |
| P3 | 双金字塔 + 显式失真自适应接纳 | V21.1完整候选 |
| P4 | 双金字塔 + Evidence接纳，但屏蔽3维显式失真 | 参数匹配的创新消融 |

P3和P4具有相同模块规模、初始化、数据顺序和训练预算。两者唯一结构变量是接纳门能否看到Legacy–Measure显式差异。

关键比较：

- P3 vs P4：显式尺度失真的独立贡献；
- P3 vs P1：自适应接纳是否优于无条件替换；
- P3 vs P0：最终性能竞争力，而非创新存在与否的唯一门槛。

## 4. 机制记录

训练和验证的`metrics.jsonl`增加：

- `v21_1_alpha_coarse_*`与严格为0的Mid对照；
- `v21_1_distortion_coarse_*`与Mid路径一致性检查；
- `v21_1_support_gap_coarse_mean`；
- `v21_1_correction_coarse_norm_mean`。

离线机制分析进一步计算：

- Legacy、Measure、Calibrated相对完整尺度目标的MAE；
- 估计失真与真实Legacy尺度误差的Spearman相关性；
- 失真与接纳系数的相关性；
- Measure真实优势与接纳系数的相关性；
- 四个失真分位组的缺失位置MAE和接纳系数。

如果P3提高最终MAE，但接纳系数不随失真或真实Measure优势变化，只能视为增加参数带来的结果，不能支撑核心机制。

## 5. 文件与兼容性

- 双金字塔数据契约：`data.scales.pyramid_mode=dual_observation_moment`；
- 新架构：`model.architecture=v21_distortion_calibrated_moe`；
- P3配置：`configs/v21.1-single/distortion_calibrated.json`；
- P4配置：`configs/v21.1-single/ablations/evidence_gate_no_distortion.json`；
- 输出根目录：`outputs/v21.1-single/`。

默认配置仍使用原Legacy路径。V14和V21已有配置及输出目录均不修改、不覆盖。

## 6. 执行顺序

一轮1 epoch真实闭环：

```bash
python scripts/v21.1-single/train.py \
  --variant distortion_calibrated \
  --dataset TaxiBJ --mask fixed --rate 0.6 \
  --gpu 0 --epochs 1
```

新增P3/P4共12组正式Core-6：

```bash
python scripts/v21.1-single/run_core6.py --gpu 0
```

中断后重复同一命令会跳过真正完成的实验。

汇总P0–P4：

```bash
python scripts/v21.1-single/summarize_core6.py
```

对某个完成的P3/P4运行机制分析：

```bash
conda run --no-capture-output -n difftdi \
  python scripts/v21.1-single/analyze_distortion.py \
  --run-dir RUN_DIR --gpu 0
```

只有Core-6结果和机制分析共同成立后，才进入三种子高缺失率与跨mask泛化实验。
