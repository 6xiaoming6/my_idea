# V21.2-single：观测留出配对尺度风险校正

日期：2026-09-06。状态：研究候选实现，不是已经验证成功的创新。

## 1. 为什么改变 V21.1

Core-6 显示 P3 的显式路径分歧特征没有稳定优于去分歧特征的 P4。
额外检查又发现：P3/P4 都能减小平均粗尺度误差，但最终补全未必改善。
所以本版不继续堆叠路由器，也不把 Legacy–Measure 分歧叫作真实误差。

研究问题改为：**在缺失导致尺度统计估计不可靠时，能否从可观测数据中学习
“相对保留原表示，某个有限校正动作会增加还是减少误差”，并允许不校正？**

这是 V21 系列的新候选，底座仍是 V14。V14、V21、V21.1 文件和历史结果不覆盖。

## 2. 与已有工作的关系及创新边界

- [Partial Convolution, ECCV 2018](https://arxiv.org/abs/1804.07723)：有效像素掩码归一化已经存在，不能把 sum/count 归一化本身作为新颖性主张。
- [Noise2Self, ICML 2019](https://arxiv.org/abs/1901.11365)：自监督性能估计与留出校准已有系统研究，其独立噪声等假设不能直接搬到结构化缺失上。
- [SAITS](https://arxiv.org/abs/2202.08516)：时间序列插补中的联合训练和加权组合已有工作，本版不把一般的额外遮挡或加权融合包装成首创。
- [Prediction with Incomplete Data under Agnostic Mask Distribution Shift, IJCAI 2023](https://www.ijcai.org/proceedings/2023/525)：缺失分布漂移必须单独考虑，观测留出分布不自动等于真实缺失分布。

拟验证的区别是：以多尺度聚合算子为决策对象，对同一留出支持上的候选聚合动作
计算配对相对风险，再把风险预测用于 MoE 输入金字塔的局部校正/拒绝。
不仅是修改 MoE 门控；MoE/多尺度主干保留，新增贡献位于尺度表示的构造与监督。
这只是经初步检索形成的贡献假设，不能保证文献中从未有相同方法，不能承诺导师/评审认可。

## 3. 数据流与模型

正常输入只含观测值 X_obs 与掩码 M：

1. Legacy 层级均值形成 L；fine 直接 sum/count 形成 Measure 表示 U。
2. 10 通道描述 = 7 维观测证据 + 3 维路径差异。路径差异是辅助特征，不再当作真实失真。
3. 一个 10→16→2 的 1×1×1 网络预测候选校正 a∈{0.125,0.25} 相对 a=0 的归一化风险差。
4. 预测风险最小的动作若没有超过负风险门槛，则 alpha=0；否则平滑增加接纳强度：

   alpha = a_best × clip((-risk_best - margin)/temperature, 0, 1)。

5. 将 L + alpha(U-L) 输入原 V14 多尺度 MoE。Mid 不修改，原可靠度不修改。

默认 margin=0.02、temperature=0.1；这是决策阈值，不是置信区间。
alpha≤0.25。风险头初始输出正值，故开始时 alpha 严格为零，公共参数初始化与 V14 相同。
**这只保证初始化的输入/输出锚定，不保证训练后性能永不退化。**

该网络有 210 个参数；不增加第二个完整主干，不做教师预训练或多阶段训练。
推理只增加双金字塔统计与小风险头，不做额外遮挡、采样或在线优化。

## 4. 观测留出配对监督

训练时，从 M=1 的位置取 25% 为 H，保留 K=M-H。
fixed 使用整条时间共享的空间柱留出，random 使用时空点留出。
这只匹配粗粒度几何类型，**不是完整匹配真实缺失分布**。

仅用 K 的值生成另一个 Legacy/Measure 金字塔和证据，并由风险头预测风险差。
H 的值仅用于监督，不得进入 K 的输入、描述符、归一化或路由。
原 M=0 位置的真值完全不参与这个辅助分支；常规补全主损失仍遵循原训练协议。

对粗尺度单元内 H 的一阶、二阶矩 m_H、q_H，候选值 z_a=L+a(U-L) 的留出平方风险为：

R_a = mean_channel(z_a² - 2 z_a m_H + q_H)。

监督标签：d_a = (R_a-R_0)/(R_a+R_0+epsilon)，范围 [-1,1]。
同一单元内比较两个动作，共享的 q_H 在风险差分子中抵消，避免把信号本身的局部方差
直接误认成校正收益。只使用至少 2 个留出点且仍有保留观测的单元。
SmoothL1 监督风险差，标签 detach；alpha 在主任务路径也 detach，使风险头只由明确的配对标签学习。

总损失 = 原 V14 损失 + proxy_weight × L_paired，默认 proxy_weight=1。
两个参数组在同一训练循环更新；只增加廉价池化/风险头计算，无第二次主干前向。
代理分支独立 RNG，step 随 checkpoint 保存，不改变原主干 dropout 的随机流。

重要限制：H 是原观测支持的子集，不能把它称为对固定缺失区域或 MNAR 区域真实风险的无偏估计。
风险标签可能随留出数量变化，训练的稀疏支持与部署的完整观测支持也存在分布差异。
尤其固定缺失的位置从未出现在 H 中，必须用跨掩码/跨种子机制实验检验迁移。

## 5. 预先定义的对照

所有参数、epoch、val_epoch 集中放在 `configs/v21.2-single/experiments.json`。

| 配置 | 内容 | 检验问题 |
|---|---|---|
| risk | 完整配对风险校正 | 主候选 |
| no_distortion | 相同网络/监督，去掉 3 个分歧输入 | 分歧特征是否提供独立信息 |
| constant | alpha=0.05，不学习风险 | 是否只是简单混合 |
| constant_mid / constant_max | alpha=0.125 / 0.25 | 固定插值强度曲线；不能只选一个弱常数对照 |
| shuffled | 同一有效单元集合内错配监督目标 | 风险与局部单元的对应关系是否重要 |
| anchor | alpha=0 | 当前工程环境内的 V14 输入锚点 |
| risk_three_scale / anchor_three_scale | 匹配地开启完整三尺度 | TaxiBJ 默认 fine_mid 的路径消融 |

初筛默认只跑 risk/no_distortion/constant 共18组；完整机制结论还需要后续对照。
TaxiBJ 默认保留 V14 的 fine_mid，不偷偷改为三尺度；Coarse 仍经 V14 条件/细化路径参与。
三尺度开关必须与 anchor_three_scale 配对，不能只改候选。

可接受性能的预设筛选参考：验证 MAE 相对 P0 宏平均退步不超过2%，单点不超过5%。
这些是本项目的工程容忍阈值，不是论文界通用标准，也不是统计显著性检验。
主指标接近之外，至少应胜过固定插值或打乱监督，并呈现预测收益与真实收益的关系。
若 no_distortion 不差，后续论文应删除“显式分歧不可或缺”的表述。

初筛只用验证集决定是否推进；冻结方法后做三种子和跨缺失几何验证。
测试集只运行验证选中的最佳模型，不根据测试结果逐点选择 variant。
已多轮查看现有测试集的探索限制应在论文中如实交代，最终结论最好另有未参与调参的划分/数据。

## 6. 执行

在 my_idea 项目根目录运行；默认单卡顺序执行，不自动启动双卡。

```bash
# 检查18条正式任务及配置，不训练
python scripts/v21.2-single/run_core6.py --gpu 0 --dry-run

# 可选：三个数据集六点、主候选，完整1 epoch流程
python scripts/v21.2-single/run_core6.py --gpu 0 --variants risk --epochs 1

# 正式初筛18组，TaxiBJ160/BikeNYC140/CHAP150 epoch
python scripts/v21.2-single/run_core6.py --gpu 0

# 汇总已有结果；未完成任务会明确列出
python scripts/v21.2-single/summarize.py
```

只启动主候选6组：`python scripts/v21.2-single/run_core6.py --gpu 0 --variants risk`。
单点入口：`python scripts/v21.2-single/train.py --dataset TaxiBJ --mask random --rate 0.6 --gpu 0`。

重复命令只跳过配置指纹、种子、训练轮数匹配且具有完整验证/测试日志及 best.pt 的运行。
配置/关联源文件改变后不会复用旧结果。中断任务重新训练，不是优化器断点续训。
现有 V14 训练器负责周期验证、覆盖保存单个 best.pt、训练末尾重载 best.pt 测试。

## 7. 输出与验证边界

路径：`outputs/v21.2-single/{dataset}/ablation/v21_2_{variant}/{mask}/rate{rate}/{run}/`。
沿用 train.log、val.log、test.log、metrics.jsonl 和 checkpoints/best.pt。
新增诊断保存在 metrics.jsonl（保持 train.log/val.log 的精简表格不变）：
alpha、accept_fraction、predicted_regret、correction_rms；训练另记
l_v21_2_proxy、proxy_valid_fraction、proxy_sign_accuracy、proxy_gain_fraction、proxy_regret_mae。
比较符号准确率时必须同时查看 gain_fraction：始终预测“不改善”就有 1-gain_fraction 的准确率，不能把类别不平衡误当作学会预测。
验证/测试没有留出标签，也没有代理损失；日志缺少该项是正常设计，不伪造为0。

单元测试检查初始化V14等价、隐藏真值不影响预测/代理监督、留出标签不进入代理特征、
固定掩码时间一致、接纳边界、空支持、辅助梯度、保存重载及训练验证闭环。
小样本真实尺寸检查不属于正式性能实验，不得用其 MAE 宣称效果提升。
