## 0. 先用一段话把 idea 说清楚

我们从单尺度、带缺失的时空网格出发，不要求额外提供粗尺度观测。把每个观测看作三维坐标 $$q=(t,x,y)$$ 上的信息，学习哪些跨时间、跨位置的可见观测应该被组织为同一个粗粒度单元。

前端组织 MoE 提供多种组织方式：它们在相同的粒度预算下，学习不同的时空关联区域，而不是预先分别指定为平均池化、求和池化或几个固定窗口。每个专家构造自己的粗节点，对粗节点进行交互，再分别读回同一个待补全坐标。目标条件路由器选择适合该位置的组织结果。

后端重建 MoE 保留现有 ST_DILATED 主线，结合细粒度表示、中粒度表示、粗粒度表示及观测支持信息，预测缺失值。

**核心问题不是“两个 MoE 是否比一个强”，而是：在稀疏观测下，先学习如何联合组织时空信息，再学习如何针对目标使用这些信息，是否比固定或分离的组织方式更有效。**

这是有依据的待验证方向，不是已经成立的新颖性结论。三维坐标、可学习聚合、时空多尺度、MoE 和可变形采样本身均不是新发明。

## 1. 研究背景：从单尺度观测到多粒度表示

### 1.1 我们实际面对的任务

城市交通流量、共享单车需求和空气质量等数据，通常同时存在空间关联和时间关联。某些位置、某些时间的数值缺失，模型需要利用允许访问的观测恢复它们。

单个样本的完整目标可表示为 $$Y\in\mathbb{R}^{C\times T\times H\times W}$$。其中 $$C$$ 是变量数，$$T$$ 是时间长度，$$H,W$$ 是空间网格大小。观测掩码为 $$M\in\{0,1\}^{1\times T\times H\times W}$$，1 表示可见。

模型输入是观测值和掩码，而不是完整目标：

$$$$
X_{\mathrm{obs}}=\operatorname{where}(M=1,Y,0),\qquad
\widehat Y=f_\theta(X_{\mathrm{obs}},M).
$$$$

公式中的完整目标用于定义任务；实际代码必须先屏蔽隐藏值再执行统计和编码。不能依赖乘零消除 NaN，也不能把隐藏值提供给区域生成器。

本方案默认是窗口内离线补全：在协议允许时可以使用目标前后时刻的可见值。若改成在线补全或预测，必须额外施加因果掩码，不能直接沿用双向信息。

### 1.2 为什么单尺度输入可以构造多粒度表示

单尺度指输入数据的原始分辨率一致，不意味着模型内部只能采用一种粒度。

细粒度保留局部细节；较粗粒度把若干相关观测组织到一起，可以扩大信息覆盖范围，并减少对某一个缺失位置的依赖。但这不是凭空增加观测：粗表示完全由当前可见信息计算而来，不可能创造额外测量信息。

因此，本工作的背景应表述为：

> 单尺度稀疏观测下的自适应多粒度时空表示与数据补全。

不宜表述为“融合多个独立感知设备提供的多尺度数据”，除非数据和实验协议确实包含那些输入。

### 1.3 与组内两篇多尺度工作的联系和区别

《Non-Aligned Multi-Scale Data Completion for Sparse Mobile CrowdSensing》关注非对齐多尺度观测的表示与交互；《Spatio-Temporal Pyramid-Based Multi-Scale Data Completion in Sparse Crowdsensing》研究多尺度补全和金字塔式建模。两者为“跨粒度信息有利用价值”提供了研究背景，但不能直接证明本文的新聚合形式有效。[Non-Aligned 原文](https://cis.temple.edu/~jiewu/research/publications/Publication_files/iwqos2025-final14.pdf)，[Pyramid 原文](https://cis.temple.edu/~jiewu/research/publications/Publication_files/Spatio-Temporal_Pyramid-Based_Multi-Scale_Data_Completion_in_Sparse_Crowdsensing.pdf)。

需要区分两种协议：

- 先由完整细数据生成粗数据，再分别模拟各尺度缺失：这是构造多尺度观测的实验协议，需要明确声明。
- 先遮蔽细数据，再只用可见细数据生成粗表示：这是本文的协议，不额外获得粗尺度测量。

区别在于输入的信息可用性和聚合、遮蔽的顺序，而不是粗数据是否来自真实的另一台设备。不能因为先前论文使用求和或平均模拟粗观测，就认为它们与本文完全相同。

## 2. 问题动机：为什么考虑联合时空组织

### 2.1 有用的空间位置可能随时间偏移而改变

设目标是补全 C 区域在 8:20 的流量。一个可能的关联模式是：

| 时刻 | 位置 | 可用信息 |
|---|---|---|
| 8:00 | A | 出现流量上升 |
| 8:10 | B | 出现相似变化 |
| 8:20 | C | 数据缺失，等待补全 |

同一时刻邻域未必包含最有用的信息；同一位置的历史也可能全部缺失。相关信息可能来自“不同时间的不同位置”。

这只是说明机制的例子，不是对当前三个数据集已发现规律的陈述。区域间的时间关联可能来自传播、滞后响应或共同因素，不必对应真实物体移动，更不能直接称为因果路径。

### 2.2 独立空间、时间聚合可能带来组织偏差

固定空间区域把同一片位置聚在一起；固定时间窗口把相邻时刻聚在一起。如果相关空间位置随时间变化，这样的组织可能混合不相关信息，或者先平均掉有用的时间差异。

在一个简化线性情形中，先进行固定空间平均，再进行固定时间平均，其联合权重可分解为：

$$$$
a(t,p)=a_T(t)\,a_S(p),\qquad p=(x,y).
$$$$

而联合组织允许：

$$$$
a(t,p)\neq a_T(t)\,a_S(p).
$$$$

重要限制：上面的可分离表达只说明一种受限聚合形式。带非线性、内容依赖、残差和多层交互的时空网络不一定满足这个分解。因此不能据此声称所有“先空间后时间”模型都无法学习时滞，也不能证明当前 A 模型在表达能力上必然不足。

本文真正检验的是：**在有限参数、训练数据和计算预算下，把联合时空关系直接放入粗单元构造，是否比让后续网络间接恢复这种关系更有效。**

### 2.3 缺失模式改变了可利用的信息来源

即便两段数据的真实时空规律相近，可见位置不同，也可能需要不同的组织策略。

因此区域生成器应同时读取可见数值特征和掩码，而不是先根据完整数据构造理想区域，再把这个区域偷偷提供给补全模型。

但是“观测更多的区域”不一定最有用。模型若只追逐可见点密集区，可能忽略目标附近的关键信息。设计需要同时保留目标对齐、位置约束和细粒度回退路径。

### 2.4 为什么考虑多个组织专家

一套组织方式可能不足以兼顾局部突变、平缓背景和不同的时滞关系。多个组织专家可以提供不同的候选表示，再由目标条件路由选择。

这是使用前端 MoE 的假设，而不是必要性证明。相同容量的单个组织器、更宽网络或普通多分支集成都可能做到同样好，必须设置这些对照。

### 2.5 当前项目给出的支持和限制

根据目前源码，A_ST_DILATED 每个时刻分别在空间维度上聚合，再进行粗节点交互和时间处理。它已包含时间信息和随时间变化的分配，不是纯空间网络。见 `src/stmoe_imputer/models/dual_moe.py` 中 `ObservationAggregationMoE`、`RegionInteraction`。

近期可恢复性实验未支持用更复杂模块替代 A。该事实支持“保留成熟后端、避免同时堆叠多个新机制”的开发策略，**并不能证明失败原因就是时空聚合不匹配**。详见 [已有实验报告](../experments_report/20260915_第23版_可恢复性双MoE三数据集30组实验分析.md)。

此外，当前掩码配置包含空间掩码在整个时间窗口上广播的情况，例如 `data/TaxiBJ/random_mask/0.8/train.json` 明确记录 `H*W; broadcast to all T steps at load time`。这里的 random 不能自动理解成独立的时空点缺失。时间机制能否带来收益，需要在这一真实协议下检验，不能假定缺失网格自身总有可见历史。

## 3. 预期创新点，以及不能宣称的内容

### 3.1 主创新假设：以联合时空观测区域为粗化基本单元

不再只把每张时间切片上的空间区域视为粗节点，而把一组跨时间、跨位置的可见观测视为一个粗节点。区域的空间中心可以随时间变化，时间范围、空间范围和内容权重由观测条件共同决定。

希望解决的是“粗化前的信息组织是否与真实可用关联相匹配”，而不只是粗化后的特征融合。

### 3.2 配套方法贡献：组织选择与重建选择分工

前端专家负责提供不同的联合时空组织结果；后端专家负责在目标坐标上进行不同的重建计算。

两者对应不同决策，但“职责不同”不等于“两个模块必不可少”。论文必须通过前后端独立消融证明这一点；若后端或前端可以被简单模块替代，应该据实收缩贡献表述。

### 3.3 机制证据贡献：明确什么时候联合组织有价值

理想证据不是只有总 MAE 改善，而是：

1. 在已知时滞的受控数据中，联合区域能较好地对应有效信息位置。
2. 在相同缺失率下，对关系错位或时间块缺失的改善符合预期。
3. 限制联合几何、破坏时间对应或取消目标路由后出现可复现的变化。
4. 在真实数据上，性能、资源和解释性之间的取舍明确。

### 3.4 明确不作为创新的部分

- 使用三维坐标。
- 使用 3D 卷积或时间卷积。
- 单纯增加时间尺度。
- MoE、Top-K 或负载均衡损失。
- 单纯学习空间分配矩阵。
- 单纯增加专家数量。
- 单纯把“注意力权重”改称为“不规则区域”。

候选新意来自“缺失条件下的联合区域粗化＋区域—目标显式对应＋任务验证”的具体设计与证据，不来自上述部件的名称。

### 3.5 可以使用的谨慎论文表述

> 我们研究单尺度稀疏时空观测中的组织与重建问题，构造观测条件化的联合时空粗粒度表示，并通过目标对齐读出和双层专家机制进行缺失恢复。我们进一步检验这种组织方式在时滞关联及不同缺失布局下的适用性。

目前不要使用“首次”“解决了现有方法无法建模的问题”“保证专家分工”“恢复真实传播规律”等结论性措辞。

## 4. 三维坐标与时空区域的准确含义

### 4.1 坐标不是观测数值

$$q=(t,x,y)$$ 描述一个时刻和一个位置；$$X(q)$$ 才是该位置的数值。缺失位置仍有坐标，只是没有可用观测值。

代码中的索引一般是 `X[b, c, t, y, x]`，形状是 `[B,C,T,H,W]`。变量维度和批次维度不是几何坐标轴。

### 4.2 不同区域的直观形状

| 组织形式 | 在三维坐标中的含义 |
|---|---|
| 单时刻空间区域 | 时间固定的一张切片上的区域 |
| 固定位置的时间段 | 空间固定、沿时间轴延伸的线段 |
| 固定区域跨时间 | 沿时间轴延伸的直柱 |
| 随时间平移的区域 | 倾斜的软管状区域 |
| 随时间改变中心或范围的区域 | 弯曲或宽窄变化的软时空区域 |

第一版采用受限、可学习的软区域，而不是承诺任意拓扑的不规则体。软权重可以重叠，也不保证严格连通；因此称为“局部化软时空区域”比“严格连通区域分割”更准确。

### 4.3 时间和空间的单位不能混淆

先分别归一化坐标：

$$$$
u_t=\frac{2t}{\max(T-1,1)}-1,\qquad
p=\left(\frac{2x}{\max(W-1,1)}-1,\frac{2y}{\max(H-1,1)}-1\right).
$$$$

这里仅统一数值范围，并不代表一分钟等价于一个空间网格。空间宽度、时间宽度需要分别建模；时间采样间隔与真实地理距离也必须在数据描述中说明。

## 5. 总体架构：保持单阶段端到端

```text
细粒度观测 X_obs + 掩码 M + 坐标
                    │
              可见值归一化
                    │
              细粒度时空编码 F
                    │
          ┌─────────┼──────────────────┐
          │         │                  │
       细路径    中粒度组织 MoE       粗粒度组织 MoE
          │       多组时空区域         多组时空区域
          │       可见观测聚合         可见观测聚合
          │       粗节点交互           粗节点交互
          │       各专家目标对齐       各专家目标对齐
          │       目标 Top-K 融合      目标 Top-K 融合
          │         │                  │
          └─────────┼──────────────────┘
                    │
        对齐的细/中/粗特征 + 掩码 + 支持统计
                    │
       ST_DILATED 后端 MoE：共享专家 + 路由专家
                    │
              预测 → 反归一化
                    │
       原始范围指标；完整输出保留已观测数值
```

中、粗两条路径第一版直接从细特征并行构造，避免“先错误聚合一次，再继续向上放大”的混杂。这属于多粒度表示组，不要求每个中节点严格隶属于唯一粗节点。若后续要称为严格层级树，需要另加明确的父子映射。

不加入教师、多阶段冻结、外部光流估计或此前的 Gram 可恢复性模块，以免第一轮验证同时改变太多因素。

## 6. 核心方法一：安全输入与细粒度编码

对每个样本、每个通道，只从可见值计算均值和标准差；沿用当前 A 的最小标准差保护，并在统计量上停止梯度。

归一化输入和细特征可写为：

$$$$
\widetilde X=\operatorname{where}\left(M=1,\frac{X_{\mathrm{obs}}-\mu}{\sigma},0\right),\qquad
F=\operatorname{Encoder}([\widetilde X,M]).
$$$$

其中 $$F\in\mathbb{R}^{B\times D\times T\times H\times W}$$，第一版保持 $$D=32$$。

细编码器保持 A 的结构不变。特征可以包含可见输入产生的时空上下文，但不能访问隐藏真值。区域生成器也只读取这个特征及掩码统计。

位置编码不必改动公共细编码器，可在区域生成和目标读出时单独加入，便于隔离新机制。

## 7. 核心方法二：组织专家如何决定区域

### 7.1 一个专家不是一个粗节点

定义：

- $$s$$：中粒度或粗粒度路径。
- $$e=1,\ldots,E_f$$：前端组织专家。
- $$k=1,\ldots,K_s$$：空间区域轨迹编号。
- $$\ell=1,\ldots,L_s$$：有序的粗时间单元。
- $$j=(\ell,k)$$：一个联合时空粗节点，总数为 $$J_s=L_sK_s$$。

每个组织专家产生一整套区域，而不是只负责一个区域。中、粗路径均有自己的专家集合。

专家数量、节点数量和尺度数量是三个不同的超参数，不能混为一谈。

### 7.2 区域参数从哪里来

为每个专家和区域轨迹设置可学习的初始查询与参考中心。通过参考邻域内的可见特征、局部掩码密度、全局可见摘要，预测该样本对应的区域参数。

这些参考中心只用于初始化和限制搜索范围，不是最终固定分区；最终位置和权重仍由观测条件决定。各专家采用相同结构但独立参数。

第一版建议输出：

1. 空间基准中心 $$c^0_{s,e,k}\in\mathbb{R}^2$$。
2. 空间随时间的偏移系数 $$v_{s,e,k}\in\mathbb{R}^2$$。
3. 正的空间宽度 $$\sigma^x_{s,e,k},\sigma^y_{s,e,k}$$。
4. 有序粗时间中心 $$\tau_{s,e,\ell}$$。
5. 正的时间宽度 $$\rho_{s,e,\ell}$$。
6. 用于内容匹配的粗节点查询向量。

参数包含批次依赖，后续公式省略批次下标。通过有界映射限制中心偏移、宽度和时间中心扰动；时间中心保持有序，避免后续沿粗时间轴的卷积失去语义。

### 7.3 空间中心随时间变化

第一版使用简单、可解释的线性轨迹：

$$$$
c_{s,e,k}(u)=c^0_{s,e,k}+v_{s,e,k}(u-u_{\mathrm{ref}}).
$$$$

其中 $$u_{\mathrm{ref}}=0$$ 表示窗口归一化时间中心。

- $$v=0$$：退化成静止的空间区域。
- $$v\neq0$$：区域中心随时间偏移。

同一个 $$k$$ 在所有粗时间单元中共享该轨迹参数，因此跨时间的对应关系是显式建立的，不是把不同时间上“恰好编号相同”的任意区域当成同一区域。

第一版允许静止解，不强制所有区域运动；用范围约束避免区域全部飘出网格。参数 $$v$$ 只表示学习到的时空关联方向，不自动等价于真实速度。

线性轨迹是最小可检验参数化，不等于任意不规则形状。弯曲轨迹、旋转椭圆、非线性时间对齐都放到基本假设成立之后。

### 7.4 从参数得到联合几何权重

对粗节点 $$j=(\ell,k)$$ 和细位置 $$q=(u,p)$$，定义：

$$$$
d^2_{s,e,j}(q)=
\frac{(p_x-c_{s,e,k,x}(u))^2}{(\sigma^x_{s,e,k})^2}
+\frac{(p_y-c_{s,e,k,y}(u))^2}{(\sigma^y_{s,e,k})^2}
+\frac{(u-\tau_{s,e,\ell})^2}{\rho_{s,e,\ell}^2},
\qquad
g_{s,e,j}(q)=\exp\left(-\frac12d^2_{s,e,j}(q)\right).
$$$$

为什么这是真正的联合几何？因为空间中心依赖时间：同一个空间点在不同时间与区域中心的距离不同。展开平方项，会出现空间坐标与时间的交叉项；一般不能把这一几何核简单拆成独立的时间权重乘独立的空间权重。

但高斯核、交叉项和非可分离时空权重本身都不是新理论。本方案只是选择它们作为可实现、可消融的参数化工具。

### 7.5 再加入有界内容匹配

纯几何接近未必表示内容相关，因此增加内容评分：

$$$$
b_{s,e,j}(q)=b_{\max}\tanh\left(
\frac{\langle W_q[F(q),\psi(q)],\,r_{s,e,j}\rangle}{\sqrt{d_k}}
\right),\qquad
a_{s,e,j}(q)=g_{s,e,j}(q)\exp(b_{s,e,j}(q)).
$$$$

$$\psi(q)$$ 是已知的时间、空间位置编码，$$r_{s,e,j}$$ 是节点查询。区域参数和查询允许由可见输入条件化。

内容项限幅，是为了避免随意大的内容得分完全压过几何约束。它不保证严格局部性；实际实现可以再使用有上限的局部候选邻域，并把同样的搜索预算提供给对照组。

这里的 $$a$$ 是非负成员权重，允许不同区域重叠，不要求每个源位置在所有节点上的权重之和为 1。不能直接沿用旧的、假设分配概率和为 1 的分区熵损失。

### 7.6 缺失感知具体体现在哪里

不是只把 mask 放进最终乘法，而是三个位置都处理缺失：

1. 区域参数只从可见特征和掩码摘要生成。
2. 聚合数值时严格排除隐藏源值。
3. 目标读出时告知哪些粗节点有实际观测支持、支持是否稀薄。

前端不使用源 Top-K 把本来稀少的观测进一步分给少数专家。各专家可以访问全部允许的可见输入，其目标端再执行 Top-K 选择。

## 8. 核心方法三：把区域变成粗粒度表示

### 8.1 掩码归一化聚合

记源位置集合为 $$\Omega$$。定义观测权重和质量：

$$$$
w_j(q)=a_j(q)M(q),\qquad
S_j=\sum_{q\in\Omega}w_j(q).
$$$$

为保留相对时间和位置，对每个源特征构造：

$$$$
V_j(q)=\phi_v\left(\left[
F(q),\ \operatorname{PE}\left(u-\tau_j,\ p-c_j(u)\right)
\right]\right).
$$$$

在有足够支持时，粗表示为：

$$$$
z_j=\frac{\sum_{q\in\Omega}w_j(q)V_j(q)}{S_j+\epsilon}.
$$$$

其中 $$\phi_v$$ 可采用输出维度为 D 的轻量非线性 MLP，在区域和专家之间共享；$$\epsilon$$ 为数值稳定用的小正数。让数值特征与相对位置在汇总前产生非线性交互，比单纯相加位置编码更有机会保留“哪个时间对应什么数值”的关系。它会增加计算开销，必须纳入分块设计及对照预算。

这一步是跨时间、跨空间共同求和，区别于当前 A 的逐时刻空间池化。

位置编码帮助模型区分来源，但加权汇总仍可能损失细节；不能声称它完全保留序列顺序。因此保留细路径，并让每条空间轨迹包含多个有序粗时间单元，而不是把整个窗口压成一个无序向量。

### 8.2 观测支持统计

建议保留三类简洁统计：

$$$$
\operatorname{coverage}_j=
\frac{\sum_q g_j(q)M(q)}{\sum_q g_j(q)+\epsilon},\qquad
N_{\mathrm{eff},j}=
\frac{(\sum_q w_j(q))^2}{\sum_q w_j(q)^2+\epsilon}.
$$$$

第三项可用可见标准化数值的加权方差。覆盖率采用几何核计算，减少内容权重把“覆盖程度”任意重定义的问题；有效数量反映权重集中程度，并非统计独立样本数，因为时空观测存在相关性。

三项可经过有界变换后参与特征编码和路由，例如有效数量映射为 $$N_{\mathrm{eff}}/(N_{\mathrm{eff}}+n_0)$$。它们是支持描述，不是校准后的置信度或恢复误差保证。

### 8.3 空支持必须显式处理

当区域内没有可见来源或权重数值上接近零时：

- 将节点标记为不支持。
- 数值分支安全置零，避免除零或对极小质量放大。
- 粗节点交互和目标读出使用有效节点掩码。
- 如果目标找不到有效候选，返回零粗贡献和无支持标志，让细路径与共享后端承担回退。

不能用一个可学习常量填充空区域后，却把它当成真正观测支持。学习先验可以存在，但必须与观测证据的含义区分。

### 8.4 为什么不直接求和

在缺失率和区域大小变化时，求和同时受到真实数值、区域规模、可见数量影响。第一版使用归一化特征聚合，是为了让这几个因素更容易区分，再单独提供质量和支持统计。

因此 $$z_j$$ 是隐空间表示，不能解释为真实总流量；若以后要求质量守恒或总量一致，必须另行引入可解释的物理聚合设计，不能自动从当前公式获得。

## 9. 核心方法四：粗节点交互与目标对齐读出

### 9.1 粗节点交互如何保持时间和空间含义

每个尺度的粗表示形状为 `[B,E_f,L_s,K_s,D]`。

建议保持轻量：

1. 同一个粗时间单元内，在区域节点之间进行注意力交互。
2. 沿同一轨迹编号的有序粗时间轴进行深度可分离时间卷积。
3. 使用残差和前馈层更新粗表示。

所有专家可以共享这一粗处理器，以减少额外容量混杂；组织参数仍独立。如果改成独立粗处理器，应另做容量对照。

节点交互使用空支持掩码，防止无观测节点被误当成数据源。粗节点发生交互后，输出已经包含其他节点的信息，不能再把它解释成仅来自原区域；解释性分析需要同时检查聚合权重和交互路径。

### 9.2 为什么不能直接把专家节点相加

专家 1 的节点 3 和专家 2 的节点 3 未必代表相同位置。正确融合对象是它们对同一个原始目标位置给出的表示，而不是节点编号相同的粗特征。

因此必须先执行：

> 每个专家自己的粗节点 → 同一个细粒度目标坐标 → 再在专家之间混合。

### 9.3 目标坐标怎样读取粗节点

对任意目标 $$q_0=(u_0,p_0)$$，包括缺失目标，构造查询，并利用该专家自己的区域几何、更新后粗特征和支持统计评分：

$$$$
\eta_{e,j}(q_0)=
\log(g_{e,j}(q_0)+\epsilon)
+\frac{\langle Q(F(q_0),\psi(q_0)),K(z'_{e,j})\rangle}{\sqrt{D}}
+b_{\mathrm{support}}(s_{e,j}).
$$$$

其中 $$s_{e,j}$$ 为支持描述，$$z'$$ 为交互后的粗表示。在有效候选节点集合上归一化：

$$$$
\beta_{e,j}(q_0)=\operatorname{softmax}_{j\in\mathcal J_{\mathrm{valid}}(q_0)}\eta_{e,j}(q_0),\qquad
r_e(q_0)=\sum_j\beta_{e,j}(q_0)V_o z'_{e,j}.
$$$$

这里不能再乘目标观测掩码 $$M(q_0)$$，否则缺失位置永远读不到信息。掩码用于排除不可见的源值，不用于禁止缺失目标查询。

若无有效候选，应走前述回退分支，不对全负无穷 logits 执行普通 softmax。

### 9.4 聚合权重与读出权重不是同一个东西

- 聚合回答：某个粗节点由哪些可见来源组成？归一化方向是源位置。
- 读出回答：某个目标位置该使用哪些粗节点？归一化方向是粗节点。

二者共享区域几何以保持对应，但不机械共享所有数值权重。否则可能把“源上观测是否存在”错误地传给目标查询。

如果实现为局部候选版本，读出范围必须允许相关区域覆盖待补全位置。不能在所有观测都缺失的目标邻域中只检索没有支持的节点，再声称模型没有可用信息。

## 10. 核心方法五：两个 MoE 到底分别选择什么

### 10.1 前端 MoE：选择组织结果

每个专家读回目标后，得到 $$r_{s,e}(q)$$。使用目标细特征、候选表示与对齐支持统计生成 logits：

$$$$
\ell^f_{s,e}(q)=R_f\left(F(q),r_{s,e}(q),\bar s_{s,e}(q)\right).
$$$$

对选中的 Top-K 专家重新归一化：

$$$$
\alpha_{s,e}(q)=
\begin{cases}
\displaystyle\frac{\exp\ell^f_{s,e}(q)}{\sum_{e'\in\mathcal T_f(q)}\exp\ell^f_{s,e'}(q)},&e\in\mathcal T_f(q),\\
0,&\text{其他}.
\end{cases}
\qquad
R_s(q)=\sum_e\alpha_{s,e}(q)r_{s,e}(q).
$$$$

再与细特征融合，得到与原网格对齐的中、粗隐藏表示。全部无支持时提供明确回退标记，不强迫路由器从无信息候选中制造证据。

第一版为便于对比，可保持 A 的前端每尺度 8 个专家、目标 Top-4。不是因为已证明这对新模型最优，而是避免同时搜索专家数。

### 10.2 后端 MoE：选择重建运算

将细、中、粗隐藏表示、掩码和支持统计拼接成 $$U$$。后端保留 A 的 8 个 ST_DILATED 路由专家、Top-3 和 1 个共享专家：

$$$$
\widehat Y_z(q)=f_{\mathrm{shared}}(U)(q)
+\sum_{r\in\mathcal T_b(q)}\gamma_r(q)f_r^{\mathrm{ST\_DILATED}}(U)(q).
$$$$

路由专家是基于时空上下文的重建函数，不是分别固定对应细、中、粗尺度的三个专家；每个专家都可以读取三条路径的融合输入。

这一步不再决定“哪些源位置属于哪个粗节点”，而是决定“如何利用组织好的特征完成这个位置的预测”。

### 10.3 最终输出

$$$$
\widehat Y=\sigma\widehat Y_z+\mu,\qquad
Y_{\mathrm{completed}}=\operatorname{where}(M=1,X_{\mathrm{obs}},\widehat Y).
$$$$

评估在协议规定的隐藏且有真值的位置计算原始范围 MAE、RMSE。观测值保留不代表模型在这些位置预测正确，因此不能用包含大量复制观测值的全域误差代替缺失位置指标。

### 10.4 不承诺稀疏加速

若前端必须先计算全部候选才能评分，后端也像当前 A 一样先计算所有专家再乘稀疏权重，那么这里是“稀疏混合”，不是条件执行带来的计算节省。论文应报告实际耗时和显存，不能仅凭 Top-K 宣称高效率。

## 11. 完整数据形状和一个具体例子

设 $$N=HW$$，$$Q=TN$$。以下忽略具体存储布局，表中箭头表示逻辑形状变化。

| 阶段 | 逻辑形状 | 含义 |
|---|---|---|
| 原始输入 | `[B,C,T,H,W]` | 单尺度观测 |
| 细特征 | `[B,D,T,H,W]` | 保留原始坐标 |
| 源特征展平 | `[B,Q,D]` | 每个时空位置一个 token |
| 某尺度成员权重 | `[B,E_f,Q,J_s]` | 概念上的源—粗节点关系，实际应分块/局部计算 |
| 粗表示 | `[B,E_f,L_s,K_s,D]` | 一个节点跨多个时间、位置聚合 |
| 目标读回 | `[B,E_f,Q,D]` | 每个专家回到共同目标坐标 |
| 前端融合 | `[B,D,T,H,W]` | 每个尺度得到一条对齐路径 |
| 后端专家预测 | `[B,E_b,C,T,H,W]` | 多个重建结果 |
| 最终预测 | `[B,C,T,H,W]` | 与输入分辨率一致 |

例如 TaxiBJ 的单窗口为 `[2,12,32,32]`，取 $$D=32$$：

- 细 token 数是 12×32×32＝12,288。
- 中粒度暂取 6 个粗时间单元、32 条空间区域轨迹，共 192 个节点/专家。
- 粗粒度暂取 3 个粗时间单元、8 条轨迹，共 24 个节点/专家。
- 每个中节点覆盖某段时间及随时间变化的空间区域，不是固定的一个 2×2×2 小方块。

BikeNYC 的时间长度也为 12，可先保持 6/3 个粗时间单元；CHAP 时间长度为 7，可先试 4/2。以上仅为设计起点，不是已测出的最优参数。

**节点预算并未自动与 A 相等。**A 在中路径保留 12×32＝384 个时间—区域单元，新例子只有 192 个。正式归因实验需要补充同粗 token 数或同资源预算的控制，不能把参数量近似相等当作所有容量都已匹配。

## 12. 训练目标与稳定性

### 12.1 单阶段训练目标

建议总体保持简洁：

$$$$
\mathcal L=
\mathcal L_{\mathrm{imp}}
+\lambda_f\mathcal L_{\mathrm{bal},f}
+\lambda_b\mathcal L_{\mathrm{bal},b}
+\lambda_g\mathcal L_{\mathrm{geom}}
+\lambda_{\mathrm{aux}}\mathcal L_{\mathrm{aux}}.
$$$$

- 主损失沿用 A 的有效隐藏位置 Smooth L1 及其既有计算尺度，不在结构实验中悄悄改成不同目标。
- 辅助分支监督若沿用 A，应保持监督对象与权重可比，并在方法消融间一致。
- 原来的空间分区损失不能原样施加于重叠非归一化区域；应明确禁用或重新定义，并设置相同损失开关的 A 控制。
- 优先通过参数有界化保证范围；额外几何正则默认从 0 起，确有退化再在训练/验证集上选择。

损失改动也会影响结果，不能把“换了区域＋换了正则”的所有收益都归给区域。

### 12.2 前后端负载均衡

可延续 Switch 风格的概率质量与实际分派比例相乘的辅助目标，按当前 Top-K 选择归一化。这是已有方法的适配，不是创新点。[Switch Transformers，JMLR 2022](https://www.jmlr.org/papers/v23/21-0998.html)。

对有效目标集合 $$\mathcal V$$、专家数 $$E$$ 和选择数 $$K_{\mathrm{top}}$$：

$$$$
P_e=\frac1{|\mathcal V|}\sum_{q\in\mathcal V}\operatorname{softmax}(\ell(q))_e,\qquad
f_e=\frac1{K_{\mathrm{top}}|\mathcal V|}\sum_{q\in\mathcal V}\mathbf1[e\in\operatorname{TopK}(\ell(q))],
\qquad
\mathcal L_{\mathrm{bal}}=E\sum_e P_e\operatorname{stopgrad}(f_e).
$$$$

前端按尺度计算后平均，后端单独计算。有效位置原则上使用待补全目标，排除没有实际候选而只走回退的位置；无有效位置时该项为零。共享专家不参与路由均衡。

$$P_e$$ 保留梯度，$$f_e$$ 停止梯度。均匀分派时该损失约为 1，不是 0。它不能保证专家学出不同功能，也不能保证每个样本均匀分派。

第一版可保留 A 的两项 0.001 系数作为对照起点，记录每个专家的激活率、概率质量与梯度；若候选有效性导致可选专家数量变化，应重新核对统计口径，不能直接套用常数 K 的公式。

### 12.3 保持训练—验证—测试一致

多轮训练，按 `val_epoch` 定期验证，根据验证集指标保留最佳状态，训练结束后恢复该状态并对测试集评估一次。

沿用当前 A 的运行策略时，最佳状态可仅保存在 CPU 内存中，不必落盘；这一选择不改变“最后测试最佳验证状态”的原则。应记录是否恢复、最佳 epoch、指标和代码/配置指纹。

只允许根据训练/验证选参数。不能看完测试结果后逐个缺失率选择不同结构，却仍报告为一个固定模型。

## 13. 第一版如何控制实现复杂度

### 13.1 第一版保留什么

- 原有细编码器、归一化、ST_DILATED 后端。
- 单阶段训练，细/中/粗三路径。
- 前端每尺度 E8、Top-4；后端 E8、Top-3、共享专家 1 个。
- 线性中心轨迹、正的时间/空间宽度、有界内容项。
- 三类支持统计和安全回退。
- 显式区域—目标读出。

### 13.2 第一版暂不加入什么

- 任意形状硬聚类及连通域优化。
- 任意非线性轨迹、区域自动出生/消失。
- 外部传播标签、物理速度监督或光流预训练。
- Gram 可恢复性、教师蒸馏、风险预测头。
- 跨城市迁移和多阶段训练。
- 未经测试的完整时空全连接注意力。

### 13.3 显存风险必须预先处理

以 TaxiBJ、batch 16、E8、中节点 192 为例，仅一个完整成员权重张量就有：

$$$$
16\times8\times12288\times192=301989888
$$$$

个元素。FP32 单张量约 1.125 GiB，FP16 约 0.5625 GiB；这还不含 logits、梯度、读出、专家特征和后端。

因此不能直接同时物化所有尺度、所有专家、全部源—目标关系。优先考虑专家/目标分块、局部候选、在线归一化或重计算，并实际测试反向峰值显存。简单把计算写成循环但保留所有计算图，并不必然降低训练峰值显存。

先在小 batch 上做显存和耗时检查，不自动启动双卡或长队列，不宣称原 batch16/32 必然可用。若要改 batch，应同步调整比较协议，而不是只给新模型更少的数据更新次数。

## 14. 如何验证这个 idea，而不是只验证模型变大了

### 14.1 先验证数据前提

只用训练集检查跨位置滞后关联是否稳定：跨多个窗口统计，做去趋势/时间模式控制，避免 T=7 或 T=12 的单窗口相关系数偶然很高。

重点问：是否存在稳定的非零时滞信息？当目标自身不可见时，它是否仍来自其他可见位置？是否仅由共同日周期造成？

相关性不是因果传播。如果训练数据中这个前提很弱，不应继续把主要故事写成“传播轨迹恢复”。

### 14.2 合成机制实验

至少包括四种情况，并保持观测比例与噪声水平可比：

1. 静止、同步变化：检验模型是否能退化到静态组织。
2. 已知非零时滞或移动模式：检验联合几何是否具有预期作用。
3. 多种关系混合：检验多个组织专家是否比单个更有价值。
4. 无稳定关联或高噪声：检验错误归纳偏置是否带来明显伤害。

报告补全误差和受控关系对齐误差。不要只生成恰好符合线性高斯管假设的数据，还应包含不匹配、分叉或不连续模式，防止实验只验证自己设定的答案。

### 14.3 核心结构对照

| 组别 | 内容 | 回答的问题 |
|---|---|---|
| A | 原始 A_ST_DILATED，不改动 | 是否具备实际替代价值 |
| B | A 加独立时间聚合，保持相近预算 | 收益是否只是增加时间粒度 |
| C | 固定三维块聚合 | 学习组织是否比普通时空池化有效 |
| D | 联合几何但仅一个组织专家，做容量匹配 | 多组织候选是否必要 |
| E | 多个联合组织专家、均匀融合 | 收益是否来自普通集成而非目标路由 |
| F | 完整联合组织＋目标 Top-K＋原后端 | 完整候选 |
| G | 可变形时空采样/注意力，资源相近 | 粗单元瓶颈是否优于直接自适应采样 |

还需设置“关闭空间漂移”的消融，但必须准确命名：若内容项仍跨时空联合变化，关闭漂移并不等于整个算子严格可分离。若要检验严格分离假设，应同时约束几何和内容权重的分解形式。

不应只拿 F 与 C 比较后宣称 MoE 必要；不应只拿 F 与 A 比较后宣称所有新增部件均有贡献。

### 14.4 双 MoE 的 2×2 独立作用

在核心方案有信号后，对前端和后端分别保留/替换：

| | 普通重建器 | 后端 MoE |
|---|---|---|
| 单组织器/固定融合 | 两个条件选择均取消 | 只保留后端选择 |
| 前端组织 MoE | 只保留前端选择 | 完整双 MoE |

普通模块采用容量匹配的有效模型，不使用明显劣化的小网络。既比较主要效果，也比较两模块组合是否有增益；不要求每个条件都赢，但应在预先指定的大部分条件、平均相对误差和多 seed 稳定性上有支持，并检查少数严重退化。

### 14.5 真实数据与缺失协议

保留 TaxiBJ、BikeNYC、CHAP 的原始划分和 fixed/random 结果口径，在原有缺失率上比较。

额外机制实验可加入时间点缺失、连续时间块、空间块和联合时空块，但应单独命名和统计，不把新协议与旧协议混在一张平均结果中。更不能专门挑选只有新模型擅长的掩码来替代原始实验。

主要模型选择基于验证集；确认阶段冻结设计，对测试集报告全部预定条件。

### 14.6 除了 MAE/RMSE 还应记录什么

- 每条件原始范围 MAE/RMSE、相对 A 的变化、胜/平/负与 seed 波动。
- 时序峰值幅度误差、峰值时间偏差；无明确峰值的窗口应单独处理。
- 区域时间跨度、空间跨度、漂移幅度和覆盖率分布。
- 区域重叠与空支持比例，避免大量节点完全冗余。
- 专家使用率与专家间候选相似性；负载平衡不等于功能互补。
- 打乱时间对应、限制漂移后的指标变化，但注明推理时干预可能导致分布外输入，不能独立作为因果证明。
- 参数量、峰值显存、单 epoch 时间、最终测试时间。

对时间粒度、搜索半径和节点数的变化，需要报告实际预算。参数相等、FLOPs 相等和粗节点数相等无法总是同时满足，应明确采用哪种控制，并提供敏感性检查。

## 15. 可能失败的原因与停止条件

### 15.1 时间窗口过短

TaxiBJ/BikeNYC 当前窗口为 12，CHAP 为 7，可能不足以稳定识别复杂关系。若必须大幅增加时间长度才能获益，应单独与同样长窗口的 A 比较，不能把更多输入信息算成新结构收益。

### 15.2 当前 A 已足够表达这些关系

A 的时间卷积和时变空间分配可能已经捕捉到关键关联，新参数化反而限制灵活性。若强对照相近，合理结论是显式结构未体现净收益，而不是简单认为 epoch 不够。

### 15.3 几何约束与数据不匹配

城市关联可能具有远距离功能相似性，不沿局部连续路径发展。局部时空管会引入偏差，因此要保留细路径、静止解，并与非局部内容方法比较。

### 15.4 平滑和压缩掩盖了真实细节

平均指标改善可能伴随峰值损失。需要检查峰值和高波动片段，而不是仅用更平滑的预测获得表面上的低 MAE。

### 15.5 MoE 退化成重复专家

多个专家可能给出近似区域和预测。负载均衡仅让路由不塌缩，不保证专家差异有用。若单专家或均匀融合相当，应承认 MoE 的额外必要性证据不足。

### 15.6 值得继续的标准

大部分预定条件有可重复的改善，整体不出现不可接受的退化；机制实验支持联合组织假设；相近预算强基线不能轻易解释全部收益；资源开销可接受。

如果这些证据不能成立，可以保留“联合组织有用、双 MoE 不必要”的较小结论，或回到 A。没有必要为了保住两个 MoE 的叙事而人为削弱对照。

## 16. 常见追问及回答边界

### 问：这不就是 3D 注意力吗？

存在联系，不能简单否认。区别拟体现在：显式构造有限数量、可复用的多粒度区域节点，再以自己的几何对应读回目标，而不是直接对每个目标做全量源注意力。这个瓶颈与几何约束是否有价值，必须与同预算注意力比较。

### 问：这不就是可变形卷积吗？

同样存在学习采样位置的共同点。本文希望学习的是一套用于聚合、交互和多个目标读取的粗单元，而不是仅为某一个卷积输出学习采样偏移。但如果实现最后只剩少量偏移采样加权，就应承认与可变形操作高度接近，不能只靠名称区分。

### 问：为什么必须是 MoE？

目前没有“必须”的证明。多个组织器用于覆盖不同关联模式，目标路由用于条件选择，这是假设；单专家、均匀集成、容量匹配 dense 对照决定是否有实证依据。

### 问：是否恢复了真实传播过程？

没有。训练目标是补全，没有真实传播监督，学习到的区域首先是预测有效的统计组织。除非另有物理标签和可辨识性证据，否则不要称为真实传播路径。

### 问：是不是只要大部分情况最好就可以？

可以，不需要每个条件都最好。但“大部分”要用预先确定的实验集合、合理的相对指标和重复实验衡量，不能通过增加相似条件计数掩盖少数很大的退化。

### 问：现在能保证创新点足够吗？

不能。当前已经有一个比“MoE＋多尺度”更明确的研究问题和可执行机制，但仍需要更完整的近邻文献对照及实验证据。导师和评审是否认可，最终取决于区别是否实质、验证是否公平、收益是否稳定以及表述是否准确。

## 17. 可直接用于汇报的总结

### 一句话版本

> 我想从“怎样融合多尺度”前移到“怎样组织可见观测”：在单尺度稀疏时空数据中，用前端 MoE 学习跨时间、跨位置的粗粒度区域，再由后端 MoE 面向缺失目标进行重建。

### 一分钟版本

> 现有多尺度方法和我目前的模型已经能够利用空间、时间信息，但粗化时通常采用固定或逐时刻的组织方式。我想检验：当有用的空间来源随时间偏移时，先采用这样的组织是否会损失可利用的信息。
>
> 新方案把数据表示为时间、横向位置、纵向位置构成的时空块。每个组织专家根据当前可见值和缺失布局，生成一组可随时间变化的软区域，只聚合其中的可见观测，得到中、粗粒度特征。不同专家先把自己的粗特征读回同一个目标坐标，再进行目标条件选择，最后交给已有的时空重建 MoE。
>
> 我的重点不是宣称首次使用时空多尺度或 MoE，而是验证联合观测组织是否比独立聚合更有效，以及组织选择与重建选择是否具有互补作用。会用合成时滞实验、同预算结构对照、多数据集缺失协议和双 MoE 消融提供证据。

## 18. 后续实施顺序

1. 保留 A 和历史结果，先检查训练数据中的时滞前提。
2. 用合成数据实现最小联合区域算子，检查隐藏值不变性、全空支持、对齐和梯度。
3. 在相同细编码器、后端和损失口径下接入一条候选前端，检查真实数据小批次的训练—验证—最佳恢复—测试闭环。
4. 测量显存、耗时，冻结可比较的初始预算。
5. 运行核心强对照，再根据验证证据决定是否扩大到全条件和多 seed。

**本文完成的是研究设计，不代表已实现以上算子，也不代表已获得相对 A 的性能提升。本次不修改当前主力模型，不启动训练。**
