## 2. 论文借鉴与适用边界

1. [From Sparse to Soft Mixtures of Experts，ICLR 2024](https://arxiv.org/abs/2308.00951)：将输入token的软聚合dispatch与输出combine分开，专家处理输入的加权组合。本轮借鉴“聚合输入”和“读取输出”不必共享一次硬筛选；不照搬其视觉Transformer、slot归一化或性能结论。
2. [Attentive Neural Processes，2019](https://arxiv.org/abs/1901.05761)：用目标条件的注意力读取上下文，缓解所有目标共享一个全局聚合表示的限制。本轮据此把空间平均的专家prior替换成目标位置条件的专家读取；不是复现其概率模型，也不是该论文已证明本数据集会改善。
3. [Learning to Reconstruct Missing Data from Spatiotemporal Graphs with Sparse Observations，NeurIPS 2022（SPIN）](https://arxiv.org/abs/2205.13479)：在稀疏观测下重建时空图信号，强调从可见观测组织重建信息。本轮遵守仅使用可见值及掩码的条件建模；不引入其完整图网络，不将本方法称为SPIN。
4. [Switch Transformers，JMLR 2022](https://jmlr.org/papers/v23/21-0998.html)：沿用全softmax概率importance与实际分派频率乘积的负载均衡思想。本实现按Top-K总选择数归一化，不是原论文的Top-1配置。

这些是设计依据，不构成新颖性或性能保证。将目标条件读取用于组织专家，是当前代码的可检验修改；创新性还需与更多相关工作、等容量对照区分。

## 3. 模型与数据流

输入只有细尺度可见值X、观测掩码M（1=可见）；缺失处的值先清零，仅用可见值计算归一化统计。细尺度编码产生H。

中、粗两级分别有8个独立可学习区域分配器，每专家分别最多32、8个区域；这些是内部表示，不是额外的传感器观测。每个专家从H、局部可见上下文、坐标和M预测自己的分配矩阵A_e(i,r)，对区域r归一化。相同尺度内专家学习不同组织，而不是各专家预设一个不同尺度。

**聚合阶段不再做源Top-K：**令w_e(i,r)=M_i A_e(i,r)/E，按观测质量归一化得到区域特征：

\[
Z_{e,r}=\frac{\sum_i w_e(i,r)H_i}{\max(\sum_i w_e(i,r),\epsilon)}.
\]

保留1/E是为了与旧E8等权模型的mass/support统计完全同口径；它不是拒绝7/8的观测。各专家通过不同A对全部可见位置进行软组织；仍可能因学习到的A而集中到少量位置，不能保证有效支持永不下降。

区域特征拼接可见质量、有效样本数、异质性三项统计，经过同尺度共享的区域注意力/时间处理。每个专家用**自己的A_e**恢复到细目标坐标：R_e(i)=Σ_r A_e(i,r)Z'_e(r)。先恢复、后融合，绝不把不同专家的第r号区域直接相加。组织专家拥有独立分配参数，区域处理块在同尺度内共享，不宣称有8个完全独立的补全网络。

目标路由使用共享的加性注意力打分：

\[
\ell_e(i)=v^\top\tanh(W_q\operatorname{LN}(H_i)+W_k\operatorname{LN}(R_e(i))+W_s S_e(i)),
\quad \alpha(i)=\operatorname{softmax}_{\operatorname{Top4}(\ell(i))}\ell(i).
\]

S_e是对应目标恢复的三项支持统计，detach，不是经监督校准的置信度。共享打分器同时看到目标与候选内容，不依赖任意专家编号。非线性保证query项不是softmax中被相消的公共常数。每个目标的中/粗表示为Σ_e α_e(i)R_e(i)，再与细特征条件融合，得到中/粗独立预测。

后端保留fine/mid/coarse三个补全路径，逐目标Top-2融合各尺度预测。两侧同时端到端训练，没有教师、分阶段预训练或强制残差限幅。两个MoE分别选择“同尺度内哪个组织表示适合目标”和“哪个尺度的补全结果适合目标”，语义不完全相同；是否存在冗余仍需实验检验。

Top-K仅使混合权重稀疏：现在仍先计算所有候选，**不承诺计算/显存/功耗降低**，新增目标评分有少量额外成本。单卡运行；此次未修改DDP。

## 4. 预设参数与理由

| 参数 | 本轮候选 | 依据/限制 |
|---|---|---|
| 前端专家数 | 中/粗各8 | 已有容量趋势，非最优性证明；总计16个区域分配器 |
| 前端Top-K | 每目标4/8 | 保留更宽组合，避免直接沿用不佳2/8；新的目标路由尚未做K最优搜索 |
| 后端专家数/Top-K | 3/2 | fine/mid/coarse三种语义路径；暂无依据盲目增加后端同质副本 |
| dim/key/depth | 32/8/1 | 保持容量及训练预算可比 |
| 区域数/温度 | 每专家32、8 / 0.5 | 沿用旧E8，隔离本轮路由位置变化 |
| 前/后均衡系数 | 0.001 / 0.01 | 新前端减弱均匀化压力，后端保留原设置；前端0.001属于待验证假设 |
| 分支辅助/分区正则 | 0.01 / 0.001 | 保留旧设置，避免一次改变多类机制 |
| epoch/val/batch | 120 / 每2轮 / 4 | 与上一轮比较口径一致 |
| 学习率/衰减 | 0.001 / 0.0001 | 沿用AdamW、cosine、梯度裁剪1、AMP |
| 保存参数 | false | 最佳验证state_dict在CPU内存覆盖，最后恢复测试；进程中断则丢失 |

新前端负载均衡在**缺失目标位置**计算，两尺度取平均；后端同样在缺失位置计算。记录full probability、实际selected/load、门控均值/熵和有效支持；硬选择均衡不等于任务贡献均衡。全观测样本的两侧均衡和重建项为0。各loss原始项和乘权重项均写日志。

以上是一套有依据的起始参数，不能称为网格搜索得到的最佳参数。保留旧E8等权参考。如果新路由表现不佳，不应靠把等权对照故意配差来扩大消融差距。

## 5. 执行与公平验证

在项目内层目录、difftdi环境中：

```bash
python scripts/train_scale_completion.py --preset dual_moe_target \
  --dataset TaxiBJ --mask random --rate 0.4 --gpu 0 --seed 42 --train-windows 2048
```

默认Q11。改为BikeNYC及511训练窗口可匹配上一轮Bike口径。`--dry-run`只检查并打印，不启动训练；省略`--train-windows`使用完整训练集。参数集中在`configs/presets/dual_moe_target.json`，已完成运行保存各自config，不修改其记录。

四组对照仍用同一个训练入口，可单卡顺序执行（此循环会重新训练，不自动跳过）：

```bash
for front in uniform topk; do
  for back in uniform topk; do
    python scripts/train_scale_completion.py --preset dual_moe_target \
      --dataset TaxiBJ --mask random --rate 0.4 --gpu 0 --seed 42 \
      --train-windows 2048 --front-mode "$front" --back-mode "$back" || break 2
  done
done
```

| 组别 | 前端读取 | 后端融合 | 要回答的问题 |
|---|---|---|---|
| Q00 | 等权 | 等权 | 同容量组织表示基础 |
| Q01 | 等权 | Top-2 | 仅后端路由 |
| Q10 | 目标Top-4 | 等权 | 仅前端路由 |
| Q11 | 目标Top-4 | Top-2 | 双MoE组合 |

uniform保留所有专家并冻结对应打分器，将该侧balance设0。这是“路由与对应均衡机制”的对照，不是纯门控或完全相同可训练参数量实验。**等权融合不等于固定空间平均聚合**；要声称强于固定平均/求和，仍需另做固定聚合对照。

比较时优先看Q11相对Q01/Q10的验证MAE及稳定性；RMSE同报，最终测试只在最佳验证模型上执行一次。先确认两数据集、再多种子/缺失率扩展，不根据test反复调系数。本轮不安排自动大规模队列，也未启动正式120轮训练。

## 8. 独立种子复现：检验“双 MoE 的收益是否稳定”

### 8.1 依据与问题

用户完成第7节12组后，TaxiBJ Q11相对Q01/Q10的test MAE分别降低4.30%/3.62%；BikeNYC相对Q00仅降低0.10%；CHAP等权Q00仍最好。因此接下来的最小有效实验是固定模型和预算、增加独立随机种子，而不是再次根据同一个seed42调整结构。

本轮是看到探索结果后的定向复现：优先TaxiBJ的强信号和BikeNYC的弱信号，并不代表可以删除CHAP的不利结果。CHAP区域空置的原因尚未验证，另设机制诊断更合适。现在不同时更改区域数、Top-K、温度或负载均衡，以免无法判断稳定性。

### 8.3 预先确定的分析规则

主要看同种子条件增益：

- 前端作用：Q11对Q01。
- 后端作用：Q11对Q10。
- 整体价值：Q11对Q00。
- 辅助解释：Q10/Q01各自对Q00，以及Q11−Q10−Q01+Q00交互项。

逐数据集报告两个种子的原始分数、均值、样本标准差、配对百分比变化和获胜次数。先看验证MAE，最终test MAE/RMSE描述泛化，不以测试分数再调参。若TaxiBJ在新种子仍同时优于Q01/Q10且没有明显RMSE倒退，原强信号获得复现支持；若方向翻转，应按不稳定结果报告。BikeNYC尤其要检查Q11是否能稳定超过Q00，不能只超过两个较弱的单路由组便认定组合有实际收益。

两个种子仍不足以宣称统计显著性；也不证明固定平均池化不如当前模型、不拆分门控与均衡损失贡献、不证明全缺失模式/率有效。若复现通过，再决定补第三种子和更广缺失设置。若不通过，先分析差异，不能挑选表现最好的种子。

### 8.4 执行、时间目标与验证

## 9. 保留前端，拆分后端可学习融合、硬选择与负载均衡

### 9.1 实验动机与固定条件

两种子结果表明TaxiBJ的Q11均优于Q10/Q01；BikeNYC的Q11均优于Q01，但相对Q10、Q00的方向随种子翻转。尤其seed2026的BikeNYC仅前端Q10优于完整Q11。因此本轮不改前端，区分后端三个因素：是否学习融合权重、是否进行Top-K硬选择、是否使用负载均衡。

“保留前端”指固定其架构和超参数，不是冻结某次训练的权重：中/粗各8个组织专家、目标Top4、前端均衡0.001、区域数32/8、分配温度0.5全部不变；每组仍从相同种子对应的初始化开始端到端训练。前端权重会随后端条件共同适应，因此本实验测量训练方案的整体影响，而不是在冻结表示上只更换推理算子。

三个fine/mid/coarse补全专家、分支监督0.01、分区正则0.001、观测归一化、学习率和调度不变。不加入新损失，不改变模型实现，不增加专家数量。

### 9.2 四种后端

| 组别 | 后端融合 | 后端均衡系数 | 配对问题 |
|---|---|---:|---|
| BU | 三尺度等权 | 0 | 无可学习后端路由参考 |
| BD | 三尺度密集softmax | 0 | 对BU：可学习融合是否有用？ |
| BK0 | Top2 | 0 | 对BD：硬稀疏选择有益还是有害？ |
| BK1 | Top2 | 0.01 | 对BK0：均衡本身有益还是有害？ |

BD用已有`completion_mode=topk, completion_top_k=3`实现完整softmax。这与Top2路由头采用相同初始化，而直接切换旧learned模式会采用全零初始化，形成额外混杂。3选3的硬计数均衡为常数，故BD关闭该损失；其日志硬选择负载天然一致，不能据此证明概率没有塌缩，要看权重均值/熵和各分支误差。BU会冻结其无用的路由头，因而与BD不完全相同可训练参数量；其余共有参数初始化相同。所有专家仍被实际计算，不声称Top2节省计算。

### 9.3 数据与预算

| 数据集 | 作用 | 种子 | 训练窗口 | epoch | 组数 | 完整val/test |
|---|---|---|---:|---:|---:|---|
| BikeNYC | 主要机制验证 | 42、2026 | 全511 | 100 | 8 | 73 / 147 |
| TaxiBJ | 辅助检查 | 42 | 等间隔1280/2491 | 140 | 4 | 356 / 712 |

均random@0.4、batch4、每2轮验证。先完成BikeNYC两种子8组，再完成TaxiBJ4组。TaxiBJ为了23:00预算减少训练窗口，但同一数据集四种后端的数据/轮数/掩码行号严格匹配；不能直接与历史2048窗口分数比较，也不代表全量训练结论。BikeNYC预算保持与原复现相同，新队列仍重跑四组以形成自洽记录。

训练结束恢复最佳验证MAE对应的CPU内存state_dict，完整测试一次。默认不保存权重文件，保留配置、train.log/val.log/test.log、metrics.jsonl和队列原始日志。若中断，未完成组从头训练，已完成组可跳过。

### 9.4 预先约定的判定

- BD优于BU：支持当前前端下学习尺度融合权重有价值。
- BK0弱于BD：支持硬Top2筛选可能是限制因素，而非“后端可学习融合都无效”。
- BK1弱于BK0：支持当前0.01后端均衡约束可能不合适，不能据此概括所有均衡形式都无效。
- BD/BK0/BK1均不优于BU：本设置下没有证据支持复杂后端必要性，应保留负面结果。

以上先看验证MAE，再报告相应最佳验证模型上的test MAE/RMSE；BikeNYC按两个种子逐个比较，方向翻转要显式标注。不能根据测试集选最终超参数，不能把单/双种子当作统计显著性。若BikeNYC最优选择损害TaxiBJ，只能报告数据集依赖，不应强行宣称统一最佳。

自动汇总6组配对：BD/BU、BK0/BD、BK1/BK0、BK1/BU、BK0/BU、BK1/BD，报告配对变化、均值/标准差、完整种子数和获胜数；本轮不是2×2结构消融，交互项为空。CHAP未包含，其已有负面结果不删除，也不据此声称三个数据集都通过。
