# V22 Full Idea：MoE 不规则区域构造与粗细联合补全

## 1. 本次实现的目标与边界

对应《研究想法讨论稿_缺失诱导尺度失真与MoE自适应不规则粗化》的想法二。
不是继续调整 V22.1 的有界门控，而是实现完整的“构造粗尺度 → 粗细联合补全”数据流。
本次名称为 `v22-full-idea`，不擅自改称 V23，不覆盖原始 V22、V22.1 或历史结果。

旧 V22：每个粗化专家分别聚合、规则网格卷积、回投细网格，最后路由融合。
新模型：MoE **先组合细格点对粗节点的分配关系**，形成一套真正进入后续模块的区域节点；
粗节点做图消息传递和时间处理，再与细粒度特征双向交互。

这里的“不规则”是内容/缺失感知的**软重叠区域**，不是硬分割。
粗节点有固定数量和持久锚点编号，但成员和权重可以随样本、时刻改变。
当前使用局部/较宽邻域候选，不宣称实现全局任意聚类、硬连通区域、动态区域数或严格稀疏计算加速。
该实现满足本次提出的功能链路，不等于已证明性能提升或学术新颖性。

## 2. 完整数据流

```text
细粒度观测 Xobs + Mask（不读取隐藏真值）
    ↓ 仅用观测位置计算逐样本、逐通道均值和标准差
标准化观测 + Mask + 坐标
    ↓ stem / 时空编码器
细粒度上下文 Hf
    ├── stride=2：规则 / 局部不规则 / 较宽不规则分配专家
    └── stride=4：规则 / 局部不规则 / 较宽不规则分配专家
             ↓ MoE 在聚合前组合分配 A
             ↓ 仅观测值参与统计聚合
不规则区域节点：数值均值、观测特征、支持度、方差、几何、质量
             ↓ 区域图注意力 + 每个区域的时间卷积
             ↕ 同一 A 建立粗细对应，细特征反馈 / 粗特征回投
细粒度时空补全（默认共享参数交互两轮）
             ↓ 输出头 / 反标准化
原始数值范围的细粒度补全结果
```

各尺度直接从 Fine 构建，不把 stride=2 的有缺失粗值当作 stride=4 的独立真值。
粗化专家没有各自独立的预测头，也不是对多个最终预测进行加权。

## 3. MoE 负责构造区域，不是事后混合预测

每个尺度包含三个分配专家：

- E0：固定锚点块，半径 0，是可解释的规则参考。
- E1：相邻锚点候选，半径 1，由内容相似性与距离先验决定软成员关系。
- E2：较宽锚点候选，半径 2，允许跨原始块边界聚合。

每个专家返回行归一的稀疏分配 `A_e(i,j)`。三个专家使用相同锚点编号，因而允许在聚合前相加：

`A(i,j) = Σ_e g_e(i) A_e(i,j)`，且 `Σ_j A(i,j)=1`。

路由输入是细粒度上下文及七个额外通道：Mask、邻域观测率、观测方差、两维坐标、通道平均的局部观测均值、邻域是否有观测。
默认 `top_k=3`，即全软路由；提供 `top2` 对照。
Top-2 会选取并重新归一路由权重，但当前仍计算全部分配专家，不能称为计算量减少。
初始路由为等权，不叠加此前实验未普遍有效的 Fallback 或有界接纳头。

## 4. 粗粒度到底包含什么

对区域 j，令 `q_j=Σ_i A(i,j)`、`c_j=Σ_i A(i,j)M_i`：

- 标准化观测均值：`μ_j=Σ_i A(i,j)M_i Xnorm_i / c_j`，分母带数值保护。
- 观测特征均值：同样只聚合 `M=1` 的 stem 特征。
- 支持度：`c_j/q_j`；是否有观测；观测值方差。
- 几何：所有成员的加权质心、观测质心相对区域质心的偏移。
- 几何质量：`log(1+q_j)`。

没有观测的区域仍保留其查询成员与节点，使用空区域嵌入，并通过图/时间/细特征获得补全信息。
统计均值是**已观测成员的均值**，不冒充完整区域真实均值，更不冒充物理流量总和。
`return_regions=True` 可返回分配、质量、观测质量、标准化数值均值与区域状态用于检查；默认不输出这些大张量。

## 5. 不规则区域与细粒度联合补全

区域节点不再被直接当成规则图像做空间 Conv3d。
每个节点在相邻锚点定义的最多九条候选边上，通过内容、质心差和支持度计算注意力。
候选图仍有局部先验，注意力权重依赖当前区域；不是全局自由拓扑。
之后对持久锚点编号进行时间 Conv1d，保持时序信息。

每轮交互包括：

1. `Aᵀ Hfine / q` 把当前细粒度特征反馈给粗节点。
2. 粗节点图消息传递与时间补全。
3. 通过同一个 `A` 将区域特征回投细网格，保持成员对应关系。
4. 融合 Fine 与全部尺度视图，再做细粒度时空补全。

反馈聚合包含缺失位置的**推断特征**，不是新观测，不更新前述 `c/μ/support` 证据统计。
默认两轮共享模块参数，是一次前向内的特征交互，不是多阶段训练、教师训练或额外预训练。

## 6. 损失与训练协议

复用 V22 的损失与训练引擎：

`L = L_missing(normalized prediction, normalized target) + 0.001 L_mass + 0.001 L_balance`。

- 主损失默认 Smooth L1，仅在指定缺失位置监督。
- 质量约束使用不依赖观测掩码的几何参考，避免删除缺失查询区域。
- 路由均衡约束使用软路由的平均使用率，不增加虚构的规则粗尺度标签。
- 每 `val_epoch` 轮验证，最后一轮也验证；只按验证 MAE 更新 `best.pt`。
- 验证更好时原子替换同一 checkpoint；训练结束加载该参数，只跑一次测试。
- MAE/RMSE 在原始数据范围的缺失位置统计，评估分片不补重复样本。
- `.log` 文件为 `logs/train.log`、`logs/val.log`、`logs/test.log`，另保留 `metrics.jsonl`、配置及代码指纹。
- 当前默认仍是 60 epoch / 每 2 轮验证 / seed 42 / 每进程 batch 4 的筛选预算，不冒称充分收敛。
- 单卡总 batch=4；双卡默认总 batch=8。比较时必须控制总 batch、训练预算等，旧结果不能自动当作同协议对照。

数据加载器为兼容历史接口可能仍提供规则 Mid/Coarse；**本模型不读取这些值、外部粗观测或 GT**，全部区域从 Fine 观测构造。

## 7. 文件与执行

新增内容放入现有目录，不新增杂散脚本目录：

- 模型：`scripts/v22/full_model.py`。
- 统一入口：`scripts/v22/run_full_idea.py`。
- JSON：`configs/v22/full_idea.json`。
- 测试：`tests/test_v22_full_idea.py`。
- 输出：`outputs/v22/full_idea/`；合成测试另置其 `smoke/` 下。

模型暂放在现有 scripts/v22 中，采用与 V22.1 相同的 worker 内显式注册方式。
这是为了**不改动 src 和旧训练入口，不使既有 V22 源码指纹失效**。
配置保留兼容训练引擎的 `architecture=v22_coarsening_moe`，但 `version=v22-full-idea`、
`model.v22.full_idea`、`full_source` 和 `experiment_policy.model_implementation` 明确指向新实现。
必须通过新入口运行/加载，不要把新配置直接交给旧 `train.py`；旧入口不执行新 builder 的注册。

从项目内层目录执行，先看计划：

```bash
python scripts/v22/run_full_idea.py --gpu 0 --dry-run
```

单卡运行当前六个点：

```bash
python scripts/v22/run_full_idea.py --gpu 0
```

先只运行一个真实点：

```bash
python scripts/v22/run_full_idea.py --gpu 0 --datasets BikeNYC --patterns fixed
```

显式选择消融或全部缺失率（不会自动运行它们）：

```bash
python scripts/v22/run_full_idea.py --gpu 0 --variants fixed uniform full
python scripts/v22/run_full_idea.py --gpu 0 --rates 0.2 0.4 0.6 0.8
```

可选 DDP 用 `--gpus 0 1`，但服务器刚发生重启，建议先排查硬件/内核原因。
本次实现不会自动设置功率、重启训练或尝试双 GPU 压力测试。

查看完整结果或跳过已完成任务：

```bash
python scripts/v22/run_full_idea.py --gpu 0 --summary
```

正常执行默认跳过**同配置、同源代码、同数据身份且完整训练/验证/测试**的结果。
中断实验重新开始并写新目录，不声称恢复优化器断点，也不会删掉旧目录。

## 9. 可验证的研究假设

本版把创新主张落实在“路由改变区域成员关系，再由区域与细粒度共同补全”，而不是增加预测专家数量。
需要的证据包括：固定区域与自适应区域的同补全器对照、等权与学习路由对照、单轮与双轮交互对照、
区域成员随内容/缺失几何变化的可视化，以及多种子最终补全指标。
不能只凭模型图和一次测试 MAE 宣称创新成立或所有数据集均有提升。
