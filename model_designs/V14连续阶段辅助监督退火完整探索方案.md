# V14 连续阶段辅助监督退火（CSAS）完整探索方案

## 1. 研究动机

本路线仍以原始 V14 为唯一基础，不继承任何已失败候选。GSA 固定缩放实验
证明：从训练开始就削弱 mid/coarse 监督会使 TaxiBJ 验证 MAE 退化
17.9%–21.0%，但在 CHAP 上又能改善 MAE 7%–8%。结合检查点梯度诊断：

- TaxiBJ 与 CHAP 的训练后期存在阶段辅助梯度冲突；
- BikeNYC 多数阶段辅助梯度与最终目标同向；
- 固定缩放破坏了 TaxiBJ 训练早中期需要的多尺度优化引导。

因此，这一轮不再搜索固定权重，而是保持原始阶段监督完成早期表示学习，
随后连续、平滑地降低其影响，让训练后期更多服从最终缺失值目标。

另外对 `0.25 × L_base` 的 Core-6 梯度审计显示 5/6 点与最终目标同向，
CHAP 的正向作用尤其强，故不开展固定 base-anchor 权重搜索。

## 2. 路线约束

CSAS 不修改：

- V14 网络结构、参数量、前向路径和推理；
- 主干、refiner、controller、专家路由或残差表达；
- 原始 `lambda_v14_mid=0.05`、`lambda_v14_coarse=0.03`；
- 优化器、学习率计划、验证频率或最佳模型选择方式。

训练仍是一次连续的端到端训练，没有冻结/解冻、教师模型、预训练检查点或
第二训练阶段。辅助权重变化与普通学习率退火相同，只是一个连续调度函数。

## 3. 数学定义

令总训练进度为：

```text
p = (epoch - 1) / (epochs - 1)
```

候选指定衰减起点 `p0`。当 `p <= p0` 时：

```text
s(p) = 1
```

当 `p > p0` 时：

```text
q = (p - p0) / (1 - p0)
s(p) = 0.5 × (1 + cos(pi × q))
```

实际阶段监督为：

```text
L_stage = s(p) × (0.05 × L_mid + 0.03 × L_coarse)
```

所有候选最终都平滑衰减到 0，只改变 `p0`，避免同时搜索起点、终点和曲线
形状。原 V14 不配置该调度时始终返回 `s=1`，旧实验行为保持不变。

## 4. 三个单变量候选

| 候选 | p0 | 含义 | 全程平均尺度（约） |
|---|---:|---|---:|
| C01 | 0 | 从训练开始连续余弦衰减 | 0.50 |
| C02 | 0.25 | 前25%保持原监督，再衰减 | 0.625 |
| C03 | 0.50 | 前50%保持原监督，再衰减 | 0.75 |

这三个候选比 GSA 的固定 `0–0.01` 保留了大得多的早期累计监督，能够直接
验证“TaxiBJ 需要早期引导、后期冲突”这一机制解释。

## 5. 九组完整预筛

沿用 GSA 的相同三个点，确保可直接比较：

| 数据点 | 用途 |
|---|---|
| TaxiBJ fixed@0.4 | 检查能否恢复 GSA 丢失的早期引导 |
| BikeNYC random@0.8 | 正向辅助梯度安全点 |
| CHAP fixed@0.8 | mid/coarse 后期冲突点 |

共 `3 候选 × 3 数据点 = 9` 次完整训练。正式运行使用 TaxiBJ/BikeNYC/CHAP
的 160/140/150 epoch，定期验证，只覆盖保存一个最佳验证 MAE 检查点，最后
加载该检查点测试一次。

## 6. 晋级标准

只使用验证集选候选，必须同时满足：

1. 至少 2/3 点验证 MAE 改善；
2. 三点宏平均验证 MAE 改善至少 0.5%；
3. 三点宏平均验证 RMSE 不退化超过 0.5%；
4. TaxiBJ fixed@0.4 验证 MAE/RMSE退化不超过 2%/3%；
5. BikeNYC random@0.8 验证 MAE退化不超过 1%；
6. 任一点验证 MAE/RMSE退化不超过 2%/3%；
7. 无 NaN/Inf，`v14_stage_aux_scale` 与预期曲线一致，完整保存最佳检查点。

若多个候选通过，依次按宏平均验证 MAE、RMSE和最大单点退化选择一个。
冻结选择前不得查看测试排名。若全部失败，关闭阶段辅助监督时间调度路线，
不继续插值其他 `p0`。

通过后依次执行 Core-6、Core-6 三随机种子、seed=42 全 24 点；标准沿用
现有 V14 探索协议。
