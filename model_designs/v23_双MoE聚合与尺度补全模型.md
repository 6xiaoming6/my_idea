## 路由的实际含义

- 前端：中/粗尺度各3个可学习区域聚合专家，`aggregation_mode=topk`、`aggregation_top_k=2`。每个**观测源位置**选择2个专家参与聚合，未选权重精确为0。
- 后端：fine/mid/coarse三个独立补全专家，`completion_mode=topk`、`completion_top_k=2`。每个**目标位置**选择2个尺度，缺失位置参与损失及路由负载统计。
- 前端仍保留原观测源权重的空间平均prior；不同源位置可选择不同专家，因此整个帧/最终对齐读出可能使用到全部3个聚合专家。不能把它描述成每个目标只读取2个前端组织专家。
- K>=2时，在选中logits上重新softmax，权重和为1。K=专家数退化为dense softmax。
- K=1仍硬选一个且前向权重为1；为了避免归一化单选导致任务梯度恒零，使用选中完整softmax概率的straight-through梯度近似。默认K=2不使用这一近似。
- Top-K head用小随机权重打破零初始化的完全并列，验证/测试没有随机路由噪声。初始化不推进共享模块的随机数状态，便于匹配共有参数初始化。
- 当前为**权重稀疏路由，不是条件计算加速**：保留所有专家的批量前向，后端路由仍读取各尺度隐藏特征，0.01辅助损失仍监督各尺度。无容量截断或token丢弃，不承诺节能/减显存。

## 真正参与训练的负载均衡

参考 [Switch Transformers, JMLR 2022](https://jmlr.org/papers/v23/21-0998.html) 的可微importance与实际分派频率的乘积损失。这里按Top-K总分派数对hard load归一化，是针对当前网格路由的适配，不是完整复现Switch架构。

对于有效位置集合V、E个专家及K个选择：

\[
P_e=\frac{1}{|V|}\sum_{i\in V}\operatorname{softmax}(z_i)_e,\quad
f_e=\frac{1}{K|V|}\sum_{i\in V}\mathbb{1}[e\in\operatorname{TopK}(z_i)],
\qquad L_{bal}=E\sum_e P_e\operatorname{stopgrad}(f_e).
\]

`P_e`保留梯度，`f_e`为实际离散选择、detach；不是不可导的hard-count方差。前端分别计算中/粗尺度，再取平均；前端V为观测位置，后端V为缺失位置。通道数不会重复计作路由token，无有效位置时对应项为0。当前为单卡/minibatch负载，不声明跨DDP进程全局均衡。

新配置总损失：

\[
L=L_{main}+0.01L_{scale}+0.001L_{partition}
 +0.01L_{bal,aggregation}+0.01L_{bal,completion}.
\]

两项新增配置为 `loss.dual_moe_aggregation_balance_weight` 和 `loss.dual_moe_completion_balance_weight`。与旧架构的 `lambda_balance` 等无关，明确接入当前 `compute_dual_moe_loss`。权重设0可做消融；权重为正但路由不是Top-K/缺少metadata时直接报错，不静默忽略。

均衡时Lbal约为1，不是0；正值不代表失败。损失能给未选专家的路由概率梯度，但不保证每步负载严格相等，也不是“哪个专家预测最准确”的直接监督。0.01是可配置起点，需要实际精度/负载消融，不能保证总效果提升。

# 历史候选：共享细尺度预测的有界修正 MoE

本节对应新增设计 `model.dual_moe.design=anchored_scale_moe`。旧 `learned_regions_v2` 定义、配置、实验和检查点均保留；下面的旧设计说明作为历史记录。没有切换分支，也没有新建版本模型目录。

## 本次改动依据

三阶段实验说明：粗特征并非未被使用；多聚合器主要在 TaxiBJ random 给出优势；前端动态权重没有普遍增益；0.01 分支监督明显减少误差抵消，部分场景同时改善精度。不能由此直接推断规则池化更优，或有界修正一定更优。

因此新默认采用“3 个可学习聚合器均匀组合 + 后端尺度 MoE”，而不是保留第二个动态门控。新增规则金字塔选项，解除对不规则形状的要求；它是待比较的备选，不以未做过的对照作为默认依据。

## 新模型数据流与关键公式

输入仍只有细粒度观测和 mask。归一化统计只使用观测，隐藏真值仅进入损失和指标：

```text
观测 + mask → 观测归一化 → 细时空编码 → 细预测 p0
                        ├→ 中尺度聚合 → 粗节点交互 → 对齐回投 + 细上下文 → r_mid
                        └→ 粗尺度聚合 → 粗节点交互 → 对齐回投 + 细上下文 → r_coarse
三路径隐藏特征 + mask + 支撑统计 → 后端 MoE 权重 β
p_final = p0 + σ × (β_mid δ_mid + β_coarse δ_coarse)
```

其中 `δ_s = B × tanh(r_s)`，σ 是观测归一化尺度，B 为配置给定的修正上限（默认1.0个观测标准差，下限归一化尺度仍为1）。

三条候选预测为 `p0`、`p0+σδ_mid`、`p0+σδ_coarse`；后端权重非负且和为1。数学上有 `|p_final−p0|≤σB`，两条修正候选之间的距离不超过 `2σB`。这限制了分支在相对细预测方向上的自由漂移，**不保证误差更小、不完全消除误差抵消，也不约束 p0 自身的绝对大小**。

细预测 p0 是本模型共同训练的预测，不是 V14 教师，不使用预训练或多阶段冻结。中/粗修正头零初始化，起点精确等于细预测；第一步某些上游修正路径/路由梯度可为零，修正头更新后共同学习，不把零初始化时暂时无梯度误判为断路。

保留粗路径中的细上下文。干预实验显示细与粗信息都重要，没有依据将细上下文全部砍掉。后端 fine 权重应理解为“不采用粗修正”的权重，不再把三条路径表述为完全独立的三个完整补全器。

## 两种可选聚合

| 模式 | 聚合方式 | 默认配置 | 定位 |
|---|---|---|---|
| learned_regions | 3 个独立可学习分配，均匀组合，不学习前端专家门控 | 中/粗节点32/8 | 保守的主候选，保留现有实验中有价值的表示能力 |
| regular_grid | 仅在观测位置做规则区域归一化均值 | 空间步幅4/8 | 验证是否需要学习区域；不是已验证更优的结构 |

规则聚合按每个区域实际观测数做归一化，不将缺失补零当作真实观测，不以零填充的边界面积稀释均值。支撑统计保留 mass/(mass+实际区域面积)、有效样本量比例和归一化方差。回传按对应区域索引精确映射，不分配稠密 N×K one-hot 矩阵，避免无意义的内存开销。

规则聚合没有可训练前端路由，也没有分配熵正则；聚合后的节点仍经过注意力和时间处理。它没有冒充自由区域，默认产生的节点数也不与 learned_regions 完全匹配，因此两种模式的比较是构造方案比较，不是严格同容量的纯形状消融。

## 损失、配置与日志

继续单阶段训练：
- 最终缺失位置的归一化 SmoothL1；
- 0.01 × 三条候选预测的平均缺失重建损失；
- learned_regions 保留0.001的分配正则，regular_grid 不使用该项。

辅助监督施加在“细预测 / 细预测+中修正 / 细预测+粗修正”上，不把修正量直接拿去拟合原始真值。0.05 在已有实验中并非普遍更优，所以新默认使用0.01。既有 loss 实现可以直接支持这些候选输出，无需再添加多个新辅助目标。

新增配置 `configs/presets/scale_completion.json` 和 `scale_completion_grid.json`，保留旧 default/dual_moe preset 的用途；直接调用旧入口不会悄悄换成新模型。关键可调项为 design、aggregation_kind、grid_strides、residual_bound、dual_moe_expert_weight。默认 dim32、80 epoch、val_epoch2、batch4、AMP、学习率0.001和余弦调度均沿用。输出分开到 `outputs/v23/scale_completion/learned_regions/` 和 `regular_grid/`。

仍按验证 MAE 覆盖唯一 best.pt，最后重载并测试一次；train.log/val.log/test.log/metrics.jsonl 保留原始范围指标。新增平均归一化修正幅度及修正饱和比例（|δ|>0.95B）；饱和率持续高可能意味着上限过紧，但也不能只靠该指标增加上限。

# 历史 V23：可学习不规则区域聚合与尺度补全双 MoE

修改日期：2026-09-09。历史协议：`learned_regions_v2`，仍可显式加载。以下保留该阶段实现与实验规范；末尾折叠保留更早固定半径实现的历史说明。

## 1. 设计判断与边界

思路可实施：前端学习如何组织观测，后端学习目标位置如何使用组织后的表示。与“选择几个固定池化窗口”不同，前端直接学习细节点到潜在粗节点的分配矩阵。

但可实现不等于已经证明创新性或精度提升。还需要证明：不同聚合专家学到了不同而有用的组织；单个可学习聚合器存在可重复的局限；补全路由带来独立增益。本文不承诺论文录用或超过历史模型。

本版只固定每个尺度的区域数量，不固定区域形状、成员、中心、邻域半径。输出是可重叠、可能不连通的**软区域**，不是保证连通的物理区域或新增传感器观测。默认中尺度 32 个节点、粗尺度 8 个节点，这里的“尺度”指表示压缩粒度，而非确定的空间直径。

## 2. 完整数据流

```text
细尺度观测 + mask
  → 仅观测值的逐样本、逐通道归一化
  → 1×1 编码 + 细尺度时空块 → 细特征 h
       ├─ fine 预测
       ├─ 中尺度聚合 MoE：3 个专家各学习 A_e ∈ R^(N×32)
       │    → 各自带 mask/源路由的聚合 → 各自粗节点交互
       │    → 各自 A_e 回投到 N 个细位置 → 对齐后组合 → mid 预测
       └─ 粗尺度聚合 MoE：3 个专家各学习 A_e ∈ R^(N×8)
            → 各自带 mask/源路由的聚合 → 各自粗节点交互
            → 各自 A_e 回投到 N 个细位置 → 对齐后组合 → coarse 预测
  → 补全 MoE：逐时空位置融合 fine / mid / coarse 预测
  → 逆归一化 → 原始范围预测；观测位置回填输入观测
```

N=H×W。中/粗尺度为并行地从细尺度构造，不是级联池化。时间长度 T 不压缩。
两个 MoE 是两种职责：中/粗尺度各实例化一个前端路由，后端一个尺度路由；没有第三个独立可学习回传路由。

## 3. 前端：直接学习聚合形状

### 3.1 分配关系

每个尺度、每个专家有独立 query MLP 和 K 个可学习槽向量：

`A[e,t,i,k] = softmax_k(q_e([h_i, observed_context_i, y_i, x_i, mask_i]) · slot[e,k] / (sqrt(d_key) × temperature))`。

默认 key_dim=8、temperature=0.5。所有细节点均可分配到所有粗节点；不存在硬距离掩码、固定锚点或 r0/r1/r2。坐标仅作为输入特征，不能解释为预先规定边界。不同专家结构相同、参数独立，组织原则由数据学习，不给它们预设“局部/全局”等结论性名称。

细特征和观测上下文来自观测输入，隐藏真值不进入前向。细编码仍有规则卷积，前端路由仍使用 3/7/15 的密度统计及 7 邻域上下文；**这些是打分输入特征，不是聚合成员范围约束**。

### 3.2 源节点门控与独立聚合

源路由 α 在 E 个聚合专家上做 softmax，输入为观测局部上下文和 mask/密度/密度差分。对各专家分别计算：

`w[e,i,k] = mask[i] × α[e,i] × A[e,i,k]`

`mass[e,k] = Σ_i w[e,i,k]`

`c[e,k] = Σ_i w[e,i,k] × h[i] / max(mass[e,k], ε)`。

各专家的区域编号没有共同空间含义，因此**不把不同专家的第 k 个粗节点直接相加**。整体观测质量满足 Σ_e,k mass[e,k] = 观测节点数。有效样本量在各专家的区域内部计算，不能把不同专家的重复观测数量相加解释为新增观测。

### 3.3 支撑统计

每个专家的每个粗节点携带：
- mass/(mass+N/K)：相对名义区域大小的分配质量；
- n_eff/(n_eff+N/K)，n_eff=mass²/Σ_i w²：有效权重数量；
- var/(1+var)：归一化观测原值的加权通道平均方差。

这些统计停止梯度，是描述量而非校准过的置信概率。极小 mass 使用 ε 保护；全缺失输入仍可产生有限的先验预测，但不能称为由实际粗观测支撑。

## 4. 粗节点处理与对齐

粗节点张量为 [B,E,T,K,D]，不再重排成 H_c×W_c 网格：
1. 每个专家、每个时间片在 K 个节点上进行多头自注意力；
2. 每个槽沿时间进行共享的深度时间卷积；
3. 节点级前馈残差更新。

各聚合专家的粗节点独立处理，同一尺度共享处理块参数。没有粗网格空间卷积或双线性插值。时间处理沿同一槽索引进行，但不宣称每一帧的槽覆盖同一个物理区域。

回投 `u[e,i] = Σ_k A[e,i,k] × c_processed[e,k]`。每个专家用**自己的**映射，得到同一细网格坐标上的表示后才混合。

混合权重是该时间片观测源 α 的平均：`prior[e] = Σ_i mask[i]α[e,i] / Σ_i mask[i]`；全缺失时均匀。它由前端路由导出，不增加第三个路由网络。缺失源位置的 α 不影响聚合或该 prior；缺失目标的区域对应由 A 给出。支撑统计同样按自身 A 回投，供后端使用。

中/粗表示在细网格上结合细特征后分别预测，因此是“粗信息条件化的细位置预测”，不能解释为纯粗尺度独立预测。共同置换槽向量、粗节点与对应分配列不改变预测，测试覆盖此不变性。

## 5. 后端补全 MoE 与损失

后端输入三条路径隐藏特征、mask 和对齐后的中/粗支撑统计，输出逐位置 β_f/β_m/β_c，三者非负且和为 1。原始范围最终预测等于三条原始范围预测的加权和。

训练单阶段端到端：
- 主损失：在缺失位置计算观测尺度归一化后的 SmoothL1；
- 可选各路径重建辅助项，默认权重 0；
- 可选分配正则，默认权重 0.001：在观测节点上计算 H(A|i)−H(mean_i A)，鼓励分配可区分且避免全部挤入同一槽。

正则不使用标签，可能为负，因此总 loss 也不要求始终非负；不能直接与 MAE 比较。它不保证专家多样性、区域连通性或彻底避免塌缩。设 `dual_moe_partition_weight=0` 可关闭；全观测批次不计算该项以保持无缺失损失为零。旧 V14/跨尺度/平衡损失不进入新架构。

### 9.2 第一阶段：模型究竟依赖什么？

六个点分别检查 A01/A11，共 12 个冻结的最佳检查点；每个执行 9 次完整验证：

| 操作 | 改变什么 | 检验用途 |
|---|---|---|
| baseline | 不改变 | 复现原最佳验证 MAE，失败则停止 |
| slot_permutation_control | 独立重排各专家槽向量，网络自然重排对应分配列/粗节点 | 阴性对照，应保持预测基本不变 |
| zero_mid | 置零中尺度 condition 层接收的回投粗特征 | 中尺度特征依赖 |
| zero_coarse | 置零粗尺度 condition 层接收的回投粗特征 | 粗尺度特征依赖 |
| zero_both | 同时置零两路回投粗特征 | 两路粗特征的联合依赖 |
| zero_fine_context | 仅置零传给中/粗预测头的细上下文 | 检查细特征捷径，fine 路径自身不变 |
| shuffle_both ×3 | 将回投粗特征的空间位置随机排列，使用种子17/29/43 | 保持特征边际分布，破坏目标空间对应 |

空间排列在同一验证过程中对所有样本、时间片保持一致，中/粗尺度使用独立排列。不会交换样本或读取目标。所有干预通过临时 hooks 完成，结束/异常后移除；槽参数在阴性对照结束后恢复，不保存修改后的权重。

**边界**：这里干预的是“回投粗特征”，不是删除整个粗路径。粗节点支撑统计仍保留，后端门控会自然重新计算。置零/扰乱属于分布外敏感性诊断，不能将性能下降直接解释为训练该模块一定有益，也不能将小变化直接解释为粗尺度完全没有使用。若 zero_both 影响小而 zero_fine_context 影响大，才形成细上下文捷径的线索；必须结合后续训练实验。

记录原始范围 MAE/RMSE、相对原预测的 MAE 变化、每条分支误差与平均有符号偏差、路由与分配统计。额外计算：

`error_cancellation_fraction = 1 − Σ|最终预测−真值| / Σ_s Σ β_s |分支s预测−真值|`。

所有求和只在缺失目标上，越高说明加权分支误差抵消越明显；它不是性能指标，也不要求越低越好。已有单独分支 MAE 也一并保存，防止只看这个比值误判。

### 9.3 第二阶段：一个可学习聚合器是否已经足够？

新增每点一个 `S2_E1`，总计 6 次训练，只将 A01 的 aggregation_experts 从3改成1，其余配置继承。主对照是原 A01（E=3、均匀专家门控、学习补全门控），原 A11 作为额外参照；不能把 S2_E1 与 A11 的差异全部归因于专家数，因为前端门控也不同。

固定各专家的节点数32/8、dim32和训练预算，比较单聚合器与多个聚合器的收益。**参数量并不完全匹配**：双通道默认 E1 共85,218参数，A01共95,778参数；需要结合日志中总/可训练参数量解释。虽然训练种子一致，专家数改变会改变随机初始化调用序列，不宣称跨架构所有公共参数初值逐项相同。单种子结果是线索，不是独立排除容量和随机因素的证明。

### 9.4 第三阶段：弱分支监督能否改善输出分工？

对 A01 和 A11 分别设置 `dual_moe_expert_weight=0.01/0.05`，0权重复用已有对照。共2种骨干门控×2种权重×6点=24次新增训练。只改变该损失权重，不同时改变节点数、温度、学习率、路由形式或训练周期。

继续单阶段联合优化：最终缺失重建 + λ×三分支平均缺失重建 + 原有分配正则。弱监督可能改善分支预测，也可能压制互补性，因此不预设结果。

训练结束后重载各自最佳参数，在验证集再计算与阶段一 baseline 相同的分支/抵消诊断，不重复测试。主要观察：

1. 验证 MAE 是否改善，测试指标作为最终报告而非选权重依据；
2. 各分支误差/偏差是否下降，抵消比例是否改变；
3. A11 是否缩小相对同权重 A01 的差距，后端路由是否仍有位置差异。

若仅抵消减少、最终误差变差，不能称为改进。不要仅因为某一组权重的测试成绩最好就选它。配置的0.5%变化标记仅是预声明的实用幅度标签，不是统计显著性阈值。

## 2. 总体结构

```text
x_f_obs [B,C,T,H,W], m_f [B,1,T,H,W]
    │  仅观测值的逐样本、逐通道归一化
    ▼
1×1 特征编码 [B,D,T,H,W]
    ├── 细尺度时空专家 ──────────────────────────────► fine 预测
    │                   │                            │
    │                   ├──► 中/粗专家的细上下文条件   │
    │                   └──► 补全路由输入             │
    ├── 聚合 MoE，stride=2 ─► 中尺度特征+支撑统计      │
    │                        中尺度时空专家            │
    │                        固定空间插值+细上下文 ──► mid 预测
    └── 聚合 MoE，stride=4 ─► 粗尺度特征+支撑统计      │
                             粗尺度时空专家            │
                             固定空间插值+细上下文 ──► coarse 预测
                                                        │
                   补全 MoE：逐时空位置选择 fine/mid/coarse
                                                        │
                     预测加权求和 → 逆归一化 → 缺失位置输出
```

两个 MoE 指两种职责。前端在中/粗两个目标尺度上各有一个聚合路由实例，后端有一个三尺度补全路由。不是“前面三个专家分别对应三个尺度”。前后端路由既不共享权重，也不复用路由结果。

默认 D=32，空间步幅 2/4，key_dim=8，每条时空处理分支 depth=1；ResidualSTBlock 使用两个 3×3×3 卷积、GroupNorm 和 GELU。所有操作保持时间长度不变。C 来自数据集配置，支持 TaxiBJ/BikeNYC 的双通道及 CHAP 的单通道。

## 3. 仅由观测构造粗粒度信息

### 3.1 观测归一化

使用 `torch.where(mask, x, 0)` 隔离隐藏值，观测均值和标准差仅由 m=1 的位置计算。标准差默认下限 1.0；无观测时中心为 0、尺度为 1。隐藏位置的 NaN 不进入计算，观测位置若非有限则报错。

模型完全不读取 `x_f_gt`、外部 `x_m_obs/x_c_obs` 及其 mask/reliability。兼容包装器可以接收这些键，但骨干忽略它们；输入只有 `x_f_obs` 和 `m_f` 也可前向。目标只在损失和指标计算时使用。观测值回填也读取 `x_f_obs`，不读取 GT。

### 3.2 三个聚合算子专家

每个尺度保留锚点格，粗格尺寸为 ceil(H/s)×ceil(W/s)。细节点的候选粗锚点邻域半径分别为 0、1、2：

- r0：所属锚点的硬成员关系，局部保真；
- r1：附近 3×3 锚点内的内容相关软成员关系；
- r2：附近 5×5 锚点内的内容相关软成员关系。

r1/r2 共享本尺度 query/key 投影，以内容相似性减去距离代价后做 softmax，非法边界锚点权重为零。key 的锚点特征是观测归一化均值，不把缺失填充值当作真实观测。

前端路由输入为邻域观测特征均值，以及 mask、3/7/15 邻域观测密度和两个方向的密度差分。窗口超出边界时按实际有效网格面积归一化。`aggregation_geometry=false` 仅去掉显式几何通道，观测均值计算仍使用 mask，不能称为完全不感知缺失。

记三个算子为 A_e，路由为 α，实际分配为 A_ij=Σ_e α_ie A_e,ij。粗节点为：

`c_j = Σ_i m_i A_ij h_i / max(Σ_i m_i A_ij, ε)`。

因此只有观测节点的路由能影响聚合。测试明确干预所有缺失节点的前端门控，要求最终预测严格不变。前端门控只接受来自聚合路径的重建梯度，不通过回投路径再次作用于缺失查询。

这是**固定锚点格上的软不规则聚合支持**：成员关系可学习并重叠，锚点位置和粗节点处理网格仍固定。不能宣称已经实现自由区域数、自由拓扑的不规则粗图，也不能把构造的粗表示称为额外传感器观测。

### 3.3 支撑统计

每个粗节点携带三个有界统计：

1. `mass/(mass+s²)`：观测分配质量相对名义区域面积的支撑代理；不是观测覆盖率。
2. `n_eff/(n_eff+s²)`：权重集中度代理，其中 n_eff=mass²/Σ_i(m_i A_ij)²。
3. `variance/(1+variance)`：归一化观测值的加权通道平均方差，作为异质性线索。

不同专家可能重复连接同一观测与锚点。计算 n_eff 时先合并这种重复来源再平方，避免同一个观测被算成多份独立证据。一个观测无论经几条专家边到达锚点，正常数值范围下 n_eff 都应为 1。

统计停止梯度，减少通过操纵支撑通道取巧的路径；它们不是真实独立样本量或校准置信概率。空节点统计为零，后续网络仍可推断其表示，但日志会保留空节点比例。

## 4. 后端尺度补全 MoE

细尺度时空专家输出 fine 预测。中/粗专家分别接收各自的粗特征和三个统计，经独立时空处理后，使用**固定双线性空间插值**回到细网格，不跨时间插值，也不使用前端 A 或 α。之后各自与细尺度上下文结合，产生 mid/coarse 两个细网格预测。

中/粗预测是“粗尺度条件化的补全专家”，不是不看细信息的纯粗尺度独立预测。细、中、粗三个预测直到最后才混合。

后端路由输入三个专家的隐藏表示、细 mask、上采样后的中/粗支撑统计。输出 β `[B,3,T,H,W]`，在尺度维度 softmax：

`x_hat = β_f x_hat_f + β_m x_hat_m + β_c x_hat_c`。

路由随时空位置变化，默认各通道共享尺度权重。权重非负、和为 1，模型可以降低无用粗尺度的占比，但这不构成相对 V14 或细专家的“不退化保证”。

`completion_use_support=false` 只切断支撑统计到后端路由的直接输入；中/粗专家仍接收自身统计。因此这个开关应表述为“无直接支撑信息传递到补全路由”，不是删除所有可靠性处理。

## 5. 单阶段训练与消融接口

默认只优化缺失位置、观测标准差归一化的 Smooth L1 损失。训练目标 GT 不参与编码、聚合、路由、归一化或推理。MAE/RMSE 在原始数值范围计算。

不继承 `lambda_cross`、V14 regret、旧负载平衡等损失。`loss.dual_moe_expert_weight` 可显式启用三个专家的辅助重建监督，默认 0；先不强迫每个专家都适合每个位置。没有教师、冻结阶段、路由预训练或硬 top-k。两个路由从均匀分布起步，通过同一个最终目标共同训练。

`model.dual_moe.aggregation_mode` 和 `completion_mode` 各支持：

- `learned`：逐位置的可学习门控；
- `static`：可学习但跨位置共享的三个比例；
- `uniform`：固定等权。

所有模式保留相同专家分支及共同初始化，未使用的路由参数被冻结，不以闲置参数伪装相同可训练容量。基本四组实验：uniform/uniform、learned/uniform、uniform/learned、learned/learned。这里后端 uniform 是“等权预测融合”，不是旧探针的可学习卷积融合；不能直接复用旧结果当作四组中的基线。

## 2026-09-14补充：多尺度条件的8路由＋1共享后端

### 结构与可配置入口

新增opt-in `completion_layout="routed_shared"`，并非把前端专家数改成8，也不是总共8个里包含共享专家。
该后端默认8个独立路由专家、1个独立共享专家，每个位置选择3个路由专家；共享专家在每个位置始终参与，不占Top-K名额。

输入`h=concat(h_fine,h_mid,h_coarse,mask,support_mid,support_coarse)`，维度`3*dim+7`。
三条隐藏表示已经包含时空上下文，9个专家各自采用独立`1x1 Conv -> GELU -> 1x1 Conv`，不是重复同一个预测头或仅用8个权重混合同三个预测。
共享头输出归一化基础预测`s(h)`，8个路由头分别输出修正`r_i(h)`。
路由使用PointRouter，完整8维Softmax用于重要性统计，选出Top3后在选中专家内归一化，未选权重严格为0：

`z_hat = s(h) + sum_{i in Top3} w_i(h) * r_i(h)`

`y_hat = z_hat * observed_std + observed_mean`

所有归一化统计仍只使用观测值。共享头不再额外重复添加center，修正也不是独立完整预测。
前端的成员映射、粗节点32/8、E8/Top4目标读出、fine主干与中粗处理均保持原设计。三尺度预测头保留用于原辅助损失，不再被后端直接三选一融合。
新模块初始化不改变已有前端/尺度模块同seed初始化；旧`scale`布局的模型键与初始化行为保留。

### 与L的区别

L的等权回退会让未选路由专家获得非零权重，因此新布局禁止`completion_blend=fixed/learned`。
共享专家承担始终参与的公共预测，不等同于L的等权基底；这是结构改动，不是L仅增加一个参数。
后端路由不把8个专家固定映射到细/中/粗标签，每个都能使用全部尺度。没有额外阶段训练、教师或真值可靠性输入。
当前实现计算所有专家后再稀疏加权，并非稀疏dispatch，因此不能宣称8选3自动降低计算开销。

### 损失、日志与解释边界

主任务仍为缺失位置归一化SmoothL1；三个原尺度头的平均辅助损失权重0.01；分区权重0.001；前后端负载均衡默认各0.001。
后端均衡只使用8个路由专家的概率和选择计数，在缺失目标位置累计；共享专家不计入分母，不需要被均衡。
共享头和被选修正头从主任务获得梯度；未选修正头在该token上的主任务贡献为0，路由概率可通过均衡项获得梯度。
没有新增对每个修正头拟合完整真值的损失，否则会混淆残差与完整预测。

日志中：

- `completion_missing_e0...e7_mean/std`表示8个路由专家的实际混合权重，不再误标fine/mid/coarse。
- `topk_completion_*`为8专家负载，`selected_per_token=3`，共享不占名额。
- `completion_shared_always_active=1`，`mae/rmse_completion_shared`记录基础预测。
- `mae/rmse_completion_e{i}_with_shared`记录`s+r_i`的完整预测误差，不直接拿原始残差与真值相减。
- `backend_diagnostics=true`时，分观测密度误差、胜率及误差相关改为8个`s+r_i`候选；不报告不存在的L参数alpha，不把其oracle当作可部署结果。
- 三个旧尺度头的`mae_expert_fine/mid/coarse`仍是辅助头诊断，与8个后端专家不同。

所有记录进入各run的train/val/test.log及metrics.jsonl。新增共享/路由模块总梯度范数；不据此保证专家互补性或性能提升。
