### 历史和受控差分

差分仍取当前 H 减前轮输入 Hprev，经逐样本逐通道 THW RMS 匹配；缩放 detach、分母下限1e-6，以共享门0.1*tanh修正池化前的专家输入，首轮旁路，Router读原H。

历史池保存 `P_i=M*Xobs+(1-M)*prediction_i` 且 detach，不跨 batch、只读取过去，不用真值选择历史、不把预测计入观测。评分器输入 P_i/s、最近P/s、绝对差、年龄、真实mask覆盖，8→16→1；s为观测RMS下限1。自适应读取 R=Σ softmax(score_i)*P_i。注入器 [R/s,mask] 为4→32→64，以0.1*RMS(H)*tanh和缺失比例修正专家输入。两模块末层零初始化，分支参数与 Y12 逐值一致；原 hidden 链正常反传。

Z04/Z05 保留原评分器参数键，但冻结且不调用评分器，分别使用等权与最近权重，避免初始化、注入器结构变化。它们总参数与Y12相同、可训练参数减少161，不宣称相同有效容量。Z05 仍保存历史以沿用原状态结构，但前两项历史不参与读取。

Z06 的新探索只将注入器数值输入换为 `(R−P_last)/s`，评分器、mask输入、注入幅度、位置均保持不变。动机是将早期历史中相对最近预测的变化作为候选修正，避免重复注入共有数值水平。仅一条历史时该数值输入为零，但mask输入仍存在，因此不声称整个分支第二轮必定零输出。这种中心化不等于学得可靠性，也不保证逐轮修复或优于绝对表示。

### 交互和容量

两个已执行专家按编号排序，分别进行无仿射通道LayerNorm，原Top-2加权和U不变。交互 MLP 一律128→32→64、6240参数、跨轮共享，末层零初始化，输出0.1*RMS(U)*tanh加到U，不额外执行专家、不调整融合权重。Z01/Z07 与 Y12/Z08 是相同容量不同输入表示的主要对照。

Z02/Z03 删除一个输入半部的信息，使用零张量补足128维并保留完全相同初始化、宽度、参数形状。首层被置零输入对应2048个权重没有来自数据的梯度（仍在参数统计和优化器中），所以它们是信息删除消融，**不是相同有效容量的独立新模型**；不能把有效容量减少的退步完全归因于某种数学算子。乘积唯一性必须优先看 Z01/Y12、Z07/Z08。Z08 与 Y12 同结构，仅训练/验证/测试缺失率变化。
