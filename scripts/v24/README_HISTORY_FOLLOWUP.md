### 差分与历史池

差分保持K04：当前H与上一轮输入Hprev之差，经样本/通道THW RMS幅度匹配，缩放detach；共享条件门0.1*tanh、末层零初始化。池化前修正专家输入；Router读原H。

历史池保持X05/X06：池初始为空，保存每轮P_i=M*Xobs+(1-M)*prediction_i且detach；只读此前轮次，不跨batch，不把预测当观测。共享评分器输入P_i/s、最近P/s、绝对差、年龄、原mask覆盖，8→16→1 Conv/GELU/Conv后逐位置跨历史softmax；s=max(观测RMS,1)。共享注入器[历史读取/s,mask]的4→32→64 Conv/GELU/Conv，零初始化末层；以0.1*RMS(H)*tanh(inject)*(1-mean_channel(mask))注入专家输入。历史分支2433参数，原hidden链正常反传。历史预测detach不阻止Y01–Y04的直接中间监督梯度。

### 中间轮监督：Y01–Y04

使用现有损失实现，明确启用lambda_coe_mid=0.1：

`L = L1(P4,GT) + (0.1/3) * sum_{r=1..3} L1(Pr,GT) + 0.01*L_balance`。

各L1仅在原始有效缺失标签处计算。使用同一共享decoder，无新增预测头和参数，四轮仍相同专家预算。没有单调惩罚或真值控制器；GT只进入loss/事后诊断。固定系数，不按测试或阶段结果调参。它是深监督诊断对照，不将常规深监督包装成新贡献；可能改变最终ID/OOD取舍，不保证逐轮误差下降。验证loss包含辅助项，best只按最终MAE选择；有/无中间监督的总loss不可直接比较大小。

### 全专家可见三平面：Y09–Y11

在每轮native scale、state_projection与state_norm之后得到z[B,64,T,h,w]，额外共享TriPlaneBranch(64)：64→16降维，以真实mask覆盖q（两通道均值，粗尺度为平均覆盖）沿W/H/T投影为TH/TW/HW；每平面独立depthwise3×3 Conv2D/GELU/pointwise16→16。按平面覆盖图3×3邻域平均决定有效支持。Y09对有效视角等权；Y10/Y11按覆盖归一化。无支持投影/输出置零；广播回原native网格、16→64映射，末层零初始化，乘0.1后加到z。

三平面每轮全batch计算一次，8个专家均具备读取它的路径，**只执行Top2选中的专家**；未选专家不运行，Router不额外读平面信息，ST原3D网格分支不改。分支跨轮共享，Y09/Y10参数及初始化严格一致；Y11只额外加入原自适应历史池。新增全专家三平面3424参数；X07/X08是ST内部128通道的5536参数分支且只在选中ST时执行，因此Y09/X07与Y10/X08混合了位置、维度、容量和执行频次变化，只能作为探索对照，不能宣称严格隔离“可见范围”。记录全局平面权重、覆盖、幅度、四轮执行次数和真实成本。

### 历史池与双专家交互组合：Y12

使用原X05的历史池与原X10交互模块。只执行已选Top2的A/B，按专家编号排序，通道LayerNorm后读取[Abar*Bbar,Abar-Bbar]，128→32→64共享MLP，末层零初始化；delta=0.1*RMS(原加权和)*tanh(MLP)，加在native尺度原加权和上。新增交互6240参数，不改融合权重。K04/X05/X10/Y12形成组合四格，可检验收益是否只是叠加；没有交互+历史的拼接等容量对照，不能仅凭组合收益归因于乘积。
