## 3. 必须明确的差分时序

设 H0 为 F/M/C 编码融合后的初始隐藏状态；Hr 为第 r 轮的输出。所有隐藏状态的外部接口均为 `[B,64,12,32,32]`，C/M 输出恢复至 F 网格。

原 CMFF 流程：

```text
H0（融合表示） ── C ──> H1 ── M ──> H2 ── F ──> H3 ── F ──> H4
第二轮差分：H1−H0    第三轮差分：H2−H1    第四轮差分：H3−H2
```

因此，原第四轮尽管在 F 上计算，所用差分仍来自 F 输出与 M 输出，**不是 F→F 差分**。H4−H3 才是原 CMFF 的两个 F 输出之差，但四轮已经结束，当前模型不使用它。

CFFF 流程：

```text
H0（融合表示） ── C ──> H1 ── F ──> H2 ── F ──> H3 ── F ──> H4
S09 只在第四轮使用 H3−H2：两个状态均来自 F 轮。
```

各差分组均沿用原条件门、RMS 匹配、±0.1 上界、零初始化及插入位置；只改变启用轮次。关闭位置直接传递当前隐藏状态，不额外加残差。历史更新规则不变。

S07 与 S09 都仅启用一次差分，都在第四轮向 F 专家输入施加修正，可减少启用次数与作用位置造成的干扰。不过 CFFF 改变第二轮计算和原始观测再注入，故这仍不是完全相同状态上的纯语义干预。应比较 S07−B1 与 S09−S08，不能直接把 S09−S07 全部归因于差分来源尺度。

## 4. 结构探索的具体规则

### S01：自由硬选尺度，专家保持 Top-2

- H0 仍融合全部 F/M/C 真实观测。自由选择决定当轮计算网格和重新读取哪一尺度观测，不决定该尺度信息是否首次可见。
- 四轮独立尺度路由头，每轮每个样本只选 C/M/F 中一个；允许回到 C 或重复同一尺度，不强制最后一轮 F。任何路径的输出均恢复到 F 网格，再由同一 decoder 输出 F 预测。
- 专家路由继续动态原生 Top-2。每个样本每轮只实际执行两个选中专家，不运行未选尺度，也不进行三尺度输出软融合。
- 路由只读取模型可见隐藏状态、观测/掩码摘要及路径上下文，不读取完整标签或隐藏位置误差。第一版沿用已有路由特征合同，不同时加入新的可靠性模块。
- 从第一轮训练开始使用硬选择，不加入软尺度预热。采用已有选中分支的 straight-through 近似梯度思路，并明确其为有偏近似；需要验收尺度头得到任务梯度。不得将只执行选中分支的估计器描述为完整三尺度软路由梯度。
- 完整披露每轮选择分布、路径分布、熵、是否塌缩到单一路径，以及 ID/OOD 路径变化。若主要选择单一路径，本批不能证明自由路由优于该固定路径，需要后续另设固定路径从头训练对照。

### S02/S03：动态 Top-k 专家

- 每轮从同一个八专家池中按 router logits 取 Top-k，选中集合内 softmax 加权。Top-8 执行全部八专家，但仍按分数加权，不能误称为平均融合。
- S03 第一轮 Top-1 的前向权重为 1。选中集合 softmax 在 k=1 时不能提供任务路由梯度，需显式使用选中概率的 straight-through 系数，前向系数保持 1；报告此训练估计器差异，不能声称仅改变 k。
- 公共 router/encoder/decoder/专家初始化与 B1 逐值匹配；新增分支隔离随机流。冻结/启用参数分别统计。
- 保留 candidate 均衡损失系数 0.01，以及原生两两候选分数映射到专家 importance 的规则；只改变实际执行的 Top-k。记录 Top-8 下均衡项仍约束分数分布，但不改变执行覆盖。

|方法|专家调用数|面积代理|
|---|---:|---:|
|B1、CMFF Top-2 差分组|8|4.625|

- 沿用当前四类混合 mask，各尺度缺失率 0.4，训练逐 epoch 重采样；不是改回纯 random_point。

## 6. 配对分析与解释边界

1. S01/B1：自由尺度是否获得 ID/OOD 收益，是否依赖单一路径；成本与训练估计器均需披露。
2. S02/B1、S03/B1、S03/S02：更多专家与后期细尺度融合的收益；不能只以精度判优或声称等成本。
3. S04/原B2：本批从头复验是否仍出现 ID 改善、OOD 恶化。如果不重复，应先处理稳定性，不能预设原机制解释正确。
4. S05/S06/S07 对 B1：哪个单一差分位置出现负迁移；位置、状态来源与剩余计算深度仍有关联，不能只据一组锁定原因。
5. S04 对单位置组：全链差分的损害是否大于单位置。若单位置均正常而全链变差，优先考虑累积/联合适应问题；否则优先定位单位置。
6. S09/S08：同计算尺度差分是否有独立收益。与 S07/B1 的配对效应比较，支持或削弱跨尺度差分假设。
7. 若 S09 仍明显 OOD 退步，跨尺度状态变化不能单独解释问题，后续再研究 RMS 放大、门控可靠性或观测一致性；本批不同时改这些因素。

所有机制组记录 gate 的有符号/绝对值摘要、输入修正幅度、原始差分 RMS 与匹配比例、真实启用位置、M/C 可见观测聚合残差。分布尾部统计比仅看门均值更有帮助；这些指标仍是诊断，不能替代消融证据。

本批均为 seed7 筛选，不能据此宣布稳定泛化或机制已证明。旧 B1/本批运行环境未严格独占匹配，成本仅作为实测记录；后续最终方法仍需多训练种子、跨数据集复验。
