## 多尺度数据协议

依据项目根目录两篇组内论文的多尺度观测定义：先在各自时间 split 内，由完整 F 构造每通道每时间的空间求和 M/C，再在每个尺度独立模拟采集。

- 沿用 TaxiBJ `v24_clean_abc_20260917` 的训练/验证/测试窗口，不重新切分或假设 stride-1 连续时间轴。
- F/M/C 分别为 `[B,2,12,32,32]`、`[B,2,12,16,16]`、`[B,2,12,8,8]`。时间尺度不变。
- `prepare_data.py` 离线输出 x_f_gt/x_m_gt/x_c_gt；M 是 F 的 2×2 求和，C 是 F 的 4×4 求和。每尺度观测为完整真值乘自己的观测掩码；绝不从 masked F 的局部均值伪造粗尺度观测。
- 输入模型只有 x_f_obs/m_f、x_m_obs/m_m、x_c_obs/m_c；完整 F 仅进入监督。M/C 真值不随 batch 暴露给训练模型。
- 训练恢复 v24 的四类均衡混合缺失：`random_point/node_outage/temporal_gap/spatial_region`，缺失率 0.4、seed7；每个样本分配一种缺失族，每 epoch 重采样。验证使用同样四类固定混合 mask；不是只在随机点上选 best。对 T/H/W 抽样、两个流量通道共享掩码。四组 F 掩码完全一致；B 组三个尺度分别缺失约 40%（四舍五入精确计数），A 组粗尺度全部不可见。
- 基础 mask seed20260917，验证+20000、测试+30000。F 使用既有 DiverseMaskSchedule；M/C 使用 SeedSequence([seed,epoch,index,100003×sid])，同一窗口的缺失族/比率与 F 一致，尺度之间随机位置独立。
- 6 套测试：四类混合 ID、未见两元组合、未见几何、三元组合、两元 mask 复测、几何 mask 复测。族和种子直接复用 `configs/v24/core_validation/test_protocol.json`；已见的三种单结构属于 ID，不再称为 OOD。ID 内仍分别披露四种缺失族结果。OOD 同时作用于各尺度，不能称为只扰动 F。
- 数据文件保留流量统计量总和；模型在编码 M/C 前除以已知区域面积 4/16，以 F 的每网格数值单位融合。这是可逆的已知尺度转换；不拟合归一化统计量、不使用测试数据统计量。后续跨尺度约束需在对应物理单位计算。

## 模型与训练

新架构名 `v25_observed_multiscale_coe` 和专用 dataset 显式接入训练、评估入口；不改写 v24 单尺度语义。

共享编码器编码三尺度观测/掩码/支持度/位置。粗尺度编码只在观测处保留，再确定性上采样至 F，与 F 编码拼接，经 1×1 卷积形成共同初始状态。每轮从当前尺度真实观测和当前隐藏状态构造专家输入；缺失处的后备预测不会标记为观测。

四轮固定 C→M→F→F，共享八专家 T/S/TD/SD/TA/ST/TL/SL，每轮动态原生 Top-2，按选中权重融合，每窗口 8 次专家执行。隐藏状态在轮间统一回 F 网格。差分为当前/前次轮输入隐藏状态之差，经 RMS 幅度匹配（比例 detach，分母下限1e-6），共享条件门 0.1*tanh，末层零初始化。仅修正专家输入；Router 读取未修正隐藏状态。首轮无差分。

不加入历史池、乘积差值交互、FFN、第二视图、一致性、自由尺度选择、粗尺度损失或跨尺度约束损失。损失为 F 缺失位置 L1 + 0.01 candidate 均衡。

100 epoch、batch32、每5 epoch验证、AdamW、lr1e-3余弦到3e-4、weight_decay1e-4、clip1、AMP、严格确定性、GPU0单卡串行。best 仅按 ID 验证 MAE；last 每 epoch 保存模型/优化器/调度器/scaler/随机数/训练上下文。原始流量单位计分，主要输出 F。

## 解释边界

B/A 的信息预算不同：同为缺失0.4，B总观测标量数约多31.25%，不能把收益全部解释为架构创新。首批不证明 CMFF 优于 FFFF；后续调度比较必须保证两者都能看到相同多尺度观测。单训练种子和测试mask复测不证明稳定性；误差不保证逐轮下降。恢复正确任务定义不等于提出新贡献。

批次结束自动导出 `experments_report/{date}_v25_真实多尺度输入混合mask四组验证_{suite}_完整分析报告.md`，方法与复现信息在前，随后完整结果/曲线/诊断，最后配对分析和负结果。未齐只写阶段报告。
