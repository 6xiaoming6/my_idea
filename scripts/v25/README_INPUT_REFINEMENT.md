## 真实数据流与输入边界

原I37：F/M/C编码后形成H0和初始预测P0；c.completion一直是回填可见F的P0。它同时进入路由值统计和各尺度原生输入的缺失槽。每轮虽有新的last_prediction，但原completion没有刷新。

新实现仅覆盖两处：

1. 路由显式值统计，可保持原值或改为按可见计数归一的F观测均值；缺失预测值统计置零。H_i和mask/support统计仍进入路由，不能说路由完全不接触模型估计。
2. 原生尺度专家输入，可保持原P0补位、缺失槽清零，或用detach当前预测的有界值补位。mask始终描述真实可见性，预测不成为观测。

I57/I60只将逐轮专家输入中的support/position槽置零，H0和路由的原有元数据保留，native mask保留。原始三尺度观测、掩码不可变。

I58/I60：F观测不变。M预算扣内部可见F；C预算扣可见M总量及未被这些M覆盖的可见F。除以剩余F个数，形成静态预算密度；没有剩余格点的槽无消息、有效mask为0，并重算对应support。此密度不减当前预测，不随模型迭代更新。H0和最终投影仍使用原三尺度观测。sum/mean先转换为相同总量口径；隐藏粗尺度真值和隐藏槽不得读入。

I59：fallback=0.1×sigma×tanh(stopgrad(pool(P_current))/sigma)，sigma只由可见F/M/C的密度RMS计算，每样本每物理通道，最小1并detach。只写缺失槽，观测原值保留；每轮上界都是0.1×sigma。tanh限幅及detach都是已有技术，这里只作为预测输入路径的受控对照，不认领为新发明。

## 理论动机与相近工作边界

- 原I37有确定的显式依赖：初始缺失估计会改变每轮专家输入和路由统计。清零这些槽，可直接检验/消除这两条显式依赖；不能推导隐藏状态和历史误差也被消除。
- 静态预算是线性的观测扣除；独立嵌套观测中更细的已知部分不再次作为粗尺度新增值。区域扣除来自原I05投影，不重新声称发明。与I44动态残差不同，本轮不让当前预测误差决定观测输入。
- 仅可见值条件化及估计融合已有充分相关工作，例如[Partial Convolutions, ECCV2018](https://openaccess.thecvf.com/content_ECCV_2018/papers/Guilin_Liu_Image_Inpainting_for_ECCV_2018_paper.pdf)与[SAITS](https://arxiv.org/abs/2202.08516)。本轮没有复制它们的网络层或把常规mask处理包装为独立创新。
- 限制反馈幅度可以限制这条输入支路的数值大小，不能保证整体专家网络的误差收敛或泛化改善。目标是可审计的小改动及公平对照。
