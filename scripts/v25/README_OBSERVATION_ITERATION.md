## 观测定义与通信

F可见格点为单点约束。M扣除其内部可见F；C扣除可见M总量及这些M之外可见F。剩余约束区域互不重叠；空区域不产生消息。所有sum/mean观测先转为密度，再以面积转回总量计算剩余预算。每个区域消息为剩余预算减当前预测区域和，再除剩余格点数。隐藏观测槽先清零，不读取完整M/C标签。

每尺度统计为：可用区域归一化残差绝对均值、RMS、剩余格点覆盖率、有效区域的平均自由度比例(n-1)/n。归一化尺度只由可见F/M/C密度RMS计算，最小1，detach。12→16→3与4→16→8的路由偏置跨轮共享、GELU、末层零初始化。

预测差分保留梯度；区域残差改善比和RMS尺度detach。预测总量分量按clamp((|旧残差|-|新残差|)/max(|旧残差|,1e-6),0,1)衰减；细节分量保留。2C→32→64逐点映射、末层零初始化，tanh后乘0.1倍隐藏RMS。原隐藏差分门保留但冻结，不能双重注入。

历史池依旧在每轮写入回填可见F后的预测并detach。原评分器读取后减当前预测，去区域均值，再逐样本逐通道沿T/H/W去最近细节变化的平行分量。历史注入器计算“消息+mask”的输出减“零消息+mask”的输出；零消息严格零注入。第二轮只有当前一条历史，创新必为零。评分器仍可训练，池、当前及最近预测不回传历史梯度。

I48/I51两专家一次选定，按路由分数稳定排序（并列时专家编号），先后各执行一次。第一候选临时解码，刷新观测差异，再构造第二专家输入；不重复通信。两个候选仍以原Top-2权重融合。每窗口8次专家，但多一次/轮临时解码和残差计算，不声称等FLOPs。

I49/I51粗尺度更新为 old + broadcast(native - region_mean(old))，仅写入归属区域；F全格点更新。物理通道掩码可能不同，而64维隐藏状态共享：因此隐藏更新采用各物理通道归属区域的交集，保守避免覆盖其他通道已知细节。交集为空保持原状态，专家照常计数。R/U恒等式在有效交集区域成立，报告不得把它写成全网络误差下降定理。

## 理论依据、相近工作和原创边界

- [MoDL](https://arxiv.org/abs/1712.02862)已有共享参数迭代重建；不把共享或多轮本身认作新贡献。
- [Learned Iterative Reconstruction](https://arxiv.org/abs/1704.04058)支持残差驱动学习迭代。这里的消息是区域二次观测误差的负梯度，但专家网络不自动继承下降性质。
- [Deep Null Space Learning](https://arxiv.org/abs/1806.06137)已有零空间学习。新候选针对每样本独立缺失的嵌套F/M/C动态去重，并区分短期与长期通信；非线性映射后不保证仍在观测零空间。
- [Chain-of-Experts](https://arxiv.org/abs/2506.18945)已有专家串联；这里固定已选Top-2，以当前剩余观测作为专家间信息，不能仅以串联宣称新颖。
- [STAMImputer](https://arxiv.org/html/2506.08054v1)涉及时空专家协作；本轮检验的是独立缺失的多尺度观测约束组织。
- [MgNet](https://arxiv.org/abs/1901.10415)、[Multi-Scale Learned Iterative Reconstruction](https://arxiv.org/abs/1908.00936)提供多尺度更新依据；本轮区域由真实观测mask决定，仍需机制消融验证。

区域扣除和最终学习分配投影复用原I05，不重新认领。所有方案是待验证候选，不声称全球首次、收敛或逐轮误差必降。

## 选择、测试与执行边界

所有组从对应seed公共未训练初始化独立训练；保留参数逐元素核对。seed7还核对冻结I37初始状态；seed17建立新公共初始状态。新增模块独立随机数流，不改变旧参数初始化。

I53的10个候选配置和初始化预先全部冻结。训练 I42→I51→I52 后，在验证划分对前十组和I37 best跑六套开发协议，mask基种子2026101701–2026101706按既有协议顺序分配，数据集仍自动应用原split偏移。开发ID MAE≤I37同协议103%才合格，排序为三类别等权OOD相对MAE、相对RMSE、ID MAE、参数量、编号。二元/形态各先平均两次mask；无合格者按ID超限比例最小复验并标不合格。

冻结选择记录后训练I53，才对本批全部组开放原六套test；I37和入选方法seed7/17另测上述新mask的test确认协议。训练器本批 `defer_test=True`，不在每组训练末尾自动测试。best仍按原ID验证MAE选择。推荐门槛：原test ID相对I37≤1.03、OOD三类MAE平均比≤0.97、最差类别≤1.05；seed17单独比较I52/I53。不以测试结果改组合，不把mask复测算新训练种子。
