## 推荐标准与边界

保留原ID≤8.8709门槛，并展示相对I25的ID代价及其10%界限。二元组合和未见形态各先平均两次mask测试，再与三元组合等权比较；展示原始MAE/RMSE、最差类别变化与ID/OOD折中，不强行推荐新模型。

该批为单seed开发探索。OOD已用于多轮设计，不能视作完全未触及的最终验证集；后续需要新种子、未参与选择的缺失条件及跨数据集确认。当前假设是原始预测能力、通信和尺度交互可能影响泛化，不能提前认定历史、差分或投影有害。
