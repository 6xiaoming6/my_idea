## 公平性与实现

- 所有输入为真实稀疏F/M/C，BikeNYC F=[B,2,12,24,12]，M=[B,2,12,12,6]，C=[B,2,12,6,3]。复用已清理跨split重复帧的数据（511/72/146窗口）；原底部3行零填充仍参与mask和评分，四组及S组一致。
- M/C先从完整F求和构造，再各尺度独立抽mask，编码时除已知面积4/16。H0融合三尺度，每轮重新读取对应尺度原始可见数据，K0后备不更新。隐藏F仅用于损失，不作为输入。
- 两个缺失率各自的train/val/test和所有OOD都使用本率，四基础族random_point/node_outage/temporal_gap/spatial_region混合；不是纯点缺失。训练逐epoch重采样，ID/OOD种子沿用，6套评估按ID best检查点，mask复测不等于训练seed复验。
- 全部seed7、200epoch、batch32、val5、AdamW lr1e-3余弦200轮至3e-4、weight_decay1e-4、clip1、AMP、严格确定性。F缺失位置L1+0.01原candidate均衡。总参数相同，启用自由尺度头/门导致可训参数不同。全部初始state_dict逐值核验为旧BikeNYC B1初始化。
- 专家共享T/S/TD/SD/TA/ST/TL/SL。原生Top-k只执行选中专家，选中集合内softmax。S01只运行一个硬选尺度，无软尺度预热，选择分支使用ST近似梯度；S03 Top1任务路由也有选中概率ST系数，前向为1。均不是等成本对照；S02调用16次，S03调用15次，其余8次。
- 差分按样本通道在T/H/W进行RMS匹配（比例detach），0.1*tanh条件门末层零初始化，首轮无历史，只修正专家输入，router读取原状态。无历史池、FFN、乘积交互、第二视图、一致性或中间轮监督。
- S09第四轮使用F输出减F输出；CMFF的S07第四轮用F输出减M输出。S09/S08与S07/B1配对对比仍受CFFF第二轮计算/观测注入变化影响，不能视作纯语义因果实验。

冻结源码、数据、配置和参考证据；best/last完整保存；完成跳过，中断从last全状态续跑，失败停止。每组评估后按export-experiments-report规范生成阶段报告，全19组及参考审计通过后导出正式报告，tmux自动退出。每个缺失率独立比较ID/OOD、分族、路由/门、成本与失败，不将不同率混作同条件对照。正式候选仍需要多训练种子与TaxiBJ验证。
